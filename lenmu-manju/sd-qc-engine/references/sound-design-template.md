# 聲音設計模板（音效/人聲/環境音/BGM 層級）

> 精編自《靈境AI漫劇製作流 V3.9.0》manju-sound-design-director

## 〇、定位與邊界

- **目的**：根據鎖定台詞、角色音色與剪輯分段，設計對白、畫外音、環境聲、擬音、音樂與靜默；逐段複核台詞、換氣、停頓和反應時長，保證跨段長台詞不漏字、不重字。
- **邊界**：不改台詞，不虛構已生成音頻，不重新設計角色聲線（只寫場次聲學與情緒調製），不在未授權時復刻真實人物聲音。

## 一、聲音層級與混音電平（與總控同一口徑）

$$\text{第一層：對白清晰度 (0 dB)} > \text{第二層：動作物理音效 SFX (-6 dB)} > \text{第三層：環境聲景與 BGM (-14 dB ~ -18 dB)}$$

- 對白永遠處於最高清晰度優先級；動作音效（骨裂/破風/撞擊）不得遮蓋人聲。
- BGM 在激烈打鬥或對白爆發時自動避讓（Ducking）。
- 使用聲音橋連接合理鏡頭；使用靜默突出決定、真相或衝擊（`SILENCE` 也是一層設計）。

## 二、人聲分類（嚴禁互換）

| 類型 | 規則 |
|---|---|
| 畫內對白 | 台詞逐字不改；寫時間、角色、語氣、重音、停頓、口型可見度和聽者反應 |
| 畫外音（OS 內心獨白 / VO 旁白） | **聲畫分離紅線**：OS 發聲時畫面角色必須閉口，禁用 `{}` 鎖口型通道；VO 冷漠審視、不復述畫面；一律走"聲音："段，台詞字段只裝畫內開口對白（機檢 C14 兜底）；配額：VO+OS 佔聲音容量 ≤30%、60~80 字/分鐘，防廣播劇化 |
| 電話音 / 系統音 | 非畫內人物，不綁定口型 |
| 旁白 | 不復述畫面已呈現信息 |

## 三、與總控 Seedance 原生音效標記體系的銜接（★必讀，防衝突）

本模板是**設計與複核層**；投餵提示詞中的聲音寫法唯一權威是總控：

| 總控體系 | 銜接說明 |
|---|---|
| **[SFX:] 標記**（Seedance 2.5 原生音效標記） | Seedance **2.5 建議**使用 `[SFX:]`（機檢 C5）；Seedance **2.0 禁用** `[SFX:]` 與頓挫詞。本模板的 `PROP_SFX/AMBIENCE/FOLEY` 設計條目落到投餵稿時，2.5 走 `[SFX:]`，2.0 融入鏡行畫面/聲音描述，禁混寫版本語法 |
| **【音效】欄**（七段式核心欄之一） | 分層結果回填進總控七段式【音效】欄；欄名與段數以總控 `short-drama-director/references/model-adapters.md` 為準，本模板不另立格式 |
| **語氣位**（`台詞：【角色（語氣）："…"】`） | 對白必須帶語氣位（2.0/2.5 同規格必寫，機檢 C16）：聲音詞只進語氣位禁進畫面段；語氣按四維寫（情緒色/力度/音質/節奏），禁空泛結果詞（開心/難過/憤怒）；道具動作與語氣一致（強情緒禁把玩類動作） |
| **音色鎖** | 僅 2.5 且可選增強（投 `reference_audio` 並在【核心人物】行尾標註"鎖定音色"）；不做資產體系、不設前置門禁 |
| **聲音詞豁免反形容詞規則** | 語氣位/聲音段/【音效】豁免"形容詞必須可畫"規則（聲音沒有肌肉動作可寫），但同樣禁空泛結果詞 |

## 四、環境聲 / 擬音 / 音效寫法

1. **環境聲（AMBIENCE）**：保持空間連續——同一場內環境底噪不斷層；跨段環境狀態與連續性台賬的場景賬一致。
2. **擬音（FOLEY）**：證明接觸、重量和材質——腳步聲配地面材質，衣物聲配動作幅度。
3. **道具音效（PROP_SFX）**：關鍵聲音精確落在動作幀（聲畫同步點寫明）；與語氣位不衝突（C16d）。
4. **音樂（MUSIC）**：默認作為後期獨立層。若目標視頻模型提示詞要求無背景音樂，明確隔離不寫；需要配樂時輸出音樂功能、進入/退出點與強度，不讓其遮蓋對白。
5. **戰鬥段「只要音效、禁 BGM」選項**：一鏡到底的高動態戰鬥段，BGM 會與連續音效搶頻、削弱打擊感與壓迫感。**戰鬥段可顯式聲明"只生成對應音效、不生成任何背景音樂"**——音效按招式/接觸點逐條列清（出鞘、金屬咬合脆響、低頻轟鳴、音爆、介質崩解碎光、火柱騰起等），**BGM 完全不進該段**（既不寫進模型提示詞、也不做後期鋪底，除非用戶另行要求）。**這是戰鬥段的優先選項、不是全片默認**——文戲/情緒段照走總控 BGM Cue Sheet（`post-music-sound-design.md`）。**與投餵層銜接**：sd-feed-engine 默認不出 BGM，本節是"戰鬥段連後期也不鋪"的強化聲明，需在交付說明裡對用戶講清。

- `layer` 取值：`DIALOGUE / VOICE_OVER / AMBIENCE / FOLEY / PROP_SFX / MUSIC / SILENCE`（裁定：不再強制 V3 公共信封根字段與 actor_profile_id 引用，角色音色以總控資產口徑的 character_id/voice_id 表達；其餘字段語義不變）。
- `segment_timing_validation`：逐段複核對白秒數 + 換氣停頓 + 反應時長 ≤ 段長；不為容納聲音私自改台詞或拉長生成段。
- 跨段台詞：核對同一 `dialogue_id/voice_id`、前段結束字詞、後段起始字詞和呼吸連續，確保不漏字、不重字。
- 口頭禪只有在鎖定對白已有對應文本時才標記 `catchphrase_id`；聲音崗位不得新增或替換台詞。

## 六、質量門

- 全部鎖定台詞和聲音標籤被覆蓋；每個說話角色引用當前音色版本。
- 每段聲音時長不超過模型上限且與剪輯分段一致（C1）；跨段台詞逐字連續。
- 聲線未被場次情緒替換；環境底噪連續；無台詞角色明確閉口。
- 畫外聲配額與聲畫分離合規（C14 / H9 / H10）。
- 缺少精確時碼時形成待對齊 cue，不偽造已同步音頻。
