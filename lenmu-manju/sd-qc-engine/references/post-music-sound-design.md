## 〇、定位與邊界

### 本模塊負責

1. 為已生成視頻/粗剪版/定稿分鏡設計全片 **BGM 情緒曲線**。
2. 輸出 **BGM Cue Sheet**：每段音樂從哪進、哪出、哪裡淡入、哪裡突停、哪裡完全不要音樂。
3. 輸出**音樂搜索關鍵詞**（中文 / 英文 / 素材庫標籤）。
4. 輸出 **AI 音樂生成提示詞**（適配 Suno / Udio / ElevenLabs Music / Stable Audio / 剪輯軟件 AI）。
5. 設計**聲音層次**：對白、環境聲、關鍵音效、轉場音、低頻鋪底、靜默點與音樂的關係。
6. **檢查**音樂是否搶台詞、過度煽情、破壞節奏、有版權風險。
7. 為短視頻平台提供**音樂節奏建議**：前 3 秒 / 反轉點 / 情緒爆點 / 結尾鉤子。

### 本模塊不負責

1. 不替代專業作曲、混音、母帶或版權律師。
2. 不承諾任何音樂素材一定可商用；**只能提醒用戶檢查授權**。
3. **不生成或仿寫**具體歌曲、歌手、影視原聲、平台熱門 BGM 的可替代版本。
4. **不把 BGM 強行加到所有段落**——靜默、環境聲和無音樂也是設計。
5. 不處理視頻畫面提示詞；**不把 BGM 寫回投餵稿**（投餵稿只含環境聲、對白原聲、同步音效）。

## 一、什麼時候調用

**觸發詞**：配 BGM / 後期音樂 / 哪裡該有音樂 / 音樂情緒遞進 / 音樂 Cue Sheet / 我該搜什麼音樂 / Suno 提示詞 / Udio 提示詞 / 剪輯音樂怎麼進怎麼出 / 台詞下面鋪什麼 / 要不要突然靜音 / 成片聲音設計。

**提前做**：用戶還沒生成視頻但已有分鏡/投餵稿時，可提前做"**預配樂方案**"，但**必須標註時間點為暫定**，最終以實際剪輯時長為準。

## 二、輸出模式（4 種）

| 模式 | 適用場景 | 輸出內容 |
|---|---|---|
| **A 快速找音樂版** | 用戶只想知道搜什麼音樂 | 音樂功能、中文搜索詞、英文搜索詞、篩選條件、版權提醒 |
| **B 全片 Cue Sheet 版** | 用戶已有視頻或粗剪，要進剪輯 | 全片時間軸、BGM 進出點、靜默點、音量、音效、情緒遞進 |
| **C AI 音樂生成版** | 用戶準備用 AI 音樂工具生成 | 每段 AI 提示詞、時長、結構、樂器、節奏、禁止項 |
| **D 聲音體檢版** | 用戶已有成片但覺得情緒不對 | 檢查音樂是否搶戲/過滿/過煽情/節奏不對/版權風險 |

**默認推薦**：已有粗剪 → B；只有劇情或分鏡 → A + C；要上架發佈 → B + 版權檢查；音樂已放但不滿意 → D。

## 三、核心原則（9 條）

| # | 原則 |
|---|---|
| 1 | **音樂服務敘事，不服務炫技**：每段 BGM 必須說明功能（鋪底/推進/壓迫/反轉/催淚/喜劇停頓/結尾鉤子/轉場橋）。 |
| 2 | **對白優先**：有重要對白時，音樂低存在感、少旋律、無歌詞或弱旋律，並給壓混建議。 |
| 3 | **靜默是武器**：驚嚇/反轉/難堪/壓迫/強忍情緒時，靜默或只保留環境聲可能比 BGM 更有效。 |
| 4 | **不要從第一秒鋪滿到最後一秒**：必須有起伏、留白和斷點。 |
| 5 | **情緒不要一上來滿格**：悲傷/燃/懸疑/浪漫都要有遞進。 |
| 6 | **音樂配合平台節奏**：前 3 秒可用音色鉤子或節奏鉤子；反轉點用突停/低頻/衝擊音；結尾用懸而未決的尾音。 |
| 7 | **搜索詞必須可執行**：不能只寫"傷感 BGM"，必須給中文+英文+篩選條件。 |
| 8 | **AI 提示詞必須寫結構**：時長、是否無歌詞、樂器、節奏、情緒曲線、進入退出、禁止項。 |
| 9 | **版權優先**：不使用具體歌名/歌手/影視原聲/熱門 BGM/"某某同款"作為生成目標。 |

## 六、AI 音樂生成提示詞結構

**必含 9 項**：時長 / 是否無歌詞 / 音樂功能 / 樂器與音色 / 情緒曲線 / 節奏速度或 BPM / 進入與結束方式 / 禁止項 / 使用場景。

**通用模板**：
```
生成一段 [時長] 的無歌詞背景音樂，用於 [劇情場景/情緒功能]。
整體情緒是 [情緒]，不要一開始就爆發。
主要樂器/音色：[樂器1]、[樂器2]、[氛圍音色]。
節奏：[慢速/中速/逐漸加速]，約 [BPM範圍]。
結構：[0-X秒] 低存在感鋪底；[X-Y秒] 情緒輕微遞進；[Y-Z秒] 達到小高潮；

禁止：不要歌詞、不要人聲、不要明顯流行歌主副歌結構、不要旋律過滿、
```

## 七、剪輯與混音建議

### 對白下方
- 音樂音量低於對白，保持低存在感。
- 優先無歌詞、弱旋律、長音、氛圍 pad、稀疏鋼琴。
- 情緒強台詞落點前，可短暫降低或抽掉音樂。
- 不要讓鼓點踩在每個字上，除非喜劇或快節奏剪輯。

### 情緒爆點
- 爆點前漸弱，讓觀眾注意角色表情或對白。
- 爆點瞬間用突停、低頻衝擊、短促 stinger。
- 爆點後**不要立刻鋪滿大音樂**，給 0.5-2 秒反應空間。

### 靜默點（適用情況）
```
① 角色強忍情緒    ② 反轉前一秒      ③ 難堪、尷尬、無法回應
④ 觀眾需要讀表情  ⑤ 恐懼壓迫        ⑥ 喜劇包袱落點
```

### 轉場橋
- 跨場景硬切可用**音樂尾音、環境聲橋或轉場音**連接。
- 平行剪輯可用**同一 BGM 節奏**統一兩個空間。
- 回憶/夢境/閃回要用**音色變化**區分現實。

## 八、版權與商用檢查（★ 必讀）

輸出任何音樂方案時都要提醒：

1. 商用發佈前**必須確認音樂素材授權範圍**。
2. **保存授權頁面、購買記錄、下載記錄或平台授權說明截圖**。
3. 不要使用未授權影視原聲、熱門歌曲、歌手作品、平台爆款 BGM。
4. 不要要求 AI 音樂工具"模仿某歌手 / 某歌曲 / 某電影原聲"。
5. 用素材庫時，檢查是否覆蓋**短視頻平台、商業廣告、信息流投放、影視節、海外平台**等用途。
6. 用 AI 音樂工具時，檢查**當前賬號套餐是否允許商用**，以及生成作品的歸屬和限制。
7. 客戶項目/品牌項目/付費投放項目，版權風險**默認按高標準處理**。

**固定提示語**：
```
版權提醒：以下搜索詞和 AI 音樂提示詞只用於尋找或生成原創/可授權音樂。發佈前請確認素材庫或
AI 音樂平台的商用授權，不要直接使用未授權歌曲、影視原聲、熱門 BGM 或具體歌手風格。
```

## 九、聲音體檢（用戶說"音樂不對/太吵"時）

| 檢查維度 | 常見問題 | 處理 |
|---|---|---|
| 是否搶台詞 | 音樂蓋過對白，鼓點踩字 | 降低音量、去旋律、去鼓點 |
| 是否過滿 | 從第一秒鋪到最後一秒 | 加留白、加斷點、加靜默 |
| 是否過煽情 | 第一秒就大旋律，情緒沒遞進 | 改為遞進結構，降低起始強度 |
| 節奏是否匹配 | 快節奏畫面配慢音樂 | 按平台節奏調整速度 |
| 是否需要靜默 | 反轉/難堪處有音樂反而稀釋衝擊 | 改為靜默或只留環境聲 |
| 是否有版權風險 | "某某同款"、影視原聲、具體歌手風格 | 替換為原創/可授權素材 |
