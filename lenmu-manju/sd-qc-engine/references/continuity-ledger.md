# 連續性台賬（跨鏡/跨集一致性管理）

> 精編自《靈境AI漫劇製作流 V3.9.0》manju-continuity-supervisor

## 〇、定位與邊界

- **目的**：把鎖定劇本、**資產台賬（按素材形態：M0《外觀檔案冊》/ M1《資產編號冊 + 素材接線單》/ M2《資產圖冊》）**、分鏡與投餵稿合併為單一事實源，逐場記錄人物賬、場景賬、時間軸賬，檢查狀態生效區間，防跨鏡/跨段/跨集穿幫。
- **衝突優先級**：`用戶硬約束 → 劇本事實 → 已鎖定設計決定 → 資產依據（M2 資產參考圖 / M1 編號與外觀要素 / M0 文字檔案） → 保守假設`。衝突必須記錄來源與處置，禁止靜默取捨。
- **寫入隔離**：只寫台賬與衝突報告，不修改任何劇本、資產、分鏡、投餵文件；發現衝突路由回責任階段（裁定：原 V3 公共信封/階段目錄交付機制由總控《劇組產出冊》台賬承擔，台賬本身以本模板 markdown/json 形式交付）。

### 驗收證據與範圍

- **M0/M1 驗收提示詞**：核對角色、道具、九宮格整板固定 16:9，內部佈局獨立聲明，成片跟 B 鎖；核對文字檔案與接線單，不填寫“圖片已核驗”。**M2 核實圖**：登記實際圖像來源、尺寸/比例及逐項核驗結果；無法讀取圖像時標“未核驗”，不得冒充通過。
- **P4.5 與 P3CLEAN_GRID 分列驗收**：P3CLEAN_GRID 指 P3 的 CLEAN_GRID 生產資料，P4.5 是預演故事板溝通附件（`sd-storyboard-engine/references/p45-previs-storyboard.md`）；名稱、用途與原有權威文件均保留，不改名互替。M0/M1 驗收兩者提示詞，M2 才增加實際圖面檢查。
- **生成段、真實剪輯鏡頭、鏡內時間片分賬**：時間戳或面板邊界不等於剪輯點；連續運鏡逐段核對可通行路徑、起終機位、遮擋與軸線，不用全片禁長鏡代替檢查，也不新增輔助運鏡 1/3 閾值。
- **模型能力經驗不是官方斷言**：項目實測、製作傾向須標“經驗/待驗證”及適用條件；無可追溯官方依據不得寫成模型絕對能力或限制。
- **規則加載不等於已讀**：切片 coverage 僅代表本頁輸出；記錄實際讀取範圍、未讀範圍與續頁，不從標題清單或預填回執推導全量已讀。

## 一、人物賬（跨鏡/跨集）

每個人物逐場記錄，一項都不能缺：

| 賬目項 | 檢查要點 | 穿幫病灶（實測） |
|---|---|---|
| 站位 | 段初位置 + 相鄰段無移動時不得漂移（依託物/相對位） | 上一段「秀蘭身後半步」，下一段憑空變「八仙桌旁」 |
| 朝向 | 與軸線一致；轉頭有交代 | 無故反轉朝向、跳軸 |
| 服裝/造型 | 基礎年齡/臉體層與 LOOK 妝容/髮型/服裝層分開；傷損、固定裝飾有生效區間 | 隱形換裝、飾品消失 |
| 道具持拿 | 持有者、左/右手位、道具狀態（完損/位置）；離手必有落點 | 道具換手、憑空消失/出現 |
| 姿態狀態 | 撐起/坐起/起身一旦發生，後續鏡保持或顯式交代回退過程 | 前鏡已坐起，後鏡又躺回（C18b） |
| 表情/動作/口頭禪 | 引用角色鎖定版本；招牌項必須有**來源 + 觸發條件 + 頻率上限 + 禁用場景**四項登記，且**不每鏡機械復讀** | 語言習慣漂移、聲線突變 |
| 聲音身份 | 音色/語氣基線引用同一角色版本，場次只寫情緒調製 | 跨段音色突變 |

**跨段生死線（與總控法則 20「人物賬連續·擺位必入畫」完全同一口徑）**：

1. **擺位必入畫**：站位聲明擺了位的每個人，本段鏡行至少帶到一次（正拍/焦外身影/全景群像/反應鏡頭均算）；實在給不了鏡頭，站位括號寫明 `段末離畫 / 退場·去向`——出稿機檢 **C17** 兜底（單人站位段不觸發）。
2. **入畫要交代**：離場的人重新入畫，站位必須寫 `段初自門口入畫` 等方式。
2b. **新面孔首現要交代**（2026-10-13 新增 · `segment-splicing.md` §四·補二）：**相鄰兩段在場人物集合不同**時，後段**新增的具名人物**必須有①畫內入畫 / ②畫外先聲 / ③空鏡轉場 / ④末鏡行句尾一句過渡之一（`（在場）`靜默人物可走軟口徑「首鏡一句已在場」）——出稿機檢 **C17e** 兜底（WARN 參考級）。
3. **站位不漂移**：相鄰段沒寫移動的人，位置/朝向/依託物不得無交代改變。
4. **（在場）標記口徑**：核心人物行無標記=本段有台詞或明確動作反應，`（在場）`=畫面可見但無台詞無反應；兩級的人都必須進站位聲明，禁自創其他標記。

## 二、場景賬

| 賬目項 | 檢查要點 |
|---|---|
| 場景固定物 | 擺設、出入口位置跨鏡一致 |
| 天氣/時間 | 段與段之間有因果演進或顯式跳變；無憑空晴轉暴雨 |
| 光源 | 實際光源（燈火/天光）方向與存在狀態連續；體積光不誤當場景固有資產 |
| 空氣介質 | 霧/煙/塵/雨的來源、密度、運動、沉降/衰減有狀態區間；清潔空氣不被無故替換 |
| 尺度參照 | 巨構/巨獸場景保持熟悉參照物，參照物不消失 |
| 空間損毀 | 打鬥/災害損毀有持續區間與解除節拍 |

## 三、時間軸賬

- 逐場記錄入口時間 → 各節拍時長 → 出口時間；**Seedance 側整數秒口徑**（禁時間碼、禁小數秒，與總控一致）。
- 每段時長 ≤ 模型上限（2.5=30s / 2.0=15s，機檢 C1）；相鄰鏡頭無斷檔/重疊（C3）。
- 台詞時長按語速倒推（3.5~6 字/秒；判定按最快檔 6 字/秒），禁拉伸湊時（C15）；鏡長按劇情倒推，禁機械等分（C13）。

## 四、逐場台賬模板

每場一份，入口狀態 → 變化清單 → 出口狀態：

```json
{
  "scene_id": "SC-001-001",
  "entry_state": {
    "characters": [],
    "actor_identity_refs": [{
      "character_id": "",
      "voice_id": "",
      "active_expression_codes": [],
      "active_gesture_codes": [],
      "approved_deviations": []
    }],
    "looks": [],
    "props": [],
    "positions_directions": [],
    "set_state": "",
    "time_weather": "",
    "practical_lights": [],
    "atmosphere_state": {},
    "scale_evidence_state": {}
  },
  "changes": [{"beat_id": "", "change": "", "new_state": ""}],
  "exit_state": {},
  "must_carry_forward": [],
  "unresolved_conflicts": []
}
```

字段說明：

- `entry_state/exit_state`：本場入口/出口的人物賬全量快照（站位、朝向、服裝、道具持拿、姿態、光源、天氣、空氣介質、尺度參照）。
- `changes`：每處狀態變化必須掛 `beat_id`（觸發節拍）——沒有觸發節拍的變化是穿幫隱患。
- `must_carry_forward`：必須帶進下一場/下一集的狀態（傷損、持拿中的道具、未解除的天氣）。
- `unresolved_conflicts`：未決衝突，逐條寫來源與建議路由。

**資產引用表**：台賬另附一頁，逐項記錄 `asset_id`、**素材形態（M0/M1/M2）**、版本、生產狀態、參考圖路徑（**M0/M1 留空——本包不持有圖**）、職責、允許覆蓋範圍——**`TEXT_SPEC`（文字設定）在 M0/M1 下是合法資產形態，不是"偽裝"**（對齊總控 `short-drama-director/references/asset-delivery-modes.md`）；只有 **M2** 下才要求"參考圖路徑"非空，且此時 `TEXT_SPEC` 不得冒充已鎖定資產參考圖。

> ⚠️ **本表隨素材形態改判**：**M0/M1 下"參考圖路徑"列必然為空，這不是缺陷**——不得因此索要圖片或判定台賬不完整。**禁止**在下游寫"已與《資產圖冊》核對一致"之類未做過的斷言（機檢：`gate_check.py` 閘門 6B）。

## 五、質量門（台賬放行標準）

- 所有下游可見資產與人物身份引用存在，同一角色的音色/語氣/表情/動作版本一致。
- 沒有隱形換裝、聲線突變、語言習慣漂移、飾品消失、道具換手、空氣介質突變、尺度參照消失、場景跳位、姿態無聲回退、站位無交代漂移。
- 每處狀態變化有觸發節拍，且持續到明確解除。
- 擺位必入畫對賬通過（每人本段至少帶到一次，或寫明離畫去向）。
