## 〇、核心原則：先素材，後畫面

寫提示詞時**先說明素材是誰**，再寫畫面動作。多主體或需跨鏡頭複用時，人物錨定固定寫：

```
將 圖1 中的[身份/外觀/服裝]定義為 <角色名>
```

錨定後，後續鏡頭只用 `<角色名>` 指代。錨定句**只寫定義，不追加說明**。

**關鍵道具錨定（2026-10-13 新補 · 治「道具在投餵層無 @ 位」）**：道具與人物同理，**先錨定再引用**，但**不新增欄位**——寫在【場景資產】欄、與 `@SCN-` 並列：

```
【場景資產】@SCN-xxx（參考圖N）；@PRP-xxx（參考圖M）  ← M1/M2全能參考極簡寫法：只@資產與參考圖號，嚴禁二次介紹場景陳設、人物外貌衣著或道具材質（防止文字覆蓋/干擾參考圖）；隨身核心道具（如主角佩劍/法寶/信物）須在持有角色出場的所有段落全程 @ 跟隨！（兼容舊式「外觀以場景/道具參考圖鎖定；狀態…」）
```

- **只錨關鍵道具**（承擔敘事功能 / 跨鏡一致 / 有狀態變化）；場景固定陳設隨場景母版出圖，**不寫 `@PRP-`**；
- **M0 無圖時**改「道具外觀複述」（材質·造型·尺寸基準·色彩/紋樣 + 狀態軌跡），逐段複述、禁"同上"；
- 判定與完整紀律見總控 `model-adapters.md` §5「道具錨定紀律」；道具出圖歸 `sd-asset-engine/references/prop-template.md`。

> ⚠️ **M0 替代寫法（無圖時）**：`<角色名>` 的指代照用，但**不寫"將 圖N 中的…"**，改為**外觀檔案複述塊**——即每次（每段）首次提及時完整複述該角色的外觀五要素（發/服裝/體態/年齡感/標誌物），**禁止寫"同上 / 同前 / 照舊"**。理由：模型每段零記憶，"同上"等於沒寫（權威與理由見總控 `short-drama-director/references/asset-delivery-modes.md` §三 文字鎖）。

## 一、素材編號體系

| 寫法 | 對應角色 | 說明 |
|---|---|---|
| **圖1 / 圖2 / 圖3 …** | 總控「圖N」體系 | **唯一寫法** |
| 視頻N | 視頻參考 | 動作/運鏡參考或被延長視頻 |
| 音頻N | 音頻參考 | 環境聲/語氣/同步音效 |

⚠️ **禁用寫法**：`@圖片N` / `@ImageN` / `@Video N` / `asset-xxx` / `CH001` / `SC001` / `ST001` —— 這些是外部包或內部管理編號，**不得出現在最終可投餵提示詞裡**。

## 二·五、參考圖投餵順序約定（戰鬥/特效重場首選）

> **來源**：吸收自用戶玄幻一鏡到底參考稿的"參考圖順序"寫法。**順序本身就是優先級聲明**——把最需要"鎖死"的素材排在前面。

**推薦順序（場景優先 · 敵人可省）**：

| 序 | 素材 | 為什麼排這裡 |
|---|---|---|
| ① | **場景** | 空間與光是**剛性錨點**——模型會重繪人物，但不會重繪空間結構；先定空間，後續鏡頭才有立足點 |
| ② | **主角/核心角色** | 全片出鏡最多、最不能漂的資產 |
| ③ | **初始武器 / 關鍵道具** | 與主角同框的穩定物；有形態變化時用初始形態 |
| ④ | **進階形態**（武器第二形態 / 變身後形象） | 與③**相鄰編號**，幫模型建立"同一角色/同一件器物的兩個形態"關聯 |
| ⑤ | **敵人 / 群演 / 龍套** | **可無參考圖，純文字描述**——把有限的圖位留給更需一致的資產 |

**五條鐵律**：

1. **場景永遠排第一**——順序不是"想到哪張寫哪張"，場景優先是硬序；
2. **順序寫進《素材接線單》的排列**——用戶在平台素材區按單子順序掛圖，順序 = 接線單行序；
3. **群像/敵人可省圖**——省下的圖位（按該模型上限：2.0 ≤9 / 2.5 ≤30，紅線 2）留給更需要一致性的資產；
4. **同角色多形態相鄰編號**——避免模型把兩個形態當成兩個無關主體；
5. **同角色多形態分組建**（★ 2026-10-17 新增 · 粉絲「森林」實測反饋）——第 4 條解決"這倆是**同一主體**"，本條解決"**一次生成裡別同時出現**"：同一角色的不同形態 / 年齡 / 服裝版本**不得落在同一個投餵單元（組）**，否則兩版形象會在同一段裡互相揉臉（＝汙染）。**兩條並存、分層生效：編號照樣相鄰，組必須分開**；判定與例外見 `sd-feed-engine/references/feed-mode-and-gates.md` §閘門 5·補 門檻 C。

## 三、素材引用紅線（11 條）

| # | 紅線 |
|---|---|
| 1 | **圖號只能有兩個來源**：① **用戶提供**；② **本次交付的《素材接線單》顯式定義**。**除此之外禁止憑空寫圖號**——尤其禁止"為了提示詞看起來完整"補一個編號進去。圖號是**給用戶的接線說明書**，憑空寫＝讓用戶去掛一張不存在的圖 |
| 2 | 每組/每單元實際使用的**圖片參考總數**按 A 鎖模型取上限：**Seedance 2.0 ≤9 張** / **Seedance 2.5 ≤30 張**（總數 ≤50）/ **Seedance 2.0 ≤9 張**（★2026-10-17 修訂：原寫「單圖 1 張」，與粉絲實測不符——其 2.0 投餵稿掛 3~4 張資產圖正常跑通；官方參考圖槽為單參考圖鎖形象、**無首尾幀**，平台側多錨點上傳可多圖，故機檢取保守上限 9）。⚠️ **9 張是 2.0 的上限，不得套到 Seedance 2.5**（2.5 支持 30 圖）（原寫死 9 張會人為壓制 2.5 的多圖一致性能力，2026-10-12 修訂） |
| 3 | 參考圖狀態不是"定稿"時，**必須標註風險** |
| 4 | 同一角色多段儘量用同一圖號；錨定後優先用穩定 `<角色名>` |
| 5 | `視頻N` **不得同時承擔角色/動作/風格/構圖四種任務**，必須說明只參考哪一項；延長任務直接寫"向後延長 視頻1" |
| 6 | 音頻參考**必須提醒版權/可商用性** |
| 7 | 啟用首幀圖時，寫清**只控制第 0 秒**，不控制整段動作和結尾狀態 |
| 8 | 啟用場景角度圖時，寫清**只控制當前鏡頭空間方向和透視** |
| 9 | 場景母版/角度圖/角色圖/道具圖/首幀圖/調度圖**不能互相替代**；每張圖都說明"只參考什麼/不參考什麼" |
| 10 | 首幀圖與場景角度/調度圖衝突時，**不要輸出最終提示詞**，先提示重做 |
| 11 | 不把 `asset-xxx`、`CH001`、`ST001` 等內部 ID 直接寫進可投餵描述；必須通過圖號、`<角色名>` 或自然語言橋接 |

## 四、首幀 / 調度 / 參考圖優先級

> ⚠️ **M0 不適用**：本節整體以"圖確實存在"為前提。**M0（純提示詞）下不啟用任何一條**——本包看不到圖，無法核對優先級與衝突，硬寫只會產生虛假斷言。

同時存在多種素材時，按以下優先級理解：

| 優先級 | 素材 | 鎖定內容 | 不繼承 |
|---|---|---|---|
| 1 | **首幀圖** | 第 0 秒構圖、人物初始位置、道具位置、空間側別、攝影機側、光影方向 | 整段動作、結尾狀態 |
| 2 | **調度圖 / 側別鎖定卡** | 空間邏輯、點位、移動路線、攝影機安全區、軸線、內外側、禁止區 | 畫風、人物外觀 |
| 3 | **場景角度圖** | 當前鏡頭從哪個方向看同一空間、空間透視、門窗傢俱相對位置、固定光源方向 | 人物、人群、劇情動作、第 0 秒構圖 |
| 4 | **場景母版** | 空間結構、固定傢俱、門窗、光源、透視、環境風格 | 人物、人群、劇情動作 |
| 5 | **角色圖** | 臉型、髮型、服裝、體態、年齡感 | 場景、臨時表情、姿態 |
| 6 | **道具圖** | 外觀、材質、顏色、狀態；文字內容須在提示詞另寫 | — |

### 衝突處理規則

> ⚠️ **M1 下的根本限制**：本包**看不到圖**——因此本節所有"衝突判定"在 M1 下**只能基於文字信息推導**，**不得聲稱"已比對確認衝突"**。正確動作是**向用戶提出需要核對的點**（附"怎麼核對"），而不是給出一個基於想像的結論。**M2（圖已入庫）才可做圖像級判定。**

| 衝突 | 處理 |
|---|---|
| 首幀圖 ↔ 調度圖 | **停止輸出**，要求先重做首幀或修正調度圖 |
| 首幀圖 ↔ 場景角度圖 | 先確認角度圖是否與場景母版一致；角度圖正確 → 重做首幀；角度圖與母版衝突 → 重做角度圖 |
| 首幀圖 ↔ 場景母版 | 優先保留場景母版的空間結構，重做首幀 |
| 場景角度圖 ↔ 場景母版 | 優先保留用戶確認的場景母版，重做衝突角度圖 |
| 首幀圖 ↔ 角色/道具外觀 | 優先保留角色/道具圖，重做首幀或在限制中明確修正 |
| 道具已在場景/角度/首幀可見 + 又引用道具圖 | **不視為衝突**，但必須啟用**道具單實例鎖**；無法判斷是否同一件 → 要求用戶確認或標註高風險 |

## 五、人物 / 道具錨定細則

**標準句式**：
```
將 圖N 中的[身份/外觀/服裝]定義為 <角色名>
```
**道具寫法（不新增欄，併入【場景資產】欄）**：
```
@PRP-道具名（外觀以道具參考圖鎖定；狀態：〔初始〕→〔終態〕）
```

**規則**：
1. 錨定句**只寫定義，不追加說明**。
2. 沒有正式角色名時，臨時命名 `<角色A>` / `<角色B>`，仍按同一句式錨定。
3. **不使用編號主體標籤**做人物錨定。
4. 如果圖號後緊接動詞或方位詞，必須改成 `<角色名>` 或補名詞隔斷，**避免數字粘連歧義**。
5. 一致性細節放進素材錨定、鏡頭限制或段末狀態。
6. **道具錨點族 = `@PRP-`**：與 `@CHR-`（人物）、`@SCN-`（場景）並列；**僅關鍵道具登記**，同一道具跨段/跨集**沿用同一 `@PRP-` 名**（對齊 `prop-template.md` §四 三處同名）；道具的**持握/位移/狀態變化**寫鏡行，錨定行**只鎖外觀與狀態**。
