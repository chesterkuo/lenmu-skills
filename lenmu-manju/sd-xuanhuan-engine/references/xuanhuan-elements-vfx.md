## 一、 能量四態系統（先定形再有光）

嚴禁使用“一團光芒”、“強烈能量束”等無輪廓描述，能量必須歸屬於以下四態之一：

1. **態一 · 附著態（貼刃纏身）**：能量死死咬在兵器或肢體表面。劍脊走主流能量，刃口燒至白熾最銳，金色/紫色電弧順金屬紋理螺旋攀附。揮斬時爆亮延展，收勢瞬間回縮貼刃。
2. **態二 · 脫體態（斬擊光刃）**：離開載體獨立飛行的實體。具備明確的幾何截面（半月形、月牙薄刃、破空光錐），厚度扁平，邊緣帶水墨飛白或鋸齒，飛行時切割空氣留痕。
3. **態三 · 聚集體（萬劍/法陣群流）**：先釘單體、再寫集合。單體為標準尺寸冷銀飛劍（劍尖向前、劍柄在後），整體按三維魚群組織（前部錯層鋒線、中部穿插補位、後部追入回填），外部機位展現宏觀流動，禁止平面劍板。
4. **態四 · 移動氣場態（流向尾流）**：靜止蓄力時能量向心匯聚翻湧；極速位移時衣襬與屬性真氣被風壓倒拽，拉出錐形流光長拖尾，身體前端形成透明空氣音爆錐。

## 三、 十三類三層複合元素標準庫全解

1. **水墨黑白三層（劍仙/居合專屬）**：外層水墨暈染飛白 + 中層青藍水浪翻湧 + 內層白熾冰晶核心，邊緣附著金色細碎流光符文。
2. **墨黑紫電三層（魔宗狂刀專屬）**：主體濃稠墨黑吸光液態流體 + 邊緣暗紅搏動血紋 + 表面狂暴跳躍純紫鋸齒電弧，末端爆裂細碎火星。
3. **赤紅三層（長槍/霸王槍專屬）**：主體半透明赤紅熔岩能量 + 表面金色螺旋轉動符文 + 前端純白高壓激波錐。
4. **暗金白三層（體修/金剛拳宗專屬）**：主體暗金液態真氣（厚重金屬質感）+ 前端純白壓縮激波 + 周圍環繞土黃石屑與金色古道紋。
5. **紫藍白三層（九霄神雷專屬）**：主體紫藍粗壯雷柱（內部電漿翻騰）+ 純白樹枝狀分叉跳躍電弧 + 外圍金色雷印，伴隨黑色細微空間裂隙。
6. **金橙黑三層（焚天火刃專屬）**：主體純金火核 + 邊緣橙紅翻湧火浪 + 外層黑色螺旋升騰煙塵，高溫使空氣劇烈熱浪扭曲。
7. **幽藍白三層（玄冰劍修專屬）**：主體幽藍半透明冰晶 + 中層純白濃厚霜霧 + 外層藍色水浪流動，表面浮現六邊形冰裂符文。
8. **透翠綠三層（風系神速專屬）**：主體完全透明高壓風刃 + 中層翠綠流動風紋 + 邊緣金色極細光芒。
9. **土褐金三層（地脈厚土專屬）**：主體粗糙土黃岩石尖刺 + 中層深褐地脈裂隙 + 外層金色厚土符文。
10. **黑紫金三層（虛空裂隙專屬）**：主體純黑虛空裂縫（吞噬一切光線）+ 邊緣紫色飄散餘燼 + 周圍金色空間扭曲碎紋。
11. **金紫黑三層（神識攝魂專屬）**：主體金色精神水波紋 + 中層深紫神念流體 + 外層墨色陰影擴散。
12. **金白羽三層（聖道金身專屬）**：主體純金神聖光柱 + 中層白熾淨化光芒 + 外層飄落的金色羽刃與神聖光輪。
13. **暗綠毒瘴三層（萬毒魔煞專屬）**：主體墨綠腐蝕性流體 + 中層慘綠翻騰毒霧 + 表面暗紫氣泡爆裂。

## 四、 角色勁氣性格庫與冷暖色彩對沖

### 1. 經典角色簽名勁氣速查
* **太極**：黑白陰陽雙色，螺旋凝聚尖錐與重甲，剛柔並濟；
* **白鴿**：紫黑色氣焰，新月弧刃與飛旋刀輪，踢技軌跡強可視化；
* **紅茶**：橙紅色爆裂火焰，一擊一炸，蠻力與熱浪翻湧；
* **凜羽**：冰藍銀白霜霧，寒氣滲透如紗如霧，唯有終結技化作冰暴；
* **雷電**：純紫與銀白電弧，零前搖瞬閃殘影，雷光撕裂虛空；
* **芭樂**：淺粉漸變至深粉，花瓣飄散到花蕾暴風，越打越濃烈；
* **冰女**：藍白漸變硬冰，結晶蔓延與冰刺封殺，觸碰即凍結；
* **劍神**：紅紫色瞬閃光軌，劍尖細銳白光、劍脊紫銅火星，出劍即收；
* **緋雪**：火紅刀焰，沿刀鋒前撲吞咬，貼臉連斬，火潮斷空。

### 2. 冷暖色彩對抗鐵律
* **同色相撞大忌**：嚴禁“藍劍打藍霧”、“黑焰打黑夜”，視覺缺乏辨識度。
* **高反差對沖**：暖色能量（赤紅/金橙）必須砸在冷色環境或冷色防禦（青黑/深藍）上；冷色能量（冰白/紫電）必須撕裂暖調光塵。
* **三方強分離**：`主衝擊色 vs 敵人主體色 vs 場景基底色` 必須兩兩可辨。
