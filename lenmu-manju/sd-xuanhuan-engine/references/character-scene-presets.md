# 08 · 角色設定、武學綁定與場景風格預設庫 (Character & Scene Presets)

## 一、 九大經典打戲角色資產卡與武學綁定

### 1. 太極（以柔克剛 · 剛柔互濟）
* **綁定武學**：太極拳 / 八極拳 / 詠春拳 / 八卦掌
* **戰鬥邏輯**：遠則太極化勁卸力，近則八極短打硬炸，中線詠春連環，走位八卦繞打。
* **勁氣視覺**：黑白陰陽雙色氣焰，近身爆發凝聚成尖錐，化勁時呈漣漪散開。
* **角色鐵律**：動作絕無生硬直撞，必有弧形導引與借力反擊。

### 2. 紅茶（暴力壓制 · 剛勁頓挫）
* **綁定武學**：泰拳 / 散打 / 空手道 / 八極拳
* **戰鬥邏輯**：全剛無柔，泰拳膝肘內圍絞殺，散打接腿快摔，八極鐵山靠硬砸，全程暴烈前壓。
* **勁氣視覺**：橙紅爆裂火焰，熱浪翻湧，一招一炸，打完留下焦黑灼痕。

### 3. 白鴿（靈動機動 · 腿法宗師）
* **綁定武學**：巴西戰舞 / 36路腿法 / 譚腿 / 跆拳道 / 截拳道 / 少林旋風地堂腿
* **戰鬥邏輯**：巴西戰舞空翻彈躍閃避，36路大開大合連環抽踢，低位地堂腿偷襲破下盤，540°水平旋風腿終結。
* **勁氣視覺**：紫黑色烈焰氣旋，踢擊弧線可視化為新月紫黑光刃。

### 4. 凜羽（形意穿刺 · 破招纏打）
* **綁定武學**：形意拳 / 八卦掌 / 擒拿 / 合氣道 / 柔道 / 柔術
* **戰鬥邏輯**：70%時間形意直線穿刺與八卦走圈穿插，30%時間擒拿鎖關節與柔道過肩翻摔，拿住立刻連打。
* **勁氣視覺**：冰藍銀白霜霧（薄霧輕紗流動，非硬冰），唯有終結技凝聚為漫天冰暴。

### 5. 雷電（神速極殺 · 零前搖）
* **綁定武學**：截拳道 / 詠春拳 / 散打 / 武俠身法 / 八極拳速度版
* **戰鬥邏輯**：天下武功唯快不破，零前搖中線截擊，打完三招對手才看到第一招殘影。
* **勁氣視覺**：純紫與銀白鋸齒電弧，出招沿途留下不規則紫色閃電殘痕與音爆雲。

### 6. 芭樂（漸變綻放 · 靈巧降服）
* **綁定武學**：柔術 / 蔡拳 / 巴西戰舞 / 跆拳道 / 形意拳
* **戰鬥邏輯**：站立蔡拳密集偏門快打，近身巴西戰舞翻身換位，倒地巴西柔術鎖臂降服。
* **勁氣視覺**：淺粉漸變深粉花瓣氣焰，輕擊淺粉飄散，重擊深粉炸裂如暴風。

### 7. 冰女（硬冰封殺 · 極度深寒）
* **綁定武學**：泰拳 / 八極拳 / 空手道 / 洪拳 / 擒拿
* **戰鬥邏輯**：泰拳膝肘與八極硬打硬攻，打到哪裡硬冰就凍結到哪裡，擒拿抓住直接結冰鎖死。
* **勁氣視覺**：藍白漸變堅硬冰晶，命中點瞬間向外蔓延厚實冰甲與銳利冰刺。

### 8. 劍神（絕世劍尊 · 九劍無痕）
* **綁定武學**：武當玄門劍 / 獨孤九劍 / 華山劍法 / 玉女劍 / 峨眉子午劍，佩專屬「紫霄神劍」。
* **戰鬥邏輯**：九套劍法切換無痕，出劍即破招，看到劍光時劍已收回，點穴刺喉。
* **勁氣視覺**：紅紫瞬閃光軌，劍尖細長高亮白芒，劍脊格擋紫銅火星，終結滿月紅紫劍波。

### 9. 緋雪（極致前壓 · 火焰刀宗）
* **綁定武學**：緋雪櫻灼流單太刀術 / 火焰刀 / 焚櫻刀禪 / 武俠身法，佩單柄「灼霜」長刀。
* **戰鬥邏輯**：不講試探，不做退讓，貼臉即連斬，刀刀破防，火紅刀浪一路向前狂撲吞咬。
* **勁氣視覺**：火紅熔金刀焰，揮斬拖出厚重彎月火刃與暗赤尾焰碎火。

## 二、 二十大經典打戲場景參考庫

1. **國風水墨 · 深山竹海古剎**：暴雨傾盆，狂雷橫掃，青竹彎折，懸空青石棧道積水飛濺。
2. **寫實紀實 · 城市雨夜小巷**：霓虹倒影，潮溼路面，鐵製消防梯，雨滴水花飛濺。
3. **仙俠奇觀 · 浮空雲海仙台**：殘破白玉石台，雲層翻滾，萬丈懸崖，流霞碎金。
4. **賽博朋克 · 霓虹廢土窄巷**：全息廣告投影，故障掃描線，機械義體反光，潮溼地面。
5. **大漠荒涼 · 千佛萬窟絕壁**：漫天狂風黃沙，風化巨佛石窟，落日熔金，斷壁殘垣。
6. **太古極北 · 萬丈玄冰殘殿**：倒塌青銅梁柱，萬載凍雪呼嘯，深淵幽藍寒光。
7. **地心烈焰 · 熔岩火海懸橋**：赤紅熔岩翻騰，斷裂黑石懸橋，地熱熱浪扭曲空氣。
8. **東海極淵 · 驚濤天瀑龍闕**：萬丈海嘯狂卷，斷裂盤龍青銅神柱，暴雨如注，漩渦撕咬。
9. **幽冥地府 · 忘川奈何血河**：慘綠磷火漂浮，血紅彼岸花海，殘破奈何石橋，陰霧遮天。
10. **宗門禁地 · 萬劍插地天坑**：千萬柄鏽蝕古劍倒插成林，中央巨大劍碑傾頹，劍意森森。
11. **古羅馬風 · 巨石角鬥狂沙**：巨大環形石砌看台，漫天黃沙飛揚，烈日炙烤。
12. **虛空裂界 · 破碎星辰浮石**：虛空星雲背景，懸浮隕石碎片，空間黑色裂縫交錯。
13. **高山雲巔 · 鐵索連橋天險**：萬丈懸崖間橫跨粗大生鏽鐵索，雲霧在腳下急速掠過。
14. **末日廢墟 · 傾頹鋼筋都市**：斷裂高架橋，長滿雜草的摩天大廈殘骸，夕陽餘暉。
15. **極簡水墨 · 純黑留白畫鏡**：大面積純黑負空間，極淡水墨山水輪廓，腳下鏡面水波。
16. **道家祖庭 · 九宮八卦石坪**：黑白陰陽魚太極石陣，四周九根盤龍漢白玉華表。
17. **皇宮大內 · 金鑾殿琉璃金頂**：傾盆夜雨，金色琉璃瓦連綿起伏，飛簷斗拱，閃電劈落。
18. **深海遺蹟 · 沉沒青銅龍宮**：透光海水，珊瑚巨柱殘垣，氣泡遊戈，水下折射光斑。
19. **蒼茫雪原 · 枯木荒村斷橋**：積雪沒膝，黑白枯樹林，斷裂木橋，寒鴉盤旋。
20. **魔宗血煞 · 祭血萬魂魔壇**：暗紫魔霧升騰，巨大森白頭骨祭壇，地面血紋符陣流轉。
