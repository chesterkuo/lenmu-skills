# 史詩戰場協議（R3 玄幻 · 一鏡到底群戰專章）

> **來源**：吸收自用戶提供的玄幻一鏡到底參考稿（30s 單人 vs 滿屏獸潮）。
> **定位**：本協議是 **R3 玄幻檔「一鏡到底 + 群戰 + 武器形態變化」**的補充規則層，與 `core-combat-laws.md`（黃金顆粒度/雙向力量互換）、`grand-scale-domains.md`（尺度四件套）並列使用。**衝突時**：鏡頭顆粒度以 `core-combat-laws.md` 為準，大場面尺度以 `grand-scale-domains.md` 為準，本協議只管"陣營色彩 / 位移 / 群戰數量 / 武器形態 / 蓄力收束"五件事。

---

## 〇、適用場景

- 單人（或少數人）對**滿屏敵軍/獸潮/軍陣**的清場式戰鬥；
- **一鏡到底**（無切鏡、無空鏡轉場）的高動態戰鬥總綱；
- 戰鬥中存在**武器形態變化**（如一劍化雙刀）、**超高速位移**、**陣營色彩對立**的場面。

不適用：雙人對招、室內近身搏擊（走 `close-quarters-engine.md`）、文戲。

---

## 一、陣營色彩鎖（Faction Color Lock）

> **一句話：敵我雙方各鎖一套色系，兩套色系全片不得互串。**

| 陣營 | 鎖定色系 | 覆蓋範圍 |
|---|---|---|
| **主角/我方** | 暖調（如 赤金 / 熔岩赤紅 / 暖金） | 主角光效、招式特效、武器輝光、殘影拖尾 |
| **敵方** | 冷調（如 青白 / 冰藍） | 敵人本體、敵人武器、敵人彈幕/衝擊波、崩解粒子 |

**四條鐵律**：

1. **主角招式恆暖色、敵人恆冷色**——包括命中衝突時，**火花/碎光是"接觸點混色"，不是陣營色互換**；
2. **敵人武器不得染成主角色**（骨刃/兵刃的刃口光澤保持冷調，即使被主角色系擊中，也只給"被燒灼的裂紋"不給"變成紅色"）；
3. **兩套色不得互串**——主角光效偶發變藍、敵人偶爾泛金，都屬違規（負面詞庫已列）；
4. **色彩鎖寫進全局契約**（`core-combat-laws.md` 第 0 步"能量主色 + 對撞色"已有此位），本協議把它**從"風格偏好"升格為"全片硬約束"**。

**為什麼**：一鏡到底沒有剪輯切點幫你分隔雙方，**顏色是觀眾區分"敵我""誰在打誰"的唯一穩定線索**。色系一亂，滿屏混戰立刻看不懂。

## 二、超音速位移 · Z 型折線三件套（Supersonic Z-Line）

> **一句話：高速位移按"斜前→銳角折返→斜前"的 Z 字折線突進；每個折點必須留三件套。**

**三件套（每個折點必現）**：

| 件 | 內容 | 寫法 |
|---|---|---|
| **① 起點殘影** | 折點處原位置留下未散的主角殘影 | "起點處一道赤金殘影未散" |
| **② 軌跡連線** | 從上一折點連向本折點的熔金軌跡 | "一道熔金軌跡自殘影連向落點" |
| **③ 終點凝實** | 落點處光聚凝實、主角顯形 | "落點處赤金光聚、主角身形驟然凝實" |

**附帶**：每個折點炸開**錐形音爆雲 + 環形氣浪**；殘影保留 **0.1~0.2 秒**後凝實再溶解；三段軌跡在空中**連成可見的 Z 字形光軌**。

**機位**：貼追折點、每個折點**甩鏡過沖回正**；Z 字光軌以俯拍角度完整入畫；強動態模糊拉滿。

**與總控條款的關係**：本協議是 `grand-scale-domains.md` 尺度四件套在"高速位移"上的具體化；**Z 型折線 = 3 次銳角變向**，段內不切鏡（一鏡到底）。

## 三、群戰遞增鐵律（Monotonic Escalation）

> **一句話：敵人的數量隨時間單調遞增、絕不回落——直到清場那一下。**

| 階段 | 密度 |
|---|---|
| 開場 | 數百隻鋪開（**首幀即滿屏，禁空鏡/前奏**） |
| 中段 | 上千只；精英單位（持械獸將/精銳兵）開始成排踏出 |
| 終局前 | 密密麻麻擠滿畫面每一處縫隙，連天光都被遮去大半 |
| 清場 | 大招一掃而空 → 清淨 → 尾幀定格（數量驟降只允許發生在**最後一次清場**） |

**四條鐵律**：

1. **單調遞增**：任何一幀的任何方向都必須看到成百上千的敵人，**絕不回落**（"打著打著敵人變少了"= 違規）；
2. **規模成片**：每一招的殺傷規模必須"成片/成排/上百隻"，**禁單個點殺**；
3. **優先"補員"**：清掉一部分後，**從更遠處湧來更多**（數量繼續遞增），不許清空一片就留白；
4. **精英分層**：精英單位（持械獸將）數量**逐幕遞增**（零星 → 成排 → 整隊壓上 → 四面圍殺）。

**為什麼**：單人 VS 群戰的爽感來自"**永遠打不完的壓迫感**"；數量回落會讓觀眾覺得"快贏了"，張力立刻洩掉。

## 四、武器形態單次變形（One-Time Weapon Morph）

> **一句話：全片只允許武器變一次形；這次變形必須完整演出，絕不憑空換模。**

**三鐵律**：

1. **唯一性**：全片武器形態變化**只發生一次**——嚴禁中途再變形態、嚴禁憑空多出一把武器、嚴禁變形後合併回原形態；
2. **完整演出**：變形動作**必須給足鏡頭、完整演完**（不許省略、不許用切鏡"跳過"）；
3. **連續可信**：變形**不是"換模型"**——是從"實體 A"通過可見的物理/能量過程"長出"實體 B（有前搖、有過程、有結果）。

**五步變形模板**（參考稿「一劍化雙刀」結構，可遷移）：

```
① 核心反應：劍脊脈線亮至極限、劍體劇烈震顫（能量在上限積壓）
② 一分為二：從中脊一裂為二，吞口/護手左右各分一頭，器靈/龍影脫出盤旋一週
③ 各向延展：兩段各向兩端延展成刃，一刃暖色熔岩、一刃暗色沉斂（一明一暗）
④ 配件展開：柄尾流蘇/鍊墜甩出並燃亮
⑤ 成式定姿：雙手各接一器、交叉成起手式，一聲金屬咬合脆響盪開（漣漪/氣浪）
```

- **全程約 0.4s**（快但不"瞬移換模"）；
- **分化前**持原武器要有明確起勢（舉過頂收束能量）；**分化後**直接接第一招；
- **機檢點**：變形瞬間給一幀近景特寫 + **一級衝擊幀**（見 `sd-combat-engine/references/impact-frame-and-banlist.md`）。

**寫作禁區**：❌"劍突然變成兩把刀" ❌"不知何時手上多了一把刀" ❌"雙刀又合成一把劍" ❌用剪輯/切鏡掩蓋變形過程。

## 五、蓄力渦旋與尾幀定格（Charge Vortex & Freeze Frame）

### 5.1 蓄力渦旋寫法（大招前）

終極技前的最強蓄力，用**"天地能量向武器匯聚"的可見渦旋**表現：

```
雙器交叉高舉向天 → 周身所有光效/火焰瘋狂向器身匯聚 → 天光被吸引形成巨大渦旋
→ 渦旋中心盤踞器靈/龍影 → 身體壓低、前足虛點、後足蹬滿（蓄勢待發的起手）
```

- 蓄力期間**四周敵人仍在成陣列壓來**（數量已滿屏）——蓄力不能把背景抽空；
- 機位**極速仰拍**，滿屏能量渦旋 + 四周壓來的敵潮剪影；
- **蓄力中絕不停頓**（"零頓幀"）。

### 5.2 尾幀定格（收束）

- **末鏡 13.5s 起**：鏡頭運動收束、人物停止大幅動作（**收束窗**）；**末鏡末 1s 整秒**：全體人物（或主角）保持姿態與站位、動作完全靜止、**畫面定格**（**2026-10-12 用戶裁定 · 整秒硬定格，剪輯時整秒剪除**）；
- 定格幀要**乾淨利落**：主角姿態完美、碎光飄落、戰場空無活物（或只剩殘局）；
- **定格幀的雙重作用**：① 藝術收束（逼格拉滿）；② **作段縫依據**——可直接截取該末幀作下一段的畫面依據（承接總控 `short-drama-director/references/segment-splicing.md` 尾幀錨定法，一致性 100%、成本 0）；
- 定格**必須發生在終結動作完成之後**（未殺完的定格、收勢未完成的定格 = 違規）。
