# 短劇視感機位體系（景別 · 焦段 · 機位 · 運鏡 · 景深 · 群像 · **四軸聯動矩陣**）

本文件是分鏡引擎的鏡頭系統規則庫。所有機位/運鏡設計必須先通過物理可行性檢查，再按情緒匹配與頻率名額執行；口徑按總控鎖系統執行（Seedance 2.5 與 2.0 語法分開禁混寫）。

## 一、景別約束

- 每個鏡頭必須標註景別，整組分鏡中景別必須有變化，不能連著三個近景。
- 可用景別：大遠景 → 遠景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特寫 → 大特寫。（**跨段承接口徑**：段縫兩側**必須同檔（0 級）**——尾幀截圖即下段首幀參考、畫面須逐檔咬合；末鏡做了收束動作的禁反向收緊 ≥1 級，未做收束的最多容忍 1 級——見 `short-drama-director/references/segment-splicing.md` §四·補）
- 基礎規則：情緒越強，景別越緊。動作越大，景別越松。
- 每組鏡頭至少包含：1個大景別（定場/環境）、1個特寫（情緒錨點）、1箇中景（信息交代）。
- 景別必須匹配場景物理空間（見 `scene-space-adaptation.md`）：室內封閉小空間最大景別上限是全景，禁止大遠景、遠景、鳥瞰。

### 景別與情緒反規則

重錘情緒反著用更有力，每場戲至少識別1個反規則機會點：

- 悲傷/絕望爆發 → 反而拉遠（拉鏡或切大景別），讓人物在環境中渺小。
- 震撼/認知崩塌 → 反而固定大特寫，讓觀眾無處可逃。
- 暴力/衝擊瞬間 → 反而切空鏡或拉遠，留白讓觀眾腦補。
- 孤獨/被遺棄 → 反而用大景別人物居中構圖。
- 判斷標準：常規情緒用基礎規則（越強越緊）；重錘情緒（生死、離別、真相、崩潰）反著用。

### 對話場景景別遞進

1. 開場定場：第一個鏡頭必須是中景或全景，交代誰在場、站位、空間關係。禁止對話開場直接給特寫或近景。
2. 對話推進：側45度過肩中景/中近景正反打為主，保持空間連貫。
3. 情緒爆點：才推到特寫/大特寫。
4. **特寫比例區間 25%~40%**（僅限人物特寫，物件特寫不計入）。**機檢 C18n 兜底**（`short-drama-director/scripts/validate_prompt.py`，越區間報 WARN）。
   - **「人物特寫」定義（2026-10-13 補齊 · 治口徑歧義）**：畫面主體為**人物的面部 / 眼睛 / 或人的身體局部（手、拳、肩背等肢體）**，且承擔表演或情緒功能 → **計入**。
   - **「物件特寫」定義**：畫面主體為**非人的物**（道具、器物、環境物件：榜文 / 旗面 / 街燈 / 馬具 / 信件 / 玉佩等）→ **不計入配額**。
   - **⚑ 判定基準（機檢同此口徑）**：鏡行內**有人物錨點（`@人名` / `@CHR-`）或人體部位詞** → 判人物特寫；**兩者皆無** → 判物件特寫，剔除。
   - ⚠️ **歷史教訓（2026-10-13）**：本區間此前**只有規則、沒有斷言** —— 某項目 72 鏡人物特寫僅 **19.4%**（低於下限）而機檢零告警。「只寫不檢」＝不生效。
5. 每段對話至少1個雙人同框關係鏡頭。

6. **長對白段必有關係鏡**：段內含台詞鏡 ≥6 時，段內至少安排 1 個**過肩雙人反打**鏡；雙側擺位 ≥2 人時，至少 1 個鏡頭**兩人同框**。二者**滿足其一即可**。缺則全程單人正拍輪切，觀眾讀不出「在對誰說話」，關係戲塌成兩段獨白。機檢 **C17b** 兜底（WARN 級，不阻斷）；**豁免三類**：單人對鏡獨白、電話/遠程對話、一方已離場。

（注：特寫 **25%~40%** 是**景別維度**的區間，非"不超過 40% 即可"——低於 25% 說明該給的特寫沒給（詳見下節場景清單）；常規鏡頭 ≤30% 是**機位維度**，兩者獨立達標、互不抵扣。**機檢 C18n 按鏡行口徑統計：含人體局部肢體、剔除純物件特寫；鏡數 <6 不判。**）

#### 特寫使用鐵律與場景清單（粉絲實測反饋併入）

> 📌 **來源**：粉絲「森林」實測反饋（2026-09-29）——「可以在 skill 裡面提示詞多加入一點特寫鏡頭，少一點空鏡頭嗎」。核實發現：特寫原來**只有 40% 上限、沒有下限、也沒有場景指引**——規則只說"不許太多"，從沒說"什麼時候必須用"，導致實操中特寫被壓到偏低。本節把"上限"補成"**區間 + 必須給特寫的場景清單**"。

**特寫不是"可選項"而是"情緒工具"**——它把觀眾的注意力強行鎖在一點上，是短劇最省成本的強調手段。區間 **25%~40%**：低於 25% 說明該給的特寫沒給（情緒落不了地）；高於 40% 說明濫用（人臉廉價化、節奏碎）。

**以下 5 類場景，必須給特寫（不允許只用中景帶過）**：

| 場景 | 為何必須特寫 | 寫法要點 |
|---|---|---|
| **情緒拐點** | 人物態度/心境轉變的瞬間，只有特寫能承載 | 轉變**發生的那一幀**給特寫，非轉變全程；配微表情（見 `shot-economy-and-acting.md` §五·五） |
| **關鍵道具** | 道具是劇情鑰匙（信件/玉佩/證據/傷口），特寫起"指認"作用 | 用物件特寫（不計入人物特寫配額）；畫面要"進行中"（正在被拿起/被看到），非靜態陳列 |
| **眼神記憶點** | 短劇靠"一個眼神"立人設/留鉤子 | 給大特寫（眼+眉），眼神要有明確對象與情緒，忌空洞平視 |
| **台詞重音** | 關鍵台詞的重音字/句尾，特寫放大器 | 特寫掛在這一句上；忌每句都特寫（只給重音句） |
| **反應鏡頭** | 聽者對關鍵信息的反應比說話更有戲 | 聽者反應特寫，與說話鏡構成正反打；反應要有具體變化（非重複前一鏡） |

**以下場景，禁止給特寫**：

- 開場定場鏡（必須先給中景/全景交代空間，見上文第 1 條）；
- 需要同時交代空間關係的鏡頭（特寫承載不了空間級事件，與總控 C18d 一致）；
- 同一情緒連續第 3 個特寫（情緒重複＝廢鏡，見鏡頭經濟性）；
- 無明確情緒/信息任務的特寫（湊數鏡）。

**自檢（不輸出）**：全段通讀——(1) 特寫佔比是否落在 25%~40%？(2) 五類必給場景是否都給了特寫？(3) 是否有"禁止場景"誤給了特寫？

### 景別與表演幅度綁定（2026-10-10 併入）

景別決定表演幅度——**每個景別只能寫它裝得下的東西**。寫入超出景別容納範圍的身體或人物，模型會直接生成錯誤畫面。這是"畫面內容"字段的硬邊界，與 §六 群像 A/B 檔互補。

| 景別 | 只能寫 | 禁止寫 |
|------|--------|--------|
| **特寫 / 大特寫** | 眼皮、眨眼、眼神焦點、唇線、喉嚨、下頜、鼻息、尾音、氣斷、沉默餘味 | 大幅肢體動作；胸部以下、完整腿腳、遠處人物、複雜空間關係（局部手部或局部道具**僅在確實入畫時**寫） |
| **近景 / 中近景** | 眉心、眼神路徑、嘴角、呼吸、肩頸、手指小動作、輕微重心變化；與對方的距離、前景遮擋、視線關係 | 多人完整站位、完整道具傳遞路徑、需展示手腳的動作（此類改中景/全景或拆鏡） |
| **中景 / 半身** | 手部、肩線、重心、身體前壓/後撤、與桌/門框/床沿/牆角等錨點的關係；面部反應清晰但不堆細節 | 堆滿五官細節 |
| **全景 / 遠景** | 身體線條、站位、步伐、距離變化、關係壓迫、空間隔離、人物被環境吞沒或推到邊緣 | 複雜微表情 |

**密度互斥（信息量守恆）**：運動鏡頭複雜時，演員動作減半；演員動作複雜時，鏡頭運動簡化；台詞複雜時，畫面動作簡化；情緒複雜時，空間動作簡化。靜態近景表演細節可以更密，但仍不得過載。

### 景別佔比預算表（★ 2026-10-16 新增 · 補「景別維度只有特寫一個區間」的缺口）

> **缺口由來（粉絲「森林」2026-10-16 反饋 · 核驗屬實）**：景別維度此前**只有「特寫 25%~40%」一個區間**，大遠景/遠景/全景/中全景/中景/中近景/近景**全無佔比預算**——執行者只能靠「階梯躍遷」+「別連著三個近景」這類軟約束兜，整段景別分佈全憑手感。本節把景別維度補成**一張表**。
>
> ⚠️ **與機位維度分開讀**：本節是**景別維度**預算；「常規鏡頭 ≤30% / 側45度 30%~40% / 側面（90°）≤15%」是**機位維度**（§三 機位配比鐵律），兩者**獨立達標、互不抵扣**（同本節上方「特寫區間」注）。
>
> ⚠️ **基準性質（★ 必讀）**：下表區間是**起步基準（推演值）**——由本包既有軟約束量化收斂而來，**不是平台實測數據**。項目首次使用應按成片實拍反饋校準，校準結果寫進項目台賬；**窄幅變體（如全程緊景別的心理驚悚向）須顯式聲明理由**，不得靜默越界。

| 景別（§一 九檔歸併） | 文戲 / 對話段 | 打戲 / 動作段 | 說明 |
|---|---|---|---|
| 大遠景 / 遠景 | 0%~10% | 5%~15% | 定場 / 環境交代；室內封閉空間按 `scene-space-adaptation.md` 禁大遠景 |
| 全景 / 中全景 | 10%~20% | 20%~35% | 空間關係 / 群像 / 位移展示 |
| 中景 | 15%~25% | 15%~30% | 信息交代主力檔 |
| 中近景 | 15%~25% | 10%~20% | 對話主力檔 |
| 近景 | 5%~15% | 5%~15% | 情緒逼近；**禁連續 ≥3 鏡**（§一） |
| 特寫 / 大特寫 | **25%~40%** | 10%~25% | 文戲沿用既有區間（機檢 **C18n**）；打戲特寫是情緒錨點，**不設 25% 下限** |

**三條讀表紀律**：

1. **是體檢表，不是配額表**——區間用於**事後核對分佈**，不是"必須湊夠"；某檔落在區間內**不等於**合格（每鏡仍須有對應情緒/信息任務，見 §九 畫面內容約束）。
2. **下限同樣有效**——低於下限＝該給的鏡頭沒給（與特寫區間的邏輯同源）；高於上限＝該檔濫用（如近景堆滿＝情緒鈍化）。
3. **小樣本不判**——段內鏡數 <6 時只看 §一 的最低結構要求（≥1 大景別 + 1 特寫 + 1 中景），**不套佔比區間**（與 C18n「鏡數 <6 不判」同口徑）。六檔**中位值之和 ≈100%**，允許按題材 ±10% 整體漂移。

## 二、焦段約束

每個鏡頭必須標註焦段。焦段是敘事工具——決定空間感、透視關係和情緒張力。

> ⚠️ **與 C20m 的分工（2026-10-24 P9 補）**：焦段寫在**鏡行頭**（`景別 · 焦段 · 角度 · 運鏡`），這是元數據槽，**C33 要求必填**；
> `C20m` 禁的是把同一套相機術語寫進**鏡行正文的動作描寫**（`焦平面全程死鎖面部無漂移`）。
> 一句話：**頭上寫焦段 = 必須；正文寫相機參數 = 禁止。** 詳見 `short-drama-director/references/model-adapters.md` §光影片段·邊界②。

| 焦段 | 等效焦距 | 敘事用途 |
|------|----------|----------|
| 魚眼 | 8-16mm | 癲狂/迷幻/主觀失衡，慎用 |
| 超廣角 | 14-24mm | 史詩場景/建立鏡頭/英雄登場 |
| 廣角 | 24-35mm | 環境交代/室內全景/群體場面 |
| 標準 | 35-50mm | 日常敘事/中景對話/客觀記錄 |
| 中長焦 | 85-100mm | 人物特寫/肖像/情緒逼近 |
| 長焦 | 135-200mm+ | 遠距離觀察/偷窺/孤立感 |
| 微距 | 1:1放大 | 極致細節/淚滴/紋理/關鍵道具 |

選擇規則：

- 大景別 → 超廣角或廣角。禁止用標準焦段拍大遠景。
- 人物特寫/肖像 → 中長焦85mm。禁止用廣角拍人物近景（除非刻意扭曲——如廣角+大仰角製造威壓畸變，須為情緒服務）。
- 遠距離觀察/偷窺 → 長焦。極致細節 → 微距。混亂/精神崩潰 → 魚眼（一部片最多1-2次）。
- 焦段必須匹配場景物理空間（見 `scene-space-adaptation.md`）。
- 全片至少使用4種不同焦段（在場景物理允許範圍內）。

### 景別 → 焦段 逐級對照表（★ 2026-10-16 新增 · 補齊「中近景 / 近景」空檔）

> **缺口由來（粉絲「森林」2026-10-16 反饋 · 核驗部分屬實）**：此前**硬綁定/硬禁令只有兩條**——① 大景別 → 超廣角/廣角·禁標準；② 特寫/肖像 → 85mm·禁廣角。全景/中景只能從上方焦段表的「敘事用途」列**推導**（廣角=室內全景/群體場面、標準=中景對話），而**中近景 / 近景兩檔完全沒有落點**。本節把逐級對照補齊——**不是新增禁令，是把既有口徑攤平成一張正列表**。

| 景別 | 首選焦段 | 允許區間 | 禁用 / 越界條件 | 依據 |
|---|---|---|---|---|
| 大遠景 / 遠景 | 超廣角 14-24mm | 14-28mm | 標準 35-50mm 拍大遠景 | 既有硬綁定① |
| 全景 / 中全景 | 廣角 24-35mm | 24-50mm | 室內長焦 >135mm（S1 層高不足） | 焦段表「室內全景/群體場面」+ `scene-space-adaptation.md` §S1 |
| 中景 | 標準 35-50mm | 28-85mm | — | 焦段表「中景對話」 |
| **中近景** | **中長焦 85mm** | **50-100mm** | 廣角 <24mm | ★本次補齊：卡在「標準 ↔ 中長焦」之間，對話半身鏡 |
| **近景** | **中長焦 85-100mm** | **85-135mm** | 廣角 <35mm（既有「禁廣角拍人物近景」的正面落點） | ★本次補齊 |
| 特寫 / 大特寫 | 中長焦 85mm | 85-200mm | 廣角（除刻意畸變，須為情緒服務） | 既有硬綁定② |
| 極致細節（淚滴/紋理/關鍵道具） | 微距 1:1 | — | — | 焦段表 |

**兩條讀表紀律**：

1. **超出「允許區間」＝須在鏡行寫明理由**（如「廣角 + 大仰角製造威壓畸變」）——既有口徑照舊，本節只是把它從"兩條"擴到"逐級"；
2. **與 §五 景深聯動**：中近景/近景/特寫 → 淺景深；中景以下 → 可按 §五 變化；強淺景深時降低物理霧或 diffusion（§五）。

## 三、短劇視感機位體系

每個鏡頭必須標註機位角度。不允許全程平視。

機位由**方向軸 × 高度軸**共同定位，兩軸可自由組合（如"側45度+大仰角"），組合讓單一鏡頭同時攜帶方向與高度的雙重情緒。

### 方向軸

| 角度 | 情緒表達 | 適用 |
|------|----------|------|
| 正面 | 直接、坦蕩、對抗 | 面對面對峙/坦白/攤牌 |
| 側45度 | 張力與交流並存、立體、有層次 | 對話與敘事的默認機位——對峙/試探/暗湧/權謀 |
| 側面（90°） | 隔絕、疏離、心門關閉、美學構圖 | 迴避/訣別/內心封閉/獨白式疏離 |
| 過肩 | 對話經典，建立空間關係 | 雙人對話/對峙 |
| 主觀視角POV | 沉浸代入 | 角色視角/恐懼/發現 |

### 高度軸

| 角度 | 情緒表達 | 適用 |
|------|----------|------|
| 平視 | 中性、平等、客觀 | 日常敘事、中性對話 |
| 微仰/微俯（≤15°） | 隱性的強弱暗示 | 常規敘事的隱形調味 |
| 仰拍（15°-45°） | 力量、威嚴、壓迫、英雄感 | 英雄登場/強者/施壓 |
| 俯拍（15°-45°） | 弱小、孤獨、無助 | 弱者/受害者/失敗者 |
| 大仰角（45°以上） | 壓倒性力量、神聖或恐怖、巨物感 | 權力碾壓/威懾時刻/恐懼源頭/不可抗力 |
| 大俯角（45°以上） | 被世界碾過、徹底的絕望、宿命 | 慘敗/被遺棄/極致孤獨/宿命時刻 |
| 鳥瞰/上帝視角 | 全知、宿命、渺小感 | 地理交代/戰場全景/宿命 |
| 荷蘭角 | 世界失衡、認知崩塌、心理異變 | 真相揭露/精神防線擊穿（每集≤1鏡或不用，見下） |

### 機位配比鐵律（短劇視感核心）

口徑：一次輸入的全部原文視作一集；多場景分文檔輸出時，名額在全集內統籌分配。

- **常規鏡頭佔比≤30%（區間25%-35%）**。常規鏡頭=平視（含≤15°微仰微俯）+正面或純過肩+平穩運鏡（固定/緩慢推拉橫移），無手持晃動、無荷蘭角。常規鏡頭是呼吸與基準線——定場、過渡、留白、平靜對話用它，讓激進機位有對比、有落差、有重錘感。壓到三成不是消滅常規，而是讓每一個常規鏡頭都有存在的理由。
- **側45度是對話與敘事的默認機位**，建議佔全片30%-40%——比正面立體、比側面保留交流感，是短劇視感的主力。
- **側面（90°）≤15%**，只給心門關閉級時刻：迴避、訣別、內心封閉、獨白式疏離。側臉必須配輪廓光（有源——窗/燈/火/霓虹），無輪廓光的糊黑側臉不合格；人物側面貼牆時改用側45度。
- **大仰角與大俯角各≤3次/集**，只給權力與命運的頂點時刻。二者對切（大仰角拍強者→大俯角拍弱者）是權力碾壓的經典組合，各算各的名額；單一大仰角或大俯角連用不超過2鏡。
- **荷蘭角每集≤1鏡，或選擇不用**。必須落在全集心理最失衡的一瞬——真相擊穿、精神崩塌、世界觀傾覆；傾斜幅度10°-20°，輕微到看不出來=沒用，誇張到滑稽=失控。全集沒有夠格的失衡時刻就不用，絕不硬湊。
- 激進機位必須由畫面情緒買單：有對應情緒節點卻仍全程平視=浪費機會；無對應情緒節點硬上傾斜俯仰=炫技廢鏡。兩種都禁止。
- 全片至少6種不同機位角度（方向×高度組合計為不同角度），連續3個鏡頭不得全部平視正面。口徑說明：單場景輸出時物理與情緒機會不足6種不硬湊——單場至少覆蓋4種，側45度優先；多場景累計達到6種。

### 物理可行性檢查

- 大仰角機位貼近地面或腰部以下向上拍，室內外均可；廣角+大仰角的透視畸變可用於威壓扭曲（刻意為之則放行）。
- 大俯角必須找到真實高點（樓梯口/二層迴廊/高櫃頂部/門框上沿/山坡/天橋），室內普通層高（S1/S2）無高點可用時降級為30°-45°俯拍，禁止憑空懸空機位。
- 側面機位需要人物側向有放置空間——側面貼牆會拍到一面牆皮，改用側45度。
- 鳥瞰要求鏡頭能放到場景正上方3米以上，室內普通房間層高不足禁止使用。
- 過肩需要機位能退到人物背後至少1.5-2米。

### 機位角度反規則

- 陰險反派 → 平視或微仰（近在咫尺的威脅比崇高更陰險）。
- 受害者的恐懼 → 大仰角拍施暴者（代入受害者視角，壓迫感最大化）。
- 失敗者的尊嚴 → 平視（保留人格）——絕境中反而平視，是他最後的體面。
- 英雄的脆弱瞬間 → 俯拍（立體化）。
- 強者從神壇跌落 → 大俯角（從雲端跌進塵埃）。
- 每場戲可識別1-2個反規則機會點。

（注：景別反規則每場**至少 1 個**，機位反規則每場 **1-2 個**，兩者獨立計數、不合並。）

### 過肩鏡頭幾何 · 左右前景判定（2026-10-10 併入）

過肩是對話戲的主力機位，也是最容易寫錯的機位——**左右前景寫反，模型會把肩膀擋在錯的位置，甚至把前後景人物顛倒**。寫"過肩"必須**同時寫清攝影機在被越角色的背後還是前側、越過哪一側肩**，並按下表落到畫面左右前景：

| 過肩類型 | 攝影機位置 | 畫面**左**前景 | 畫面**右**前景 |
|---|---|---|---|
| 後肩過右肩 | 角色**背後** | 該角色右肩 | — |
| 後肩過左肩 | 角色**背後** | — | 該角色左肩 |
| 前肩過右前肩 | 角色**前側**、向其身後拍 | — | 該角色右前肩 |
| 前肩過左前肩 | 角色**前側**、向其身後拍 | 該角色左前肩 | — |

- **前肩過肩只保留**前景角色的相應肩部、側頸或少量側臉邊緣，**完整正臉與軀幹不入畫**；
- 後方主體必須與前景角色存在**足夠橫向錯位、能從該機位真實露出**；若二人前後完全重合被前景擋住，**不得寫"後方人物可見"**；
- 無法確定攝影機在背後還是前側、或越過哪一側肩時，**不得含混寫"左/右前景"**——先明確人物朝向與攝影機位置再寫；
- 需**區分三種左右**：物理空間左右、畫面構圖左右、人物自身左右；攝影機換位或反打可以改變**畫面左右**，但**不得因此改寫人物的物理位置或自身左右**。

### 攝影幾何四步流程 · 每鏡先定機位再定可見內容（2026-10-10 併入）

**禁止先寫構圖 / 畫面內容、再倒推機位。** 寫每一鏡前，內部按固定順序完成判定：

1. **讀上一鏡結束狀態**——人物站位、朝向、視線、關鍵道具控制者；
2. **定位本鏡攝影機**——位置與觀察方向，確認是同側、過肩還是反打；
3. **判定可見性**——從該機位實際可見的人物、身體範圍、道具、前中後景與遮擋關係；
4. **只寫第 3 步成立的內容**——需要展示完整位移、多人關係或完整道具路徑時，改用足夠寬的景別。

- 構圖按 `攝影機位置 → 主體 → 實際可見前景 → 實際可見後景/遮擋 → 景別可見範圍` 依次判斷；
- **反打鏡頭由新機位獨立重建**前後景——上一鏡的後景角色**不會**因剪輯自動出現在反打裡；只有沿新機位視線真實可見、且未被前景人物或道具遮擋的角色，才能寫入該鏡；
- 不可見角色寫"**不入畫**"，**不得為了說明其仍在場而虛構後景**；
- 構圖、機位、畫面內容若互相矛盾，**以實際攝影機位置與可見性為準**，並重寫其餘字段。

**組合級禁令（★ 本節核心）**：**「人物臉部特寫 × 平視正面」是一個"組合風險"——三個軸各自合規 ≠ 組合合規**：

- **真人（BASE_LIVE）**：該組合**受 1/3 配額約束**——超配額時把多餘的臉部特寫改為側 45 度 / 過肩。
- **2D / 水墨（BASE_2D / BASE_INK）**：該組合可用，**同場連用 ≤2 次**。

**與既有規則的關係**：本節**不替代** §三 的方向軸 / 高度軸表，而是在其**上加"組合層"約束**——三軸各自合規（方向=正面合法、高度=平視合法、景別=特寫合法）**不等於**組合合規。**未感知基底 = 違規**（基底未鎖定 = 停下詢問，⛔ 不得默認真人）。

> **缺口由來（粉絲「森林」2026-10-16 反饋 · 核驗屬實且比反饋更嚴重）**：運鏡表此前**沒有獨立的「光學變焦」條目**——變焦只在 ① 上表「滑動變焦」② 單技法表 #5「Snap Zoom」（還與"直線推鏡"混寫在一句裡）兩處露面；**且機檢把變焦做成了錯誤別名**（`short-drama-director/scripts/validate_prompt.py` 舊版把 `Zoom` 一律歸為滑動變焦族，並把「變焦推進 / 急推變焦」計進滑動變焦的「全片 ≤1」名額）→ 寫一個普通光學變焦推拉，換個寫法就掉進兩個坑之一：**要麼被當成 Dolly Zoom 佔掉全片唯一名額（誤報超限），要麼完全不受任何規則約束（無檔可依）**。本節把四件套分開定義，並同步修機檢別名。

| 名稱 | 機位 | 焦段 | 畫面特徵 | 判據關鍵詞 | 名額 |
|---|---|---|---|---|---|
| **推鏡 / 拉鏡**（dolly in/out） | **位移** | 不變 | 透視關係改變（近大遠小加劇、有視差） | 推鏡 / 推近 / 拉鏡 / 拉遠 / 直線推進 | 按 §四 重技法表 |
| **光學變焦**（Zoom In/Out） | **不動** | **變化** | 透視不變、畫面**整體等比縮放**、無視差 | 光學變焦 / 變焦推拉 / Zoom In / Zoom Out | 非重技法；**不得與位移運鏡疊加**（見 §七 禁令③） |
| **急速變焦**（Snap Zoom） | 不動 | 變化（高速） | 0.2~0.5 秒內衝到位 | 急速變焦 / 急推變焦 / Snap Zoom | 一鏡只用一次，禁與升格同用 |
| **滑動變焦**（Dolly Zoom · 希區柯克變焦） | **位移** | **反向變化** | 主體尺度恆定、背景劇烈推拉塌陷 | 滑動變焦 / Dolly Zoom / 推進變焦反向拉移 | **全片 ≤1**（§四 重技法表） |

**三條判據紀律**：

1. **"位移 + 變焦"同時出現 = 滑動變焦**（無論是否寫"Dolly"）——機檢按此口徑計數（C18l）；
2. **純光學變焦不得寫成"Dolly Zoom"**，也**不得省略為孤立"變焦"**——須寫全「光學變焦推近 / 光學變焦拉遠」，否則機檢無法把它與滑動變焦區分開；
3. **光學變焦不是推鏡的替代品**——機位能移動時優先用推鏡/拉鏡（位移才有空間縱深變化）；光學變焦只用於**機位確實無法移動**的場合（貼牆 / 狹窄 / 隱蔽觀察 / 長焦偷窺）。

### 手持晃動三級烈度

烈度必須由情緒買單，禁止無理由晃動：

1. **手持微晃**——緊張上升段（情緒4-6分）的底色，替代穩定器的輕微呼吸感，讓畫面有毛邊。
2. **手持晃動**——衝突與混亂段（情緒6-8分），跟拍/圍拍中的自然顛簸。
3. **手持劇烈晃動**——爆發頂點專用（情緒≥8分）：劇烈甩動、地平線失穩、焦點呼吸，觀眾心跳跟著畫面跑。僅限暴烈衝突、驚恐逃竄、精神失穩、災難瞬間的最高點；每集≤3個鏡頭段落；允許連續2-3鏡短鏈（追逐/暴亂段落，此為"禁止連續3鏡同一運鏡"的顯式例外），鏈後必須接穩定運鏡收束形成反差；禁止在平靜/對話/抒情段落使用。劇烈晃動之前的鏡頭越穩，爆發時越炸。

### 運鏡-情緒匹配

不是if-then機械配對，由情緒強度+類型+場景節奏共同決定：

- 情緒爆發點：基礎用推鏡，重錘情緒（絕望/崩潰）反用拉鏡，震撼瞬間反用固定大特寫。不要每個angry都推鏡。
- 離別/結束/孤獨：基礎用拉鏡，獨白式孤獨反用固定中景，群體遺棄反用升降拉遠。
- 動作/行走：緊張追逐用手持（按三級烈度對號入座），莊嚴行進用軌道，漫步用穩定器跟拍。
- 頓悟/認知崩塌：滑動變焦（全片≤1次），其他頓悟用推鏡+固定組合。
- 關係揭示/主體崇拜：環繞（每場戲≤1次）。關鍵沉浸段落：按敘事需要選擇連續長鏡或真實切鏡，不為滿足鏡數強拆。連續運鏡先寫明起終機位、可通行路徑、主體位移、遮擋與軸線變化；路徑穿牆、層高不足或無法保持主體可見時，改走可行路徑或回導演層決定切鏡。此為製作策略，不是模型官方能力斷言；不得發明“輔助運鏡佔比 1/3”等閾值。
- 緊張/混亂/紀實感：手持晃動按三級烈度對號入座，緊張度越高晃動越大。運鏡速度=情緒強度。

**情緒節奏曲線（設計前內部識別，不輸出）**：通讀原文，標記每個情緒節點，標註三要素——**類型**（緊張上升／爆發／沉默留白／震撼凝固）、**強度 1-10 分**（此分值即下文三級手持烈度與運鏡速度的分檔依據）、**持續度**（持續若干鏡／瞬間）。據此畫出情緒曲線：上升段變緊變快、爆發點用重錘鏡頭、平復段變鬆變慢留白。鏡頭節奏跟隨曲線，不全程勻速。

**運鏡速度=情緒強度**：

| 情緒強度 | 運鏡速度 | 運鏡穩定性 | 典型運鏡 |
|----------|----------|------------|----------|
| 平靜/日常（1-3分） | 慢/極慢 | 穩定器般平穩 | 極緩慢推拉/極緩慢橫移/微漂移 |
| 緊張上升（4-6分） | 中速 | 微晃 | 跟拍/中速推鏡/手持微晃 |
| 爆發/混亂（7-9分） | 快/突變 | 手持晃動（8分以上升級為劇烈晃動） | 快速推鏡/手持晃動/手持劇烈晃動/快速橫移 |
| 沉默/留白 | 靜止/極慢 | 極穩 | 極慢拉鏡/極緩慢橫移（固定僅限重錘後留白長鏡） |
| 震撼/凝固（10分） | 靜止或滑動變焦 | 極穩 | 固定大特寫/滑動變焦/環繞 |

不允許"平靜情緒用快速運鏡"或"爆發情緒用緩慢固定"——除非刻意反規則。同一場戲內運鏡速度應隨情緒曲線變化，不要全程勻速。

**固定鏡頭是稀缺資源（★ 僅打戲 / 動作段適用）**：常態鏡頭一律以微運鏡（極緩慢推/橫移/漂移）替代絕對靜止，讓畫面保持流動。固定只留給三類時刻——重錘瞬間的凝固、段落句號、情緒重錘後的留白長鏡。10%上限即為此設。

> ⚠️ **文戲 / 對話段不適用本條（舊「對話段落不得全程固定」與「15s運鏡≤2」已隨本次修訂廢止）**：文戲與敘事段遵循**「動靜隨劇情自然發生」**（見 §四 運鏡分檔）——靜態聊天/展示可自由用固定，情緒逼近/人物走位可自由用緩慢推拉與跟移（配 10~15cm 物理限位），既不強迫每鏡都動，也不限制每段只能動 2 次。

**留白鏡頭**（情緒重錘後必加）：環境空鏡/反應鏡頭（無台詞）/動作細節空鏡/長固定鏡頭。每個情緒重錘瞬間後必須至少1個留白鏡頭，景別通常比爆發鏡頭更松，不允許立即接下一個情緒重錘。

**鏡頭節奏=敘事節奏**：快節奏段落（追逐/打鬥/爭吵）鏡頭短促、景別跳躍、運鏡快速；慢節奏段落（沉思/對話/獨白）鏡頭長、運鏡慢、固定多。節奏轉換必須有過渡，不允許硬切。

| Snorricam | ≤1次 | ≤1次 |
| 魚眼 | ≤2次 | ≤1次 |
| 荷蘭角 | ≤1次（或不用） | ≤1次（或不用） |
| 大仰角 | ≤3次 | ≤2次 |
| 大俯角 | ≤3次 | ≤2次 |
| 手持劇烈晃動 | ≤3個段落 | ≤2個段落 |

| POV主觀視角 | ≤3次 | ≤1次 |

### 微運鏡（畫面持續流動）

即使是"平靜"鏡頭，也優先用極緩慢的推鏡、極緩慢的橫移或呼吸感的輕微漂移讓畫面保持流動，避免絕對靜止導致的呆板。平靜≠凍結，極緩慢的推鏡是"剋制的情緒逼近"，比固定鏡頭更耐看。

### 四·二 · Lubezki × Deakins 物理運鏡與光學鎖焦規程（2026-10-14 粉絲 shotlist-builder 吸收）

> 📌 **病根與升級動機**：此前寫「極緩慢推鏡 / 手持微晃」屬定性標籤，模型不知道推進 10 釐米還是 2 米（推猛即人臉變形、站位漂移）；而為防漂移改成純「固定」又會讓畫面退化為死板監控攝像頭。本節引入 Lubezki × Deakins 電影攝影物理量化規程，**鏡行頭仍保 `[鏡頭N] 景別 · 角度 · 運鏡。` 三要素不變（兼容全套機檢），在鏡行描述內植入以下四把物理與光學鎖**：

1. **推拉運鏡釐米級物理限位鎖（10~15cm Physical Dolly Limit）**：
   - 凡使用緩慢推鏡 / 拉鏡（push-in / pull-out），必須在鏡行描述中鎖死**釐米級物理總位移與純物理軌道屬性**：`整段移動距離不超過 10~15 釐米，速度慢到幾乎察覺不到，純物理軌道微移無變焦拉伸`。
   - **震驚 / 頓悟反應標準式**：`鏡頭開始嚴格靜止凍結 0.5 秒 → 隨後極緩慢推進 10~15 釐米（純物理位移無變焦）`。既產生前景與焦外背景的真實視差滑動（Parallax），又絕不會把人物站位推崩。
2. **文戲「固定」的呼吸感與攝影師貼身隨動補償（Breathing Lock & Active Reframing · 僅限P3分鏡設計層，禁塞入P4鏡行）**：

   - **憤怒 / 緊繃對峙手持**：鏡行頭直接標 `手持微晃` 或 `緩推`，不寫冗長攝影機說明書。
3. **單鏡內分階段情緒運鏡（Phased Camera Arc · 單鏡隨表演節拍 ①②③ 同步變運鏡）**：
   - 當同一連續鏡頭內角色情緒發生轉折（如暴怒 → 強行壓抑剋制），攝影機狀態須在同一鏡內分階段同步演進，並與表演節拍序號 `①②③` 咬合：
     - `鏡頭起幅（節拍①②，角色怒氣緊繃）：攝影機明顯手持呼吸式漂移、上下微抖；`

4. **光學物理鎖（毫米焦距 + F1.4 淺景深 · 統一歸入【畫幅風格】總欄，禁塞入P4鏡行）與 0.3~0.5 秒閃切建立鏡**：

### 運鏡變化鐵律

相鄰鏡頭運鏡方式應產生變化，禁止連續3鏡使用同一種運鏡（唯一顯式例外：手持劇烈晃動的爆發頂點短鏈，見手持三級烈度）。同一場戲內運鏡方式至少覆蓋4種，避免單一手法貫穿全場。

全片至少使用8種不同運鏡方式（在場景物理允許範圍內）。口徑說明：單場景輸出時物理可用運鏡不足8種不硬湊——單場至少覆蓋4種，多場景累計達到8種；禁止為湊多樣性使用無敘事理由的運鏡。

複合運鏡的完整論述見 `shot-economy-and-acting.md`。

### 高光時刻運鏡專題（英雄登場 / 認知顛覆 / 制勝一擊）

> 本專題是 §四 的**組合應用庫**——**不新設任何名額**，所有上限仍按 §四「重技法頻率上限」與 §三「機位配比鐵律」執行；與本文件其餘規則衝突時以後者為準。
>
> 三套組合只用在**對應情緒節點**。用錯節點、或兩套疊加使用必廉價——高光鏡頭一濫，全片高光盡失。

**① 英雄登場**（人物首次以強者/主角姿態進入，或迴歸救場）

| 環節 | 寫法 | 作用 |
|---|---|---|
| 入畫 | 低機位大仰角定場，超廣角 14-24mm，人物自畫幅下緣升入 | 先給「個頭」，再給「身份」 |
| 展開 | 搖臂隨身體升起（或環繞半圈） | 把威壓從「角度」延續成「運動」 |
| 收束 | 緩推至面部中近景/近景 | 落到「人」，不落到「神」 |

- 名額：每場戲 ≤1 組；大仰角、搖臂、環繞各自照 §三/§四 名額計入，不額外開恩。
- 禁：全套連用超過 4 鏡（一過 4 鏡就變慢動作宣傳片）；人物尚未站穩就切環繞（像在轉圈，不像登場）。

**② 認知顛覆**（真相擊穿、背叛、世界觀傾覆）

- 組合：滑動變焦（Dolly Zoom · 主體不動、背景急推或急拉）→ 荷蘭角定格 → 焦點轉移（從人臉拉出到背景物證）。
- 名額：滑動變焦全片 ≤1、荷蘭角每集 ≤1（見 §三/§四）；三者**不得疊加在同一鏡**。
- 禁：與英雄登場的推鏡/環繞混用——兩套情緒方向相反，混用互相抵消。

**③ 制勝一擊**（打戲終結幀、逆轉的最後一擊）

- 組合：升格（高幀率慢放）→ 螺旋環繞半圈 → **固定大特寫凝固**（命中瞬間的「頓」拍）→ 緩拉收束。
- 名額：每場打戲 ≤1 組；打戲側「起-爆-頓-收」四拍細則見 `sd-combat-engine/references/combat-rhythm-and-load-guardrails.md`。
- 禁：命中幀用晃動或甩鏡——「頓」拍必須穩定凝固，觀眾判斷「打到沒打到」就看這一幀。

#### 單技法鏡行參考寫法（8 套 · 可直接取句式，參數按當次填）

> 上面三套是「**組合**」（一套走完一個情緒節點）；下表是「**單技法**」——任取一條寫進**一個鏡行**，用在三套組合的對應環節裡，或單獨用在某個需要強調的單鏡。**兩套疊加使用必廉價**（同一鏡不許既是滑動變焦又是螺旋環繞）。

## 五、景深約束

每個鏡頭必須標註景深策略。

| 景深 | 特徵 | 適用 |
|------|------|------|
| 淺景深 | 主體清晰，背景虛化 | 人物特寫/肖像/情緒聚焦/孤立主體 |
| 深景深 | 全畫面清晰 | 大景別/環境交代/多人物關係/全景清晰 |
| 焦點轉換 | 焦點從A轉到B | 視線引導/關係轉換/揭示/反應 |

- 人物特寫 → 淺景深（配合中長焦85mm）。大景別/環境交代 → 深景深（配合廣角，小光圈）。
- 需要引導觀眾視線從A轉到B時 → 焦點轉換。
- 全片景深策略需有變化。淺景深時降低物理霧或diffusion，避免背景被抹糊。

### 關係戲淺景深的前提（2026-10-10 併入）

- 曖昧、親密距離縮短或關係拉扯場景**可用**淺景深與明顯背景虛化（可寫"淺景深，背景明顯虛化成柔和焦外"），加強人物隔離、視覺親近感與注意力集中；
- **前提**：出口、人物站位、多人關係或關鍵道具連續性**必須清晰時，不得使用過強虛化**——雙人鏡頭須保持**雙方**必要面部反應、手部動作與聽戲反應可讀；
- 單人鏡頭保持主體面部與關鍵手部清晰；
- **淺景深不是所有場景的默認風格**——不得全片套用。

### 鏡面 / 玻璃 / 反射 · 高風險構圖（2026-10-10 併入）

- 鏡面、玻璃、反射**只在劇情或視覺任務必要時使用**，優先**直接拍攝人物**；
- 使用時**只保留單一反射面與簡單、靜止、可判斷的空間關係**；
- **關鍵身份、動作方向、人物交互與連續性結果，不得只依賴反射表達**；
- 除非用戶指定，避免：多層倒影、鏡內鏡、反射中的複雜動作、依賴鏡像方向的關鍵表演。

## 六、人物群像管理

按景別分兩級管理：

| 檔位 | 景別 | 多人管理要求 |
|------|------|--------------|
| **A檔（嚴格）** | 大遠景/遠景/全景/中全景/中景 | 必須數人頭、必須帶齊在場角色、畫面描述覆蓋所有人 |
| **B檔（寬鬆）** | 中近景/近景/特寫/大特寫 | 不強制多人、聚焦主體即可、背景人物可虛化或不在畫面 |

- 每個場景必須列出完整人物清單（主要角色+次要角色+功能性角色）。次要角色是否出鏡按敘事需求確定。
- A檔景別鏡頭必須逐一寫出每個在場角色的位置和動作，主要角色一個都不許漏。次要角色標註"出鏡"的也必須出現。
- **★ 群像行為（2026-10-24 P7 新增）**：A 檔鏡頭除"位置和動作"外，還必須給**每個無名可見人一件自己的事**（事務句三件套：手上事務 + 幅度 + 視線歸屬）。判"本段要不要群像"走 A/B/C 開關，判"寫到哪一型"走 R/P/S 三型——**權威 = 總控 `short-drama-director/references/crowd-behavior-direction.md`**。禁「眾人圍觀/大家在旁/周圍人群」這類聚合詞（= 模型自由發揮 → 全員同步站樁）。
  - 同鏡 ≥3 人時，事務必須**每人各異**；景別越緊、人離主體越近，事務細節越要寫到 R 型；遠景一律 S 型一句封頂。
  - **打戲段、純特寫段、密閉雙人戲不適用**（C 類）——這三類直接寫「除 @XX 外無其他人物」，走 C20h 原句式。
- B檔景別鏡頭只需寫清主體，背景人物寫"虛化"即可，不需要逐一羅列。
- 3人及以上場景，A檔群像鏡頭（畫面內≥2人）佔比不得低於該場景鏡頭總數的40%。
- 角色中途離開必須交代離開動作，下一個A檔鏡頭才允許消失。
- 從A檔切到B檔再切回A檔：A檔鏡頭必須恢復群像，B檔期間次要角色"消失"是正常的。

### 7.2 三條組合級禁令（★ 本節核心 · "三軸各自合規 ≠ 組合合規"）

> **原理**：§一 / §二 / §三 / §四 **各管一個軸**，四條各自合規的組合**仍可能違規**——**"組合"本身要有一條規則**。以下三條是當前已識別的高頻組合風險。

**禁令①：「緊景別（近景/特寫）× 平視正面」組合** —— 受 §三·五「形態 → 機位適配」的基底配額約束（**配額權威見 §三·五，本節只給落地口徑**）：

- **3D / 半寫實仿真人（BASE_ANIME）**：**默認禁用**；唯一豁免＝正面對峙 / 攤牌有明確情緒理由且鏡行寫明理由；
- **真人（BASE_LIVE）**：受「≤ 人物特寫總數的 1/3」配額約束；
- **2D / 水墨（BASE_2D / BASE_INK）**：可用，同場連用 ≤2 次；
- **落地口徑**：矩陣 **第 4 / 第 5 行默認給「帶角度」**——照矩陣取即可，不要臨時改回平視正面。**基底未鎖定 = 停下詢問**，⛔ 不得默認真人。

**禁令②：「大景別（全景及以上）× 長焦（>135mm）」組合** —— 長焦壓縮空間，與"交代空間 / 建立關係 / 展示站位"的任務直接相沖；室內層高不足時更直接穿幫（`scene-space-adaptation.md` §S1）。**要"宏大"用廣角 + 低機位仰拍，不是用長焦。**

**禁令③：「位移運鏡（推/拉/移/升降/跟拍）× 光學變焦」在同一鏡內疊加** —— 二者同時作用 = **無聲明滑動變焦**（Dolly Zoom，全片 ≤1）；**非刻意不得疊**。需要"主體不變、背景塌陷"就寫滑動變焦並佔名額；否則**二選一**（機位能移動 → 用位移運鏡；不能移動 → 用光學變焦，見 §四 變焦族四件套）。
