# 鏡頭經濟性與表演剋制（經濟性 · 人臉稀缺 · 表演 · **台詞鏡神態鐵律＋供給庫** · 站樁禁令 · 長鏡頭拆分 · 複合運鏡 · 銜接）

本文件是分鏡引擎的敘事與表演規則庫。核心信條：每一個鏡頭都必須有存在的理由；表演是畫面的靈魂，剋制自然比歇斯底里有力量。

## 一、鏡頭經濟性與節奏

**能刪則刪、能並則並**——每一個鏡頭都必須回答：這個鏡頭給了觀眾什麼"新信息"？給不出新信息的鏡頭就是廢鏡。

**一鏡多信息**：優質鏡頭一個畫面同時推進多層——劇情 + 人物 + 情緒 + 空間。每個鏡頭至少承載兩層信息，單層信息的鏡頭優先與相鄰鏡頭合併。例：一個鏡頭同時完成"交代位置 + 暗示關係 + 累積情緒"三件事。

**三類冗餘鏡頭直接刪除**：

| 冗餘類型 | 特徵 | 處理 |
|----------|------|------|
| 信息重複 | 與上一鏡傳達相同信息 | 刪除或合併 |
| 情緒重複 | 與上一鏡情緒強度相同、無遞進 | 刪除（不同主體的反應鏡頭不算——反應內容不同即有新信息） |
| 功能重複 | 多個鏡頭做同一件事（如兩次定場） | 只留一個 |

**快節奏段落（爭吵/追逐/動作）**：鏡頭短促、每鏡只給一個關鍵信息、景別跳躍更大、運鏡更快；過渡用匹配切（動作/視線/圖形匹配）或音橋完成，不加額外過渡鏡，直接推進。

**慢節奏段落（留白/情感沉澱）**：允許少數長鏡，但每個長鏡內部必須有動作/微表情/光影變化持續發生，不允許"靜止空鏡撐時長"。

**節奏過渡**：快慢切換必須有過渡鏡頭或音橋/視橋，不允許硬切斷裂。

**內部自檢（不輸出）**：全片通讀一遍——(1) 刪掉任意一個鏡頭，敘事是否仍完整？若完整則刪。(2) 相鄰鏡頭是否傳達同一信息？若是則並。(3) 是否有純過渡、無新信息的"過場鏡"？有則刪。

## 二、人物出現節制（人臉稀缺資源論）

**人臉是稀缺資源**——用多了廉價化。非人物鏡頭同樣如此，僅用於點綴和豐富，不可喧賓奪主。敘事以人物鏡頭為主，非人物鏡頭像 seasoning，撒一點提味，不能當主菜。

**人物鏡頭 vs 非人物鏡頭**：

- 人物鏡頭：畫面主體是人物（臉/全身/半身）——定場、過肩正反打、雙人同框、情緒爆點特寫、重要動作、權力關係建立。
- 非人物鏡頭：畫面主體是環境/物件/局部肢體不露臉/光影——氛圍點綴、情緒累積（物件承載）、留白、台詞過渡、時間流逝。

**非人物鏡頭5類**：環境空鏡、物件特寫、局部肢體、光影變化、反應局部。使用時必須承載情緒或信息，不能是無意義filler。

**非人物鏡頭佔比區間10%-20%**：

- 非人物鏡頭僅用於點綴和豐富，全片佔比控制在10%-20%。
- 防人臉接力：連續6個人物鏡頭後可考慮切1個非人物鏡頭，但不強制——有敘事理由才切，不為切而切。
- 上限20%防非人物過度（敘事碎片化、節奏斷裂）。
- 長對話中非人物鏡頭不作硬性穿插要求，僅在情緒需要時自然插入。
- 長台詞切鏡以人物反應鏡頭和動作過渡為主，非人物鏡頭不超過切鏡總數的30%。

**非人物鏡頭必要性**：每個非人物鏡頭必須能回答——(1) 承載什麼劇情/情緒？(2) 人物鏡頭能否更好替代？(3) 刪掉影響敘事嗎？回答不上來=湊數=刪除。相鄰非人物鏡頭不能信息重複。非人物鏡頭類型需多樣化（至少2-3種）。情緒累積段落可用局部肢體外化情緒，但不拍表情的前提是該物件/肢體確實比人臉更有力。

## 三、台詞約束

- 有台詞寫台詞，標註說話人。無台詞寫"無"。
- 台詞中保留原文標點，不增不減。
- 長台詞必須切鏡：一個人連續說話太久不切鏡觀眾會疲勞。台詞較長的拆分為多個鏡頭，中間插入反應鏡頭、空鏡或動作過渡。原台詞內容不刪減，分配到多個鏡頭中。即使台詞短，也須遵守"站樁說話禁令"——說話時要麼有動作、要麼切鏡。**機檢兜底：`C10`（單鏡 >6s 告警 · talking head 風險）、`C27d`（同一說話人連續 ≥2 鏡獨佔開口 = 站樁式對話）、`C27c`（開口次數不足）——但這三條都只判「稿子怎麼寫」，判不了「模型把 3 個 3s 鏡合成一個長鏡」；長獨白段必須**在鏡行裡把切點寫死**（每鏡標註獨立機位），不要只依賴時長累加。**

## 三·補、台詞標點 → 可見表演映射（2026-10-10 併入）

台詞的標點是**語義與語氣的標記，不是演員可執行的時間點**。禁止寫"說到逗號時""說到破折號時"；應寫"說完這句話後""說到最後一個語義短句時""短暫停頓後""語氣轉折後"。

| 標點 | 對應可見表演（按需取 1–2 項寫進鏡行） |
|------|--------------------------------------|
| **，逗號** | 半口氣、鼻吸、視線落到地面、手指停住、聲音壓低半拍 —— 對應呼吸 / 視線微移 / 短暫停頓，**不得寫成無意義停頓** |
| **。句號** | 眼神停住、下頜鬆開、呼吸沉下去、沉默半拍、手指慢慢鬆開 —— 對應收尾餘味，**不能一句說完表情清零** |
| **？問號** | 先判斷角色"要的是什麼"（答案 / 安慰 / 控制權 / 試探 / 真相 / 審判 / 撒嬌 / 逼迫），再寫眼神落點與尾音處理 —— **不得只寫"疑惑地問"** |
| **！感嘆號** | 能量上衝、氣息壓住、眼神壓迫、手部用力、聲音抬高但立刻收住 —— **不默認吼叫**；除非劇本明確要求，不主動寫怒吼 / 爆哭 / 失控 |
| **……省略號** | 氣斷、卡喉、視線停住、嘴唇微張、說不下去、尾字被吞回 —— **不得當普通停頓處理** |
| **——破折號** | 突然剎車、改口、吞嚥、被打斷、情緒被截斷、衝動剛起就被壓回 |
| **（沉默）** | 必須寫眼神路徑 + 呼吸變化 + 身體洩漏 + 情緒餘味 —— **不得只寫"沉默"** |

**臉·聲·詞同步**：台詞鏡頭必須做到表情、呼吸、停頓、重音與原台詞標點一致——標點提供節奏線索，表演負責把它落在可見的身體上。

## 三·補二、台詞重音落點（重音字顯性化 · 2026-10-11 併入）

> 📌 **來源**：粉絲稿對照吸收（`粉絲稿對照審計_白凰學院撞人段_2026-10-11.md`）。粉絲稿把重音單列為【加重詞彙】一行——核實發現：本包**早已在四處要求"圍繞重音字做設計"**（`facs-micro-expression.md` 表情峰值對齊台詞重音字；`short-drama-camera-system.md` §一 台詞重音掛特寫；本文檔 §三·補 臉·聲·詞同步；`director-to-prompt-protocol.md` §發聲層"『他』字重讀"），**但從沒有一處告訴創作者"這句的重音字是哪個"**——要求是隱性的，執行者只能靠猜。本節把這個隱性要求變成**可填字段**。

**判據**：每句台詞，作者必須**顯式指出 1 個重音字/詞**——不是每個字都重，也不是整句都重。

**寫法**（分鏡稿單鏡頭模板已增此欄，緊跟「台詞」）：

```
台詞：A（低 · 平）："這表，你修的。"
重音：修
```

**三重用途**（重音字定下來，三處設計才有依據）：

| 用途 | 取用方式 | 權威 |
|---|---|---|
| **掛特寫** | 一句裡最重的那一下掛特寫/放大，其餘保持常規景別——**忌每句都特寫** | `short-drama-camera-system.md` §一 |
| **表情峰值** | FACS 微表情的峰值必須**對齊重音字**，不是對齊台詞開頭 | `facs-micro-expression.md` |
| **配音重讀** | 投餵時把重音落進發聲描述（"『修』字重讀"），模型才會念出該有的抑揚 | `director-to-prompt-protocol.md` §發聲層 |

**三點紀律**：

1. **一句只標一個重音**——標兩個以上等於沒標；只有真正的對比句（"我**不**是這意思""**這表**，你修的"）才允許標兩處；
2. **與語氣位正交**——語氣位管"怎麼念"（力度/節奏/音色），重音管"重哪個字"，二者不互相替代；
3. ⛔ **`重音：` 欄屬分鏡層，投餵前必須剝離**——不得落進七段式正文（C12 攔截工作流規則詞）；其效果由"畫面內容裡的表演描寫 + 發聲描述"承擔。

**內部自檢（不輸出）**：(1) 每句台詞是否標了重音？(2) 是否只標了一個？(3) 本鏡若有特寫，是否掛在重音句上？(4) 標了重音的句，表演峰值是否也對齊了這個字？

## 四、長台詞切鏡規則

台詞較長時（大約超過兩三句），必須在台詞中間插入至少1個切鏡點。切鏡方式優先級（從高到低）：

1. 聽者反應露臉（人物）——最自然、最有力
2. 動作過渡（人物）——說話人或旁人動作
3. 雙人同框（人物）——關係鏡頭
4. **物件特寫**（非人物，台詞畫外音）——桌上茶杯/手中信件/牆上掛鐘/菸灰掉落
5. **局部肢體**（非人物，台詞畫外音）——手顫抖/指節發白/拳頭緊握/腳步後撤
6. **環境空鏡**（非人物，台詞畫外音）——窗外風景/天空雲朵/遠處街景
7. **光影變化**（非人物，台詞畫外音）——陽光移動/陰影拉長/燭火搖曳
8. **反應局部**（非人物，台詞畫外音）——手緊握茶杯/肩膀繃緊/背影微顫

人物鏡頭優先，非人物鏡頭作為點綴穿插，不作主力。

## 五、站樁說話禁令與長鏡頭拆分

**長鏡頭默認拆分 · 但不搞一刀切（2026-10-13 用戶申明修訂）**：

> **用戶原話**：「我**也不知道你為了切而切**，像有一些劇情就**不適合這種來回的切**，**靈活懂嗎？是服務劇情的**」。

**默認**：本欲用長鏡頭完成的段落，**優先**拆成多個鏡頭切換完成；若情緒需要連續沉浸，改用"微運鏡 + 鏡頭內動作調度"——運鏡極緩但不斷、動作調度不斷，讓畫面自行保持流動。

**⛔ 但"全片禁用一鏡到底"是過度收口，已廢止**。以下情形**允許保留長鏡/一鏡到底**，且必須保留：

| 允許長鏡的劇情 | 理由 |
|---|---|
| **長鏡壓迫 / 空間調度**（跟隨人物穿行、連續走位、全景一次性交代多人關係） | 切碎會破壞空間感與壓迫感 |
| **沉默對峙 / 留白 / 靜場** | 靠**時序連續**演情緒，切了就斷 |
| **宣判 / 攤牌 / 一字一頓的壓迫台詞** | 不切 = 觀眾被釘在原地看著，是設計不是懶 |
| **打鬥中的長鏡調度**（招式連貫、無剪輯感） | 動作連貫性優先 |

**寫作要求**：用長鏡時，**必須在鏡行內寫明保留理由 + 畫面內持續發生的動作/微表情/光影變化**（長鏡不等於靜止畫面——內部必須有東西在動）。**⛔ 禁止"沒有任何內部變化的靜止長鏡撐時長"**（那是廢鏡，與本條無關）。

**判準始終是劇情**：該切的時候切（爭產/質問/搶話 → 高頻正反打），該留的時候留（沉默/壓迫/留白 → 長鏡到底）。**「為切而切」與「該切不切」是同一種病。**

**站樁說話禁令（三秒鐵律 · 同樣服務劇情，非常態鐵律）**：人物不允許站在原地靜止不動地說話超過約3秒。任何含台詞的鏡頭內，只要人物在說話，必須二選一：

- **一直有動作**——說話同時伴隨持續、具體、可見的動作（走位、手勢、做某事、轉身、遞物、起身坐下、整理物件等）。動作要寫進畫面內容，且必須推進敘事或情緒，不允許無意義小動作填時長。
- **切鏡頭**——說話人一旦靜止，立即切走：換機位角度、換景別、切他人的反應鏡頭、切物件/環境空鏡、切雙人同框均可，但切出的新鏡頭必須承接並推動當前情緒。

> ⚠️ **例外（2026-10-13 補充）**：**刻意的靜止是一種表演**——沉默對峙裡"一動不動地盯著對方"、宣判時"說完就定住不動"，**都是有意的**，不受三秒鐵律約束。判據是**這句台詞的力道是否需要"定住"來放大**，而不是機械數秒。**寫這類鏡行時標明意圖（如「刻意靜止 · 壓迫感」）即可。**

**切鏡必須服務情緒渲染**：換角度、換景別、切反應鏡頭，每一次切鏡都必須對情緒渲染起作用——推進情緒、揭示反應、累積張力、或提供留白。禁止"為切而切"的機械換機位：切出去的空鏡/反應鏡頭若不能推動情緒，等於廢鏡，應刪。

**禁止純站樁正反打**：兩人對話禁止"A靜止說一句 → 切B靜止說一句"的純站樁正反打。每句台詞要麼伴隨動作，要麼在台詞間插入反應鏡頭/空鏡/雙人同框，讓畫面持續"活"著。切鏡仍須嚴守180°軸線與30°規則（見本文件"銜接約束"）。

**狀態賬 · 已達成動作不得重演（2026-10-18 粉絲實測併入 · 治「鎖了又鎖」）**：

一個動作只要在畫面上**已經完成**，後續鏡頭就**不得再演一遍完成過程**。典型病灶（粉絲實拍）：鐵門**已經鎖好**，下一個鏡頭又切到有人在**把鎖釦上**；人**已經坐下**，下一鏡又起身再坐一次。

- **判據**：前一鏡的畫面狀態 = **已完成態**（鎖已合 / 杯已碎 / 人已倒地 / 門已開 / 外套已脫）→ 後一鏡只能從**該狀態的後果**起手（推門進入 / 看著碎片 / 跨過身體 / 穿著裡衣），⛔ 不得重放「達成動作」。
- **寫法**：跨鏡承接只寫**結果**，不寫**過程**。`✅ 門鎖已扣死，他從門縫裡看她` ／ `⛔ 他伸手把鎖釦上`（上一鏡已扣過）。
- **例外（須寫明動機）**：確實要"再鎖一次"時，必須在鏡行寫清動機（`他不放心，又拽了兩下確認`），否則一律按重複判。
- **與「動作相位七態」的邊界**：七態是**鏡內**拆格用的；本條管**鏡與鏡之間**的狀態賬，兩者不重疊、不互相替代。
- **機檢邊界**：**無對應 C 碼**（同義動作識別不可靠），靠本條 + `prompt-feeding-checklist` 第 37 項人工核。

**內部自檢（不輸出）**：每個含台詞的鏡頭逐一自檢——(1) 說話人是否靜止？靜止是否逼近或超過3秒？(2) 若靜止，是否已切鏡或已安排動作？(3) 切出的鏡頭是否真正服務情緒渲染？(4) 動作是否推進敘事而非填充？

## 五·五、 台詞鏡神態鐵律與神態-動作供給庫（粉絲實測反饋併入）

> 📌 **來源**：粉絲「森林」實測反饋（2026-09-29）——「現在這個 skill 生成提示詞時，人物的**神態、動作等描寫大部分時候是缺失的**，經常出現人物**"站樁"然後說台詞**的情況」。核實發現：本站樁禁令（§五）已存在且很硬，但它只管到"**要麼有動作、要麼切鏡**"——**"動作"裡沒有強制要求含神態/微表情**，且規則集中在動作語境。本節把鉤子補到"**每一句台詞**"這一層。

### 鐵律（每句台詞必過 · 一票否決）

**任何含台詞的鏡行，必須同時掛載「可見動作」與「可見神態」兩項描寫，缺一即視為廢鏡、必須重寫。** 判據三條：

1. **神態必寫**——每一句台詞所在鏡行，必須有一個**具體的面部/眼神/呼吸描寫**（禁"表情平靜""神色複雜"這類形容詞，必須是看得見的肌肉動作）；
2. **動作必寫**——同鏡行必須有一個**具體的身體動作**（手部/重心/走向/與物件的交互），不允許"站著說"；
3. **兩者同框**——神態與動作寫在同一鏡行內（分給相鄰鏡行不算），因為模型按"鏡"渲染，分鏡即丟失。

> ⚠️ **與 §五站樁禁令的關係**：§五 管"**不允許一直靜止**"，本節管"**說的是什麼狀態**"——兩條疊加生效：台詞鏡既不靜止、又必須有神態。**只有"有動作"是不夠的**——"她一邊走一邊說"滿足了§五，但如果沒寫神態，仍然會被渲染成面無表情的念台詞（這正是粉絲看到的現象）。

### 神態-動作供給庫（按情緒取用 · 直接抄進鏡行）

> 用法：先定該台詞的情緒，再從對應行取 **1 個神態 + 1 個動作**，寫進鏡行。**同一場戲內不重複用同一條**（避免全片"抿嘴+握拳"一眼假）。取"藏七分露三分"原則（見 §六），神態寧小勿大。

| 情緒 | 神態（面部/眼神/呼吸 · 取一） | 配套動作（手部/重心/走向 · 取一） |
|---|---|---|
| **隱忍** | 下頜繃緊、喉結滾動一下、視線垂落再抬起 | 指節捏緊又鬆開、把物件放回原處、重心後壓半步 |
| **譏諷** | 單側嘴角極輕微上挑、眼皮微垂掃對方一眼 | 慢條斯理整理袖口、指尖在桌面輕叩兩下 |
| **震驚** | 瞳孔收縮、呼吸亂了半拍、睫毛顫動 | 手中物件停住、身體幾不可察地後仰 |
| **心虛** | 視線游移又移回、嚥了口唾沫 | 手指無意識摩挲衣角、把身體轉向光源背側 |
| **決絕** | 眼神定住不再閃避、下頜線繃直 | 解開袖釦、把物件推到對方面前、起身 |
| **脆弱/壓抑** | 眼眶泛紅卻別過臉、吸一口氣壓住哽咽 | 手指扣住桌沿、把眼淚逼回去並轉開頭 |
| **威脅** | 眉頭壓低、目光釘在對方臉上不移 | 上身緩慢前傾、手指點向對方 |
| **敷衍/輕蔑** | 嘴角平直不動、目光越過對方落到別處 | 邊說邊收拾東西、轉身要走 |
| **動搖** | 嘴唇微張又合上、視線在物與人之間來回 | 手伸出去又收回、腳步虛浮半步 |
| **釋然** | 眼尾放鬆、呼出一口長氣 | 肩膀垮下來、靠向椅背 |

### 內部自檢（不輸出 · 每句台詞過一遍）

對每個含台詞的鏡行逐一問：

1. 這句台詞有沒有配 **具體神態**？（"平靜地說"不算）
2. 這句台詞有沒有配 **具體動作**？（"站著說"不算）
3. 神態與動作是否**寫在同一鏡行**內？
4. 本場戲是否**重複使用**了同一條神態/動作？（重複即換）
5. 神態是否**剋制**（藏七露三）而非表情包式？

答不上任一條 → 該鏡行重寫。

## 五·六、聽戲反應規則（對話戲必有 · 2026-10-10 併入）

**無台詞角色不是"等著輪到自己說台詞"**——他在聽對方某個詞、稱呼、停頓或語氣後產生反應。對話戲必須寫"聽"的反應，**不得讓無台詞角色表情清零或無意義站立**；否則對話戲塌成兩段獨白。

無台詞反應鏡頭的完整鏈條：**聽見什麼後停住 → 眼神路徑 → 呼吸變化 → 身體哪一處洩漏 → 最後餘味停在哪裡**。

常見聽戲反應（按情緒取用，同一場戲內不重複同一條）：

- **眼神**：視線從對方眼睛移到嘴角 / 避開後又抬回 / 聽到某個詞後視線突然定住 / 視線掃向出口或對方的手；
- **手部**：手指停住 / 指尖扣緊道具 / 握拳又鬆開 / 拇指摩挲衣角；
- **呼吸**：呼吸斷半拍 / 沉默裡鼻息變輕 / 回答前吞嚥 / 說完後留沉默；
- **身體**：肩線輕微縮緊 / 下頜壓住 / 背脊突然挺直 / 重心後移 / 腳尖轉向出口；
- **情緒**：眼眶起溼意但壓住 / 聽到關鍵字後先是無反應再是一顫（**遲到的反應**）。

**與神態鐵律聯動**：含台詞的鏡行走 §五·五（神態 + 動作雙掛）；**無台詞的聽戲鏡行按本節**——兩者合起來保證"對話戲裡沒有一根木樁"。

## 五·七、對話戲節奏律（回合制切鏡 · 開口密度 · 2026-10-13 用戶實測反饋新增）

> 📌 **來源**：用戶實測反饋（2026-10-13）——「我們現在出的台詞就像**站樁式對話**，一個人說完另一個人說，缺乏**快速的正反打**；分鏡也很呆板，15 秒切成三四段、每段裡就幾個詞兒，**非常呆傻地去執行台詞量控制**」。
>
> ⚠️ **與 §五站樁禁令的分工**：§五 / §五·五 / §五·六 三條管的是「**人物不能立成木樁**」（靜止 / 無神態 / 無反應）；本節管的是「**切鏡節奏不能呆**」——**三條全過、台詞鏡也可能仍然是"一言一鏡輪流開口"的死節奏**。這是四個獨立維度，必須四條全過。

---

### ★★ 總則：節奏服務劇情，規則不是模板（2026-10-13 用戶申明 · 本節一切規則的適用前提）

> **用戶原話**：「**你靈活一點，不要說我說啥就把它完全定死了，這個東西它本身是服務著劇情走的**」；
> 「我**也不知道你為了切而切**，像有一些劇情就不適合這種來回的切，**靈活懂嗎？是服務劇情的**」。

**本節所有指標（回合制切鏡 / 開口密度 / 短句化 / OS 補位）都是"常見對話戲別拍呆"的工具，不是每段都要套用的模板。** 判準永遠是**這段劇情需要什麼節奏**，而不是"規則說該切幾刀"：

| 劇情性質 | 該用的節奏 | 本節指標 |
|---|---|---|
| **爭產 / 質問 / 鬥嘴 / 搶話 / 逼供** | **高頻正反打**——快速來回、每切換嘴、短句砸 | 按本節全量執行（開口 ≥6 次/15s） |
| **沉默對峙 / 宣判 / 攤牌前靜場** | **慢**——長鏡壓迫感、單鏡承擔、眼神與呼吸演滿 | ⛔ **不執行開口密度下限**；標「**本段為靜場/宣判段**」 |
| **情緒積累 / 回憶 / 獨白** | **留白**——允許一人獨佔、允許空鏡帶聲 | ⛔ 不執行開口密度下限；標「**本段為留白段/獨白段**」 |
| **空鏡 + 先聲（公園空鏡傳來人聲→切到兩人對話）** | **聲橋過渡** | 見 `dialogue-speed-check.md` §一·補三「空鏡帶聲」——**合法且常用** |
| **打鬥段** | 動作與音效主導 | ⛔ 不設台詞下限 |

⛔ **禁止"為切而切"**：切鏡點是**為了服務情緒/信息/關係**；若一段的劇情靠"沉默和靜止"更有力，**就不該切**。用戶批的是「**站樁式對話**」（該切不切、節奏死），**不是"任何時候都必須高頻切"**。

⚠️ **與「固定機位為主」的關係**：文戲「固定為主、運鏡 ≤2」同樣是**默認傾向而非鐵律**——若是長鏡壓迫 / 一鏡到底的調度（如整段跟隨人物穿行），**照做**。用戶批的是"**該動的時候不動**"，不是"鏡頭必須永遠靜止"。

### 病灶實證（粉絲稿 vs 本方稿 · 2026-10-13 定量）

同一量級的對話段，粉絲稿《白凰學院捉鬼師》與本方一分鐘四段稿對比：

| 指標 | 粉絲稿（30s 撞人段） | 本方稿（段2 · 15s 談判） | 差 |
|---|---|---|---|
| 鏡頭數 / 時長 | **8 鏡 / 30s** | 4 鏡 / 15s | 粉絲更密 |
| 平均鏡長 | **3.75s** | 3.75s | 持平 |
| **每鏡開口人次** | **部分鏡內 2 人交替（切鏡換嘴）** | **每鏡恆 1 人** | ★ 根因 |
| **單次發言字數** | **6~18 字（極短句來回）** | 8~25 字（長句成段） | ★ 根因 |
| **正反打頻率** | **高頻（切=換說話人）** | 低（切=換內容塊） | ★ 根因 |
| OS 內心獨白補位 | **有（2 處，零口型成本）** | 無 | 可抄 |

**根因定位（三條，全部在分鏡層、不在台詞層）**：
1. **「切」是按內容塊切的，不是按回合切的** —— 本方把"這句歸他、那句歸你"當作切點，切完還是同一個說話人續說；粉絲稿**每切一次就換一張嘴**。
2. **把「固定機位」誤讀成「不切鏡」** —— §四運鏡規則寫"文戲固定為主、運鏡 ≤2"，被誤執行成"一鏡到底慢慢說"。**固定機位 ≠ 不切鏡**：粉絲稿全程固定機位，但切得飛快。
3. **長台詞切鏡規則的觸發門檻過高** —— §四觸發條件是"台詞較長（超過兩三句）"，而**短句回合制對話根本不觸發**，導致一條本該管所有對話戲的規則只覆蓋了長台詞。

### 三條硬指標（**適用前提：本段是"該有來回"的對話戲** · 見上方總則）

> ⚠️ **本節三條是"默認傾向"，不是每段必套的模板。** 若本段劇情屬於**靜場對峙 / 宣判 / 留白 / 獨白 / 長鏡壓迫**（見上方總則表），**應在段落裡顯式標註「本段為靜場段 / 宣判段 / 留白段」，三條指標不適用**——這類戲**靠沉默和靜止更有力，切碎了反而毀掉**。
>
> ⚠️ **對話段全面豁免（2026-10-13 用戶裁定 · 與下列三條同時生效）**
>
> **正反打的標準形態就是「固定機位 + 切鏡換嘴」**——攝影機不動，靠切鏡換說話人（粉絲稿實測：全程固定機位，靠高頻切鏡做出來回）。因此**對話段內**以下判據**全部豁免**（機檢已實現）：
>
> | 被豁免的判據 | 原規則 | 豁免理由 |
> |---|---|---|
> | **C2 鏡頭數上限** | 段長 ÷ 3s（15s ≤5 鏡） | 放寬到 **÷2s**（15s ≤8 鏡）——5 鏡做不出回合制 |
> | **C2 單鏡下限** | ≥3s | 放寬到 **≥2s**——正反打實測 2s 一切 |
> | **C13 鏡長雷同** | 同值佔比 ≥70% 告警 | 回合制鏡長本就高度整齊（2s 一切是標準形態），非「機械等分」 |
> | **C18j 固定鏡過量 / 連排** | 固定 ≤10% / 禁連排 3 | 正反打就靠固定；若強求運鏡，會逼出「為動而動」的亂加運鏡 |
> | **C18k 運鏡覆蓋不足** | 段內 ≥4 種運鏡 | 同上——對話段不該為湊多樣性而加無敘事理由的運鏡 |
>
> **非對話段（空鏡 / 打鬥 / 轉場）以上判據照常生效。** 段落類型識別口徑見機檢 C27（含「對話/對白/文戲…」或 ≥2 條台詞 → 判對話段；分不清則不判）。
>
> ⛔ **豁免不等於放任**：對話段仍受本節三條指標 + C27b/c/d 約束。**豁免的是「鏡必須少、必須動」，不是「節奏可以呆」。** 反過來，**三條也不許把"該慢的戲"逼快**。

**① 回合制切鏡（Round-based cutting）**
**對話段的切鏡點 = 說話人切換點**，不是內容塊邊界。規則：
- **一次切鏡至少換一個變量**：換說話人 / 換景別檔 / 換機位角度 / 換主體（切聽者反應）——四者至少佔一；**只為"這句說完了"而切、其餘變量全不變 = 廢切**。
- **同一說話人連續佔據 ≥2 個完整鏡行 = 默認判"站樁式對話"、該段重切**（機檢 **C27d**）。**例外**：該段為刻意設計的**長獨白 / 宣判 / 靜場段**（已顯式標註）——此時允許一人獨佔，**但須在段內插入反應鏡、空鏡或聽他者反應打斷死寂**。
- **正反打基礎型**：A 說 → 切 B 反應/回嘴 → 切 A → 切 B。**一個來回至少 2 個切點**。
- ⛔ **本節只要求"該切的時候切"，不要求"任何時候都切"**——「為切而切」與「站樁不動」是**同一種病**（都不服務劇情）。

**② 開口密度參考值（對話段專用）**
按**對話段**（非空鏡段、非打鬥段）計量，**15 秒 ≥6 次開口**（每次開口 = 一次說話人張嘴，含 OS）：

> ⚠️ **這是"常見對話戲容易拍呆"的參考下限，不是"每段必須張嘴 6 次"的配額。** 劇情該慢的段落（靜場/宣判/留白）**不適用**，標註段落意圖即可。

| 段落類型 | 開口密度下限 | 說明 |
|---|---|---|
| **對話段（文戲核心）** | **15s ≥6 次**（≈2.5s 一次） | 含正反打、含 OS |
| 混合段（對話 + 行動） | 15s ≥3 次 | 行動本身佔時間 |
| **空鏡段 / 轉場段** | **不設下限**（可為 0） | 空鏡本就不需要台詞 |
| **打鬥段** | **不設下限**（可為 0~2 句） | 打鬥靠動作與音效，喊兩聲即可 |
| 獨白/宣判段 | 不設下限，但須 ≤1 人獨佔 | 刻意設計的長獨白 |

> ⚠️ **不是"為加而加"**：下限只對**對話段**生效。用戶原話：「我在空鏡的時候、在打鬥的時候肯定不需要台詞量呀，我可能就需要幾句話，但是**正常的台詞量這個要給別人補上**」。**空鏡/打戲不設下限，正是為了讓對話段敢寫滿。**

**③ OS 與短句化（密度來源）**
- **OS（內心獨白）是零口型成本的台詞來源**——不佔口型同步、不佔"誰在說話"的調度、可在任何鏡行疊加。**對話段每 15 秒至少考慮 1 處 OS 補位**（角色內心吐槽/判斷/糾錯）。
- **短句化**：單次發言**目標 ≤15 字**，超過 20 字的長句優先拆成兩次開口（中間插一個反應鏡或換嘴）。**"一句長台詞"改"兩次短開口" = 密度翻倍且更真實。**

### 內部自檢（不輸出 · 每個對話段過一遍）

1. 本段切鏡點，是否**每次切都換了說話人 / 景別 / 角度 / 主體**？有沒有"只換內容不換變量"的廢切？
2. 有沒有**同一人連續兩鏡開口**？有 → 必須打斷（插反應鏡/空鏡/換嘴）。
3. 本段開口次數是否達到**類型下限**（對話段 15s ≥6）？
4. 有沒有**超 20 字的長句**可以拆成兩短句 + 一次換嘴？
5. 有沒有可以加 **OS** 的位置（尤其是"心裡咯噔一下""這下完了""他又在演"這類）？
6. 本段是不是**空鏡/打鬥段**？是 → **下限不適用**，不要硬塞台詞。

答不上任一條 → 該段落重切重寫。

## 六、人物表演約束

**表演是畫面的靈魂**——情緒必須通過"可見的身體"外化，而非台詞直說、旁白解釋或面部誇張。畫面描述裡，人物"在做什麼"永遠比"是什麼情緒"更重要。

**剋制原則（情緒不過激）**：短劇表演最大的敵人是過火。情緒一律"藏七分露三分"——用剋制的動作暗示強情緒，勝過直接爆發。

- 禁止表情包式表演：五官扭曲、齜牙咧嘴、涕淚橫流的過度哭嚎、捶胸頓足。
- 爆發≠嘶吼：憤怒可以是一句壓低的聲音、一個攥緊的拳頭、一次緩慢的轉身，而非吼叫+摔東西。
- 悲傷≠大哭：可以是紅了眼眶卻別過臉、嚥下一口氣、手指無意識地摩挲某物。
- 驚訝≠瞪眼張嘴：可以是一次短暫的停頓、呼吸亂了半拍、手裡動作停住。
- 台詞之外的"人聲"同樣剋制：一次輕嘆、半聲哽咽、一下吸氣，比完整哭腔更動人。

**表演三通道（寫畫面內容時至少啟用一通道，重要情緒啟用兩通道）**：

1. **大動作層**——走位、坐立、轉身、遞物、靠近/後退、肢體佔位。承載關係變化與空間推進。
2. **小動作層（手部/物件）**——指節發白、拇指摩挲、轉筆、捏緊又鬆開、整理衣角、反覆開關打火機。承載內心暗湧，是最自然的外化。
3. **微表情層（面部/眼神/呼吸）**——瞳孔收縮、嘴角極輕微的抽動、喉結滾動、屏息、睫毛顫動、視線游移又移回、呼吸變淺。承載極細膩的情緒轉折。

**表演反規則**：強情緒反用"靜"更有力——真相揭曉時人物反而一動不動；崩潰前兆是突然的安靜與失神，而非立刻爆發。

**內部自檢（不輸出）**：每個含情緒的鏡頭自檢——(1) 情緒是否只靠台詞或形容詞傳達？(2) 是否寫成了誇張的面部表情？(3) 是否有具體、可見、自然的小動作或微表情外化？(4) 動作是否剋制（藏七露三）而非過火？

## 六·補、AIGC 假表演規避清單（廢鏡判據 · 2026-10-10 併入）

以下是 AI 視頻最常見的假表演——**出現即視為該鏡行需重寫**（本清單為**內部自檢用，不逐段輸出**）：

突然瞪眼 / 機械微笑 / 大幅點頭 / 頻繁搖頭 / 表情清零 / 五官同時用力 / 假哭 / 眼神亂飄 / 無意義甩頭 / 舞台劇式大動作 / 特寫裡身體動作過大 / 悲傷默認爆哭 / 憤怒默認吼叫 / 震驚默認張嘴瞪眼 / 心動默認傻笑 / 緊張默認誇張喘氣 / 對話時角色只輪流開口而無聽戲反應 / 鏡頭運動與演員動作同時過載。

**用法（三條）**：

1. **正向優先**——先通過具體的畫面與表演描述規避問題，不靠負面詞；
2. **負面約束只寫當前鏡頭最相關的 1–2 項**（如"不要假哭"），**不得每段機械堆長串負面詞**——堆負面詞會擠佔主體動作與情緒描述，對模型是噪音；
3. **與 §六 情緒反規則聯動**：情緒越強、外部動作越剋制（**除非劇本明確寫**崩潰 / 怒吼 / 痛哭 / 瘋狂 / 跪地 / 失控）。

## 七、複合運鏡

單一運鏡易顯單調，情緒重錘與關鍵動作段落應使用複合運鏡——兩種運鏡疊加，一次完成多任務。常見組合：推鏡+橫移（逼近同時展現場景）、升降+環繞（史詩揭示主體）、跟拍+微搖（跟隨中捕捉反應）、軌道+俯仰（精確構圖+垂直揭示）。複合運鏡不是堆疊炫技，必須服務於同一敘事目的，且仍需通過物理可行性檢查。複合運鏡中各單項仍受重技法頻率上限與場景空間禁令約束（如"升降+環繞"同時佔用兩個重技法名額），單場複合運鏡≤1次。表頭標註格式：`推鏡+橫移`。

## 八、銜接約束

**180°軸線規則**：對話/對峙場景中，機位必須始終在兩人連線的同一側，不允許越軸。正反打時A在畫面右看左，B必須在畫面左看右——視線相對。越軸例外（需有敘事理由）：刻意製造空間混亂、鏡頭運動自然越軸、中性鏡頭過渡。

**30°規則**：同一主體的兩個相鄰鏡頭，機位角度差必須≥30°（或焦段差異顯著），否則跳切。景別變化≥2級可彌補機位角度不足。正面與側45度切換天然滿足30°差，是正反打最順手的相鄰機位組合。

**景別跳躍規則**：相鄰鏡頭景別差≤3級為大原則。>3級時必須有過渡（插入中間景別、動作匹配/視線匹配/圖形匹配、音橋/視橋）。大景別直接切大特寫是極端手法，必須有強烈敘事理由。

**視線匹配**：上一鏡頭人物視線方向，必須在下一鏡頭落點得到回應。A看向畫面右→下一鏡B在畫面左。視線方向必須與180°軸線一致。

**運鏡節奏銜接**：上一鏡運動→下一鏡可以運動或固定（運動到靜止是合法的"句號"）；上一鏡固定→下一鏡突然快速運動會斷裂，必須有過渡。運動鏡頭接固定鏡頭作為"段落句號"，必須有情緒理由。

**音橋與視橋**：音橋——下一鏡頭聲音先於畫面切入；視橋——上一鏡視覺元素在下一鏡延續（圖形/顏色/動作匹配）。場景間轉場優先考慮音橋/視橋。場景內切換直接切鏡即可，不需要特效轉場。慎用淡入淡出/溶解。

## 八·補、鏡級狀態欄（前態 → 後態 · 2026-10-11 併入）

**寫法**（分鏡稿單鏡頭模板已增此欄，緊跟「畫面內容」）：

```

```

**觸發條件（條件必填）**：**本鏡發生狀態變化時必須寫**——起身/坐下/躺下、拿起/放下/遞交道具、換手持物、進出畫、穿脫披掛、受傷/血汙/衣物破損、門窗開合。**無狀態變化寫"—"**（靜態對話鏡不必硬填）。

**為什麼必須有這一欄**：AI **逐鏡生成、鏡與鏡之間沒有記憶**。上一鏡"已坐起"，下一鏡若只寫"她坐著說"，模型按字面渲染成坐姿——觀眾看到"坐起又躺回"的穿幫，**而稿面自身沒有矛盾，矛盾只存在於兩鏡之間**。狀態欄把這對前後態**放在同一行**，穿幫在出稿前就能被看見，不必等成片。

## 九、畫面內容約束

- **必須"看圖說話"**——不是寫文學描述，是寫屏幕上能看到什麼。拒絕"她感到悲傷"，改為"她眼眶泛紅，嘴角微顫，一滴淚從右眼滑落"。
- 不要寫"鏡頭給到""我們看到"這種元描述——直接描述畫面。
- 畫面描述必須包含：人物位置/姿態（引用場景錨點名稱）、光線方向（綁定光源錨點）、背景元素、關鍵細節。
- **★ 逐鏡畫面段最低三要素（2026-10-16 補強 · 治「畫面提示詞沒有背景描述」）**：每個鏡行的**畫面段**（＝`台詞：` 之前的部分）**必須同時出現**——① **人物位置/姿態**（綁場景錨點名）② **背景元素**（前景 / 背景**至少各一處**、且是**場景真實存在**的物件或環境行為）③ **光線方向**（**由段首【場景資產】「時段光影」基準繼承**，口徑見下方繼承條）。**缺即 WARN**（機檢 **C32**）。**不設鏡數下限**——畫面段缺背景是**逐鏡缺陷**，一鏡到底的單鏡段同樣適用（與 C18n/C18p 的"分佈類判據需大樣本"不同）。**豁免**：純空鏡（畫面段寫明「無人物」）/ 微距大特寫（材質或光線二者其一即可）/ 模板骨架行與佔位符行。
  - **病根**：本條此前**只有規則、沒有斷言**——機檢對"畫面段有沒有背景"零校驗，於是執行者只寫人物動作（`王路衝進來扶住陳薇胳膊，陳薇臉色慘白`），**背景全空**；模型只好自行補背景 → **每鏡背景不一致 = 跨鏡穿幫**，且不由人控制。**"只寫不檢 = 不生效"**（同 §一 特寫區間 2026-10-13 的歷史教訓）。
  - **正確寫法**：`陳薇背抵窗台、雙手摳著窗框，身後半拉的藍布簾被夜風掀起一角，冷綠月光從東窗硬切在她側臉上。`——位置（抵窗台）＋背景（藍布簾 / 夜風）＋光線（東窗冷綠）三要素齊備。
  - **豁免兩類**：① **純空鏡**（明確寫"無人物"的環境鏡——此時背景即主體）；② **微距特寫**（畫面本就是局部，只要求寫**材質與光線**，不要求"背景層次"）。
  - ⚠️ **③ 光線方向的繼承口徑（★ 2026-10-16 修正 · 與 `model-adapters.md` §5.0.5b「光影單一基準」對齊）**：段首【場景資產】已立「時段光影」基準時，**③ 由段級基準繼承、鏡行只寫增量**——此時逐鏡**只判 ②（背景元素）**；**段內未立基準**時才逐鏡要求 ②③ 齊備。**修正前本條與 §5.0.5b 互鎖夾殺**：照 §5.0.5b 寫（鏡行不加光線）會被 C32 逐鏡報"缺光線"，照本條寫又違背"鏡行只寫增量"、且每鏡複述主光會讓模型**逐鏡重新打光**（跨鏡光線不一致）——執行者無合規寫法。機檢 C32 已按本口徑實現（段級有基準 → 逐鏡只判背景）。
- 禁止模糊方位詞（"左邊""右邊""旁邊"），必須綁定錨點。
- 室內鏡頭必須說明光源來自哪個錨點。
- **畫面是進行中的瞬間，不是擺拍清單**。✅ "A正把茶杯往嘴邊送，熱氣糊了她的睫毛" / ❌ "A端著茶杯，看著鏡頭"。
- 多主體（3人及以上）場景必須聲明視覺中心：`視覺中心是X，其餘元素為襯托X的環境層。`
- 純場景（無人物）寫材質、天氣、時間、環境行為，不要憑空造角色。
- 畫面細節必須服務主體或情緒，不允許"為細節而細節"的填充。
- 非人物鏡頭必須明確寫出"無人物"或"局部肢體不露臉"，並說明承載什麼情緒/信息。
- 非人物鏡頭若有台詞，標註"畫外音延續"。
- **畫面層次豐富度**：畫面內容應具備前景/中景/背景的層次，禁止"主體貼白牆"的單薄構圖。前景可用場景真實存在的物件或人物局部做框架，背景要有環境行為（走動的人、飄動的簾、轉動的風扇）讓畫面"活著"。層次必須來自場景真實元素，禁止憑空加道具。
- **表演細節進畫**：情緒通過具體動作與微表情外化寫入畫面（見本文件"人物表演約束"），禁止用抽象情緒詞代替。每個含情緒的鏡頭至少寫一個可見的表演細節。

## 十、音頻約束

- **嚴禁背景音樂（BGM）**：分鏡稿全片不添加任何背景音樂、配樂、氛圍音樂。說明——BGM 屬總控管線後期聲音設計範疇（sd-qc-engine `sound-design-template.md`），分鏡稿層嚴禁混入，兩層不衝突。
- 僅使用音效（SFX）和人聲。
- 每個鏡頭區分兩類：
  - **音效**：環境聲和動作音（風聲、腳步聲、門吱呀聲、杯子放桌聲等）。
  - **人聲**：台詞之外的表演性人聲（喘息、抽泣、輕笑、嘆氣等）。
- 音效和人聲分別標註，不能混在一起寫。
- 安靜不等於加BGM——安靜就是安靜，用環境底噪即可。
- 若有音橋（聲音先於畫面切入或畫面延續到下一鏡聲音），在音頻字段標註"音橋入/音橋出"。
