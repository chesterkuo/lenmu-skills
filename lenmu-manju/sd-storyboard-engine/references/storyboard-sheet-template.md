## 〇、先劃清：本文件管的是"故事板圖"，不是另外三樣東西

本包此前**有四種容易與"故事板"混淆的產物**，必須先區分，否則一定會做重、做歪：

| 產物 | 是什麼 | 形態 | 歸屬 |
|---|---|---|---|
| **文字分鏡** | 逐鏡的文字鏡頭序列（景別/焦段/機位/運鏡） | Markdown 文本 | `sd-storyboard-engine/SKILL.md` |
| **五宮格場景圖** | **純場景** 3×3（多機位/多子區域），**畫面禁人物** | 生圖提示詞 → 1 張圖 | `sd-asset-engine/references/scene-grid-template.md` |
| **分鏡看板** | md → 單文件離線 **HTML**，雙擊即開，供人查看 | HTML 文件 | `short-drama-director/references/storyboard-board-lite.md` |
| **15 格動作 PREVIS** | **打戲**專用 15 格動作預演 | 生圖/預演 | `sd-combat-engine/` |
| **★ 故事板圖（本文件）** | **帶人物 + 帶動作相位 + 帶鏡頭信息**的多面板圖，**每段一張**，作為**視頻生成的視覺依據** | 生圖提示詞 → 1 張圖（含 N 個面板） | **本文件** |

**一句話**：九宮格管**場景長相**（無人），故事板管**這場戲怎麼演**（有人、有動作相位、有鏡頭）。

> ⚠️ **「四宮格」歧義提醒（2026-10-11）**：用戶說「**四宮格故事板**」= **本文件**管轄的 **2×2 四面板故事板圖**（**一段**的 4 個動作相位：起始/過程/反應/出口）；說「**四宮格推演 / 劇情分鏡格 / 推演宮格**」= `plot-deduction-grid.md` 管轄的 **2×2 四格劇情推演圖**（**一場**戲的 4 個敘事瞬間）。**同名不同物；用戶說不清就兩件都出。**

## 一、六條硬規則（先記這六條）

| # | 規則 | 說明 |
|---|---|---|
| **1** | **每段一張** | 以**段**（投餵的生成單元，≤15 秒或按 D 鎖段縫切成的一個單元）為單位，**一段出一張故事板圖**。跨段共用同一張＝違反（每段動作相位不同）。 |
| **2** | **格數由動作複雜度決定，不機械九宮格** | 3 格、5 格、6 格、8 格都可以；**動作複雜就多拆格，文戲靜態就少拆格**。**禁止為了版式好看強行湊 9 格**（這是本文件與九宮格的本質區別）。 |
| **3** | **面板邊界 ≠ 剪輯點** | 一個面板 = 一個**動作相位**，不是一個鏡頭。**面板變多不意味著要切鏡**；切不切由導演稿的鏡頭策略模式決定（見 §七）。 |
| **4** | **面板必須能回溯到導演稿** | 每格的面板 ID、站位、動作相位，必須能在導演稿（`short-drama-director/references/blocking-direction.md`）與文字分鏡裡找到對應項；**不允許故事板自行新造動作或鏡頭**。 |
| **5** | **版式與格數下限（★2026-10-22 修正：「下限」已廢止，格數改為 = 該段鏡數）** | **格數 = 該段鏡數，不設固定值**：一段有幾鏡就幾格，4/6/9/12 格都正常。**版式是排版結果、不是格數來源**：4 格→**2×2 四宮格**、5 格→單行 5 或 2+3、6 格→**2×3 六宮格**、8 格→2×4、9 格→3×3、12 格→3×4。⛔ 禁止把"文戲 4 格"當作硬性下限去砍鏡——下限與鏡數衝突時，**永遠是格數服從鏡數**；確需合併時用 `〔鏡K+M〕` 並在段首寫理由。（舊口徑「文戲 4 格起 / 打戲 6 格起」廢止） |
| **6** | **交付清單必列（禁靜默跳過）** | P3 收尾必須逐段在交付清單寫「**故事板圖：段N ✅ {格數}({版式}) / ⛔豁免（理由）**」；**不列清單又沒出、或只寫「略/同上/按需」= P3 未完成，禁止進 P4**；用戶點名要時**必出、不適用豁免**。 |

## 二、面板鏈：一張圖裡裝什麼

```
【故事板圖 · 段{n}】 場景 SCN-{編號} · 模型 {A鎖} · 畫幅 {B鎖} · 面板數 {N}
  面板 1  [起始]  鏡1 · 中景 · 起勢    @A（北窗下·朝南·垂手）        ← 見 §四 入口幀
  面板 2  [過程]  鏡1 · 中景 · 拔劍    @A（重心前壓·右手上抬）
  面板 3  [接觸]  鏡1 · 中近景 · 交擊  @A⇄@B（雙劍相交·衣襬外翻）
  面板 4  [頂點]  鏡2 · 近景 · 極限    @B（被壓至櫃檯角·後仰）
  面板 5  [結果]  鏡2 · 小全景 · 落定  @B 撞翻酒罈 · 道具瓶碎
  面板 6  [反應]  鏡3 · 全景 · 接收    @C（門口·驚愕後退半步）
  面板 7  [出口]  鏡3 · 中景 · 承接    @A 收劍側立（左A右B·未越軸）   ← 見 §四 出口幀
```

**每格必帶 5 項**（缺項＝該格沒做完）：

| 項 | 內容 |
|---|---|
| **面板 ID** | `段{n}-P{k}`，連續編號，不跳號 |
| **動作相位** | 見 §三 七態之一 |
| **鏡頭信息** | 景別 + 機位角度（由文字分鏡給出，故事板只搬運不新造） |
| **站位與視線** | 人物在本格的座標 + 朝向 + 視線落點（由導演稿給出） |
| **資產引用** | 用到的人物/場景/道具對應的「圖N」編號（**P4 投餵層據此寫三族行內錨點 `@CHR-` / `@SCN-` / `@PRP-`——道具與場景並列在【場景資產】欄**；本層是"圖N 編號"，投餵層是"`@` 錨點"，兩套並存的換算見 `model-adapters.md` §5） |

## 三、action_phase 七態（動作拆格的唯一依據）

| 相位 | 含義 | 拆格建議 |
|---|---|---|
| `起始` START | 動作開始前的穩定狀態（也是本段的**入口幀**） | 必出（1 格） |
| `過程` PROCESS | 動作進行中，可見的中間過程 | 動作複雜時 1~2 格 |
| `接觸` CONTACT | 動作落到對象/物上（打擊、抓握、推開、遞交） | **有接觸必出** |
| `頂點` APEX | 最大幅度 / 最強張力的一瞬 | **必出**（打戲高潮） |
| `結果` RESULT | 受力/位移的結果狀態（摔倒、破碎、移位） | 有結果必出 |
| `反應` REACTION | 受影響對象的可見反應 | 有第三方必出 |
| `出口` EXIT | 段末穩定狀態（也是**出口幀**，下段的入口） | 必出（1 格） |

**文戲最小集**：`起始 → 過程 → 反應 → 出口`（4 格）；
**打戲最小集**：`起始 → 過程 → 接觸 → 頂點 → 結果 → 出口`（6 格起）。

## 四、出入口幀繼承（跨段不穿幫的關鍵）

**鐵律**：**本段的【出口】面板 = 下段的【起始】面板**（畫面狀態必須一致）。

- **入口幀**：本段第 1 格必須**繼承上一段的出口**——人物位置、手位、道具狀態、光影、軸線、姿態連續；
- **出口幀**必須寫全六項：`人物 / 手位 / 道具狀態 / 光影 / 軸線 / 未完成動作`；
- 段與段是**獨立生成的剪輯關係**（見 `short-drama-director/references/asset-spatial-ledger.md` §三·6 跨段蒙太奇默認）：**跨段切、同段連**——跨段用蒙太奇直切時，出口幀只需寫明兩端畫面；**同段內**才要求嚴格走位繼承。

## 五、兩版輸出：CLEAN_GRID 與 TECHNICAL_ANNOTATED

| 版本 | 用途 | 內容 | 必出？ |
|---|---|---|---|
| **`CLEAN_GRID` 乾淨版** | **實際生圖用**（這是"標準性的圖"） | **無任何文字**：無面板序號、無對白框、無箭頭、無技術標籤、無水印；純畫面 + 留白分隔 | ✅ **必出** |
| **`TECHNICAL_ANNOTATED` 標註版** | **給團隊看**（溝通用） | 可用**短英文標籤**（`P3 CONTACT`）+ **圖外中文批註**（圖下留白區寫導演說明）；**不依賴模型生成長文字** | 可選 |

**硬規則**：

1. **乾淨版嚴禁文字**——模型生成的"畫面內文字"必然糊成偽文字，且會汙染參考圖；
2. **標註版不進投餵**——標註版只用於人工溝通，**不得作為視頻生成的參考圖**；
3. 兩版**共用同一套面板結構**（格數與內容一致），只是標註層有無之別。

## 七、面板邊界 ≠ 剪輯點（最容易被誤讀的一條）

**這是必須寫進產物說明的一句話**：

> 故事板的面板表示**動作相位**，**不表示剪輯**。面板變多 ≠ 要多切鏡；面板只有 4 格 ≠ 只能 4 鏡。

對應關係由導演稿的**鏡頭策略模式**決定（權威在 `sd-qc-engine/references/editing-transition-gate.md` §一）：

| 鏡頭策略模式 | 故事板的面板邊界意味著什麼 |
|---|---|
| `TRUE_ONE_TAKE` | 所有面板**同屬一個鏡頭**，面板之間**不得暗示反打/插入/切鏡** |
| `SIMULATED_ONE_TAKE` | 只有導演批准的**隱藏縫**位置可以成為面板斷點，其餘同樣不切 |
| `CUT_COVERAGE` | 面板斷點**可**對應切點，但切點必須來自導演的 `cut_directives` / `allowed_cut_windows` |
| `HYBRID` | 不可切段按長鏡頭規則，其餘按切鏡規則 |

**禁令**：**不得用"多畫一格面板"來暗示未獲授權的反打、插入或切鏡**——故事板是**執行稿**，不是**再創作**。

## 八、與投餵層的交接：按故事板生成視頻

故事板圖的**用途是驅動 P4 投餵**，交接方式有三條：

1. **面板 → 鏡行**：故事板的每一格，對應投餵稿【時間軸分鏡】裡的鏡行內容（動作相位 + 站位 + 視線），**逐格落進鏡行**，**一格都不許漏**（漏格＝該動作相位在成片裡不存在）；
2. **故事板圖 → 參考素材**：`CLEAN_GRID` 故事板圖**可作為參考圖入冊**（登記《資產圖冊》，編號 `圖{STB}-{n}`），在投餵時按官方語法標註用途；
   - ⚠️ **參考圖數量紅線**：Seedance 2.5 參考素材上限 30 張、2.0 圖 ≤9（見 `short-drama-director/references/model-adapters.md` §5）——故事板圖**按段入冊**，**不是每鏡一張**，入冊前先算總量；
   - ⚠️ **2.5 / 2.0 差異**：`first_frame`/`last_frame` **僅限 Seedance 2.5**；2.0 參考圖**僅用於鎖定形象**，不得當首尾幀用；
3. **出口幀 → 跨段接力**：故事板的出口幀，作為 D 鎖段縫**畫面鎖**的依據（末幀截圖優先；【接續狀態】文字腿 2026-10-09 廢止）（見 `short-drama-director/references/segment-splicing.md` §二 §三）。

## 十一、SHOT_TEXT 卡版式（分鏡線稿卡 · 2026-10-09 增補）

> 形態樣張：用戶提供的實拍式分鏡預演卡——**頂部俯視走位平面圖（機位+軌跡+圖例）+ 下方逐鏡卡（線稿畫面 + 攝影參數 + 台詞逐句 + 攝影調度段）**。
> **定位**：給人看的**預演/溝通件**（導演自查、團隊交接、甲方過目），是 §五 CLEAN_GRID（給生圖）與 §六·2 標註版（圖外批註）之外的**第三種形態**——**不進投餵、不作生圖參考圖**（線稿畫風會汙染視頻模型的風格參考）。

### 11.1 三形態分工（防止做混）

| 形態 | 一格 = 什麼 | 誰看 | 進投餵/入冊？ |
|---|---|---|---|
| CLEAN_GRID 故事板圖（§五） | 一個**動作相位** | 生圖模型 | ✅ 圖可用作參考素材 |
| 標註版（§五） | 動作相位 + 圖外批註 | 團隊 | ❌ |
| **★ SHOT_TEXT 卡（本節）** | **一整鏡**（線稿 + 參數 + 台詞 + 調度） | 人（預演） | ❌ |

### 11.2 兩個部件

**部件① 俯視走位平面圖（每段一張，置頂）**：

| 要素 | 要求 | 數據來源（搬運，禁新造） |
|---|---|---|
| 底圖 | 該場景的**鳥瞰線稿**（鉛筆稿質感，同場景資產 圖{SCN} 的空間結構） | 導演稿平面圖（`blocking-direction.md`）——**同一座標系、同一方位稱謂、逐字同源** |
| 攝像機位 | 按鏡號擺位（機位圖標 + 鏡號），移動鏡畫軌跡箭頭 | 文字分鏡的機位/運鏡列 |
| 角色走位 | **逐角色一色**的虛線箭頭（起點→終點） | 導演稿走位路徑 |
| 圖例框 | **必須出**：人物名→顏色 / 攝像機 / 攝像機移動 / 角色走位 四類 | — |

**部件② 逐鏡卡（每鏡一張，縱列）**——五要素：

1. **線稿畫面**：該鏡**起始構圖**的鉛筆線稿（人物可留面部細節簡化，構圖/站位/視線必須與分鏡表一致）；
2. **參數行**：景別 · 角度 · 運鏡｜鏡頭焦段（由 A 鎖/導演稿搬運；2.0 無機型綁定則寫「等效焦段」）｜**機長**（時碼，**逐字取自投餵稿鏡行**）；
3. **台詞逐句**：`角色名：台詞`——**從上游劇本搬運，零改動零刪減**（台詞完整性對照的基線紅線）；
4. **攝影調度段**：誰從哪走到哪、視線落點、動作細節、焦點變化——從導演稿與分鏡表搬運；
5. **卡 ID**：`段{n}-S{k}`（注意與相位面板 `段{n}-P{k}` 區分：S=鏡，P=相位）。

### 11.3 文字怎麼進圖（工程口徑，二選一）

1. **主推 · 圖模分工**（同 §五「中文批註圖外疊加」紀律）：模型只生成**無文字線稿**（部件①底圖 + 部件②畫面格），參數/台詞/調度/圖例由**排版工具圖外疊加**——零偽文字風險；
2. **備選 · 整卡直出**：接受模型渲染中文的錯字風險（適合快預演，不適合交付）。

### 11.4 出圖提示詞模板（圖模分工 · 主推）

**部件① 俯視圖**：

```text
生成一張 16:9 橫版鉛稿線稿俯視圖，畫的是 {場景名}（與 圖{SCN} 空間結構完全一致），鉛筆線稿質感、無上色、無渲染、無任何文字。
圖中以小矩形圖標標出 {N} 個攝影機位，旁標鏡號①~{N}；{移動鏡}的機位畫黃色虛線箭頭表示移動軌跡。
角色走位：{@A角色名}畫{色A}色虛線箭頭（從{起點座標}到{終點座標}），{@B角色名}畫{色B}色虛線箭頭（{路徑}）。
禁止：上色、渲染、文字、水印、多餘人物。
```
> 圖例框由排版疊加（圖模分工）；走位座標稱謂**逐字取自導演稿平面圖**。

**部件② 逐鏡畫面格**：

```text
生成一張 16:9 橫版鉛稿線稿分鏡畫面，鉛筆線稿質感、無上色、無任何文字。
{景別 · 焦段 · 角度}。{場景一句話，與 圖{SCN} 一致}。@A（{座標·朝向·姿態}）{本鏡起始動作}；@B（{位置}）。
構圖要求：{視線落點 / 光位方向（只標明暗素描關係，不上色）}。
禁止：上色、文字、字幕、水印、未點名人物。
```

### 11.5 硬規則

1. **搬運不新造**（同 §一規則4）：機位、走位、台詞、時碼任何一處與導演稿/分鏡表/投餵稿矛盾 = 廢卡重出；
2. **不進投餵、不入《資產圖冊》**：SHOT_TEXT 卡登記在項目主文件的「預演件」欄即可，**不佔素材槽**；
3. **台詞零改動**：逐句照抄上游劇本，一個字都不能動；
4. **時碼逐字同源**：機長列 = 投餵稿【時間軸分鏡】鏡行時碼；
5. **不必全劇都出**：與 §九同口徑——跨 2 鏡以上敘事段/打戲段/重場戲建議出，單鏡過場段可跳過。

## 十二、分鏡變更後的「故事板重出」紀律（★ 2026-10-20 實戰回寫）

> **由來**：一集 6 段 24 鏡，分鏡在四輪返工中改了台詞與鏡序，故事板**只被人手改了其中一句**就交付了。用戶翻完發現：段1 第 3 格還停在「窗外冰封大遠景」（分鏡早已改成「抬眼望監控屏」），第 6 段第 3 格還寫著「雙唇抿緊」（那一鏡她正在說台詞）。用戶原話：「你故事版改沒改？你故事版裡面不是還之前老的東西嗎？」

### 12.1 鐵律：分鏡動過，故事板**整份重出**，不許補丁式改字

| 上游改動 | 故事板必須做什麼 |
|---|---|
| 只改台詞內容（鏡頭不變） | 改該格「口型狀態」，**其餘不動** |
| 改鏡序 / 換鏡 / 增刪鏡 | **整份重出**——相位標號（起始/過程/反應/出口）與鏡號綁定，牽一髮動全身 |
| 改景別 / 角度 / 運鏡 | **整份重出**——格頭是從分鏡搬運的，搬運不許手抄 |
| 改站位 / 視線 / 軸線 | 重出，並複核出口幀六項 |

**禁止**：目檢式比對。人眼看不出「大遠景 vs 中景·變焦」這種差異，必須跑腳本（12.3）。

### 12.2 格序 = 鏡序（本包默認口徑）

- **1 格 1 鏡**：4 鏡段 → 4 格，第 N 格必須取第 N 鏡的關鍵幀。**不許按「起始/過程/反應/出口」重新分配鏡頭**（那會讓格與鏡錯位，出圖後無法回查分鏡）。
- 相位名**並列**寫在格頭：`面板 3（反應 · 鏡3）`——**相位是標籤，鏡號是身份**。
- 段內鏡數與格數不等時（3 鏡或 6 鏡），按 §一規則5 的下限補齊/拆細，並在格頭寫明「鏡X 的 A/B 兩瞬」。

### 12.3 逐鏡檢查（新增 · 出圖前必跑）

```python
# 比對：分鏡鏡行的「景別 · 視角 · 運鏡」 vs 故事板格頭，逐條相等
import io, re
md = io.open("<交付稿>.md", encoding="utf-8").read()
sb = io.open("<故事板文件>.md", encoding="utf-8").read()
shots  = [l.split("]",1)[1].strip().split("。")[0]
          for l in md.split("\n") if l.startswith("00:") and "[鏡頭" in l]
panels = re.findall(r"面板 \d（[^）]*· 鏡\d）：([^。]*)。", sb)
assert len(shots) == len(panels), (len(shots), len(panels))
bad = [(i+1,a,b) for i,(a,b) in enumerate(zip(shots,panels)) if a != b]
print("不一致：", len(bad)); [print(x) for x in bad]
```

**合格線**：`不一致 = 0`，且 `鏡數 == 格數`。

### 12.4 口型紀律（對白密集型項目必加）

台詞密度高的集（≥4 字/秒），故事板必須逐格標註口型狀態，否則模型會畫一排「安靜凝視鏡頭」的人，用戶拿到圖分不清誰在說話。

| 該格情況 | 格內必須寫 |
|---|---|
| 這一鏡有人開口說話 | `嘴唇張著在說話`（畫外對白則寫 `嘴唇閉合`） |
| 這一鏡無人說話 | `嘴唇閉合` |
| 該格是空鏡/純物特寫 | `本面板為純…特寫，畫面內無人物` |

> **圖內仍零文字**：口型狀態是**提示詞側**的說明，不是要渲染到圖上的標籤。圖上依舊不出現任何文字。

### 12.5 與主稿交付清單的聯動

主稿 `## P3 圖形化交付清單` 的「四格覆蓋」列，須與故事板**同步改寫為「鏡N 內容」的格式**（例：`鏡1 門板被砸凹（空鏡）/ 鏡2 後拉進客廳…`）。該表是人工目檢的唯一入口——表錯了，後面所有核對都是錯的。
