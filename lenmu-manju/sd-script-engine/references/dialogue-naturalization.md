## 一、 稱呼系統（★ 本包空白 · 最高優先）

> **背景**：這是用戶最直接的訴求（"增加點擬人的稱呼，更加口語化"）。在本引擎建立之前，全包"稱呼系統"僅出現 **1 次**（`six-stage-pipeline.md:419` 人物聲音卡里的一個字段名），**沒有任何定義、變體、示例或台賬**。本節補此空白。

### 1.1 稱呼不是"一個詞"，是四個變量的函數

任何一個稱呼 = **身份軸 × 關係軸 × 場合軸 × 情緒軸**。四者任一變化，稱呼就該變化。

| 變量 | 取值示例 |
|---|---|
| **身份軸** | 尊/平/卑（決定敬語層級）、職業、年齡差 |
| **關係軸** | 生疏 / 熟識 / 親密 / 決裂 / 舊情 / 上下級 |
| **場合軸** | 公開（有第三方在場）/ 私密 |
| **情緒軸** | 平靜 / 動情 / 惱火 / 示弱 / 挑釁 |

**機械化最典型的症狀之一**：全劇用同一個稱呼——不管什麼場合、什麼情緒、關係走到哪一步，永遠"李總""少爺""師父"。**那不是簡潔，是沒寫。**

### 1.2 稱呼變體矩陣（對同一對象的七種叫法）

以「一個角色對另一個角色」為行，示範四軸變化：

| 情境 | 該用什麼 | 現代都市示例 | 古裝示例 |
|---|---|---|---|
| **公開·正式·尊** | 職務/尊稱全稱 | "陳總監" | "陳大人""陳將軍" |
| **私下·熟識** | 簡省稱呼 | "老陳" | "陳兄""老爺" |
| **親密/動情** | 暱稱、去姓、加小稱 | "陳默""阿默" | "阿默""默郎" |
| **示弱/求人** | 升格敬稱（故意拉開或拉近） | "陳總，您看……" | "大人，小人斗膽……" |
| **惱火/決裂** | 降格、直呼全名、去敬語 | "陳默！"（連名帶姓） | "陳默！"（喝名） |
| **挑釁/敵意** | 貶稱、外號、反諷敬稱 | "陳大總監"（諷） | "陳大人好大的官威" |
| **劃清界線** | 退回生疏稱呼 | 從"老陳"退回"陳總監" | 從"兄"退回"大人" |

> **寫作提示**：**稱呼的"降格"和"退回"比"升格"更有戲**。關係破裂時，一句從"老陳"切回"陳總監"，比寫一句"我們完了"更有力——因為觀眾能直接聽出來。

### 1.3 三條鐵律

1. **一致性鐵律**：同一角色對同一對象，**在同一關係階段的稱呼必須穩定**，跨集不得漂移。要變，必須有**事件觸發**並在台賬登記。
2. **稱呼是"體溫計"，不是"推進器"**（與 `episode-planning.md:456` 一致）：
   > 關係弧必須通過共同經歷、試探、保護、背叛、拒絕或修復推進。**不能只用稱呼變化或旁白宣佈關係升級。**
   稱呼變化**只能反映**關係狀態，**不能替代**事件。只改稱呼不改行為 = 無效推進，標記 `ADDRESS_ONLY_SHIFT`。
3. **稱呼要有區分度**：兩個不同角色對**同一個**對象，稱呼應不同（一個叫"爸"，一個叫"老李"，一個叫"李隊"）——這是**關係位置的免費標記**。

### 1.4 產出物：`ADDRESS_LEDGER`（稱呼台賬 · 階段⑤ 硬產出）

階段③ 建卡時填寫"初始關係"，階段⑤ 逐集更新"稱呼狀態"：

```yaml
ADDRESS_LEDGER:
  - speaker: "沈硯"        # 說話人
    target: "陳默"         # 被稱呼者
    relation_stage: "初識/生疏"       # 關係階段
    address_now: "陳先生"              # 本階段用的稱呼
    history:                           # 變化軌跡（必須每次都有觸發事件）
      - episode: "EP003"
        address: "陳先生"
        trigger: "初次見面，公開場合"
      - episode: "EP011"
        address: "老陳"
        trigger: "共同熬過危局，私下交談"
    forbidden: ["陳總"]                # 本關係階段絕不該出現的稱呼（防穿越）
```

**過站檢查**：逐集比對 `address_now` 與上集是否一致；不一致則必須有 `trigger`。
**機檢**：`ADDRESS_LEDGER` 存在性 → 見 §八。

## 二、 書面語 → 口語（★ 先分題材，口徑不同）

### 2.1 ⚠️ 關鍵前提：古裝和現代，"書面"不是同一個東西

| 題材 | 什麼算"機械化" | 什麼**不算** |
|---|---|---|
| **現代/都市/懸疑** | 書面連接詞、公文腔、完整長句、被動句 | 日常口語詞、語氣詞、半截話 |
| **古裝/年代** | **現代書面語混入**（"經濟損失""邏輯漏洞""情緒價值"） | **文言簡煉是風格，不是病灶** |

> **⛔ 最容易犯的錯**：拿現代口語標準去改古裝台詞，把"臣不敢"改成"我不敢啦"。
> `dialogue-doctor-7d.md:14` 的病灶定義是**"古裝戲冒出現代詞"**——**不是"古裝戲不夠口語"**。

### 2.2 現代賽道：絕對禁用表（A 類 · 出現即標記）

以下虛詞在**現代劇的口語台詞**裡不會出現，出現即為書面腔洩漏：

```
是否   因此   從而   鑑於   予以   加以   可否   何以
頗為   甚為   以及   然而   由於   進行   予以   茲
```

> **判定口徑**：只查**台詞文本**內，不查畫面段/敘述段（古裝劇本的場景描述可以用書面語）。
> **替換示例**：`是否 → 是不是`｜`因此 → 所以/這麼說`｜`以及 → 還有`｜`由於 → 因為`｜`進行 + 名詞 → 直接用動詞`（"進行了一次檢查"→"查了一遍"）

### 2.3 古裝賽道：違和現代詞表（B 類 · 出現即標記）

```
邏輯   數據   機制   效率   系統   項目   團隊   版本   反饋   狀態
維度   定位   復盤   閉環   賦能   抓手   顆粒度   情緒價值   經濟損失
溝通   心理   壓力   節奏（作抽象義時）   關係（作抽象義時）
```

> 依據 `dialogue-doctor-7d.md:14`「古裝戲冒出'經濟損失/邏輯漏洞'等現代詞」。
> **邊界**：`節奏`/`關係` 等詞在古裝裡**作具體義**（"擊鼓的節奏""父子關係"）可用，只有**現代抽象義**違和——判定看語境，不只看詞。

### 2.4 通用：長句拆解（句式層）

機械化的第三種形態是**句法**，不是詞彙：

| 症狀 | 處方 |
|---|---|
| 成對關聯詞（"因為……所以……"、"雖然……但是……"） | 口語裡**後半截常常不說**——"因為下雨了"後面直接接行動 |
| 完整主謂賓、無一處省略 | **刪主語**（口語大量省略："吃了嗎？""早說啊"） |
| 被動句（"被……所……"） | 改主動 |
| 一句話說完才停 | **插入停頓點**（逗號/破折號/省略號至少一處） |

## 三、 「撒碎屑」四法（把書面句掰成人話）

> **來源**：`short-drama-director/references/acting-direction.md:267` 壞表演圖鑑第 8 條「**台詞太乾淨**——街頭角色說著書面長句 → **撒碎屑：打斷、掉尾、重複**」。
> ⚠️ **標註紀律**：`acting-direction.md` 頭部聲明其示範句均為 `【待驗證·未實拍】`（來源為粉絲投稿、本包未實拍驗證）。**本節把原來的 6 個字展開為可執行手法**，示範句因此同樣標 `【待驗證·未實拍】`，**不得寫成 ✅ 正例、不得進機檢修復建議文案**。

### 3.1 打斷（自己打斷自己）

人說話會改口、會推翻自己半句。

- ❌ "我本來是想告訴你這件事的，但後來我覺得還是不要說了。"

**用法**：用於**猶豫、隱瞞、動搖**的人物狀態。**不宜每場都用**（誰老改口誰就像結巴）。

### 3.2 掉尾（說一半不說了）

把關鍵信息**留在沉默裡**，由對方的反應補齊。

- ❌ "你要是敢動她一根頭髮，我絕對不會放過你。"

**用法**：**威脅、訣別、說不出口的告白**。與 §六 的"金句留白"配合。

### 3.3 重複（口吃式重複 / 回聲）

- ❌ "你說什麼？我沒聽清。"

**用法**：**受衝擊、難以置信、慌亂**。重複**只重複關鍵詞**，不要重複整句。

### 3.4 語氣詞與墊詞（★ 機械化最有效的解藥）

書面句最明顯的特徵就是**一個語氣詞都沒有**。中文口語的顆粒感大量來自句尾助詞與墊詞：

| 類別 | 詞 | 功能 |
|---|---|---|
| 句尾助詞 | 啊 吧 呢 嘛 唄 啦 呀 哦 咯 罷了 而已 | 緩和/確認/反問/無所謂 |
| 前置墊詞 | 那什麼 這個 我說 你聽我說 得了 行吧 | 起話頭/爭取時間 |
| 應答詞 | 嗯 唉 哎 嘿 喲 嘖 | 情緒色彩 |
| 程度墊詞 | 特別 賊 巨 超 老（老遠了） | 替代"非常/十分" |

**反例**（禁）：
- ❌ "我知道了，你不用擔心。"——書面腔，無口語墊詞、無句尾助詞

### 3.5 借物說話 / 答非所問（潛台詞通道）

用**手邊的東西**代替直接表態——這也是七維維度2「潛台詞層級」的落地手法。

- ❌（拒絕表白）"對不起，我不能接受你的感情。"

與 `dialogue-doctor-7d.md:12` 的示例「茶涼了，換杯熱的再上路吧」同源。

## 四、 機械化認症表（反例庫）

> 用途：**寫完以後掃一遍**，命中即改。這是"體檢"側，與 §三 的"生成"側配對使用。

| # | 症狀 | 表現 | 處方 |
|---|---|---|---|
| 1 | **等長句** | 每句字數接近、結構一致 | 長短交錯；長句後必接短句 |
| 2 | **零語氣詞** | 整段對話沒有一個"啊/吧/呢/嘛" | 按 §三·4 補（注意場合） |
| 3 | **全完整句** | 每句主謂賓齊全、無人省略 | 刪主語、掉尾、打斷 |
| 4 | **人人同口吻** | 把角色名遮住認不出誰在說 | 建**角色特徵詞表**（每人 3~5 個專屬用詞） |
| 5 | **信息均勻分配** | 像輪流念資料，你一句我一句對等 | 製造**信息差**：一方知道得多，一方在猜 |
| 6 | **說明式對白** | 向觀眾交代背景（"我是你師兄，當年……"） | 改為動作/反應呈現（七維維度5） |
| 7 | **書面連接詞** | "因此""是否""以及" | 查 §二 禁用表 |
| 8 | **情緒結果詞** | "我很憤怒""他很傷心" | 情緒用行為和潛台詞體現，不直說 |
| 9 | **全員敬語/全員粗口** | 無差別禮貌或表演型粗野 | 按身份軸分層（§1.1） |
| 10 | **復讀** | 同一句台詞在相鄰集原樣重複 | 見 `six-stage-pipeline.md` `KEY_LINE_OVERUSE` |

## 五、 同口吻識別法（自檢工具）

寫完一場戲，做三個測試：

| 測試 | 做法 | 判定 |
|---|---|---|
| **遮擋名測試** | 把角色名遮住，只看台詞 | 認不出誰在說 → **不合格**（七維維度1 紅線） |
| **句長方差測試** | 統計同一角色連續 5 句的字數 | 標準差 < 2 字 → 語境單一，考慮長短交錯 |
| **專屬詞測試** | 每角色列出 3~5 個"只有他會用"的詞 | 列不出 → 角色沒立住 |

> 與 `story-bible-and-ip.md` §1.8 `PERFORMANCE_AND_VOICE` 的"角色語言指紋"呼應——**特徵詞要落進聲音卡，不能只停在腦子裡**。

## 六、 台詞擬人化過站（執行流程 · 階段⑤硬產出）

### 6.1 觸發時機

**階段⑤ 逐集十道主編工序 · 第 8 道「台詞改寫」之前**（`six-stage-pipeline.md` §6.9 第 8 條）。

### 6.2 四步過站

| 步 | 動作 | 產出 |
|---|---|---|
| **1** | **讀台賬**：調出 `ADDRESS_LEDGER`（§1.4）+ 各角色 `PERFORMANCE_AND_VOICE`（§1.8） | — |
| **2** | **逐句診斷**：按 §四 認症表掃全篇 | 問題句清單 |
| **3** | **逐句重寫**：按 §二（詞彙）+ §三（撒碎屑）+ §一（稱呼）改寫 | 改寫後正文 |
| **4** | **回籤**：標註改了哪些句、依據哪一條、是否觸碰人物身份 | 過站卡 |

### 6.3 過站卡（輸出契約）

```markdown
【原句】"我是否應該告訴你這件事？"
【改寫】"我吧……想跟你說個事兒。"
【依據】
  ① 詞彙禁用：`是否` → 口語不出現（§2.2）
  ② 撒碎屑·前置墊詞：加"我吧"起話頭（§3.4）
  ③ 掉尾：不把話說完，留給對方追問（§3.2）
【人物校驗】符合"沈硯·猶豫不決"的語言指紋 ✅
```

### 6.4 ⛔ 段落豁免（不許硬掰）

以下段落**豁免過站**，但須在段首顯式標註意圖：

| 段落類型 | 標註寫法 |
|---|---|
| 宣判/壓迫/長鏡頭靜場 | `【本段為靜場宣判段·刻意書面】` |
| 權威人物的官腔（**人物設定如此**） | `【本段官腔為人設·非缺陷】` |
| 古裝文言對白（題材語體） | `【本段為文言體·題材要求】` |

> **判準**：這段"不口語"，是**劇情需要**還是**作者沒寫**？前者豁免，後者過站。

## 七、 邊界與禁令

1. **不注水**：口語化不得增加無效信息。與 `six-stage-pipeline.md` §6.8「對白豐富但不注水」一致；仍須通過**逐句刪除測試**。
2. **不破身份**：粗人糙話≠全員糙話；書生引典≠全員文縐縐。見 §0.4·2。
3. **不改事件、不改因果、不改人物設定**：本引擎只改**台詞的表達層**。任何需要改事件才能說通的台詞，回 `six-stage-pipeline.md` §6.9 重做劇情。
4. **下游不越權**：P3 分鏡 / P4 投餵的鐵律是「**台詞逐字保留、不得刪改**」（`dialogue-speed-check.md` §一·補二）。**下游只能報，不能改**——改台詞必須回階段⑤ 過站。
5. **示範句標註紀律**：凡源自 `acting-direction.md` 手法（§三）的示範句，一律標 `【待驗證·未實拍】`，實拍通過後方可回收為正式正例（依 `model-adapters.md` §5.0.5）。
6. **不新增字段**：稱呼與語言指紋寫入既有的聲音卡與台賬，**不新增七段式字段、不改投餵稿結構**。

## 八、 機檢口徑

> **誠實邊界**：**"有沒有人味"無法機檢。** 本節能機檢的是**可判定的子集**，用於**下游兜底探測**（補上 R5 缺失的反饋迴路），不能替代人工過站。

### 8.1 可機檢（下游 · `validate_prompt.py` C28 系列）

| 碼 | 判定 | 級別 |
|---|---|---|
| `C28a` | 台詞文本出現**現代書面虛詞**（§2.2 A 類表） | WARN |
| `C28b` | 對話段台詞 ≥40 字且**語氣詞數為 0** | WARN |
| `C28c` | 單句 ≥20 字且句內**無任何停頓標點** | WARN |

- **只報不改**：下游鐵律「台詞逐字保留」→ C28 是**提示**，觸發**回階段⑤ 過站**，不是自動改寫。

### 8.2 不可機檢（人工過站負責）

稱呼是否得體、潛台詞是否成立、撒碎屑是否自然、是否破人物身份——**一律人工**。

### 8.3 劇本層登記項（非機檢，但必須落盤）

`ADDRESS_LEDGER`（§1.4）與 §6.3 過站卡 —— 由階段⑤ 產出，供圓桌審核抽查。

## 九、 短劇對白密度與「帶刺的活人話」（★ 2026-10-20 用戶改稿回寫）

> **由來**：一集 90 秒的現代災難題材短劇，初稿寫成了「展示驅動」——她涮和牛、她翻手機、她走貨架、她倒湯，六段裡四段沒人開口。用戶連打三次回票，原話：「台詞太少了，其實你自己去看一下紅果短劇，那台詞量是很密集的，不然的話你就在那展示展示展示，其實他根本不知道咱們在幹嘛」。最終用戶自己重寫了一版才對味。本節是這次返工的規則化，**優先級高於 §二~§六 的單項技巧**——技巧再對，密度不夠就是廢稿。

### 9.1 一條鐵律：短劇是台詞驅動，不是畫面驅動

| 寫法 | 判定 | 依據 |
|---|---|---|
| 一段 15 秒裡只有環境音與動作，觀眾要靠畫面推斷髮生了什麼 | ⛔ **不合格** | 豎屏小屏 + 手滑場景，觀眾沒有注意力做推斷 |
| 每段至少 2 條人聲事件（畫內台詞或畫外對白），且**信息靠嘴說** | ✅ 合格 | 紅果/抖音短劇通行密度 |
| 六段裡有「展示段／純氛圍段」 | ⛔ **不合格** | 「展示段」是長片語法，短劇裡等於空轉 |

**換算公式（寫之前先算）**：

```
段台詞字數 ≈ 段秒數 × 3.5 ~ 6.5
90 秒集 ≈ 300 ~ 580 字
```

- 低於 **3.5 字/秒** → 觀眾會覺得「拖」，且必然出現無台詞段。
- 高於 **6.5 字/秒** → 演員說不完、口型對不上，需拆鏡或刪句。
- 實測合格區間：**4.0 ~ 6.4 字/秒**（本包 2026-10-20 案例：初稿 4.0 被判拖，改到 6.4 才過）。

### 9.2 信息分配：世界觀優先由「反派/配角台詞」說出

**⛔ 最容易被誤用的通道是旁白。** 旁白受 `validate_prompt.py` **C14** 硬卡（一段只許 1 鏡 VO、總字數 ≤20 字 +5 容差），且天然「聽書化」，在短劇裡是最貴的額度、最低的性價比。

**正確做法**：把設定塞進**正在生氣的那個人的嘴裡**。

| 要交代的信息 | ⛔ 旁白寫法 | ✅ 台詞寫法（由對手喊出來） |
|---|---|---|
| 氣溫 -70℃、已封城 47 天、門外是一家三口 | 旁白：「零下七十度，封城四十七天，一家三口在門外。」 | 門外老太太：「零下七十度！四十七天了！你想凍死你婆婆啊！」 |
| 她已把家產全變現 | 旁白：「三天，她把百億換成了鋼板。」 | 律師（免提）：「沈總，全款六折拋售虧了三十個億！」 |
| 她囤了多少貨 | 旁白：「三千七百箱壓縮乾糧。」 | 老陳（報數）：「三千七百箱壓縮乾糧，兩千箱罐頭，和牛五百公斤，柴油八十噸，全齊了。」 |

**判定**：一段裡如果出現「旁白 + 內心獨白」兩項以上，或旁白承擔了**人物關係**信息 → 回爐，改成對白。

### 9.3 額度口徑：C14 只管 VO/OS，**畫內台詞不受任何字數限制**

這是初稿返工最貴的一課。寫手容易把信息往旁白塞，因為「旁白看起來能一次說完」，結果被 C14 卡死；其實**讓她開口，說多少都行**。

| 通道 | 寫法 | 受 C14 限制 | 用法 |
|---|---|---|---|
| 旁白 / 內心獨白 | `畫外·旁白（……）` / `OS` | ✅ 受 | 萬不得已才用，≤20 字 |
| 畫內開口 | `台詞：【角色（語氣）："…"】` | ❌ **不受** | **主通道**，一段可 3~4 句 |
| 畫外對白（門外喊、電話、聽筒） | 寫進 `聲音：`，**不寫「旁白」二字** | ❌ 不受 | 對手戲的另一半 |

> ⚠️ **口徑陷阱**：C14 的統計桶會把「旁白 + 門外畫外喊 + 畫內台詞」**合併計數**。所以旁白寫 11 字也可能報「31 字超限」。判斷時看**旁白本體**是否 ≤20 字，別被合計數嚇住就不敢寫台詞。

### 9.4 語序紀律：按時間順序內嵌，**禁止把台詞一律堆到行尾**

**症狀**（真實返工）：段3 鏡3 寫成「…一字一字往外說。聲音：聽筒男聲『沈總？您說清空？』台詞：【她：『三天內清空。』】」——**對方先問、她後答，時序反了**。

**硬規則**：

1. **按時間順序寫**：這個鏡頭裡誰先說，誰的聲就先出現。
2. **畫內開口緊貼動作**寫，讓動作與開口同一拍：`把手機舉到耳邊，一字一字往外說。台詞：【…】`
3. **畫外聲 / 環境聲**進 `聲音：`，只裝沒入畫的人聲與音效。
4. 兩種合法次序：
   - 畫外先說 → `聲音：門外喊話 …… 她這才開口。台詞：【…】`
   - 她先說 → `……開口。台詞：【…】 聲音：環境音 / 對方回話`
5. **聲音詞（一字一頓 / 拔高 / 氣聲 / 冷笑）不許寫進畫面段**——只放台詞語氣位，否則模型會照著畫表情（機檢 `C16a` 會攔）。

### 9.5 金句改造四式：**端著的總結句 → 帶刺的活人話**

> 用戶原話：「把端著的金句改成帶刺兒的活人話」。同樣一個意思，**能當場還嘴的才叫金句，需要想一下才懂的叫廢話**。

| # | 招式 | 舊（端著的） | 新（帶刺的） | 差別 |
|---|---|---|---|---|
| ① | **先接住對方那句，再拐一刀** | 「四十七天，我天天聽著。」 | 「叫這麼大聲幹嘛，省點力氣還能多熬半小時。」 | 舊的是自言自語，新的是**在對罵** |
| ② | **用對方的邏輯堵對方的嘴**（歸謬） | 「三口人，一頓飯。」 | 「再說了，劉阿姨，我還沒過門呢，哪來的婆婆？」 | 舊的是評論，新的是**當場解掉對方身份** |
| ③ | **把動作描述改成「反問 + 指令」** | 「這碗湯，我倒了。」 | 「不是想要熱湯嗎？舔乾淨，明早還有。」 | 舊的是旁白式陳述，新的是**命令** |
| ④ | **加一個生理/日常層面的詞，讓狠話有生活質感** | 「上回我跪了一夜，你們誰開門了？」 | 「磕這麼響幹嘛。上輩子我跪在門外求你們的時候，你們不也讓我忍忍嗎？」 | 「磕這麼響幹嘛」把對方的表演**當場拆穿** |

**四條自檢問句**（逐句過）：

1. 這句**能不能被對方聽見**？聽不見的＝自言自語，改。
2. 這句有沒有**接住上一句**？沒有＝各說各話，改。
3. 這句裡的信息，**觀眾需要想幾秒**？需要想＝太繞，改。
4. 把這句從劇本里刪掉，**劇情會不會斷**？不會斷但爽感掉了＝金句；連爽感都不掉＝廢句，刪。

### 9.6 交付前逐段打勾

- [ ] 每段 ≥2 條人聲事件，**無「展示段」**
- [ ] 段台詞字數 ≈ 段秒數 × 3.5~6.5（全片在 4.0~6.4 之間）
- [ ] 世界觀/背景信息**由角色台詞承擔**，無旁白承擔關係信息
- [ ] 每句台詞**按時間順序內嵌**，無「行尾標籤堆疊」
- [ ] 聲音詞只在語氣位，畫面段乾淨
- [ ] 四式改造過一遍：無「需要想一下才懂」的總結句

### 9.7 與 §七 的邊界（改造不等於放水）

- **不注水**：撞高密度靠**對罵與信息對撞**，不靠廢話墊字。仍須過逐句刪除測試。
- **不破身份**：她可以尖銳，但不能變成另一個人。本例中她的攻擊性來自「上一世死過一次」的確定感，不是天生毒舌——所以台詞全用短句、不解釋、不重複。
- **不改事件**：只改表達層。若必須改事件才能說通，回 `six-stage-pipeline.md` §6.9。

## ★ 電影寫實剋制檔（可選）＋ 觀眾零計算直譯律

### A. 電影寫實剋制檔（適用懸疑 / 現實 / 電影向劇本，與短視頻大白話爽劇檔按題材切換）
1. **重要對白三層結構**：每場關鍵對話同時承載 **表面事件**（眼前具體小事）+ **人物關係**（試探/靠近/施壓/迴避）+ **深層情緒**（不直接喊出口的遺憾、戒備或依賴）。
2. **用日常瑣事載情緒，把抽象表演詞換成可拍動作**：不寫“眼神複雜、五味雜陳、強忍淚水”，改為具體手部與道具停頓（如折衣袖停半拍、把碗輕推過半寸）；停頓與半句話必須核對「停之前本來想說什麼 / 停的當下在看誰 / 停之後誰接話」。
3. **剔除“替觀眾解釋”五類廢話**：凡直接解釋人物心理、複述已知過去、替觀眾總結主題（“其實人生就是…”）或畫面已演出的情緒對白，優先刪減交還給動作與反應。

### B. 觀眾零計算直譯律 ＋ 行為型打臉優先
1. **核心數字必走「報數字 + 給參照/差額 + 說後果」**：不拋“成本是售價 4 倍”讓觀眾自己心算，直接替觀眾算完說出口（如“收 60 萬，光試錯就燒了 200 多萬，賣一台倒虧 100 多萬”）。
2. **打臉強度排序**：**對手被迫改變實際行為**（停產/合作/改策略） > **硬事實與結果當場反轉** > 對手嘴上認輸。
