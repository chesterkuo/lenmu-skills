# 劇本視聽可拍性門禁與爆款節奏升級（V8.2.0-SLIM · 融合 short-drama-factory v5.1）

> 歸屬技能：`sd-script-engine`（劇本引擎）｜用於從源頭消滅「下游分鏡拍不出來、開局慢熱、中後段注水、優化誤改原稿」四大頑疾。

---

## 一、 劇本視聽可拍性四門禁（`E37~E40` · 進分鏡前必清）

1. **`E37` 禁否定式偽動作（硬攔截）**：嚴禁在 `△` 中寫 `非但沒跪 / 非但沒退 / 看都沒看一眼 / 連眼角都沒掃` 等攝影機拍不出來的否定句，一律改寫為正向可見動作（如 `△ 負手立於堂中，下巴微抬，目光越過眾人落在主位`）。
2. **`E38` 道具交接來源閉環**：`△` 凡出現「接過 XX」，必須寫清從哪位在場角色手中接過或從何處取出，嚴禁憑空接物導致下游分鏡亂配遞物人。
3. **`E39` 禁台詞未提先知（幽靈反問）**：前文未出現且角色未在場得知的專名，嚴禁後句突然反問 `什麼XX？`，必須先由對手拋話頭或先亮物證。
4. **`E40` 禁同空間假切場**：相鄰兩場空間、時間、人物完全相同且無真實位移或時間跳轉詞，嚴禁硬拆場次。

## 二、 爆款開局與長劇防注水骨架

1. **第 1 集「極速進場五步拍點」**：`0~3s` 強視覺砸臉 ➔ **前 5 句台詞內大白話挑明反派具體利益算盤/金額/死線** ➔ 反派加碼逼死角 ➔ **第 1 集半場（35~65s）主角必亮首張實質反制牌**（查封/凍卡/撤資/收信物） ➔ 當場見血 + 破門斷章。
2. **女頻清算 A/B 雙軌**：A 軌「當場掀桌·剝皮清算型」（第 3 集只結表層賬，必留深層死賬火種防 3 集演完大結局） vs B 軌「蓄力刀人·證據回放型」（第 1 集不可逆切割，第 2 集物證回放 3 筆血淚賬，第 3 集公開抽底牌）。
3. **L1~L4 四級被看見圈層階梯**：`L1 內宅/基層 ➔ L2 行業/城際 ➔ L3 權貴/名流 ➔ L4 中樞/天下`，單矛盾單元 ≤30 集必閉環並升維更換更高階裁判與【質疑者配角】。
4. **立項六項《世界規則卡》**：寫前鎖定①權力上限 ②利益鏈條 ③空間壁壘 ④核心物證 ⑤**金手指代價鎖** ⑥稱謂階梯，排除貶妻為妾/私拆御匾/撕自己手裡原契等降智雷區。

## 三、 長劇防崩與「優化 ≠ 改編」路徑消歧

1. **抗上下文壓縮滾動快照**：批量連寫每 5~10 集運行 `python sd-script-engine/scripts/rolling_checkpoint.py <劇本目錄> --out rolling-state.md`，卸載舊集正文，只攜狀態包與最近 1~2 集尾態續寫。
2. **「優化 ≠ 改編」路徑消歧鐵律**：用戶拿**自己已有成稿**要求潤色優化時，**嚴禁改劇名、嚴禁改主角姓名、嚴禁推翻原世界觀外殼**；僅對標外部作品仿寫時才執行剝殼換殼與第一性原理降維外化。

## ★ 劇本推進力與 AI 可拍性強化框架（吸收 R7.6 生產控制門）

1. **每場必推「劇情狀態賬本」+ 高潮後只升維**：
   - 每場結束必須至少改變 1 項狀態：**主角處境 / 核心困難 / 剛剛的決定 / 已驗證結果 / 對手認知 / 影響範圍**；若聊完一遍六項全未變，該場併入前後場或刪除。
   - 連續升級型故事層級**只進不退**（不先全球震動後退回某小團隊當新危機）；**高潮核心打臉一旦成立，後續只保留「影響擴大 + 對手被迫改變行為 + 一句主題收刀」**，嚴禁再把前面講過的數據或方法重新上課複習一遍。
2. **事件先於解釋 + 角色認知賬本**：
   - 優先「真實問題先發生 → 人物發現、判斷、爭執與決定」，**嚴禁角色剛問一句“會不會出事”，下一秒就剛好出事配合演出**。
   - 內部登記各主要角色“已知 / 親眼見過 / 尚未知”，**嚴禁兩個本來都知道內情的角色互相科普給觀眾聽**；角色不能說出當下不可能知道的未來預言。
3. **AI 生產倒逼「可見證據」與說話人精簡**：
   - 關鍵證據必須讓 AI 視頻畫面一眼看得懂（如“零件裝不上、卡死、封條二次熱封痕”），**不把劇情押在“偏差 2 毫米”或需要 AI 穩定生成複雜小字表格/報告上**；
   - 正文單場優先控在 **2 個核心說話人**（第 3 人僅作短信息補位），降低多人口型與切鏡成本；長對白場必須插入可見狀態變化（送物、響鈴、停機、起身等）。
4. **改稿防回滾：A/B/C 鎖定分級 + 反饋作用域判定**：
   - **A 級絕對鎖死**（已生成視頻/已定鏡一字不改，除非用戶點名局部解鎖）；**B 級含義鎖**（核心事實與節點不動，僅修措辭）；**C 級方向鎖**（允許重構實現方式）。
   - 收到修改意見先判清作用域——**單點 / 同類 / 階段 / 全局**，絕不把“開頭節奏再狠點”誤推廣成“全篇碎短句”。
5. **史實骨架 vs 戲劇表現層雙層施工（僅真實人物 / 企業史 / 紀實逆襲題材按需啟用）**：年份、成績、商業/賽事結果與真實人物貢獻歸屬屬於事實骨架，嚴禁為爽感篡改；允許用匿名/複合功能角色承載真實存在的行業質疑或群體壓力。
