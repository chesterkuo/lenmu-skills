# 對標情報卡（intel-card）

> 本文件回答一個問題：**採回來的東西，按什麼格式交出去。**
> 配套：[source-ladder.md](source-ladder.md)（去哪兒找）· [recon-evidence.md](recon-evidence.md)（怎麼才不出錯）

## 〇 · 這是什麼

《對標情報卡》是採風環節的**唯一交付物**。一張卡 = 一部劇（或一個題材）的公開情報全集。

**它不是什麼**：不是劇本、不是分集大綱、不是複製粘貼的素材堆。它是**給下一步生產用的結構化輸入**。

**一條鐵律**：卡里每一欄都要能被**獨立核查**——寫明"誰在哪一天說的"。寫不出來的，寫進 ⑫ 未找到項。

## 一 · 十三項字段總表

| # | 字段 | 必填 | 一句話要求 |
|---|---|---|---|
| ① | 劇名 | ✅ | 中文名 / 原文名 / 別名 + 是否改編 |
| ② | 平台與上線 | ✅ | 平台 / 上線日期 / 是否仍在榜 |
| ③ | 體量 | ✅ | 集數 / 單集時長 / 總時長 / 是否分季 |
| ④ | 題材與標籤 | ✅ | 題材歸類 + 常見標籤 + 同題材對比位置 |
| ⑤ | 主創 | ⭕ | 主演 / 導演 / 編劇 / 出品方（公開可見者） |
| ⑥ | **熱度證據** | ✅ | 分條列出：指標 / 數值 / 時點 / 來源 / 分級 |
| ⑦ | 故事骨架 | ⭕ | 一句話前提 / 主要衝突 / 結局走向 |
| ⑧ | 爽點結構 | ⭕ | 開局鉤子 / 反轉點位 / 情緒峰值位置 |
| ⑨ | 觀眾反饋 | ⭕ | 正面 / 負面分列，各標來源 |
| ⑩ | **可遷移點** | ✅ | ★ 哪些結構能被新項目複用 |
| ⑪ | **不可遷移點** | ✅ | ★ 哪些是它的專屬資源，抄不來 |
| ⑫ | 未找到項 | ✅ | 明確列出沒查到的字段 |
| ⑬ | 採集記錄 | ✅ | 檢索詞 / 覆蓋源 / 採風時點 / 採風者 |

**⭕ = 找不到時寫「未找到」並通過，不算失敗。** ✅ = 必須有一欄內容，哪怕內容是「未找到」。

## 二 · 逐字段填寫口徑

### ① 劇名

```
劇名：《禁止閃婚：甜桃烈酒2》
原文名：（不適用 / 英文名：…）
別名：（無 / 平台另名：…）
是否改編：☐ 原創  ☐ 改編自〈作品名〉  ☐ 未找到
```

**口徑**：劇名必須**逐字照抄來源原文**（外網檢索時尤其重要——模型很容易把劇名"翻譯"成看起來很合理的樣子）。**分季標記要保留**（《XXX 第八季》不是《XXX》）。

### ② 平台與上線

```
主平台：紅果 / 抖音 / ReelShort / DramaBox / …
上線日期：2026-10-03
當前狀態：在榜（截至 2026-10-07）/ 已下榜 / 未知
```

**口徑**：多平台同發時要**分列**；「在榜」必須帶**截至日期**。

### ③ 體量

```
集數：77（若官方標註，照抄官方數字）
單集時長：未找到 / 約 1.5 分鐘
總時長：未找到
分季：無 / 有（第 N 季）
```

**口徑**：集數**以官方標註為準**；**禁止用"每集 1~2 分鐘 × 集數"反推總時長**（那是估算，不是數據）。

### ④ 題材與標籤

```
題材：家庭倫理 / 愛情 / 古風 / 系統重生 / …
標籤：（照抄來源給出的標籤，如 系統、重生、逆襲、打臉虐渣）
同題材位置：據〈來源〉〈日期〉，相對當周同題材中位數 …（有則填，無則寫"未找到"）
```

### ⑤ 主創

```
主演：A / B / C          （照抄；不確定的人數不要湊）
導演：
編劇：
出品方：
```

**口徑**：**只寫來源明確寫出的**。不認識的職務不要硬填。

### ⑥ 熱度證據（★ 核心欄 · 一行一條，禁止合併）

```
| # | 指標 | 數值 | 時點 | 來源 | 分級 |
|---|---|---|---|---|---|
| 1 | 榜單排名（日榜） | 第 11 名 | 2026-10-07 | 短劇工程單劇頁（原始來源標註為抖音官方短劇數據中心） | T1.5 |
| 2 | 歷史最高排名 | 第 11 名 | 2026-10-06 | 同上 | T1.5 |
| 3 | 在榜天數 | 3 天 | 2026-10-05~10-07 | 同上 | T1.5 |
| 4 | 當週熱播指數 | 911（環比 -1%） | 截至 2026-10-07 | 同上 | T1.5 |
| 5 | 首日排名 | 第 92 名 → 次日第 11 名 | 2026-10-05 → 10-06 | 同上 | T1.5 |
```

**四條硬口徑**：

1. **一行一條**，禁把多個指標擠在一行（"熱度 911、排名 11、在榜 3 天"= 三條，不是一條）；
2. **每條必須帶時點**——沒有日期的熱度數字**不進卡**；
3. **「熱播指數」不是播放量**，照抄指標原名，**禁止改寫成"播放量 911 萬"**；
4. **平台不同不可比**，跨生態排名禁止並列；外網源的排名單獨成表並註明"與國內平台不可比"。

### ⑦ 故事骨架

```
一句話前提：〈主角〉在〈處境〉下，必須〈目標〉，否則〈代價〉。
主要衝突：（2~3 條）
結局走向：〈公開可見者；未知寫"未找到"〉
```

**口徑**：只寫**公開可見**的簡介級信息。**禁止**為補全骨架而編造分集情節——分集內部細節通常拿不到，寫「未找到」即可。

### ⑧ 爽點結構

```
開局鉤子：（前 3 秒 / 前 1 集給出的衝突或反差）
反轉點位：（公開討論中反覆被提到的反轉處）
情緒峰值位置：（第 N 集附近 / 結局）
```

**口徑**：本欄多為**推斷**，**必須標註推斷依據來源**。拿不到就寫「未找到」。

### ⑨ 觀眾反饋

```
正面：（照抄或轉述，標平台 + 時點 + 鏈接）
負面：（同上；爭議點尤其重要——爭議往往比好評更有信息量）
```

**口徑**：**正反必須都記**。只記好評的卡是**失真**的卡。

### ⑩⑪ 可遷移點 / 不可遷移點（★ 本卡的價值所在）

見 §三 專項方法。

### ⑫ 未找到項

```
- 單集時長：未找到
- 付費卡點位置：未找到（需實際觀看）
- 完播率：未找到（平台不公示）
```

**口徑**：**主動列**，不要留空。這份清單是**誠實度的證據**，也是下一輪採風的待辦。

### ⑬ 採集記錄

```
檢索詞：（逐條列出實際用過的檢索詞）
覆蓋源：（按分級列出：T1 ___ / T1.5 ___ / T2 ___）
採風時點：2026-10-08
預算狀態：未用盡 / 已用盡（未覆蓋：___）
採風者：（工具/執行者標識）
```

## 三 · 可遷移點 / 不可遷移點：怎麼提

**這一步是採風的目的**。做完 ①~⑨ 只是"抄回來了"，做完 ⑩⑪ 才是"能用了"。

### 3.1 可遷移點（問：這個結構換一批人、換一個朝代/地點，還成立嗎？）

| 判據 | 例子（寫作時替換為實際內容） |
|---|---|
| **衝突結構**能否換殼 | 「被貶妻為妾 → 直接進宮面聖」的**反應模式**可遷移（不哭訴、立刻反制）；換成任何"被壓制 → 立刻反制"的處境都成立 |
| **人物關係**能否換殼 | 「表面廢人、實則馬甲一層層揭」的**反轉節奏**可遷移 |
| **鉤子位置**能否搬 | 「開局即高能，第一集就決裂」的**時間點**可遷移 |
| **標籤組合**能否復配 | 「系統 + 重生 + 打臉」的**組合方式**可遷移 |

### 3.2 不可遷移點（問：這個東西，我新項目裡拿得到嗎？）

| 類型 | 說明 |
|---|---|
| **演員資源** | 主演自帶的流量與表演能力，新項目未必有 |
| **平台流量** | 該劇吃到了平台某次推薦位 / 檔期紅利，不可複製 |
| **IP 基礎** | 改編自已有讀者基礎的作品，原創項目沒有 |
| **檔期紅利** | 假期檔 / 競品空窗期，屬外部條件 |
| **製作規模** | 高成本實景 / 特效投入，短劇項目通常夠不到 |
| **運氣成分** | 二次傳播、意外出圈——**必須承認存在**，不要寫成方法論 |

### 3.3 反模式（這樣寫 = 白採）

- ❌ 「這部劇節奏好、人設好、值得學習」——**空話，不可執行**；
- ❌ 「照它這個來」——**沒說清要照什麼**；
- ❌ 把 ⑨ 觀眾討論裡的評價直接搬進 ⑩——**那是別人的判斷，不是可遷移結構**；
- ❌ 只寫可遷移點、不寫不可遷移點——**會誤導項目組以為能全盤復刻**。

## ⑩ 可遷移點
- **排名走勢形態**：首日 92 名 → 次日 11 名，屬"首日低調、次日爆發"型；
  可作為"開局鉤子後置發力"的參照形態（換任何題材都成立）。
- **關係設定**：「被迫同處一個空間（同組/同住）+ 需要對外隱瞞關係」——
  是低成本高張力的通用結構，與職業、朝代無關，**可復配到多種題材**。
- **職業衝突對位**：兩人職業相同但立場對立（手術檯上針鋒相對），
  這屬於"同專業內對抗"結構，**可遷移**。

## ⑪ 不可遷移點
- **主演資源**：韓雨彤 / 梁思偉 等主演的既有觀眾基礎，新項目不必然具備。
- **平台檔期**：2026-10-03 上線的檔期紅利（國慶檔），**不可複製**。
- **出品方資源**：小鹿亂撞的發行能力與推薦位資源，屬外部條件。
- **同期競爭環境**：當週同題材競爭強度未知，無法排除"題材空窗"紅利。

## 五 · 交付前自檢清單

- [ ] ①  劇名**逐字照抄**來源，未被"翻譯"或"美化"；
- [ ] ⑥  熱度證據**一行一條**，每條帶時點，分級標註正確；
- [ ] ⑥  沒有把「熱播指數」寫成「播放量」；
- [ ] ⑥  跨生態排名未並列比較；
- [ ] ⑨  正反面都記了（不是隻記好評）；
- [ ] ⑩⑪ **兩欄都寫了**，且 ⑩ 裡沒有空話；
- [ ] ⑫  未找到項**主動列出**（哪怕 0 項也要寫"無"）；
- [ ] ⑬  檢索詞、覆蓋源、時點、預算狀態齊全；
- [ ] 全文**沒有任何未標來源的硬信息**。

**任一項不通過 = 卡不合格，返工後重交。**
