# 漫劇老李 AIGC 創作全流程 Skill · V8.2.0-SLIM 精簡套裝版（Short-Drama Director Suite）

面向 **AIGC 視聽創作** 的工業級全流程創作技能包，供 AI 助手 / LLM 調用——從創意立項、劇本、資產、分鏡到視頻模型投餵提示詞與獨立質檢。
典型場景為 AI 短劇 / 漫劇 / 短視頻劇集；管線與題材解耦，同樣適用於 AI 廣告片 / 宣傳片、分鏡預演（PREVIS）、武打動作設計、微表情專項等一切需要跨鏡頭一致性的 AIGC 視頻生產。

> 🔑 **核心理念：本包不持有圖，交付的是"提示詞 + 接線說明書"。**
> **圖由用戶在外部平台（即夢 / Seedance / 豆包等）自行生成並持有**——本包默認只出提示詞，不代用戶出圖（用戶明確下"出圖口令"才執行）。因此"素材"按**存在形態**分三檔，**每次交付首行必須聲明**：
> - **M0 純提示詞**：稿件內**不出現任何圖號**；跨鏡一致性由**文字鎖**承擔（外觀檔案複述塊五要素：發/服裝/體態/年齡感/標誌物，**禁寫"同上"**）。
> - **M1 編號佔位（默認）**：稿件保留 `圖N` 槽位，並**必附《素材接線單》**——用戶只需在平台的素材區按單子把圖掛上，**不需要把圖交回本包**。
> - **M2 已入庫**：用戶主動交回圖並登記台賬，此時**才**可做圖像級核驗。
>
> ⚠️ **四鐵律**：**不索要圖片**（不得把"把圖發我"當作繼續條件）· **不因缺圖阻塞**（門禁按形態改判，"沒有圖"本身永不構成阻斷）· **不假裝**（禁止寫不存在的圖號；**禁止聲稱"已核驗/與資產圖冊一致"而實際從未見過圖**）· **要聲明**（首行寫明形態）。權威 = `references/asset-delivery-modes.md`。
>
> 📌 **A 軸與 M 軸正交**：`A0~A3` 管"要不要走資產鏈"（任務複雜度）；`M0~M2` 管"圖在不在手裡"（門禁怎麼判）。**A 軸判不清按 A3；M 軸按用戶實際條件，不取最高檔**——用戶手上沒圖就 M0，不為了"合規"逼用戶出圖。
