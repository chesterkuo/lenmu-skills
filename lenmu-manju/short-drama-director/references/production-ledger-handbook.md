# 《劇組資產圖冊》與工業化台賬總控規範 (Production Ledger Handbook)

> 🔗 **流程位置：P2 數字資產包（見 `asset-first-pipeline.md` ★權威）**。本規範定義台賬**結構**。
>
> ⚠️ **台賬按素材形態分三種（權威 = `asset-delivery-modes.md`）**：**本包不持有圖**——圖由用戶在外部平台生成並持有。因此：
> - **M0 純提示詞** → 產出 **《外觀檔案冊》**：CHR/SCN/PRP 每條附**外觀檔案複述塊**（發/服裝/體態/年齡感/標誌物）+ 場景座標系與 `SET_STATE`；**無"資產參考圖"字段**；
> - **M1 編號佔位（默認）** → 產出 **《資產編號冊 + 素材接線單》**：每條附**編號 + 用途 + 外觀要素**，並逐號給出"你該掛哪張 / 只控制什麼 / 不控制什麼"；**"資產參考圖"字段保留但留空**（用戶側持有）；
> - **M2 已入庫** → 產出 **《資產圖冊》**：**此時"資產參考圖"字段才必須填寫**。
>
> **本節以下所有"資產參考圖"必填字段，僅在 M2 下為硬約束；M0/M1 下留空不是缺陷**，不得因此索要圖片或判定台賬不完整。

## 一、 資產圖冊核心架構（Markdown 標準結構）

一份合格的《資產圖冊》（由原《劇組產出冊》升級）必須包含以下六大核心板塊：

```text
《[劇名]_資產圖冊.md》
├── 1. 風格與攝影基準（機型、鏡頭組、色溫光系、參考電影、畫幅鎖定）
├── 2. 風險與合規監測（平台敏感詞過濾、防封禁合規轉譯）
├── 3. 角色資產台賬（CHR- 編碼、層級、必定演員、運行範圍、**資產參考圖**）
├── 4. 聲音與音效資產表（AUD- 編碼、OS/對白/環境音、分層電平）
├── 5. 關鍵道具與資產表（PRP- 編碼、關鍵特徵、防穿模規範、**資產參考圖**）
├── 6. 空間場景清單（SCN- 編碼、空間類型、光線/時段、機位基準、**資產參考圖**）
└── 7. 分集單元執行表（U01~Uxx、生成方式、渲染規格、狀態）
```

> ⚠️ 相比舊版核心升級：CHR / SCN / PRP 三板塊新增 **“資產參考圖”** 字段（角色 4 View 資產板 / 場景資產圖（母版+九宮格；複雜場景加機位調度版或站位版） / 道具圖）。**該字段的填寫要求按素材形態分級——M0/M1 下留空，M2 下必填**；文字描述在 M2 下降級為索引標籤，**在 M0/M1 下則是資產本體**。

## 二、 六大資產標準化編碼規範

### 1. 角色資產編碼（CHR-）
- **格式**：`CHR-[角色名]-[正面/側面/狀態/服裝]`
- **必填字段**：
  | 字段 | 說明 | 示例 |
  |---|---|---|
  | **永久ID** | 角色全局唯一標識 | `CHR-荊恪-正面` |
  | **身份/設定** | 年齡、職業、核心性格 | 30歲男主，外表冷靜寡言，眼神冷峻 |
  | **梯隊分級** | A（核心主角）/ B（常駐配角）/ C（群眾） | `A - 核心主角` |
  | **必定演員** | 綁定臉模/LoRA ID 或指定生成模型 | `ImageGen: 1024x1536 high-cinematic` |
  | **運行範圍** | 登場集數與場景覆蓋 | `第 1~12 集，全劇核心` |
  | **資產參考圖** | **4 View 資產板（16:9 白底）**，分鏡/投餵直接引用 | `@CHR-荊恪-正面` → 資產圖文件 |

### 2. 聲音資產編碼（AUD-）
- **格式**：`AUD-[角色名/音效]-[類型]`
- **類型定義**：
  - `AUD-[角色]-OS`：內心獨白（乾燥近講，相對電平 0 dB）
  - `AUD-[角色]-對白`：現場台詞（環境空間感微混響，相對電平 0 dB）
  - `AUD-[場景/動作]-SFX`：物理碰撞與招式音效（相對電平 -6 dB）
  - `AUD-[情感/氛圍]-BGM`：背景配樂（相對電平 -14 ~ -18 dB）

### 3. 關鍵道具資產編碼（PRP-）
- **格式**：`PRP-[道具名]`
- **必填字段**：
  - 道具名稱與屬性（如 `PRP-金屬打火機`：復古磨砂黑銀雙拼，帶刻痕）
  - 劇情關鍵作用（如“第四集揭露身份的關鍵物證”）
  - 防穿模/防變異描述（材質、反光度、手持抓握基準）
  - **資產參考圖**：關鍵道具出圖，分鏡引用 `@PRP-打火機`（**投餵層落位＝【場景資產】欄，與 `@SCN-` 並列寫**；判定與 M0/M1 寫法見 `model-adapters.md` §5「道具錨定紀律」——2026-10-13 補，此前該寫法僅存於本手冊、投餵層無位可放）

### 4. 場景空間清單（SCN-）
- **格式**：`SCN-[場景名]`
- **空間屬性**：室內/室外、日景/夜景、主色調（如暖橙晨光、冷藍夜雨）
- **空間快照**：設定 3D 空間左右邊界與 180° 軸線基準
- **資產參考圖**：核心場景出空間資產圖（佈局/材質/光源/機位佔位），分鏡引用 `@SCN-山門`
- **出圖標準**：跨 2 鏡以上或關鍵打鬥/重場戲的場景必須出圖（見 `asset-spatial-ledger.md` §三）

### 5. 分集單元執行表（U01~Uxx）
- **格式**：`U01` ~ `Uxx`（按**模型契約表** `model-adapters.md` §5 的組數預算切分——2.5 默認 25~30s/組時 3 分鐘約 6~8 組，2.0 ≤15s/組時約 12~15 組；本表**不寫死組數與單組時長**，以編譯時實際契約為準）
- **單元屬性**：視覺生成方式（圖生視頻/文生視頻）、美術設定、對白與語速自檢狀態、渲染規格（9:16 / 16:9 4K）、狀態（待生成/已初審/已定剪）。

## 三、 指令交互與輸出流程

當用戶輸入 `/劇組產出冊`、`/生成台賬`、`/數字資產包` 或 `/資產圖冊` 時，系統按 `asset-first-pipeline.md` P2 流程執行：
1. 輸出《完整資產清單》（編碼 + 16 項 + 6 項 + 親緣推導表）→ 用戶確認；
2. 分批出圖（角色 → 場景 → 道具），每批確認鎖定；
3. 交付《資產圖冊》（CHR/SCN/PRP 全部附資產參考圖 + 短錨點 @名）；
4. 文末提供分鏡推進建議（P3）。
