# 台詞語速自檢引擎 (Dialogue Speed Check Engine)

> 🔎 導航（2026-08-28 自檢新增）：本模塊為**台詞語速與對白時長的唯一自檢流程**，與 `wenxi-micro-expression.md`（對白時間預算）`dialogue-doctor-7d.md`（七維第6維節奏）協同。**每條台詞投餵前必須過本自檢**，尤其是有對白的分鏡/視頻提示詞。
>
> ⚠️ **關鍵修正（2026-10-08 · 用戶實測反饋）**：舊版把「快速爆發」寫作 `> 5 字/秒` 並附「單段連續 >5字/s 不得超過 3 秒」——**這條限制過嚴且不成立**。真人快念 **5.5~7 字/秒** 完全做得到（生活化短劇對白常態即落在 5~7 字/秒），只有 >7 字/秒 才需授權。**因此"這句台詞塞得進這個鏡嗎"的判定必須以最快檔 7 字/秒為基準，不得拿標準檔中值（4~4.5 字/秒）硬卡**——後者會把大量本可快唸完的台詞誤判成"念不完"，進而誤觸發"精簡台詞"。

## 一、 語速四檔標準

| 檔位 | 語速 | 適用場景 |
|---|---|---|
| **慢速重音** | **2.5 ~ 3.5 字 / 秒** | 金句宣言、臨終遺言、情緒頂點、威懾台詞（一字一頓、哽咽、氣音） |
| **標準語速** | **3.5 ~ 5 字 / 秒** | 普通對白、文戲推進、信息交代 |
| **快速** | **5 ~ 5.5 字 / 秒** | 情緒失控、爭吵、緊張逼問、連珠炮 |
| **高速** | **5.5 ~ 7 字 / 秒** | 短劇常態快念——**這是完全可行的語速，不是極限**。日常口語、生活化對白、急促追問、演員個人語速偏快，均可覆蓋 |
| （極限，需授權） | > 7 字 / 秒 | 搶話、急辯、快嘴喜劇——僅短句授權，須在提示詞寫明快念 |

**速算公式：**
$$\text{口播時長} = \frac{\text{可發音字符數}}{\text{語速（字/秒）}}$$
$$\text{對白總時長} = \text{口播時長} + \text{標點/句讀停頓} + \text{情緒停頓} + \text{金句餘韻}$$

* **最快可行時長（★ 判定基準）**：`字數 ÷ 7` ← **"這句念得完嗎"只看這一條**
* **最慢舒適時長**：`字數 ÷ 3.5`
* **判定區間**：口播部分落在 `[字數/7, 字數/3.5]` 秒內即為**合法區間**。
  * 只要 `字數÷7 + 停頓 ≤ 鏡長` → **一定念得完**（演員加速即可）→ **不得判為超載、不得建議精簡**；
  * 只有連 `字數÷7 + 停頓` 都塞不進鏡長，才叫**真念不完**（P0）。
* **總對白時長**須再疊加停頓與餘韻，且整組 ≤ 單組上限（15s）。
* **字數口徑**：只數可發音字符（漢字、數字、外文字母），標點符號不計入語速公式，另按獨立停頓預算處理（頓號/逗號 ≈ 0.1~0.3s，句號/感嘆/問號 ≈ 0.3~0.6s）。

## 一·補、 語氣 → 語速檔聯動（2026-09-19 新增）

台詞語氣位（`台詞：【角色（語氣）："…"】`，規範見 `model-adapters.md` §5.2）裡的**力度維與節奏維直接決定語速檔**——語氣不是純音頻描述，它會改動鏡長預算：

| 語氣詞類型 | 語速檔 | 對鏡長的影響 |
|---|---|---|
| 氣音 / 低語 / 斷續 / 一字一頓 / 拖長音 | **慢速重音 2.5~3.5 字/s** | 按慢檔下限算時長（`字數÷3.5` 起） |
| 急促 / 連珠 / 拔高 / 搶話 / 快 | **快速·高速 5~6 字/s** | 按快檔上限算（`字數÷7`）——**不再限定"3 秒內"**，短劇快念可覆蓋整段 |
| 冷笑 / 嗤笑 / 譏誚 / 平直 | 標準 3.5~5 字/s | 冷嘲類"說半句停半句"，句內停頓時長按 ×1.5 估 |
| （無語氣位） | 標準 3.5~5 字/s | 默認標準檔 |

- **必做**：語氣位裡出現慢檔詞（氣音/低語/一字一頓）時，**不得再按標準檔 4 字/s 倒推鏡長**——這是"台詞塞不進鏡、被迫拉伸湊時"的常見根因（與法則 17 時長守恆聯動）；
- **反過來說**：鏡長按法則 17 由劇情倒推時，語氣檔是"劇情"的一部分，必須參與計算。
- 判"塞不塞得進"時，**慢檔詞用慢檔下限（÷3.5）算，快檔/無標記的用最快檔（÷7）算**——即只有慢檔詞才會真正需要長鏡，普通對白一律按 7 字/秒判是否超載。

## 一·補二、 每鏡字數密度互校表（2026-10-10 併入 · 與語速檔互校）

除按語速檔倒推外，另用**"每鏡字數密度上限"**做**第二把尺**——兩把尺同時過，取**更保守者**作為拆鏡提示。**但判定"真念不完"仍只認 `字數÷7 + 停頓 > 鏡長` 這一條（見 §一）**，本表是**密度提示**，不是硬性字數上限，不得取代自然口型、停頓與情緒時長的判斷。

| 鏡長 | 台詞上限 | 內心獨白上限 | 典型用途 |
|---|---|---|---|
| **2 秒** | ≤6 字 | ≤8 字 | 動作鏡頭 / 特寫 |
| **3 秒** | ≤10 字 | ≤12 字 | 快節奏銜接 |
| **4 秒**（最常用） | ≤15 字 | ≤16 字 | 標準對白 |
| **5 秒** | ≤20 字 | ≤25 字 | 慢情緒 / 長句尾 |

- **超過本表密度 → 優先拆鏡**：說話人換景別/機位、聽者反應、關鍵道具特寫（見 `sd-storyboard-engine/references/shot-economy-and-acting.md` §四 拆鏡優先級），**台詞逐字保留、不得刪改**；
- **無台詞 / 無內心獨白**的鏡頭時長 ≤3 秒；
- **節奏適配**：高燃打鬥、快節奏劇情多用 2–3 秒短鏡銜接動作；慢情緒、重對話、敘事橋段多用 3–4 秒鏡過肩對打。

## 一·補三、 台詞密度**下限**（對話段專用 · 2026-10-13 用戶實測反饋新增）

> 📌 **由來**：用戶實測反饋（2026-10-13）——「**我們的台詞量比較少，這是非常多人反饋的一個問題**……這個台詞量不是為了加而加，比如說我在**空鏡的時候、在打鬥的時候肯定不需要台詞量**，我可能就需要幾句話，但是**正常的台詞量這個要給別人補上，我們現在的台詞量就太少了**」。
>
> **病根**：本套此前**只有上限、沒有下限**——§一 語速檔、§一·補二 密度表、閘門2、閘門3 全在防"超載"。結果：**描述是"必須寫"、台詞是"可以少寫" → 被犧牲的必然是台詞**。包內實測：一分鐘四段稿初版 60s 只有 **55 字台詞（0.9 字·秒⁻¹）**，讀起來像技術說明書（正常短劇對白 **2.5~4 字·秒⁻¹**）。

**下限適用於「對話段」，其餘段落類型一律放行**：

| 段落類型 | 台詞密度下限 | 開口次數下限 | 說明 |
|---|---|---|---|
| **對話段（文戲核心）** | **2.0 字·秒⁻¹**（15s ≥30 字） | **15s ≥6 次** | 正反打回合制，見 `shot-economy-and-acting.md` §五·七 |
| 混合段（對話 + 行動） | 1.2 字·秒⁻¹（15s ≥18 字） | 15s ≥3 次 | 行動本身佔時間 |
| **打鬥段** | **不設下限**（0~2 句） | **不設下限** | 打鬥靠動作與音效，喊兩聲即可 |
| **空鏡段 / 轉場段** | **不設下限**，⛔ **但也不禁言**（可為 0，也可帶台詞） | 不設下限 | ⚠️ **見下方「空鏡帶聲是合法且常用的手法」** |

### ⚠️ 空鏡帶聲是合法且常用的手法（2026-10-13 用戶補充 · 改前必讀）

> **用戶原話**：「有時候**空鏡的時候它是聲音先入畫**——比如兩個人在那兒散步，我拍一個**公園的空鏡**，那這個時候它是有那個比如**女生在那兒說話那個聲音**，然後再馬上再切過來，然後發現他們兩個在那兒對話，**這種是可以的**……**你靈活一點，不要說我說啥就把它完全定死了，這個東西它本身是服務著劇情走的**」。

**「空鏡段不設下限」的意思是「不強制、不考核」，不是「禁止寫台詞」。** 兩種寫法都合法：

| 寫法 | 說明 | 例 |
|---|---|---|
| **純空鏡**（無聲或只有環境音） | 情緒留白、空間交代、時間流逝 | 靈堂供桌掃過，只有燭火輕響 |
| **空鏡 + 先聲（聲橋）** | **聲音先於畫面出現**——觀眾先聽見人聲，畫面還在公園空鏡上，隨即切到說話人 | 公園長椅空鏡 → 傳來女生聲音「……你說他到底知不知道」 → 切到兩人並走 |

**這正是「③ 聲音橋」過渡的標準實現**（見 `sd-script-engine/references/episode-planning.md` § TRANSITION_AS_BEAT）。**寫作要點**：
1. **聲音要寫進【音效】行 + 該鏡行**，並寫明**說話人身份與畫外屬性**（如「女聲由畫面外傳來」「人聲先於人物入畫」）——聲畫分離口徑見 §五·七 與 C14（OS 走「聲音：」段）；
2. **切過來的那一鏡，人物要"接著話音"出場**——聲音不能憑空斷掉，要有承接感；
3. **空鏡 + 先聲的段落，判為「混合段」而非純空鏡段**（既有環境承載、又有台詞承載），密度下限按 1.2 字·秒⁻¹ 參考，**不強制**。

⚠️ **機檢口徑**：C27 段落類型識別裡，「空鏡」一詞會讓該段**跳過密度與開口考核**——這是**為了不誤傷純空鏡**，**不代表空鏡帶聲違規**。若你的空鏡確實帶先聲台詞，**不必改段落標籤遷就機檢**（機檢是 WARN 參考級、不產 FAIL）。

**三條鐵律**：
1. **對話段按密度下限自檢**——15 秒對話段台詞 <30 字，或開口次數 <6 次，**判"台詞量不足"、必須補**（補法見下）。
2. **⛔ 不是"為加而加"，也不是"為省而省"**——下限**只對對話段生效**；其餘段落**既不強制、也不禁止**。**唯一的判準是"這段劇情需不需要台詞"**，而不是"規則說該不該有"。
3. **補台詞的正確來源（按優先級）**：
   - ① **OS（內心獨白）補位**——零口型成本，可在任何鏡行疊加（詳見 §五·七·③）；
   - ② **短句化拆解**——把一句 25 字長台詞拆成"兩次短開口 + 中間一個反應鏡"，**字數不減但開口翻倍**；
   - ③ **加上對方的回嘴/追問**——把"宣判式長句"改成"你問一句、我答半句"的來回；
   - ④ ⛔ **不得靠"拉長台詞文采"湊字**——補的是**回合**，不是**辭藻**。

⚠️ **與上限的關係**：**下限管"夠不夠"，上限管"塞不塞得進"**。兩把尺同時生效——一條 15 秒對話段既要有 **≥30 字 / ≥6 次開口**（下限），又要保證**單鏡不超載**（上限 §一 + 閘門2）。**同時不滿足 = 段落切分有問題**（不是台詞寫少了，是**回合沒設計好**），須回 `shot-economy-and-acting.md` §五·七 重做回合制切鏡。

> 🧭 **總原則（2026-10-13 用戶申明 · 貫穿本節與 §五·七）**：**這些是服務劇情的工具，不是必須套用的模板。**
> - 有些劇情適合快速正反打（爭產、質問、鬥嘴）；**有些劇情就不適合來回切**（沉默對峙、宣判、留白、長鏡頭情緒積累）——**用戶原話：「我也不知道你為了切而切，像有一些劇情就不適合這種來回的切，靈活懂嗎？是服務劇情的」**。
> - **下限是"常見對話戲別寫太少"的提醒，不是"每段都得塞夠 30 字"的硬指標**。若一段確實該用沉默/留白/單鏡壓迫感表達，**照做，不必遷就下限**——但要在段落裡明確標註段落意圖（如「本段為長鏡頭宣判段」「本段為靜場留白段」），機檢自會跳過。

## 二、 三檔自檢判定（P0~P2 級）

| 判定 | 條件 | 處置 |
|---|---|---|
| ✅ **合規** | 語速在 3.5~6 字/s（含高速檔），且單句 ≤24 字 | 通過，按預算時長投餵 |
| ⚠️ **超長句（P1）** | 單句 > 24 字 | **強制拆鏡**：通過正反打/過肩/切入反應鏡頭拆 2~3 鏡，每鏡 ≤18 字 |
| ⚠️ **金句缺發酵（P2）** | 關鍵台詞/高潮金句後無 0.3~0.8s 無對白反應鏡頭 | 補 0.3~0.8s 微表情/旁觀者反應鏡頭（瞳孔驟縮/倒吸涼氣/靜場） |
| 🔴 **真念不完（P0）** | 連 `字數÷7 + 停頓` 都塞不進該鏡預算 | 重構台詞或調整鏡次分配，嚴禁超鏡時長。**注意：鏡長 ≥ 字數÷7+停頓 即不算超載——不得因"按 4 字/秒算不夠"而誤判精簡** |
| ℹ️ **偏快提示（非缺陷）** | 實際語速落在 5~6 字/s | 僅提示"此處需快念"——**不是缺陷、不觸發精簡**；若表演需要停頓呼吸，自行加 0.5~1s 即可 |

## 三、 五步自檢流程

1. **拆句**：把台詞按逗號/句號/感嘆/問號拆成獨立小句；
2. **計數**：每句只數**可發音字符**（漢字/數字/字母），標點不計入字數；
3. **停頓預算**：按句內逗號（≈0.1~0.3s）與句末符號（≈0.3~0.6s）估算標點停頓；
4. **套檔**：按場景情緒選定語速檔（慢速重音/標準/快速/高速）；
5. **速算**：先按**最快檔 7 字/秒**算 `字數÷7 + 停頓` 得**最短可行時長**——鏡長 ≥ 此值即判"念得完、合規"；再按 3.5~5 字/秒算舒適時長作參考，對照該鏡時間軸預算；
6. **判定**：套用二、三檔判定 → 輸出結論 + 建議。

## 四、 輸出契約（每條台詞自檢卡）

```markdown
* **台詞**：“[台詞文本]”
* **字數**：N 字
* **語速檔**：慢速重音 2.5~3.5 / 標準 3.5~5 / 快速 5~5.5 / 高速 5.5~6 字/s
* **語氣檔來源**：語氣位（如 `氣音·發顫`）→ 判慢速重音（無語氣位或標準檔語氣詞則寫"標準檔"）
* **所需時長**：約 X ~ Y 秒（N÷7 ~ N÷3.5；**N÷7 為最快可行、判定用**）
* **判定**：✅ 合規 / ⚠️ 超長句需拆鏡 / ⚠️ 缺金句發酵 / 🔴 真念不完（連 N÷7 都塞不進）/ ℹ️ 偏快提示
* **建議**：[拆鏡方案 / 補反應鏡頭 / 重構]
```
