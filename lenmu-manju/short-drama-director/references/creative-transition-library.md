## 一、 總原則（改前必讀）

### 1.1 三層轉場觀

| 層 | 例子 | 何時用 |
|---|---|---|
| **① 結構化銜接（默認層）** | 換機位硬切 / 尾幀錨定 / 段縫景別承接 | **默認**——大多數段縫用它就夠，最穩、最不容易穿幫 |
| **② 敘事型過渡（劇本層戲點）** | 動作橋 / 空鏡敘事 / 聲音橋（見 `episode-planning.md` §TRANSITION_AS_BEAT） | **段與段之間需要"加戲"時**——過渡本身承載新信息 |
| **③ 技巧型轉場（本庫）** | 相似動作 / 形狀匹配 / 遮擋 / 甩鏡 / 閃白 / 畫中畫 / 大師招 | **需要一個"視覺巧勁"時**——用在敘事/情緒的關鍵咬合點，**單集限量** |

### 1.2 四條鐵律（防濫用）

1. **意圖先行**：寫每個創意轉場前先回答「**這個轉場替我省了什麼 / 加了什麼**」——省掉一段趕路（Ellipsis）/ 造一次驚嚇（J-cut 聲先入）/ 建立一次因果對比（形狀匹配）/ 傳遞一次情緒轉折（遮擋）。
2. **限量不集郵**：**技巧型轉場單集 ≤3 處**（與空鏡過渡共享"呼吸額度"精神，但獨立計數）；**同一段內不得連用 ≥2 處**不同花式——連用即"炫技"，讀作剪輯師刷存在感。
3. **服務段縫或鏡頭咬合**：創意轉場**要麼落在段縫**（跨段），**要麼落在段內兩個關鍵鏡之間**（如情緒轉折點），**不能到處撒**。
4. **物理可信**：遮擋物**必須有來源**（前景走過的人/柱/車/袖），甩鏡**必須有方向與目標**（甩向哪、為何甩），形狀匹配**兩形必須真的相像**——⛔ "為了轉場硬造一個遮擋物 / 硬甩一次鏡頭" = 失敗。

### 1.3 與機檢的關係

- 本庫**全部為 WARN / 語義級參考**，**不設硬配額、不進 FAIL**。
- 已有相關機檢：**C12**（工作流規則詞禁進投餵正文——⛔ 轉場術語如"J-cut / Whip Pan / Match Cut"**不得原樣寫進投餵稿**，必須轉譯成可執行的畫面描述）、**C11**（段末不寫接續尾行）、**C18m**（段縫景別落差）。
- ⚠️ **轉場手法名不能裸寫進投餵稿**：投餵稿寫的是「**畫面怎麼接**」（"鏡頭貼左側廊柱橫移，柱身瞬間糊滿畫面，糊滿的一瞬切到後院全景"），**不是**"用前景遮擋轉場"。術語只在**分鏡層標註**（段縫兩側逐對標註接縫式別，見 `segment-splicing.md` §四）。

## 二、 文戲技巧型轉場六式（對話/情感/懸疑/日常）

> 文戲轉場的選型邏輯與打戲相反：**打戲求"快、狠、能量守恆"，文戲求"省、藏、情緒張力"**。文戲段縫**優先走空鏡過渡（§五）或換機位硬切**，創意轉場用在**需要一次"視覺巧勁"的咬合點**。

### 文戲·式一 · 相似動作轉場（Match Cut on Action）

| 項 | 內容 |
|---|---|
| **原理** | 上一場某人**正在做的動作**，在下一場**由另一個人（或另一時空的同一個人）以相同動作接續**——動作跨時空守恆，觀眾意識不到被換了時空。 |
| **觸發** | 時空跨越（同一動作在兩處發生 · 暗示"日常重複"或"命運呼應"）/ 換人換場但功能相同（"揭蓋頭→揭鍋蓋"）。 |
| **文戲寫法** | `上一段末鏡：@母 抬手，指尖觸到舊木箱的銅釦，銅釦彈開的一瞬；下一段首鏡：@女 抬手，指尖觸到檔案袋的封口繩，繩結被挑開的一瞬。`（動作 = 抬手 + 指尖觸物，兩場用一個動作焊死） |
| **禁忌** | 兩動作**幅度差太大**（抬手 vs 劈砍）→ 不成匹配；⛔ 動作方向反了（左抬 vs 右抬）→ 讀作跳切。 |
| **大師例句** | 《2001 太空漫遊》**骨頭→太空船**（3 百萬年跨界，靠"高舉、下砸"一個弧線焊死）；《教父》**洗禮→屠殺**（同一聲管風琴，兩組"舉手"動作對位——**廣義動作對位**：它實際更接近「交叉剪輯＋聲橋」，亦見 §4.4 反差族）。 |

### 文戲·式二 · 形狀/圖形匹配轉場（Shape / Graphic Match）

| 項 | 內容 |
|---|---|
| **原理** | 上一鏡畫面裡一個**形狀/構圖/色塊**（圓/三角/一線天/同心圓），與下一鏡的**同形物**在**同一畫面位置**重合——用"形"騙過眼睛，用"意"建立隱喻。 |
| **觸發** | **建立隱喻/對照**（戒指圓環 → 井口 → 月亮，串起"承諾/深淵/遙不可及"）/ **抽象概念落地**（錶盤 → 時鐘樓 → 日曆翻頁，"時間"主題貫穿）。 |
| **文戲寫法** | `上一段末鏡：冰面裂紋的弧線橫貫畫面右側；下一段首鏡：手掌被鐵鏈勒出的血痕弧線，落在畫面右側同一位置。`（弧線位置必須對齊——這是"匹配"，不是"都有條弧線"） |
| **禁忌** | 兩形**只是"都圓"但大小/位置差太多** → 視覺不接；⛔ 顏色/調子跳太狠（暖金圓 → 冷藍圓）會破掉匹配。 |
| **大師例句** | 《阿拉伯的勞倫斯》**火柴熄滅→沙漠日出**（一點火→一輪日，同位置同色系的圓形匹配）；《2001》**骨頭→飛船**之外的**圓艙→眼球**（同心圓對位）。 |

### 文戲·式三 · 前景遮擋轉場（Foreground Wipe / Occlusion）

| 項 | 內容 |
|---|---|
| **原理** | 一個**有來源的前景物**（走過的人、門框、車、柱、蒸汽、袖口）**完全遮滿畫面**，在遮滿的**黑瞬**切到下一場，遮擋物退開時已是新時空。 |
| **觸發** | **空間跨越但不想用空鏡**（街頭 → 屋內，一輛車駛過就把兩處焊死）/ **情緒遮斷**（人物走過鏡頭 = 情緒翻篇）/ **懸疑遮擋**（遮住時換了人/換了物）。 |
| **文戲寫法** | `上一段末鏡：@秀蘭 起身向門外走，她的背影擦過鏡頭右側，衣料瞬間糊滿畫面；下一段首鏡：衣料自畫面左側斜掠而過退開，露出八仙桌旁的四人——時空已換至靈堂。`（**遮擋物要從一側入、另一側出**方向連貫才有"穿隙"感） |
| **禁忌** | ⛔ **遮擋物沒有來源**（憑空一塊黑）→ 讀作設備故障；⛔ 遮擋後人物站位**跳變無交代** → 穿幫（還要疊加段縫換機位鐵律）。 |
| **大師例句** | 《俄羅斯方舟》全片一鏡裡的**人流遮擋換場**；《諜影重重》**人群/車流遮擋**實現連續追逐的空間省略。 |

### 文戲·式四 · 甩鏡轉場（Whip Pan / Swish Pan）

| 項 | 內容 |
|---|---|
| **原理** | 鏡頭**高速橫向甩動**產生運動模糊，甩動中/甩停處切入新場景——用"糊"把接縫吞掉。**文戲用要剋制**（甩鏡天然帶"急"的氣質，慢戲慎用）。 |
| **觸發** | **對話場內的重擊式換角度**（一句話砸下來，甩到對方反應臉）/ **時間跳接**（"三小時後"用一次甩鏡帶過）/ **喜劇節奏**（甩鏡接笑點）。 |
| **文戲寫法** | `@父 說完"這家產沒你的份"，鏡頭隨他的話音向畫面右側高速一甩，運動模糊糊滿；甩停時已是 @陳志強 的正面特寫，他剛要把杯子摔下。`（甩鏡方向 = 從說話人甩向聽話人，視線因果清晰） |
| **禁忌** | ⛔ **無目標甩鏡 / 連甩多次** → 眩暈；⛔ 甩後空間方向反掉（從右甩出、新場卻在左）→ 觀眾方位感崩。 |
| **大師例句** | 《爆裂鼓手》排練室的**甩鏡換角度**；《瘋狂的麥克斯》用甩鏡縫合高速動作的空間。 |

### 文戲·式五 · 閃白/閃黑轉場（Flash Cut / Dip to Color）

| 項 | 內容 |
|---|---|
| **原理** | 用**一瞬全白/全黑**（0.1~0.3s）作"視覺標點"，橫跨時間跳躍或強烈情緒斷點。 |
| **觸發** | **閃白**：記憶閃回 / 頓悟 / 強烈衝擊（**文戲慎用，太"電子"**）/ **閃黑**：死亡 / 失神 / 場景硬分幕。 |
| **文戲寫法** | `畫面在一瞬全白中切斷，白褪去時已是三日後醫院的走廊，@秀蘭 獨自坐在長椅上。`（"全白"用一次，**單集 ≤1 次**，多則廉價） |
| **禁忌** | ⛔ 文戲濫用閃白 → 讀作"剪輯沒剪好"；⛔ 閃白用於**本該情緒連貫**的兩鏡之間 → 硬生生打斷。**這是全庫最容易被濫用的手法**。 |
| **大師例句** | 《閃靈》的**白屏切章**；王家衛片子裡用**抽幀/欠曝**替代閃白做時間跳躍（見 `director-style-catalog-74.md`）。 |

### 文戲·式六 · 畫中畫/畫框內的畫框轉場（Frame within Frame）

| 項 | 內容 |
|---|---|
| **原理** | 利用畫面內的**天然畫框**（門/窗/鏡/取景器/手機屏/相框）作"框中之框"，在框內切場——觀眾以為在看"屏裡/鏡裡"，實則已經換場。 |
| **觸發** | **窺視/監控/回憶**（手機屏裡播出上一段，切進回憶場）/ **鏡像換場**（照鏡子，鏡中人一變即換場）/ **門框引導**（穿過門框即進入新時空）。 |
| **文戲寫法** | `上一段末鏡：@父 舉起手機，屏幕裡回放白天的靈堂畫面，畫面在手機屏裡微微發亮；下一段首鏡：手機屏裡的畫面被放大、鋪滿整個銀幕——觀眾已進入回憶時空的靈堂全景。`（"屏內放大到全屏"是畫中畫轉場的標準接法） |
| **禁忌** | ⛔ 畫框佔比過小 → 觀眾看不出"框內是另一個時空"；⛔ 框內框外信息打架（屏裡在哭、屏外也在哭）→ 讀不出"該切了"。 |
| **大師例句** | 《後窗》**窗框取景窺視**；《銀翼殺手 2049》**屏幕/全息框**作時空接口；諾蘭常用**畫框內的畫框**做時空嵌套。 |

## 四、 大師技巧輯錄（跨文戲/打戲 · 增補）

> 這一節收錄**經典電影語法中被反覆驗證的轉場智慧**，供"需要一次高級巧勁"時調用。**仍是選用、不是必用**。

### 4.1 聲音先導族（J-cut / L-cut · 最"隱形"的高級手法）

| 手法 | 寫法 | 效果 |
|---|---|---|
| **J-cut（聲先畫後）** | 下一場的聲音**先於畫面 0.5~1s 進入**，聲音進來時畫面還停在上一場 | 觀眾耳朵先過段、眼睛後過段，**接縫感最低**——文戲段縫首選 |
| **L-cut（畫先聲後）** | 畫面已切到下一場，上一場的**聲音尾巴延續**進來 | 情緒延續、反應留白；追問、沉默時極好用 |
| **音橋（Sound Bridge）** | 一段聲音橫跨兩場（警笛由遠及近貫穿切場） | 把兩場"縫"在一個聽覺事件裡 |

**寫法示例**：`上一段末鏡：@陳志強 站在堂屋門口，嘴正張開要說話，畫面靜止；本鏡聲音：門外傳來 @母 的哭聲（下一場 @母 的聲音先入）。下一段首鏡：切至後院，@母 蹲在井邊掩面哭泣——哭聲比她的畫面早到了 0.8 秒。`

⚠️ **本包已有**：`dialogue-speed-check.md` §一·補三「空鏡帶聲」+ `shot-economy-and-acting.md` §八「音橋與視橋」——**J-cut 是這兩處的統一表述**，此處正式命名為 J-cut/L-cut 便於調用。

### 4.2 視線引導族（Eyeline Match / Point-of-View Cut）

| 手法 | 寫法 | 效果 |
|---|---|---|
| **視線匹配切** | 上一鏡人物**看向畫外某方向**，下一鏡**必是該方向的落點**（人/物/空景） | 觀眾視線被"牽著走"，零搜索成本 |
| **主觀視點切（POV）** | 上一鏡是人物正臉，下一鏡直接接**他所看到的畫面** | 強代入；懸疑/驚悚點題 |

⚠️ **本包已有**：`shot-economy-and-acting.md` §八「視線匹配」+ 硬項「視線落點：看向 @某人/某物」——本處補**跨段用法**（下一段首鏡接上一段末鏡的視線落點）。

### 4.3 時間省略族（Ellipsis / Montage）

| 手法 | 寫法 | 效果 |
|---|---|---|
| **動作省略**（拔刀→刀尖染血） | 直接切到動作**結果**，略去過程 | 榨乾節奏，視覺留白 |
| **環境代動作**（震落的落葉代隔空勁力） | 用環境的**反應**表現不可見的力 | 高級留白（玄幻/打戲） |
| **時鐘/日曆/季節元素** | 鐘錶指針、日曆翻頁、四季空鏡 | 時間流逝的"標點" |
| **同一動作多時空並置**（蒙太奇） | 同一動作在不同時空重複（起床/洗漱循環） | 表現"日復一日" |

⚠️ **本包已有**：`camera-transitions-6types.md` §三「視聽省略法則」——本處歸併命名。

### 4.4 反差與錯位族（Contrast Cut）

| 手法 | 寫法 | 效果 |
|---|---|---|
| **對比剪輯**（富/貧、笑/哭、生/死對切） | 兩個屬性相反的鏡頭**直接相接** | 主題性對照，不靠台詞說明 |
| **聲音錯位**（畫面在葬禮、聲音是婚禮歡鬧） | 聲畫**故意不對位** | 強烈戲劇諷刺 |
| **情緒反差切**（極喜→極悲硬切） | 不給過渡，直接反向 | "刀子"式衝擊（慎用，**須劇情確有此意圖**） |

### 4.5 空間與軸線族（Spatial Transition）

| 手法 | 寫法 | 效果 |
|---|---|---|
| **越軸過渡**（中性鏡頭/運動自然越軸） | 用中性鏡頭或運動把軸線**推過去** | 只在此處合法的越軸，見 `shot-economy-and-acting.md` §八 180°軸線 |
| **穿過門框/窗框** | 鏡頭**隨人物穿過**框形結構進入新空間 | 天然的"換場"動作，與形狀匹配/畫中畫可疊用 |
| **升降/搖臂揭示** | 從局部升到全景（CRANE），或搖臂橫過遮擋物 | 從細節到宏觀的尺度過渡 |

### 4.6 定格與抽幀族（Freeze / Stutter）

| 手法 | 寫法 | 效果 |
|---|---|---|
| **定格轉場** | 上一鏡**定格**，定格幀**化作**下一鏡的畫面（如定格成照片/畫） | "凝固瞬間"式換場（慎用，與本包段末定格區區分） |
| **抽幀/跳幀** | 抽掉若干幀製造"卡頓"，配合切場 | 王家衛式情緒標點（見 `director-param-library.md` 王家衛） |
| **負片/閃幀** | 一幀負片或閃幀作視覺標點 | 打戲爆點（`impact-frame-and-banlist.md`） |

⚠️ **與段末定格的區別**：本包的**段末末 1 秒整秒硬定格**（`segment-splicing.md` §二）是**產出尾幀截圖供下段參考**的**工作流手法**，**不是**本節的藝術化定格轉場——**兩者不要混為一談**。

## 五、 選型速查表（段縫 / 段內 · 一表定位）

| 場景 | 首選轉場 | 備選 | 理由 |
|---|---|---|---|
| **文戲慢段銜接**（對話/情緒落地） | **空鏡過渡**（§五 `segment-splicing.md`）或 **J-cut 聲先畫後** | 換機位硬切 | 硬切六式反顯急躁；聲橋接縫感最低 |
| **文戲·時空跨越**（同一動作跨場） | **相似動作轉場** | 形狀匹配 | 動作守恆，觀眾意識不到換場 |
| **文戲·建立隱喻對照** | **形狀/圖形匹配轉場** | 對比剪輯 | 用"形"騙眼，用"意"立主題 |
| **文戲·空間跨越但不想用空鏡** | **前景遮擋轉場** | 甩鏡轉場 | 遮滿黑瞬換場，有"穿隙"感 |
| **文戲·對話重擊換角度** | **甩鏡轉場**（剋制用） | 反應鏡頭切 | 甩鏡帶"急"，慢戲慎用 |
| **文戲·時間跳躍/分幕** | **閃黑**（單集 ≤1 次） | 時鐘元素 | 閃白太"電子"，文戲慎用 |
| **窺視/回憶/鏡像換場** | **畫中畫/畫框內畫框** | 視線匹配切 | 框中之框，天然時空接口 |
| **情緒頂點收段** | **反應鏡頭切**（六式·二） | L-cut | 借反應放大 |
| **段間爆點 / 位移追逐** | **景別跳切 / 動勢匹配切**（六式·三/六） | 甩鏡 | 尺度反差或動量守恆 |
| **打戲任意切換** | 走**打戲五方式**（§三） | — | 打戲域已有完整體系 |
