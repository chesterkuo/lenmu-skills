## 一、 角色資產 16 項硬性鎖定規範

### 1. 五官 10 項必寫（杜絕臉部漂移）
1. 臉型骨相（方圓臉/冷豔瓜子臉/重頜方臉）；
2. 眉形細節（平直劍眉/微挑柳葉眉/斷眉）；
3. 眼型與眼窩（狹長丹鳳眼/深邃眼窩杏眼）；
4. 瞳色與反光（深褐琉璃瞳/赤金銳利高光）；
5. 鼻梁山根（高挺直鼻/小巧微翹駝峰鼻）；
6. 唇形與唇色（薄唇微抿/硃紅飽滿唇峰）；
7. 下頜線條與折角（下頜線清晰銳利/方正剛硬）；
8. 耳廓耳型（貼腦耳/白淨分明耳廓）；
9. 標誌性特徵（眼角淚痣/眉心淺疤/斷鼻骨）；
10. 面部肌肉與膚色（冷白無暇/古銅粗糙/刀削般體塊）。

**性別錨點（必寫·2026-09-15 實測補強）**：面部特寫句必須以 `X~Y歲男性/女性（身份代稱）` 收尾（如 `24~26歲青年女性`、`55~60歲老年男性（老將）`），性別詞不可省略——只寫"老將/文士/武將"等身份代稱或只寫年齡段，模型會自行推斷性別導致漂移；所有下游投餵詞（人物入場句）提及該角色時，性別指向必須與資產板一致（如女文士不可寫成"青衫文士"）。

**★ 年齡錨 / 體型錨 / 身份外觀三件套（必寫·2026-10-12 新增 · 機檢 C26c/C26d）**

> **由來（粉絲群實測反饋）**：「**人物年齡，人物身材比例都卡不到**」「人物也搞得像**協警**，和外賣員的特徵沒有關係」。
> **病根**：此前"年齡錨"只作為**投餵層**的一句建議（`model-adapters.md` §5.0.3），**沒進資產板必寫項、也沒進機檢**——規則寫在散文裡，執行時不生效。

| 項 | 要求 | 正例（外賣騎手 陳舟） | 反例（會被判不合格） |
|---|---|---|---|
| **年齡錨** | 必寫年齡段，且**可換算**（`28~32歲`）；禁只寫"青年/中年人" | `28~32歲男性` | `青年男性`、`他` |
| **性別錨** | 必寫（既有鐵律，不重複） | `男性` | 只寫`騎手` |
| **體型錨** | **必須有數字或明確體型詞**——身高 + 體型 + 上下身比例 | `178cm·精瘦，肩寬窄、腿長佔比偏高` | `高大`、`身材不錯` |
| **身份外觀三件套 ①職業標識物** | 至少 1 個**可入畫的硬標識** | `胸前橙色方形外賣箱 + 平台工牌` | 無 |
| **身份外觀三件套 ②服裝形制與材質** | 寫形制 + 材質 + 磨損 | `橙色騎手衝鋒衣·尼龍·袖口磨白·反光條掉漆` | `穿制服` |
| **身份外觀三件套 ③氣質體態** | 把職業寫進身體習慣 | `常年騎車致含胸駝背、右肩低、手掌粗大` | 無 |
| **⛔ 反漂移清單** | 逐條寫死"不能被畫成什麼" | `禁寫成協警警服/公文包/對講機` | 無 |

**四條鐵律**：
1. **身份必須落到可畫要素**——只寫"外賣員"不算數；缺三件套任一項，模型就會給**鄰近職業的泛化形象**（最高發：外賣員→協警、護士→白大褂醫生、教師→制服群眾演員）。
2. **年齡與體型必須可複述**——年齡段 + 身高體型，禁止"中年男性""高大"這類不可複述的概括詞。
3. **⛔ 反漂移清單必寫**——正向描述禁不住漂移，必須同時給出**禁止畫成什麼**。
4. **上游來源唯一**：本表數值一律從劇本層《人物錨卡》（`sd-script-engine/references/story-bible-and-ip.md` §1.11）抄錄，**資產層禁另編一套**；改錨 → 資產/分鏡/投餵稿逐級標 `STALE`。
5. **機檢兜底**：**C26c**（年齡錨缺失）/ **C26d**（身份可渲染外觀缺失）。

### 2. 服裝材質 6 項必寫（杜絕塑料感）
1. 面料類別（重磅斜紋棉麻/做舊啞光皮革/高密生絲）；
2. 編織與表面紋理（粗糙麻織肌理/皮革龜裂細紋）；
3. 垂墜受力與硬挺度（厚重硬挺垂墜/貼身流線）；
4. 戰損汙損與做舊細節（袖口磨損起毛/衣角泥水浸潤/領口汗漬）；
5. 金屬與扣具光澤（啞光拉絲古銅釦/冷銀金屬拉鏈反光）；
6. 縫紉與剪裁工藝（雙排工整明線/暗青色提花刺繡）。

## 三、 3D 空間快照與 180 度軸線鎖 (Spatial Ledger)

> 🔗 **上游**：本章是**投餵執行層**的站位規則（怎麼寫進提示詞）。**先有導演稿**——場面的調度、權力幾何、節拍閉環、鏡頭策略模式，唯一權威在 `blocking-direction.md`（★權威）；本章把導演稿的【人物初始位】+【位移】翻譯成一行式【站位聲明】。**跳步直接寫站位＝憑感覺，站位必然漂。**

1. **絕對視角基準**：所有“畫面左/右”嚴格指觀眾看畫面的左/右。
2. **空間錨點固定**：確定場景中的核心固定參照物（門、窗、辦公桌、立柱、擂台邊緣）。
3. **180 度動作軸線法則**：在同一場戲中，攝像機必須始終在雙方視線連線（動作軸線）的同一側，嚴禁跨越軸線導致角色方位在鏡頭間無故反轉。
4. **移動軌跡閉環**：角色移動必須具備 `起點 -> 可見運動路徑 -> 終點`，上一鏡在左側的角色，下一鏡嚴禁瞬間移動到右側。
5. **空間站位風險分級（S0~S4）**：空間能力全保留，但按任務複雜度加載，低等級不加載高等級規則——**S0 單人**：簡版站位一行（位置+朝向+動作），免軸線行免位移鏈；**S1 雙人靜態**：一行式站位聲明（四要素）+ 軸線行（左A右B·禁越軸）；**S2 多人靜態（3~4 人）**：站位聲明全員具名（每人四要素）+ 軸線行；**S3 多人移動**：在 S2 基礎上加逐人位移因果鏈（起點→終點·每步有動作原因·禁瞬移）；**S4 複雜戰鬥/多人空間切換**：全量空間規則——頂視圖 CAM1~4 調度、合法越軸、V3 系統備查（`spatial-reference-system-V3.md`，LEGACY/備查）。判定不清按高一級處理。

6. **多角色在場聲明鐵律（2026-09-04 粉絲實測丟人問題修復）**：AI 視頻模型每段獨立生成、零記憶——誰在本鏡出現完全取決於本鏡提示詞寫了誰。有"空間連續性"還不夠，必須補"人員連續性"：
   - **在場聲明**：同場景多鏡的每一鏡【核心人物】段必須**點名本鏡全部在場角色**（動作主角+靜止配角全列，寫身份+位置+狀態）；無"來人/離開"描述時，默認全員原樣在場；⚠️ **（2026-10-15 單一方位權威）此處的"位置"釘依託物/狀態即可，畫面左右一律以段首【站位聲明】為準、不每鏡重寫**——雙重發位是用戶實測"東一個西一個/突然出現在身後"的病根（見 `model-adapters.md` §5.0）；
   - **人員承接鏈**：跨鏡顯式聲明延續，如 `承接上鏡：@B 仍在門口`；
   - **主次同框四件套**：第二人（含遠景/背景人）必須**具名+具象+定位+狀態**，寫法 `@B（遠景·灰袍老者·斷橋盡頭·背身而立）`；嚴禁"遠處站著個人"類弱指令；被主體"看見"（視線/動作連接）的配角不會被省略；雙主體關鍵同框鏡用同框圖鎖定形象。
   - **畫內/畫外清單（2026-09-15 審計補強）**：每鏡時間軸行內，**入畫者逐個具名**（含只聽不說的聽話者——他們物理上就在取景半徑內，不寫模型就會自行決定刪或加）；**畫外者明寫"×不入畫"**，全部在畫角色一個不漏、畫外角色一個不混；道具支撐視線動作時（如"視線落在軍牌上"）必須錨定道具入畫方式（前景虛化等）並註明持有人不入畫，防憑空長出手；
   - **跨段蒙太奇默認（2026-09-15 用戶定案，修正當日早先"過渡走位"寫法）**：段與段是**各自獨立生成的剪輯關係，不是連續拍攝關係**——跨段位置/場景不一致時，**默認用蒙太奇直切**（前段終態→後段開場，剪輯點自然銜接），段縫只需按 D 鎖配齊**畫面鎖與兩端機位關係**（**段末不寫接續尾行**，該欄 2026-10-09 廢止）；**嚴禁為湊連續性把兩個場景塞進同一個生成單元**去表現"連續走位"——雙場景穿梭是穿幫高發源，蒙太奇才是零成本轉場。**同段內**位置斷層才需要走位聲明或省略交代（同場景內"過渡走位不拍攝"合法，因為場景資產唯一）。判定口訣：**跨段切、同段連**——跨段蒙太奇，同段內才講連續性。
   - **跨段錨點鉤子（2026-09-15 實測補強）**：蒙太奇直切省了走位，但**前段收尾畫面必須為後段核心登場元素埋鉤子**——後段要登場的人物/物/景，在前段尾拍以遠景剪影、視線指向、聲音預告等方式提前入畫（如段3 尾拍遠處高台敵將剪影→段4 開戰），否則後段登場元素無來由、觀眾跳戲；同時前段【禁止項】的人數鎖定必須為該鉤子元素**開單例豁免**（寫明唯一豁免條件：何時/何處/剪影級/靜止/僅一人），豁免要收窄到不會引發人數失控。
   - ✅ 已實測驗證（2026-09-04）：修復後雙鏡（分鏡1 林越+沈硯同框 / 分鏡2 中心林越+遠景老僕）投餵確認沈硯留住、老僕出現；修復前對照（只點名主角+"遠處站著個老僕"）確認會丟人。

7. **單實例鐵律與位移當前態錨點（2026-09-15 實測分身問題修復）**：
   - **單實例**：每個點名角色在畫面中全程只有一個身體。凡【強制禁止項】必須含"單人單實例——每個點名角色全程只有一個身體，禁止同角色分身、複製人、同框重影"；人數鎖定（僅 X 人）只防"多出陌生人"，防不了"點名人自己變兩個"，兩條都要寫；
   - **位移當前態錨點**：站位聲明裡登記過位移的角色（如 `A 沙盤→帥案前半步`），在其後每一鏡被點名時必須**帶當前位錨點**（如 `@白珩（保持鏡2進言位：帥案前半步·拱手而立·全程僅此一處）`），禁止懸空點名——已位移角色只寫名字不給當前位置，模型會把起點實例和終點實例各渲染一次（拉鏡/全景把全場拉進畫面時尤其高發）；
   - **遷移非複製**：位移行註明"單實例遷移，舊位不得殘留"。

8. **景別-取景半徑匹配鐵律（2026-09-15 實測分身根因二次修復）**：鏡頭能框住誰，由**景別 × 站位物理距離**共同決定，不由台詞需要決定——
   - **可見動作必須在取景半徑內**：點名做可見表情/動作（側目、點頭、回望）的角色，必須處在該鏡景別能框住的物理距離內（中近景≈單人；中景≈相鄰 2~3 人；全景≈同屋全員）。站位隔著沙盤/半個廳的角色與持鏡主體不在一個取景半徑裡，卻在提示詞裡被要求做可見反應——模型無法讓畫外人物入畫，只能把人物**位移到主體身邊渲染或複製分身**，這是分身/亂位的真正根因之一；
   - **三種合法處理**（按戲優先選）：① 升景別改全景，全場同框做反應；② **拆反應鏡**——主體鏡（中近景·畫內僅主體，明確寫"其餘角色不入畫"）+ 反應鏡（全景·眾人各歸其位做反應）；③ 降級為畫外音/聲音反應，不入畫；
   - **禁止**：中近/中景裡點名遠處角色做可見動作；"緩慢拉鏡拉出全員"不算合法處理（拉鏡只是景別漸變，改不了物理距離，模型照樣補人）。

## 四、 場景出圖執行規範（P2c·第二批）

**流程**：核心場景出空間資產圖，每張確認鎖定。

### ★ 場景出圖產物分工表（治「同一場景被出成兩套圖」）

|---|---|---|---|---|---|---|---|

1. **都要出，不互替**——母版管「**這個場景長什麼樣**」、九宮格管「**這個場景有哪幾個子區域、各區域從哪些機位看**」。**缺任一類 = 該場景資產不完整**（是否屬必要出圖場景按本節末「出圖標準」判定：跨 2 鏡以上 / 關鍵打鬥 / 重場戲）。
2. **畫布與格內構圖區分**——九宮格整板、母版與調度/站位版一律16:9橫版，與成片B鎖解耦。九宮格內部固定3×3，每格機位與內容由模板規定；格數不改變整板畫幅。
3. **人物口徑分治**——**需要人物時只走戰鬥站位版**（帶 `@錨點` + 軸線）；母版、九宮格**一律無人空鏡**，不得在其它圖內疊人。

**① 場景母版（★必出 · 第一張 · 2026-09-15 用戶裁定 · 2026-10-11 提為第一序位）**：純場景基準圖——空間佈局 / 材質 / 光源 / 主色調 / 氛圍，畫面無任何標註與人物；**是後續所有分鏡投餵的空間一致性錨點**——後續所有鏡頭的【場景資產】與站位/背景描述，均以本圖為長相真相源交叉核對（原「場景四向長相配套圖」所承擔的「管長相」職能，自 2026-10-11 起**整體併入母版**，該配套圖不再另出）。

**③ 機位調度版 / 戰鬥站位版（⛔ 僅複雜場景按需 · 非必出 · 2026-10-11 降級）**：由原「必出二選一」降為「**複雜場景專屬**」——**日常文戲走一行式【站位聲明】+ 空間站位 S0~S4 分級即可，不單獨出調度圖**。

**複雜場景判據（滿足任一即出）**：

### 場景空間事實五件事（治"場景一致性只靠出圖、沒有事實源"）

> 病根：此前場景一致性依賴"出一張好圖 + 各鏡文字描述對齊"，但**場景本身沒有一套可複述的"空間事實"**——於是同一場景換個劇集、換個季候狀態，就在細節上漂移。精編自《靈境AI漫劇製作流 V3.9.0》`manju-environment-art-designer`：**先把場景當"空間事實"記死，再談出圖。**

#### A. 場景空間座標系（★與導演稿共用同一套）

場景資產必須攜帶一份**座標系**，與 `blocking-direction.md` §一 的【場景座標系】**同源共用**（同一場景只有一套座標）：

```
【SCN-03 客棧大堂 · 空間座標系】
  方位基：北 = 正對大門（臨街）｜南 = 後院門｜東 = 櫃檯一側｜西 = 樓梯一側
  垂直層級：地面層 / 半層樓梯平台（+1.6m）/ 二層迴廊（+3.2m）
  中央活動區：堂內方桌區（對峙/談判場）
  主入口：北·大門｜次入口：南·後門 / 東·櫃檯內門
  固定物：北牆雙扇木門、東側杉木櫃台、堂中四張方桌、西側樓梯扶手、西南角酒罈架
  安全可拍區：堂內四桌之間通道 + 樓梯平台下方不阻擋區
  禁入區：後院門外（畫外）/ 二層迴廊（除劇情需要）
```

**鐵律**：**同一 SCN 場景跨集複用時，座標系一字不改**；只有**空間結構真的變了**（改建/坍塌/季節場景替換）才創建新 SCN 編號。別名合併（"客棧大堂 / 堂屋 / 前廳"指同一空間時）必須先合併再出圖。

#### B. SET_STATE · 場景持續狀態變體（帶生效區間）

場景不是靜態照片。**凡是"持續一段劇情時間"的場景狀態**，一律登記為 `SET_STATE`，並寫明**生效區間**：

| SET_STATE 類型 | 例子 | 必寫 |
|---|---|---|
| **損毀類** | 火災後焦黑 / 戰損斷牆 / 砸碎的櫃檯 | 損毀範圍、殘留物、煙燻/水漬痕跡、**從哪個節拍起生效** |
| **停工類** | 停電（只有應急燈/月光）/ 斷電的霓虹 | 唯一光源來源與色溫、暗部比例 |
| **天候類** | 大雨 / 積雪 / 大霧 / 沙塵 | 地面溼滑反光、積水、飄落物、**可見度** |
| **節慶類** | 掛燈籠 / 貼紅紙 / 擺供桌 | 裝飾清單、配色偏移、**是否只在本集有效** |
| **時序類** | 過去 / 現在（同一空間的閃回） | 陳設差異、人物服飾差異、**色調差異** |

**三條硬規則**：

1. **生效區間必寫**：`SET_STATE: 損毀檔 · 自 EP3 段2 起 → 持續至 EP5 結束`——**沒寫結束＝默認延續到明確解除**，禁"這一鏡燒了下一鏡又是好的"；
2. **變體之間必須同源**：同一 SCN 的母版 / 損毀版 / 雨夜版**共享同一座標系與固定物位置**，只改變狀態層，**禁止把兩版畫成兩個空間**；
3. **變體必須出圖**：跨 2 鏡以上的狀態變化，**狀態版必須單獨出圖並登記《資產圖冊》**（母版 + 狀態版並列），不得只靠投餵詞文字描述。

#### B·補. CHAR_STATE · 人物持續狀態變體（★ 2026-10-13 新增 · 用戶實測反饋）

> **由來（用戶實測）**：「外賣員的資產圖裡是**戴著頭盔**的；提示詞裡讓他坐在家裡、**把頭盔夾在懷裡**——結果畫面裡**同時出現了兩個頭盔**：一個戴在頭上（資產圖帶的），一個夾在懷裡（提示詞要的）。」

**病根**：`SET_STATE` 只服務**場景**，人物此前**沒有任何狀態變體機制**——角色身上的穿戴物被立繪模板寫成「**配飾（固定不可變更·保留入圖）**」（`sd-asset-engine/references/character-portrait-templates.md` §二），而"同一人物多造型換裝"解決的是**跨造型**（A 造型 / B 造型各出一張圖），**不是「同一場戲內的狀態變化」**。
於是當劇情要求「摘下頭盔」時：資產圖鎖著"戴著頭盔"、提示詞要"夾著頭盔"，**兩者沒有優先級聲明 → 視頻模型把兩個信號【疊加】而不是【替換】→ 長出兩個頭盔。**

> **★ 鐵律（治本條）**：**資產圖鎖定的是「這個東西長什麼樣」，不是「它必須在身上」。**

**凡"持續一段劇情時間"的人物狀態變化**，一律登記 `CHAR_STATE` 並寫**生效區間**：

| CHAR_STATE 類型 | 例子 | 必寫（缺一即未登記） |
|---|---|---|
| **穿戴增減類** | 摘下頭盔 / 脫下外套 / 戴上或摘下眼鏡 / 解開領帶 | ① **脫離物去哪**（手持 / 夾在腋下 / 掛在臂彎 / 放在桌上 / 別在腰後）；② **脫離後本體的樣子**（髮型被壓扁 / 只剩內搭 / 未被遮擋的臉） |
| **傷病類** | 臉上的血 / 淤青 / 包紮 / 繃帶 | 位置、面積、**新傷還是舊傷**、是否持續惡化 |
| **汙損類** | 一身泥 / 溼透 / 燒焦的衣角 | 範圍、**乾燥進度**、是否可逆 |
| **時序類** | 閃回中的年輕態 / 入獄前後 | 與主時間線的**差異清單** |

**三條硬規則**：

1. **生效區間必寫**：`CHAR_STATE: 摘盔檔 · 自 EP2 段3 起 → 持續至 EP4 結束`——**沒寫結束＝默認延續到明確解除**，禁"這一鏡摘了下一鏡又戴上了"；
2. **跨 2 鏡以上的脫離態必須出圖**：與場景 SET_STATE 同規格——**狀態版單獨出圖並登記《資產圖冊》**（母版 + 脫離態並列）；**只跨 1 鏡**的可用**文字偏離聲明**替代（寫法見 `model-adapters.md` §5「資產偏離聲明」）；
3. **反"半途矛盾"**：寫"摘下頭盔"就必須同時寫**物理後果**（髮型被壓扁 / 額前有壓痕）——否則模型會給出"沒戴頭盔但頭髮仍是頭盔形狀"的詭異結果。同理，"脫下外套"要寫內層衣物。

#### C. 空氣介質層（有來源、有密度、有運動）

**"乾淨的空氣"也是一個明確選擇，不是默認留空。** 每個場景必須顯式聲明介質狀態：

```
【空氣介質】主介質：{清潔空氣 / 溼度 / 霧 / 煙 / 塵 / 雨雪 / 蒸汽}
  來源：{灶火 / 香爐 / 戰場揚塵 / 雨 / 地面積水蒸發 …}
  分佈：{全屋均勻 / 集中於地面 0~0.5m / 靠窗一側}
  密度與粒徑：{稀薄可見 / 中等 / 濃重} · {細霧 / 粗顆粒}
  運動：{靜止滯留 / 緩慢上升 / 隨穿堂風橫移}
  沉降與可見度：{無沉降 / 桌面薄灰} · 能見度{正常 / 略降 / 顯著降低}
  光散射：{不明顯 / 側逆光可見光路 / 光柱明顯} · 狀態變化：{隨劇情起止}
```

**兩條禁令**（與 `sd-storyboard-engine/references/scene-space-adaptation.md` 的"物理霧雙檢"同源，此處為**登記口徑**）：

1. **禁無源之霧 / 萬能光柱**：空氣介質**必須有來源**；場景只提供**介質事實 + 開口與遮擋事實**，**不為燈光崗位製造光柱**（光柱由光位決定，不由場景決定）；
2. **禁"什麼都沒寫的空氣"**：介質欄留空 = 執行者自由發揮；不確定時**寫"清潔空氣，無介質"**。

#### D. 尺度參照 scale_evidence（巨構 / 巨獸 / 異常尺度專用）

當場景或主體**尺度異常**（巨型殿宇、巨獸、深淵、千軍陣列）時，**必須提供可驗證的尺度參照**，否則模型會按常規比例渲染，巨構變小屋：

| 參照類型 | 寫法 |
|---|---|
| **熟悉參照物** | 人物與建築的比例（"門高約 6 人疊高"）、常見物件（馬車/台階/燈籠）作標尺 |
| **遮擋層** | 由近及遠 3 層以上遮擋，建立縱深與體量 |
| **地平線 / 消失點** | 明確地平線高度，判斷俯仰與體量 |
| **大氣透視** | 遠景降對比、偏冷、細節簡化 |
| **接觸面** | 主體與地面的接觸範圍、壓痕、投影長度 |
| **物理後果** | 重量反饋：風壓、揚塵、水浪、地面震裂、回聲延時 |

**與既有規則的交界**：尺度四件套的**玄幻戰力表現**（法相/劍陣的巨物化）歸 `sd-xuanhuan-engine`；本章只管**場景側的尺度事實登記**。

#### E. 年代錨 ERA_ANCHOR（★2026-10-12 新增 · 與劇本層《世界錨卡》同源）

> **由來（粉絲群實測反饋）**：「劇本大綱明確了 **2035 年南京**…他出來的是 **80 年代的破街爛車**」。

**場景出圖前必登記的五項**（從劇本層 `sd-script-engine/references/story-bible-and-ip.md` §1.11《世界錨卡》原樣抄下來，**禁在資產層另編一套**）：

| 項 | 內容 | 例（2035 南京） |
|---|---|---|
| 年份/朝代 | 精確到年；架空須聲明技術錨 | 2035 年 |
| 地域 | 市 / 區 / 場所 | 南京·城西高架橋下 |
| 技術時代 | 哪項技術已普及、哪項還沒有 | 近未來·全鏈智能 AI 已上線；飛行汽車未普及 |
| ⛔ 禁用元素清單 | 與本年代矛盾的元素逐條寫死 | 馬車 / 青磚 / 煤油燈 / 旗袍 / 長衫 / 木質樓梯 / 手搖電話 / 蒸汽機車 |
| ✅ 必現元素清單 | "一眼認得出年代"的 3~5 個錨 | 全息廣告牌 / 無人機航道 / 充電樁 / 溼瀝青反光 |

**四條鐵律**：
1. **場景母版圖、九宮格、調度版三張圖都必須對這張卡**——母版階段就鎖年代，不鎖的話後面每一張都會各自漂。
2. **人物服裝、道具、載具同受年代錨約束**——"2035 年的警察"穿的是該年代的制服，不是任何年代的"制服"。
3. **⛔ 禁用清單優先級高於"畫面好看"**——不得為了構圖好看把禁用元素畫進來。
4. **機檢兜底**：**C26a**（世界錨缺失）/ **C26b**（年代錨與正文物證衝突）；改動本錨 → 資產/分鏡/投餵稿逐級標 `STALE` 重出。

## 五、 道具出圖執行規範（P2c·第三批）

**流程**：關鍵道具出圖，每張確認鎖定。

**版式（硬性 · 2026-10-12 補）**：**單張設定圖內的四格合集 · 全圖共 4 格**（① 正面視圖 / ② 45° 側視圖 / ③ 頂部俯視圖 / ④ 關鍵細節特寫）——**不設獨立大主圖、同一視角不得重複、不得出現第 5 格**。提示詞**必須顯式聲明「全圖共 4 格」**。完整模板與負向詞**權威 = `sd-asset-engine/references/prop-template.md` §二**（本處只給執行骨架）。

```text
【道具資產圖提示詞】
畫幅：白底 16:9 靜物圖（單圖四格：正面 / 45°側視 / 頂部俯視 / 關鍵細節特寫）
道具：[名稱] · 材質：[類別+紋理+反光度] · 關鍵特徵：[磨損/刻痕/標識]
尺寸基準：[相對成人手掌或人物身高的參考比例]（僅作比例說明，禁止以手持方式呈現）
```

**出圖標準**：劇情關鍵物證 / 多鏡出現 / 有防穿模風險的道具必須出圖。

**純淨鐵律**：道具圖內**禁止出現任何人物、人手、肢體或人物剪影**，**禁止手持展示**（與 `prop-template.md` 一致——原「抓握方式 / 與手部相對大小」行易被模型執行成"畫一隻手握著"，2026-10-12 改為「尺寸基準」）。
