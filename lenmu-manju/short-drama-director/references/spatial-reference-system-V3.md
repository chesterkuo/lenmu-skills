# 空間參考系統 V3（歷史版 · 索引說明頁）

> 🗄️ **LEGACY / 備查**：本文件為歷史版空間系統，**已不再保留完整正文**（舊版 ASCII 空間圖 / 空間關鍵幀 / 外部專業分鏡解析規則已歸檔至 CHANGELOG 歷史條目）。**日常任務一律用：導演稿的「文字平面圖」+ 投餵詞的「一行式【站位聲明】」**，完整規則見 `blocking-direction.md` §一（★權威 · 文字平面圖）與 `asset-spatial-ledger.md` §三（★權威 · S0~S4 空間站位分級）。

## 何時才需要本系統

僅當滿足 **S4 複雜戰鬥 / 多人（5 人以上）多區域空間切換**，且文字平面圖 + 一行式站位聲明確已無法承載時，才從 CHANGELOG 歷史條目中取回舊版 V3 規則作參考。**S0~S3 一律不調用。**

## 與現行規則的關係（防走錯路 · 分兩層）

**過去這裡只寫"禁止畫圖"，導致執行者沒有調度手段，站位只能憑感覺——這是站位老大難的真實根因。分層：**

| 層 | 允許什麼 | 禁止什麼 | 權威 |
|---|---|---|---|
| **導演稿（內部·不投餵）** | ✅ **文字平面圖**：場景座標系（北/南/東/西）+ 固定物 + 主次入口 + 人物初始位與朝向 + 行動區 | ❌ ASCII 草圖 / 畫格示意 | `blocking-direction.md` §一 |
| **投餵詞（七段式）** | ✅ 一行式【站位聲明】：每人一段括號四要素（位置+依託物+朝向+姿態）+ 軸線行（左A右B·禁越軸）+ 位移行（起點→終點·每步有動作原因·禁瞬移） | ❌ **任何形式的圖**：ASCII 空間圖 / 座標數值表 / 俯視空間圖 / 初始圖+位移因果鏈 | `model-adapters.md` §5.0 / §5.1 禁寫清單第 4 條 |

**一句話：圖在導演稿裡，字在投餵詞裡。** 文字平面圖是導演保證站位前後不矛盾的工作產物，**翻譯成一行式站位後才進投餵詞**，導演稿本身不進投餵詞。

**空間連續性鐵律**（180° 軸線、上一鏡被擊退到哪下一鏡從哪繼續、真實場景位置 ≠ 畫面位置、在場聲明、單實例、景別-取景半徑匹配）已併入 `asset-spatial-ledger.md` §三，直接查那裡即可，無需回看本文件。
