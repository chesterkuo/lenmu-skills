## 一、 15 秒大招三段式節奏結構

一條標準的大招高燃提示詞必須分為三大連續階段，層層遞進，音畫共振：

```
┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│ 階段 1：大招蓄力 (0-3s)   │ 階段 2：法陣展開 (3-8s)   │ 階段 3：終極爆發 (8-15s) │
│ 特寫微距 + 極速環繞升鏡   │ 全景拉遠 + 空間扭曲畸變   │ 巨型法相/火龍捲 + 爆音終幀│
└──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

### 1. 階段一：大招蓄力與微距拉昇（0~3 秒，抓眼球）
* **鏡頭運鏡**：極低角度微推 $\rightarrow$ 特寫極速環繞拉昇 $\rightarrow$ 定格人物全身（⚠️ 定格僅指動作瞬間抓拍/命中 Hit-Stop，人物保持運動姿態，禁靜止站立）。
* **微觀動作**：手腕猛旋、指尖餘火纏成暗角、掌心太古籤紋極轉、足尖點噬火浪、收焰聚於掌心、青筋暴突、眼眸神光爆綻。
* **特效細節**：掌心凝刃、“主色+副色”雙色波湧燃煉、金羽凝結、空氣扭曲、碎石浮空。
* **音效設計**：**開屏即爆音！** 尖銳火雷聲/破空劍鳴 + 地面低頻轟鳴，0.5 秒特寫抖動蓄勢，瞬間拉滿壓迫感。

### 2. 階段二：法陣展開與空間異象（3~8 秒，造奇觀）
* **鏡頭運鏡**：低角度微推 $\rightarrow$ 全景平穩抬升拉遠 $\rightarrow$ 俯瞰空間格局。
* **空間動作**：單手擎天/虛空懸浮、身姿沉穩傲慢、尊袍隨狂風神風傲然揚動、俯視冷冽。
* **法陣與異象**：億萬符文如火龍盤旋漫天潑灑、空間隨陣法劇烈扭曲崩折、千道法紋鋪滿夜空頂、地面龜裂透出熔岩/雷光。
* **音效設計**：絃樂拉滿 + 重音震底，法陣展開伴隨漫天雷鳴轟鳴，節奏持續攀升。

### 3. 階段三：終極爆發與道域鎮壓（8~15 秒，情緒高潮）
* **鏡頭運鏡**：大廣角全景 $\rightarrow$ 極速推向爆發核心 $\rightarrow$ 衝擊波定格終幀。
* **終結絕殺**：凝聚十道巨型火龍捲/萬劍歸宗/黑淵禁區，碾碎漫天虛空，天地恆壓無極。
* **音效設計**：重低音音爆轟炸，餘音迴盪，絕不設平靜收尾，以最高燃爆點定格收尾！

### 4. FPV 主觀穿梭機位（萬劍/彈幕級大招專用）
> 學自 35s 玄幻秒級拆解：大招釋放段的“彈幕式”攻擊（萬劍齊發/箭雨/光彈），用**跟隨第一排攻擊的 FPV 主觀俯衝**，比旁觀全景更有代入感。
* **寫法**：跟隨第一排飛劍超高速向前俯衝，攻擊如暴雨傾瀉，呈地毯式火力壓制；
* **配套**：極速運動模糊 + 攻擊劃破雲霧/熔岩地面 + 密集機槍破空尖嘯音效（Supersonic Barrage）。

### 5. 短蓄力儀式感（慢/滯段·慎用升格）
> ⚠️ 2026-09-02 實測：**升格慢鏡破壞節奏，默認禁用**。大招蓄力/神魔顯現/法相成型段，用**短促凝神 + 能量聚核**快速帶過，保持節奏推進；除非用戶明確要求慢鏡，否則不寫“升格/慢動作”。
* **寫法（緊湊版）**：面部推鏡 $\rightarrow$ 拉開仰視全身，能量急劇坍縮成核，陰陽雙龍盤旋成太極圖（黑龍盤暗黑旋渦 + 白龍繞光明風暴 + 中央持兵）；
* **配套**：沉渾龍吟 + 史詩交響最高潮，1~2 個鏡頭內完成蓄力，緊接爆發。

### 6. 天地級異象（神魔/法相終極形態）
> 玄幻天花板級大招：**通天神魔巨軀**拔地而起，半身烈日半身熔岩，背後神環輪轉，手托擎天巨刃；下方山脈與人物如螻蟻微塵。
* **能量坍縮**：狂暴雷火向槍尖急劇坍縮凝聚為一點，空間產生引力透鏡扭曲（背景岩石被拉長、光帶彎折）；
* **滅世收尾**：神兵直插大地，地核能量柱如核爆貫穿天穹，大陸板塊斷裂，金紅光浪橫掃大陸，天際照亮成白晝，終幀高斯模糊+震屏。

## 二、 雙色粒子與高級質感配色鐵律

1. **雙色纏繞原則**：
   * 嚴禁單色塗抹，必須採用“主色 + 副色”高反差互補或漸變，例如：
     * `赤紅 + 暗金`（熔岩尊者、烈陽神明）
     * `玄黑 + 幽紫`（暗夜深淵、魔道至尊）
     * `冰藍 + 銀白`（霜雪劍聖、寒月仙尊）
     * `蒼青 + 鎏金`（太古道祖、東方修仙）
2. **UE5 級渲染與環境物理參數**：
   * 全局聲明必須包含：`UE5 超寫實真實光照，體積霧蒼茫瀰漫，8K 超高清，符文文字流動清晰、光芒微閃，材質細節極具真實感與顆粒感，開啟低空碎石虛空漂浮宏景`。

## 四、 去水五律（粒子/光效防"水"鐵律·2026-09-02 實測固化）

> 背景：多款模型默認把"粒子特效"渲染成均勻慢速的半透明彩色霧氣，把"光柱/法陣"渲染成呆板發光軟管或簡筆柱子——觀感"水"。以下五律為去水硬規則，寫任何大招/法陣/能量特效前必須逐條自查。

1. **禁評價詞**：頂級/神級/震撼/絕美/高動態範圍——模型不識別評價，純佔字數。只寫可見動作與材質。
2. **禁裸光效**：光柱/法陣/能量球/光束嚴禁裸寫，必須具象化四件套——由什麼構成（符文環/火流/鐵屑）+ 邊緣什麼樣（剝落/焦黑/白熱光邊）+ 怎麼動（輪轉/收束/分野）+ 密度層次（近實中厚遠虛）。
3. **禁寫"粒子"二字**：改寫作材質比喻——燃燒的鐵屑洪流（密度如蜂群）/ 水晶碎屑逆流 / 火星 / 餘燼 / 符紙碎屑。模型對這些材質有物理經驗，對"粒子"沒有。
4. **必寫方向與速度差**：全片一個速度=水。高速粒子帶拖尾光跡（0.2s 劃出畫面），慢速餘燼帶沉降弧線（觸地即滅）；禁"均勻漂浮"，寫"下落/逆流/貼地遊走"。
5. **生長三段論（壓縮→爆發→餘波）**：蓄力必須寫"逆向收束"（粒子像磁吸鐵屑向核心壓縮，衣袂髮絲被吸向能量場）——沒有壓縮就沒有重量感，這是水不水的分水嶺；爆發寫核心破裂+衝擊波環；餘波寫煙塵膨脹+餘燼沉降。

## 六、 雙屬性對沖與絕殺收尾範式（2026-09-04 吸收）

### 1. 雙屬性對沖成太極圖案炸散
- 兩屬性能量對沖時，禁寫"兩色光柱互推"——必須寫**兩股屬性流旋擰交纏成太極圖案，旋轉加速至臨界後整體炸散**；
- 寫法要素：雙色流體螺旋纏繞 → 圖案成型（陰陽雙魚咬合輪轉）→ 臨界過載 → 圖案崩裂炸散為漫天雙色光屑；
- 對沖雙方各自的色彩錨定遵循 `seedance-render-engine.md` §二·五·3（整套錨定+高反差互補）。

### 2. 能量吞屏切黑結尾（絕殺專用收束）
- 絕殺命中後：**能量光浪吞沒全屏 → 切黑 → 環境餘聲收束**（碎石滾落/風聲/耳鳴）；
- 三拍結構：命中爆閃（吞屏白/屬性色）→ 純黑 0.3~0.5s → 餘響漸起；
- 禁止絕殺後直接跳平靜全景——吞屏切黑給"重擊消化時間"，餘聲收束給"餘韻留白"，均不拖節奏。
