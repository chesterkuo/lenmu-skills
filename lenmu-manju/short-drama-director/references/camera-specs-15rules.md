# 15 秒完播率鏡頭規格、空間斜角與防穿模鐵律 (Camera Specs & 15-Sec Rules)

---

## 一、 15 秒完播率黃金公式

> 📐 **畫幅路由**：橫屏 16:9 / 豎屏 9:16 的構圖、景別階梯與運鏡寫法 → 以 `aspect-ratio-adaptation.md`（★權威）為準，按用戶指定畫幅切換。

$$\text{完播率} = \text{開局無試探 (20%)} \times \text{節奏呼吸 (30%)} \times \text{運鏡豐富度 (25%)} \times \text{情緒絕殺 (25%)}$$

1. **開局無試探（0~1.5s 必須見肉）**：第一幀必須雙人同框近景/中景，1.5 秒內必須爆發一次極端殺招正面硬撞，嚴禁遠景慢熱鋪墊；
2. **同運鏡 $\le 2$ 秒，同景別 $\le 3$ 秒**：15 秒內完成 5~8 次精準鏡頭切換；
3. **以高潮收尾，不設收尾幀**：15 秒最後一幀必須是終結技命中、氣血炸裂、碎石飛濺或擊飛倒地的最高潮定格，不設收腿平息畫面。

## 二、 鏡頭規格五要素（每次必寫）

格式：`[景別] · [拍攝視角+角度] · [運鏡方式] · [跟隨目標]`

* **景別**：全景 / 中景 / 中近景 / 近景 / 特寫；
* **視角**：正面(0°) / 側面(90°) / 斜角(30°-60°) / 俯拍 / 仰拍；
* **角度**：平視 / 仰視(N°) / 俯視(N°)；
* **運鏡**：跟拍跟鏡 / 急速推鏡 / 急速拉鏡 / 甩鏡閃切 / 命中瞬間定格（Hit-Stop 微停頓，1~2 幀）/（⚠️ 慢動作跟鏡、升格默認禁用，2026-09-02 實測破壞節奏）
  * ★**「命中瞬間定格」是時間類技法，可單獨佔運鏡槽**——機檢 **C18g** 詞表已收**定格族**（命中瞬間定格 / 命中定格 / 定格 / 定鏡 / 定鏡收束 / 凝固 / 凝住 / 定住 / 頓幀 / Hit-Stop / 微停頓），**獨立成族、不計入固定鏡頭配額**（C18j 只認 `fams == {"固定"}`）。**2026-10-16 修正**：此前 `CAM_FAMILIES` 只按 §四 運鏡總表的"運動類"技法建詞、**時間類技法零收錄**，照本條寫「命中瞬間定格」會被 C18g 誤報"鏡行未標註運鏡"（粉絲排查報告核驗屬實 · 已端到端復現）。同步補錄的運鏡詞還有：環移 / 甩搖 / Whip Pan / SPIN / TILT-up / TILT-down / 軌跡跟焦 / 焦點縱深拉移。
* **跟隨目標**：跟隨角色、肢體或具體接觸點。

> ⚠️ **鏡行書寫口徑（2026-09-15 用戶裁定）**：五要素是**設計檢查表**，用於確保每個鏡頭都想清楚；落到【時間軸分鏡】鏡行時**只寫三要素** `[鏡頭N] 景別 · 視角角度 · 運鏡。動作描述。聲音：…。台詞：…。`，**不寫"跟隨@誰"**——跟隨作為運鏡策略在動作描述裡自然體現（如"鏡頭隨其位移橫移"）。見 `model-adapters.md` §5.0 / §5.1。

## 三、 空間感兩大鐵律

1. **中景及全景嚴禁 90° 側面正拍**：中景和全景必須使用 **30°~60° 斜角拍攝**，建立前後遮擋與空間縱深，徹底杜絕街機橫版感；只有近景/特寫允許 90° 側拍。
2. **景別與動作幅度絕對匹配**：大幅動作配全景/中景展示張力；小幅拳肘對招配近景/中近景放大密度。

## 四、 宏微觀景別階梯躍遷 (Shot Ladder Progression)

連續鏡頭的景別與機位嚴禁平鋪重複，必須按階梯躍遷製造視覺推進感：

$$\text{標準階梯} = \text{極微距特寫（發力微觀）} \to \text{超廣角/低角度中景（雙人攻防位移）} \to \text{宏觀全景（環境/法陣破壞）} \to \text{鳥瞰/過肩定格}$$

### 1. 階梯躍遷鐵律
* **嚴禁連續兩個鏡頭使用相同景別 + 相同機位**；
* 動作高潮前插入**極微距特寫**（指尖發力/劍身微顫/眼眸神紋），淺景深虛化背景製造張力；
* 大招釋放用**宏觀全景**展示環境破壞（法陣崩碎/山峰崩塌/竹海覆滅）；
* 絕殺收尾用**鳥瞰或過肩定格**，配合滿天飛葉/煙塵撲鏡實現自然遮擋轉場（Occlusion Wipe）。

### 2. Eye-Trace 視線流引導
* 相鄰鏡頭的主體高光/視覺焦點必須保持在屏幕**同一象限**或沿動勢方向連續過渡；
* 例如：鏡頭1 右側出鞘刀光 → 鏡頭2 自右向左衝刺的流光核心，避免觀眾視線滿屏搜索。

### 3. 極限景別跳躍（Macro-Micro Jump）
> 長段高燃戰鬥/大招段，在**極微距特寫（ECU）** 與 **極宏觀大遠景（EWS）** 之間極限跳躍，製造空間張力與視覺震撼（學自 35s 玄幻秒級拆解）。與下方單向階梯互補：階梯管順序推進，極限跳躍管兩極反差。

* **兩極對跳**：ECU 雙眼怒睜蓄能 → EWS 天幕分野異象（右半邊天被金紅火色染透，左半邊鉛灰雷雲，雲層分野滾動）；ECU 兵刃咬死 → EWS 通天神魔巨軀；
* **極端體量對比**：EWS 中下方山脈與人物如螻蟻微塵，巨像背後神環輪轉（體量對比本身就是奇觀）；
* **適用**：神魔覺醒/大招釋放/滅世收尾段；普通對招不強制。

## 四·五、 四階動靜呼吸律 (Rhythm Curve)

> 長段戰鬥（≥15s 或拆段成片）的節奏骨架：**靜 → 極動 → 慢/滯 → 絕殺** 四階段遞進，缺一平淡（學自 35s 玄幻秒級拆解，對應 `sd-combat-engine/references/tier-and-finisher-system.md` §一 的“快慢交替 ≤5s”）。

1. **靜（暴風雨前肅殺）**：眼眸特寫、平心擦劍、蓄勢凝神，節奏壓到最低；
2. **極動（節奏拉滿）**：空斬、貫穿、地面犁地對沖、暴風驟雨多段拆招；
3. **慢/滯（短蓄力·不用升格）**：萬劍蓄力、神魔顯現、能量凝核——用 **1~2 個緊湊鏡頭快速帶過**，保持節奏推進（⚠️ 2026-09-02 實測：升格慢鏡破壞節奏，默認禁用，蓄力段只保留短促凝神+聚能）；
4. **絕殺定格**：法相舉戈、貫穿滅世，最高情緒與視覺爽點釋放，定格終幀。

> 適用：大招釋放段 / 長段拆分成片。普通文戲對白按標準景別切換即可，不強制階梯。

## 五、 受擊鏡頭工具箱（捱打方怎麼拍·2026-09-04 吸收）

> 受擊不是"被打飛"三個字了事——按受擊強度選用以下鏡頭手法，讓捱打方也有鏡頭語言：

- **短促徑向震動**：命中瞬間鏡頭沿受力方向短促震一下（1~2 幀），模擬衝擊波擊中攝影機；
- **輕微軸向受力**：鏡頭隨受擊方向小幅偏轉/傾斜，傳遞"攝影機也被波及"的重量感；
- **瞬時焦點變化**：受擊瞬間焦點從攻方急切到受擊方面部（痛苦細節），或焦點隨擊飛目標快速轉移；
- **動態模糊與速度匹配**：擊飛/震退段加徑向動態模糊，模糊方向與位移方向嚴格匹配，禁全屏均勻模糊；
- **Time Ramp 變速**：僅限極短受擊瞬間（命中幀前後 0.2s 內的加速/減速切換），禁整段升格慢鏡（2026-09-02 已默認禁用）。
