# 工業級五階門控劇本引擎與去 AI 機械感視聽法則 (Screenplay Gate Engine)

本模塊規範了全題材（涵蓋古裝武俠、現代都市、懸疑腦洞、動作槍戰、科幻等）短劇/漫劇從概念到專業劇本頁的工業化生產標準。核心原則：**劇本即唯一真理源 (Screenplay as Source of Truth)**，所有角色、場景、道具資產自動從劇本文本雙向綁定並派生。

---

## 一、 工業五階門控開發流水線 (5-Stage Gate Pipeline)

動筆寫劇本前必須依次通過五道門禁，嚴禁跳過結構直接寫大段台詞：

### Gate 1: Premise（核心前提與黃金 3 秒鉤子）
* **30 字前提公式**：`[主角] + [核心慾望] + [不可抗力阻礙] + [失敗的致命代價]`。
* **黃金 3 秒鉤子類型**（必須明確選定其一）：
  1. 極端懸念鉤（直接把槍口/刀尖對準主角咽喉，生死懸於一瞬）；
  2. 認知反差鉤（看似最弱的外賣員/贅婿/乞丐，展現出顛覆常理的宗師特權）；
  3. 情緒爆發鉤（至親慘遭凌辱/婚約撕毀/絕境背叛，怒氣值瞬間拉滿）；
  4. 視覺奇觀鉤（天雷裂空/上古法相降臨/超維異象爆發）。

### Gate 2: Structure（宏觀三幕比例與分集卡點）
* **單集三幕時間比例**：鋪墊建立 30%（0~30s） $\to$ 核心衝突危機 50%（30~80s） $\to$ 轉折爆發與卡點 20%（80~100s）。
* **結尾卡點鉤子（Cliffhanger）**：必須停留在決策關頭、身份暴露瞬間、援兵突現或攻擊命中的前一幀。

### Gate 3: Beat Sheet（場景因果節拍表）
* **場次存在性法則**：一場戲如果刪掉後不影響後續劇情，則該場戲必須立即刪除。
* **每場戲必須包含完整因果鏈**：`場景目標 -> 遭遇阻礙 -> 升級行動 -> 意外轉折 -> 產生不可逆新局面`。

### Gate 4: Worldview & Entity Bounds（世界觀與實體邊界約束）
* **時代法則**：明確時代背景（古代/民國/現代/賽博未來），鎖定法律、戰力天花板與技術極限。
* **人際關係網絡（Relationship Graph）**：明確上下級、仇恨、盟友關係，杜絕無動機叛變。

### Gate 5: Professional Script Page（語義化工業標準排版）
```text
[場景序號] [內景/外景] · [具體地點] - [日景/夜景]
出場人物：@角色A、@角色B
環境氛圍：[空間構圖、天氣、主導光源與聲音質感]

[動作描述]（遵循反形容詞法則，只寫攝像機能拍到的物理動作與空間位移）

@角色A（微動作指示：咬緊後槽牙，指節因用力而泛白）
“（台詞內容，遵循冰山法則與潛台詞）”

@角色B（冷笑，眼神下瞥避開對視）
“（台詞內容）”
```

## 二、 去 AI 機械感三大法則 (Natural Screenplay Laws)

1. **角色壓力與籌碼追蹤（Character Pressure Tracking）**：
   * 角色對話不是客氣的問答，而是權力、信息與立場的隱秘博弈；
   * 每句對話必須有一方施壓、另一方掩飾/反擊，杜絕毫無立場的解釋性閒聊。
2. **承重場景識別（Load-Bearing Scenes）**：
   * 區分“承重戲”（生死抉擇、秘密揭穿、宗師死鬥，投入最高視聽與微表情密度）與“過場戲”（果斷視聽省略，一鏡帶過）。
3. **冰山對白（Iceberg Dialogue & Anti-Exposition）**：
   * 嚴禁角色向已經知情的同伴解釋世界觀設定（如“你明知道這本秘籍是天下第一……”）；
   * 雙方已知信息一律轉入潛台詞、眼神與道具動作。
