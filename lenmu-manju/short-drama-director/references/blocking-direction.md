## 〇、定位與邊界（先讀這條，防與既有文件打架）

本文件解決的是**「為什麼這樣站、這樣走、這時切不切」**——即**導演決策層**。

| 層 | 回答什麼 | 唯一權威 |
|---|---|---|
| **導演決策層（本文件）** | 這場戲的人物**怎麼調度**、權力關係怎麼用空間表達、節拍怎麼走、何時切鏡 | **本文件** |
| **投餵執行層** | 站位**怎麼寫進提示詞**（一行式四要素 + 軸線行 + 位移行） | `asset-spatial-ledger.md` §三 + `model-adapters.md` §5.0 |
| **分段/轉場層** | 怎麼切成 ≤15 秒的生成段、切點落哪 | `segment-splicing.md` + `sd-qc-engine/references/editing-transition-gate.md` |
| **圖形化層** | 逐鏡面板怎麼畫、面板邊界≠剪輯點 | `sd-storyboard-engine/references/storyboard-sheet-template.md` |

**四條邊界（越界即返工）**：

1. **不改劇本**：不改台詞、不增刪事件、不改人物動機；
2. **不選器材**：不指定正式焦段、攝影設備、精確軌跡、燈光器材——那些歸 `sd-storyboard-engine` / `sd-decision-engine`；
3. **不寫投餵詞**：本文件的產物是**導演稿（內部）**，不是【站位聲明】投餵欄內容；
4. **不確定就停**：入口狀態（誰在場、在哪、手裡有什麼）不明確時**停止該場並詢問**，**嚴禁重置人物與道具**、嚴禁靠猜繼續。

## 一、場景座標系與文字平面圖（解禁 · 這是站位老大難的根因修復）

### 1.1 先講清楚"解禁了什麼、仍然禁什麼"

> **歷史衝突**：本包長期寫「**禁止畫圖、禁止座標表、禁止 ASCII 佈局**」（`model-adapters.md` §5.0）。用戶與實測的共同反饋是：**站位依然是最容易被詬病的環節**——因為禁令只砍掉了"投餵詞裡畫圖"這個錯誤做法，卻**沒有提供替代的調度手段**，執行者於是只能憑感覺寫站位，站位自然不穩。
>
> **收窄口徑（一句話）：圖畫在導演稿裡，字寫在投餵詞裡。**

| | 內容 | 判定 |
|---|---|---|
| ✅ **允許（新增）** | 在**導演稿內部**寫**文字平面圖**：用場景座標系（北/南/東/西 + 垂直層級）、固定物、入口、行動區、人物初始位置與朝向，**以結構化文字**表達空間關係 | 本文件 |
| ❌ **仍然禁止** | 把任何形式的圖**寫進投餵提示詞**：ASCII 草圖、俯視 ASCII 空間圖、座標數值表、初始圖 + 位移因果鏈、"畫個五宮格示意站位" | `model-adapters.md` §5.1 禁寫清單第 4 條 |

**為什麼這樣切**：AI 視頻模型對"投餵詞裡的圖形符號"解析能力極差（這是禁令的原始動機，依然成立）；但**導演自己需要一張空間圖來保證站位前後不矛盾**——這張圖是**思考工具**，不投餵，不進入七段式任何一段。

### 1.2 文字平面圖寫法（必須只用下面這幾類要素）

```
【場景座標系】（寫一次，全場共用，後續所有調度引用它）
  方位基：以場景實際朝向為準 —— 北 = 正對主窗/主門 / 南 = 回望入口 / 東·西 = 兩側
  垂直層級：地面層 / 台階層（+0.5m）/ 高台層（+2m）
  中央活動區：{劇情對峙/行動發生的核心區域}
  主入口：{門/缺口位置}　|　次入口：{位置或"無"}
  固定物（不可移動·可作依託）：{立柱 / 沙盤 / 長桌 / 擂台邊緣 / 斷橋石墩 …}
```

```
【人物初始位】（逐人一行，禁"畫面左右"代替真實方位）
  @角色A：{北窗下·靠東牆} · 朝向{南·面朝室內} · 姿態{立·雙手負後}
  @角色B：{中央活動區·沙盤南側} · 朝向{北·面向A} · 姿態{俯身看圖}
  群像開關：{A/B/C} —— A：逐人派事務；B：只寫密度句；C：全段寫「除 @XX 外無其他人物」
```

**三條硬規則**：

1. **絕對方位優先**：能用"北/南/東/西 + 固定物"就不用"畫面左/右"——**畫面方位隨鏡頭翻轉，真實方位不會**；
2. **每步有依託**：人物落位儘量綁定固定物（"靠東牆立柱"），**懸空站位是漂移的第一來源**；
3. **寫一次、全段引**：座標系建立後，後續節拍只寫增量（`@角色A：北窗下 → 中央活動區`），**不重複抄座標系**；
4. **群像開關逐段裁定（P7 新增）**：每段必須顯式標 `群像：A/B/C`（判據見 §4.2），**禁沉默**——不裁＝模型自己猜，要麼空場要麼亂加人。

### 1.3 與投餵層的交接（這一步不能省）

導演稿的【人物初始位】**必須**被翻譯成投餵層的**一行式【站位聲明】**才能投餵：

```
導演稿（內部·真方位）           →   投餵詞（七段式·畫面方位）
@角色A：北窗下·靠東牆·朝南      →   @角色A（畫面左 · 背靠東牆立柱 · 側身45°朝右 …）
```

翻譯規則與四要素語法見 `model-adapters.md` §5.0；**翻譯後導演稿不進投餵詞**。

## 二、權力幾何（誰高誰低，用空間說，不用台詞說）

**權力幾何**＝用**站位差、高度差、遮擋、距離**表達人物關係變化。每一場至少明確一次：

| 維度 | 低權力 / 受壓 | 高權力 / 壓制 |
|---|---|---|
| **高度** | 坐 / 跪 / 俯身 / 處於台階層以下 | 立 / 居高台 / 俯視 |
| **空間** | 被逼至牆角 / 退至門邊 / 處於中央活動區邊緣 | 佔據中央活動區 / 背靠唯一齣口 |
| **遮擋** | 被固定物遮去半身 / 被對方身影蓋住 | 無遮擋、正對光源 |
| **距離** | 被迫後撤、距離被動拉大 | 主動逼近、壓縮對方可移動範圍 |
| **取景半徑** | 需借"畫外"承接 | 佔據取景中心 |

**鐵律**：**場末的權力幾何必須與場初不同**（否則這場戲的空間沒有參與敘事）。若劇本本身權力不變（如純過場），**顯式寫明"本場為過場，權力幾何不變"**，不允許默認省略。

**與既有規則的交界**：權力幾何的**具體鏡頭實現**（大仰角/大俯角/側面疏離）歸 `sd-storyboard-engine`；本文件只負責**決定誰該在什麼空間位置**。

## 三、節拍閉環：起勢 → 路徑 → 接觸/阻擋 → 落點 → 接收者反應

每一個**動作節拍**必須五段閉合（缺段＝該節拍沒完成）：

| 段 | 寫什麼 | 缺段的後果 |
|---|---|---|
| ① **起勢** | 誰、在哪個座標、做什麼準備動作 | 動作無來由 |
| ② **路徑** | 從哪走到哪（起點座標 → 終點座標），**必經點**在哪 | 瞬移 / 穿模 |
| ③ **接觸 / 阻擋** | 動作落在誰/什麼物上；被什麼擋住 | 打空 / 動作懸空 |
| ④ **落點** | 結果狀態：誰被推到哪裡、道具到哪、誰失去平衡 | 下一節點失位 |
| ⑤ **接收者反應** | **被動作影響的對象**的可見反應（面部/體態/後退） | 動作沒有戲劇價值 |

**節拍閉環的兩條禁令**：

1. **禁瞬移**：角色從 A 到 B 必須有②路徑，**除非劇本給出瞬移設定**（如玄幻身法），此時必須寫視覺痕跡（殘影/空間裂隙）；
2. **禁穿模**：路徑**不得穿過固定物**；必須繞過或跨越，並寫明方式。

**與既有規則的交界**：本閉環負責**動作的空間邏輯**；動作的**物理動力學**（11 環動力鏈 / 受力形變）歸三個打戲引擎 `sd-combat-engine` / `sd-real-engine` / `sd-xuanhuan-engine`。

## 四、對話與群戲的調度鏈

### 4.1 雙人對話：說話者 → 聽者 → 反應者鏈

對話不是"你一句我一句給鏡頭"，而是**信息在三人鏈上的傳遞**：

```
說話者（發出）→ 聽者（接收·必須可見）→ 反應者（第三方·把隱含態度外化）
```

- **聽者必可見**：任何一句有分量的台詞，**聽者的接收狀態必須給到**（否則台詞沒有落地）；
- **反應者可缺席但要說明**：無第三方時，**反應由聽者兼任**，須寫明"本場無第三方，反應掛在聽者身上"；
- **反應優先於台詞**：判斷"這句要不要切鏡"時，**看反應有沒有價值**，而不是看誰在說話（與 `sd-qc-engine/references/editing-transition-gate.md` §三·切鏡觸發門同源）。

### 4.2 群戲：主焦點 / 次反應 / 背景行為 三級

三人以上同場時，**每個節拍只允許一個視覺主焦點**：

| 層級 | 數量 | 要求 |
|---|---|---|
| **主焦點** | 恰 1 個 | 本拍的動作或信息主體 |
| **次反應** | 1~2 個 | 對主焦點有可見反應，**必須具名 + 具體位置 + 具體狀態** |
| **背景行為** | 其餘 | 有穩定的背景活動（不搶動作），**禁"靜止的人形立牌"** |

**鐵律**：**嚴禁全員同時搶動作**（模型會把每個點名的角色都渲染一次完整動作，導致畫面散架）。收束方式：只讓主焦點做大動作，次反應做**小幅度**反應（轉頭/退半步/皺眉），背景行為做**循環性**動作（添茶/侍立/走動）。

> **★ 群像開關（第一層閘門 · 2026-10-24 P7 新增 · 本層裁定，投餵層只翻譯）**
> §4.2 的「背景行為」此前只是**調度側原則**，投餵層無槽位、機檢無斷言、且與 C35/C37/C20h 三條反向規則無裁決
> → 執行時必然選最省力的那條，背景人被按死。現在由本層**先裁開關**，把衝突消解在調度環：

| 開關 | 判據（命中任一） | 下游動作 |
|---|---|---|
| **A · 開·逐人寫** | 公共/半公共空間且 ≥2 個無名可見人；劇本有圍觀/旁聽/知情敘事；擺了 ≥2 個非主角點位；**台詞需要"被聽見"** | 每人派一件事務（R/P 型），見 `short-drama-director/references/crowd-behavior-direction.md` §三 |
| **B · 開·只寫密度** | 場景有人但不承擔敘事 | 只寫密度句（S 型），不寫個體 |
| **C · 關** | 密閉雙人戲 / **打戲段** / 純特寫 / 四下無人 / 豎屏近景對話 | 全段寫 `除 @XX 外無其他人物`（C20h 句式），**禁出現任何群像事務** |

- **C 類一票否決**：公共空間 + 打戲 = **打戲贏**（動作清晰度是剛性需求，背景真實感是彈性需求）；
- 開關標在**文字平面圖**的場景頭上（`群像：A/B/C`），一段一裁，同場景可切（教室走廊段 A，後門偷聽特寫段 C）；
- **沉默不是 C**——不裁開關 = 模型自己猜，結局要麼空場、要麼亂加人。三類都必須是顯式聲明。

## 五、關鍵道具：持有 / 轉交 / 落點 / 左右手

劇情關鍵道具（信物、武器、證物、圖冊）在本層必須**逐節拍登記四項**：

```
【道具賬】@玉佩：持有者{@角色A} · 手位{右手·虛握} · 狀態{完好} · 本拍動作{無}
        節拍③後：持有者{@角色B} · 手位{左手} · 狀態{完好·被奪}
```

**四必寫**：

1. **持有者**（誰拿著）——換人必有交接動作；
2. **手位**（左/右手）——**跨鏡換手是最隱蔽的穿幫**，換手必須有具體動作承接；
3. **落點**（離手後去哪）——**道具離手但未給落點＝下一鏡必然隨機出現**；
4. **狀態**（完好/破損/沾血/入鞘）——狀態變化必須有觸發節拍。

**與既有規則的交界**：道具的**出圖**（道具資產圖）歸 `sd-asset-engine/references/prop-template.md`；道具的**單實例鎖與跨鏡朝向**歸 `asset-spatial-ledger.md` §三·7 與 `sd-asset-engine/references/continuity-and-crowd.md`；道具的**投餵層錨點**（`@PRP-道具名`）歸 `model-adapters.md` §5【場景資產】欄——**本層【道具賬】管"怎麼決定"，投餵層【場景資產】欄管"怎麼寫進提示詞"**，兩者同源不重複（2026-10-13 補：此前【道具賬】在投餵層無對應落位，道具只能寫鏡行括號夾註）。

## 六、鏡頭策略四模式：本層"決定"，分段層"執行"

本場必須在下面四種裡**選唯一一種**，並寫明**選擇證據 + 被否決方案**：

| 模式 | 判據（互斥） |
|---|---|
| `TRUE_ONE_TAKE` 真一鏡到底 | 禁切區非空；不得含任何切鏡；跨段須保持同一鏡頭身份、軌跡、空間、焦點、光線連續 |
| `SIMULATED_ONE_TAKE` 偽一鏡到底 | 只用導演批准的隱藏縫（遮滿畫面 / 快速掠過 / 暗部 / 同構運動）銜接 |
| `CUT_COVERAGE` 常規切鏡 | 至少 1 個已批准切點；每個可見切鏡必須帶來新信息 / 新立場 / 新反應 / 時間壓縮 |
| `HYBRID` 混合 | 以不可切連續段為骨架，只在規定事件點切鏡 |

> ⚠️ **不重複定義**：四模式的**完整判據、字段、轉場優先級、生成分段政策**，唯一權威在 **`sd-qc-engine/references/editing-transition-gate.md` §一~§三**（另有 `segment-splicing.md` 段縫規程）。本文件只做**決策入口**，字段一次都不重抄。

**本層必須額外交出的兩份東西**（這是分段層拿不到的）：

- **決策證據六項**：`空間連續價值 / 表演連續價值 / 信息分佈 / 視角變化需求 / 時空壓縮需求 / 技術與生成可行性`；
- **被否決方案**：至少寫一條"為什麼不選它"（**"節奏更快、畫面更豐富"不算理由**）。

## ★ 物理承重接觸 · 跨切省略 · 鏡前六行事實核對

1. **物理承重與接觸因果**：
   - **遞物**：先寫雙方共同承托，接收方拿穩後原持物方才鬆手；物體進入口袋或袋子沿連續路徑遮入，不在手接近時憑空消失；
   - **放物/觸碰**：先物體底部接觸桌面再鬆手；手掌先碰觸衣料/髮絲，後者才發生壓迫變形；溼布/厚衣有真實垂墜重量，不整塊飄成輕紗。
2. **時間省略靠切鏡，鏡內保真速**：長距離走動、上樓、搬運可在鏡與鏡之間直接切鏡省略（開鏡人物已到門口/已坐定），但鏡內動作一律按真實速度發生，不靠鏡內瞬移壓縮。跨切承接結果狀態（如聽筒已放回、袋已推至桌中），不重複演一遍上鏡動作。
3. **動筆前內部六行事實表（只作導演核對，不外露進提示詞）**：寫任何鏡前先過一遍——①起止時間與機位高度朝向 ②人物踩哪塊地面、誰在畫外 ③哪隻手持何物與結束態 ④光源世界位置 ⑤本鏡表演動機與觸發事件 ⑥空氣/風向來源。

## ★ 鏡內朝向與本場剛性參照物四鐵律（吸收韓系電影感 v4.3.4 + 宗門大會實測復盤）

> **實測根因**：只把“面朝北”寫在段首【站位聲明】、鏡行裡卻寫“南偏西35° / 畫左下方”時，視頻模型聽不懂羅盤角度與平面座標，會自動把人物轉成正臉對鏡頭或越軸。執行以下四條徹底根治：

1. **鏡行主體焊死正/側/背朝向**：每鏡開頭主體必須自帶可見朝向詞（如 `林硯完整背影跪姿全景`、`魏無忌側前方中近景`、`林硯左臉四分之三側視中近景`）。凡需要背對鏡頭的人物，**必須在鏡行正文寫死「完整背影背對鏡頭（只露後腦與衣背），面朝〔具體物理參照物〕」**，絕不指望模型回憶段首站位聲明。
2. **機位與朝向一律落在本場剛性物理參照物上**：廢除“南偏西 35°、畫左下方、畫右前上方”等空洞羅盤與平面座標，改為**具體可見物理位置**（如 `機位貼朱漆大門內側正中，極緩推進`、`面向三階青石高台`、`偏頭看向高台西側暗紅木柱方向`），讓剛性建築/傢俱自帶透視鎖住朝向。
3. **每鏡尾補「視線指向 → 切點」閉環**：鏡行句尾顯式寫明動作或視線落點並指向下一鏡主體（如 `目光鎖死高台西緣，切魏無忌`），防止連續正反切發生 180° 視線越軸。
4. **單人近景禁寫“前景” + 5 秒鏡台詞硬控 ≤18 字**：單人近景只寫 `畫面內僅有@某人一人`，禁寫“前景左側入畫”（防模型憑空塞出無關虛焦過肩人頭）；5 秒單鏡台詞硬控 ≤18 字並留 ≥1.5 秒閉口緩衝，防止台詞溢出撞進下一鏡導致跨鏡串嘴與胡編亂詞。
5. **道具落點與進場動線同側順接**：跨段或同段中需由某角色拾取、觸碰的地面/桌面道具，其初始座標應優先落在**該角色步入路線的同側觸手可及處**（例如：角色從右側步入，則道具落在目標人物右側而非背後），避免角色繞行至他人背後或折返拾物導致走位彆扭與軸線漂移。
6. **殘損/斷折長條道具特寫防「對稱雙柄鋸」鐵律**：
   - 描述斷劍、殘刃、折斷木杖等殘損道具時，**禁用“鋸齒”一詞**（防視頻模型把整條刃口生成為手鋸鋸條），改寫為**“齊中折斷、參差不齊的暗褐金屬斷茬 / 不規則折裂鈍口”**；
   - 特寫持握時**禁用“雙手對稱托舉/握住兩端”**（防模型左右對稱腦補，在斷口另一端憑空長出第二隻手和第二個劍柄），強制改寫為**單手緊握劍柄斜舉、折斷斷口作為懸空自由端暴露在光束中**。
7. **殘損道具「單實體化」鐵律**：需要撿起、展示的折斷/破損道具（如斷劍），全鏈路（道具四格圖、白模、視頻）只保留**單一物理實體（例如唯一半截帶柄殘劍，不畫脫落的另一截）**，徹底杜絕視頻模型在全景裡把兩截焊回完整器物或在特寫裡衍生雙柄。
8. **單段 28s 黃金節奏與口播防糊鐵律**：Seedance 2.5 單段 25~28s 優先控在 **7~8 鏡**（反應/特寫 2~3s，重台詞與動作鏡 4~5s），嚴禁同角色無過渡連切跳針；多人全景首鏡按“從左到右”顯式點名全員座標防串位；台詞避開拗口四字書面連讀，改用短促自然大白話防 AI 吞音或墊字重讀。
9. **鏡行頭運鏡位對齊 `C18g`**：鏡行頭採用 `[鏡頭N] 主體朝向 · 景別｜焦段｜運鏡｜物理機位` 格式（把 `緩推/緩跟/固定/快搖` 直接置入 `｜` 段內、置於句首標點前），確保既直觀又 100% 過 `C18g` 運鏡機檢。
10. **鏡行位移禁混寫「羅盤詞 + 橫向」與全景主角顯色點名鐵律**：
    - **禁混寫羅盤詞與橫向**：一旦機位轉向側牆，“向西/向東”即變為迎面走近而非橫向，混寫“向西橫向跨出”會導致模型反向從畫面另一側跑出；鏡行位移一律採用與首鏡同向的微斜基準機位，寫死**畫面側向 + 具體起止地標**（如 `東窗穩居畫面右側，@角色離開右側東窗隊列，由畫面右側向大殿中央大步走出`）；
    - **首鏡全景防主角被群演淹沒 & 左右順序對齊**：若核心主角身處群演隊列中，首鏡全景必點明其**服裝主色 + 具體剛性位**（不可籠統寫“群演與@角色分立兩側”）；高台/主座多人同框首鏡必須嚴格按**從左到右**順序點名，確保文本提及順序與站位圖 100% 一致不打架。
