# 輕量離線分鏡看板（Storyboard Board Lite）

> ⭐ **定位**：把項目 md（唯一真相）一鍵編譯成**單文件離線 HTML 看板**——雙擊瀏覽器即開，零依賴、零數據庫、零端口。形態與 6.8.3 完整版（模塊 K）**同構**：創作藍圖層 + 分鏡生產層雙層區塊全保留；**只砍** N1~N11 深度檢查層、`validate_prompt.py` 依賴與 board_state.json 快照。
>
> 🔗 配套腳本：`scripts/build_board_lite.py`

---

## 一、 四條輕量鐵律（K-lite 1~4）

| 編號 | 鐵律 | 說明 |
|---|---|---|
| **K-lite-1** | **md 是唯一真相，看板只讀** | 看板是產物不是工作面。⛔ 禁止"在網頁裡改分鏡再同步回 md"；改稿改 md，然後**重編譯**看板。 |
| **K-lite-2** | **缺字段降級不中斷** | md 是用戶手改的文件。任何章節缺失 → 該區塊顯示"未解析到"並記 **WARN**，**看板永遠出得來**，絕不因一處格式不標準整板崩掉。 |
| **K-lite-3** | **拆解視圖與原文並存** | 每段必須同時給：① 逐鏡拆解（泳道 + 鏡頭卡，定位問題用）+ ② ` ```text ` 圍欄原文照錄（直接複製投餵用，不改寫）。只做其一 = 看板殘廢。 |
| **K-lite-4** | **⑤ 出圖提示詞與 ③ 投餵提示詞必同板** | **P2.5 資產出圖提示詞與 P4 分鏡投餵提示詞必須同時出現在看板上**——一邊出資產圖、一邊投視頻，缺 P2.5 → WARN 並在 ⑤ 區提示補齊。 |
| **K-lite-5** | **寬容識別，不為看板改寫 md** | 章節名 / 段標題 / 資產表列序 / 鏡行時間碼一律按關鍵詞寬容匹配（見 §三）。遇到不識別的新格式，**優先擴編譯器**，不許要求用戶把 md 改成契約標題——那會製造"為出看板而生的第二份 md"，直接違反 K-lite-1。 |
| **K-lite-6** | **信息零丟失** | md 裡寫下的每一樣東西都必須出現在看板上：劇本區收**正文 + 表格**（表頭/數據按 markdown 分隔行切表、保持原文順序）；未被歸區的章節（雙鎖表 / 內部 QC / API 模板 / 生成順序等）原文照錄進「⑦ 其他章節」。看板出現"未解析到"僅限該章節在 md 裡本來就不存在。 |

---

## 二、 用法

```bash
python scripts/build_board_lite.py <項目.md>              # 輸出 <項目名>_分鏡看板.html（同目錄）
python scripts/build_board_lite.py <項目.md> --out 看板.html
```

## 三、 輸入 md 契約（章節名與 6.8.3 對齊，存量項目檔可直接編譯）

```markdown
# 項目標題                      ← 一級標題 = 看板標題
【畫幅】：16:9                  ← A/B 雙鎖回顯（未聲明 → WARN"未鎖定"）
【模型版本】：2.5

## P0A · 創作基準               ← 表格: 項 | 內容 → Ⅰ 區
## P1 · 劇本                    ← 正文照錄 → Ⅱ 區
## P1 · 視聽聖經                ← 表格或正文 → Ⅲ 區
## P2 · 資產清單                ← 表格: 編碼|名字|視圖|@圖片N → ④ 區（自動算引用段）
## P2.5 · 資產出圖提示詞（★必走 sd-asset-engine 三份權威滿血模板 · 嚴禁寫兩三句簡筆！） → ⑤ 區（K-lite-4 必同板）
### 圖1 · `@CHR-林越` · 角色四格純圖板
```text
（⛔ 嚴禁寫「同板四視圖 / T-pose 參考板 / 正面左側面右側面」等簡筆摘要！必須完整調用 sd-asset-engine：
  ① 角色立繪必走 character-portrait-templates.md：真人頭身比 + 全圖共4格橫排〔①面部特寫唯一清晰臉+五官10項 ②正面無臉全身 ③90°側面無臉全身 ④背面無臉全身，頭頂至鞋完整入畫〕+ 身份外觀三件套 + 服裝材質6項 + 圖底聲紋波形錨 + ≤8詞英文音色速覽標籤 + 負向詞，外加純文本完整版英文 Voice Description；
  ② 場景圖必走 asset-spatial-ledger.md §四 16:9無人母版 + scene-grid-template.md 完整8字段3×3九宮格〔【場景定位】【場景畫面描寫】【九宮格內容分配】【參考場景鎖定模式】【九宮格攝影機矩陣（按空間類型選表①/②/③）】【攝影機參數】【光照與曝光控制】【畫面標註要求（含降級條款）】【畫面純淨要求】【風格分支】〕；
  ③ 道具圖必走 prop-template.md：左上角標註 + 純白背景無手部入畫 + 單圖4格合集〔①正面 ②45°側視 ③頂部俯視 ④關鍵細節特寫〕+ 防第5格負向詞。）
```
## P3 · 分鏡導演稿（場面調度文字平面圖 + 逐鏡九字段分鏡 + 故事板圖 CLEAN_GRID + 圖形化交付清單）
## P4 · 投餵提示詞             → ③ 區
### 段1
【核心人物】：…                 ← 段級欄（可選，渲染為標籤）
【站位聲明】：…                 ← 段級欄·一行式文字站位（四要素+軸線+位移，禁止畫圖，見 model-adapters.md §5.0）
```text
（該段完整視頻投餵提示詞，照錄）
```
[0-3秒] 逐鏡拆解行             → ① 泳道 + ② 鏡頭卡
## P6 · 發佈文案               ← 可選：【標題】【封面文案】【正文】【話題標籤】→ ⑥ 區
```

**解析規則（寬容識別 · K-lite-5）**：上面是**推薦契約**，不是硬性要求。編譯器按關鍵詞歸區，自定義標題照樣能編譯：

| 維度 | 寬容規則 |
|---|---|
| 章節名 | 按關鍵詞歸區，**不要求照抄標題**：`資產清單/資產表/P2`→④、`出圖提示詞/資產出圖/P2.5/P2c`→⑤、`投餵提示詞/分鏡提示詞/P4`→③、`劇本/故事/梗概`→Ⅱ、`視聽聖經/風格聖經`→Ⅲ、`創作基準/P0A`→Ⅰ、`發佈文案/P6`→⑥。所以 `## 二、 資產清單（P2b）`、`## 三、 P2c 出圖提示詞`、`## 四、 P4 投餵提示詞組` 都能直接編譯 |
| 段標題 | `### 段1` / `### U01 · …` / `### 第1段` 都認 |
| 資產出圖子標題 | `### 1. \`@CHR-沈硯\` · 4 View 資產板` —— 自動去前導序號與反引號，按 `·` 拆成 編碼 / 名字 / 說明 |
| 資產表列序 | 按**表頭名**映射（編碼·名字·視圖/出圖·@圖片N），兼容 `類\|編碼\|類型\|出圖\|複用單元` 這類自定義列序；未映射的列收進「附加信息」，信息不丟 |
| 鏡行時間碼 | 三種都認：本包原生 `00:00-00:05 [鏡頭1] …`、`[00:00-00:05] …`、`[0-3秒] …`；段外無拆解行時自動從圍欄原文兜底提取；檢測時間碼回跳 |
| A/B 雙鎖 | 除 `【畫幅】：` / `【模型版本】：` 行外，**還能從任意表格兜底**（如雙鎖表裡 `**B · 畫幅** \| **16:9 橫屏**`、`**A · 模型版本** \| **Seedance 2.0**`） |
| 時間軸 | 各段獨立計時（每段都從 0 起）時，泳道按累計偏移鋪成整片時間軸（15+15+12+15 → 標尺到 57s），總時長＝**累加**而非取最大值 |

## 四、 看板區塊（自上而下 · 雙層結構）

| 層 | 區塊 | 內容 |
|---|---|---|
| **創作藍圖層** | Ⅰ 創作基準 | P0A 表格項 |
| | Ⅱ 劇本層 | P1 正文照錄 |
| | Ⅲ 視聽聖經 | P1 鎖定項（一次鎖定全片繼承） |
| **分鏡生產層** | ① 時間軸泳道 | 每段一條泳道，逐鏡按秒定位色塊 + 時間刻度 |
| | ② 鏡頭卡矩陣 | 逐鏡卡（段/鏡號/時間碼/內容）——拆解視圖 |
| | ③ 投餵提示詞原文 | 每段摺疊框 + **複製投餵原文**按鈕 + 段級欄標籤——成品視圖 |
| | ④ 資產總表 | P2 表 + @圖片N 徽標 + **自動算出每個資產被哪些段引用** |
| | ⑤ 資產出圖提示詞 | 每資產摺疊框 + **複製出圖提示詞**按鈕（與 ③ 必同板） |
| | ⑥ 發佈文案 | P6 四件套（可選） |
| 頂部 | 統計條 + 段篩選 | 模型/畫幅/段數/鏡數/總時長 + 按段過濾 + **只看告警**開關 |
