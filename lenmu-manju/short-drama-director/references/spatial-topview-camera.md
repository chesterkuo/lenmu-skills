# 空間頂視圖與機位調度圖規範 (Spatial Top-View & Camera Blocking Ledger)

本規範用於通過 2D 俯視平面座標與機位網格（如 2x2 四圖合一），精確鎖定演員空間站位、視線方向、運動軌跡與機位編號（CAM1~CAM4），徹底解決 AI 視頻生成中的跳軸（180° 軸線違規）與空間穿幫問題。

---

## 一、 空間四圖合一網格架構（2x2 佈局）

針對連續劇集（如 Ep1~Ep4）或核心高潮場景，採用四分屏頂視圖架構：

```text
┌─────────────────────────────────┬─────────────────────────────────┐
│ 第 1 集：主臥 / 潛入與驚醒       │ 第 2 集：衛生間 / 搜尋與對抗     │
│ [CAM1 主全景] [CAM4 俯拍特寫]    │ [CAM2 正拍雙人] [CAM3 過肩反打]  │
│ 演員A (床) ───視線───> 演員B(門) │ 演員A (洗手檯) <─── 演員B (門框) │
├─────────────────────────────────┼─────────────────────────────────┤
│ 第 3 集：客廳 / 質問與逼近       │ 第 4 集：書房 / 檔案與反殺       │
│ [CAM1 斜角全景] [CAM3 移動推鏡]  │ [CAM2 特寫微表情] [CAM4 頂視全景]│
│ 動作軸線：紅虛線 (嚴禁非法越軸)  │ 動作軸線：藍虛線 (已做中立鏡過渡)│
└─────────────────────────────────┴─────────────────────────────────┘
```

## 二、 機位命名與調度三鐵律

### 1. 標準攝像機編碼（CAM1~CAM4）
- **CAM1（主建立鏡頭 / 空間全景）**：30°~60° 斜角俯拍或中遠景，確立空間幾何與角色左右朝向。
- **CAM2（正拍 / 雙人交鋒中景）**：平視或微仰角，承載二人對抗與動作發起。
- **CAM3（過肩反打 / 單人近景）**：主觀視點過肩鏡頭，捕捉對手壓迫感與生理反應。
- **CAM4（特寫 / 頂視俯拍 / 動力學跟隨）**：微表情特寫、要害接觸俯拍或大招運鏡。

### 2. 180° 動作軸線與越軸防護
1. **建立主軸線**：在兩名角色視線/動作連線上確立 180° 動作軸線。所有 CAM1~CAM3 必須嚴格佈置在軸線的同一側（如觀眾視點左側）。
2. **合法越軸三種手段**：
   - **鏡頭內過軸**：攝像機在單個鏡頭內跟隨角色走位連續旋轉穿過軸線；
   - **中立鏡頭過渡**：中間插入正面正對兩人的中立鏡頭（Neutral Shot）或特寫細節（Cutaway），下個鏡頭再切至反側；
   - **劇烈反彈/受擊倒地**：角色受到重大物理打擊翻滾位移後，重新建立新軸線。
3. **禁止 90° 側面正拍**：中景全景必須使用斜角，保持透視進深感與空間立體度。

---

## 三、 輸出指令規範

當用戶輸入 `/頂視圖` 或 `/機位調度` 時，系統將針對當前分鏡場景，輸出：
1. 空間座標描述（角色位置座標、門窗障礙物、光線入口）；
2. 機位部署表（CAM 編號、鏡頭焦段、拍攝高度、鏡頭任務）；
3. 軸線保護提示（標明主軸線位置與是否涉及合法越軸）。
