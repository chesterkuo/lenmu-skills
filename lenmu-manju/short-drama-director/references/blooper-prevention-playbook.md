# 成片穿幫防治軍規（Blooper Prevention Playbook）

> **版本**：P6 新增「段間銜接」章（2026-10-22，沿革見 CHANGELOG）· P6.4 加「畫幅-劇型分檔」（2026-10-23）
> **由來**：《三天》段1 成片拉片（25 幀逐格對稿）+ 長鏡連續動作拆解，兩條線共同實測總結。
> **本手冊專治一件事**：**稿子沒寫死 → 模型自行補全 → 成片穿幫**。
> 本手冊所有條目的根因都是這一句話——**穿幫不是模型隨機發瘋，是稿子把解釋權留給了模型**。
>
> ⚠️ **執行前先分檔（§十·10.0）**：**16:9 橫屏（抖音半精品）與 9:16 豎屏（紅果快節奏）不是同一套打法**——橫屏要意境與唯美，空鏡/留白/反應鏡是加分項；豎屏節奏優先，空鏡是負資產，銜接全靠台詞鉤與衝突。**把橫屏那套套到豎屏，產出的就是一堆無意義鏡頭。**

## 〇、總綱：三條第一性原則（先背這個）

1. **模型不會讓任何狀態憑空消失。** 你建立了一個姿態（趴桌、拎球衣、外套搭肩），不寫它的終結，它要麼原樣保留、要麼**掛到畫面裡最近的另一個人身上**。
2. **模型不用方位詞自洽，用位移自洽。** 你只寫"東側後門"沒寫"畫右"，它把門放錯側之後，會讓角色**走一大段路圓回來**——用一個穿幫補另一個洞。
3. **模型看不懂連續路徑，只看終態。** "從門框一路摸到窗沿"它理解成"手在窗沿"這個結果，中間過程直接跳幀——這就是用戶說的"敷衍"。

---

## 一、連續動作拆解軍規（治「敷衍」）

**案例**：長鏡（15 秒）裡寫"從門框一路摸到窗沿"，初版一句帶過 → 成片上一秒手在門框、下一秒已在窗沿，中間瞬移。

> ⚠️ **適用面（P6 修訂）**：本章治的是「**單鏡裝得下連續長路徑**」的長鏡（長鏡承載）；**SD 2.5 單鏡 3~5s 物理上裝不下**「從A到B」的完整過程，寫了也只會被壓成硬切——這類稿按常規一鏡一動作寫即可，C36 機檢對單鏡 <6s **不觸發**。

| # | 軍規 | 反例（會穿幫） | 正例 |
|---|---|---|---|
| 1.1 | **連續動作必須切成帶路徑的離散鏡**：一區一鏡，路徑上的每個空間落點單獨成鏡 | 單鏡寫"從門框一路摸到窗沿" | 門框→門板→牆裙→窗台→窗沿，每落點一鏡 |
| 1.2 | **每鏡三件套**：當前接觸點（手/道具在哪）+ 主動方手位 + 被動方身體反應 | 只寫"他摸過去" | "指尖落在門框邊沿；左手扶著門板；她在門內半步外、肩膀微微一縮" |
| 1.3 | **被動方（或對手戲方）反應是模型的進度條**：縮肩、後撤半步、視線跟著手動、呼吸變淺——告訴它"動作真的在走"，也防整場拍成兩塊木頭 | 對手方無反應 | "@女主 視線跟著他的手移了半格、肩膀微微一縮" |
| 1.4 | **禁止項必須點名禁跳幀**：正面描述 + 禁止側雙向夾 | 只正面寫路徑 | "禁止手部位置瞬移或跳躍（每一鏡只准停在當前落點，一鏡內禁止從門框直接到窗沿）" |
| 1.5 | **快慢節奏對比**：起手快切（手持 + 運動模糊），過程慢推（緩慢推進/橫移），張力全在快慢切換 | 全程同速 | 大幅調度 4 秒快 → 貼身細部 8 秒慢 |
| 1.6 | **橫屏禁純垂直下移**（高度有限，兩下出畫）→ 主體**斜置**、鏡頭沿**斜軸**移動（畫左上→畫右下） | 豎屏寫法照搬橫屏 | "人物斜臥於房間中央·頭朝畫左上、腳朝畫右下；鏡頭沿人物斜軸緩慢下移" |

> 📌 機檢：**C36 連續動作一句帶過**（見 machine-check-manual）——**單鏡 ≥6s** 的鏡行畫面主體出現"從A摸/撫/蹭/拂/掃/劃到B" → WARN。**單鏡 <6s 不觸發**（SD 2.5 單鏡 3~5s 裝不下長路徑）。

## 二、姿態交接軍規（治「姿態懸空甩鍋」）

**案例**：沈甜在鏡1/鏡3 趴桌探身爆料；鏡4（江野入場）畫面主體只寫江野，沒交代沈甜下場 → 成片 15-16 秒**蘇念趴在桌上**——模型把"趴桌"這個姿態從沈甜身上摘下來，掛到了畫面裡最近的另一個人身上。

| # | 軍規 |
|---|---|
| 2.1 | **姿態三問**：每個標誌姿態寫稿時問——**誰建立 / 何時終止 / 終止時換上什麼**。三問缺一，姿態就懸空 |
| 2.2 | **姿態終結必須顯式交接**：正面寫下場（"@沈甜 已坐直、雙手收回桌上，背對鏡頭不再探身"），並點名"止於鏡N、禁轉移給任何其他人" |
| 2.3 | **只禁承接方 = 無效**：上輪修復只寫"禁蘇念趴桌"治標——禁了承接方沒管放出方，模型下次把趴桌掛到周越身上。**必須放出方承接方兩頭都寫** |
| 2.4 | **非主體人物也要交代姿態**：他人鏡頭裡的配角，寫明"保持X姿勢不動（禁加戲）"——不交代，模型就給他加戲 |
| 2.5 | **站位聲明是姿態憲法**：每個具名角色的姿態與切換點寫在【站位聲明】，鏡行只寫增量；跨鏡不變的特徵（左右關係、坐/站）只在這裡說一次 |

## 三、背景人物軍規（治「多人同動」）

**案例**：鏡4 原文"@周越 與兩個男生虛焦的側影，只抬手起鬨"——"只抬手"沒限定人數 → 成片 12-13 秒兩個男生**同時比劃**。

| # | 軍規 |
|---|---|
| 3.1 | **群體動作必須點到人頭**："僅 @周越 一人抬手起鬨，另兩個男生靜坐不動"——"只抬手"是人家的動作不是人數 |
| 3.2 | **C35 層次原則延伸到龍套**：多人物鏡的"清晰主體 + 虛焦陪襯"不只管具名角色，背景群像同樣適用——動作只能屬於一個，其餘靜坐 |
| 3.3 | **背景一律虛焦 + 不給正臉 + 每格 ≤3 人**（已在禁止項，保持） |
| 3.4 | 起鬨/反應鏡頭：**一個聲音 + 一個動作**，其餘是"靜"——靜才是主角的放大鏡 |

> 📌 機檢：**C37 背景多人同動未點名**——鏡行畫面主體含"兩個/N個 + 同學/男生/人"群體詞與動作詞、卻無"僅X一人"分配證據 → WARN。

## 四、狀態鎖定軍規（治「模型自行補全」）

**案例**：CHAR_STATE 寫"球衣→離身（拎於左手），外套仍穿著"——"仍穿著"沒說裡面穿什麼、拉鏈什麼狀態 → 成片江野**光著上身只披外套，胸腹全露**。

| # | 軍規 |
|---|---|
| 4.1 | **狀態寫到可執行級**：服裝狀態必須寫"拉鏈拉到哪 / 內搭什麼 / 手在哪 / 持什麼"。"仍 / 依然 / 照舊"這類詞 = 把解釋權交給模型，**禁** |
| 4.2 | **CHAR_STATE 登記時同步寫"防疊加"**：立繪里沒有的件，鏡行裡出現必須登記為狀態覆蓋（"基準圖 + 狀態覆蓋"兩句並寫） |
| 4.3 | **狀態偏離要複述**：道具/服裝在鏡行裡每次出現關鍵狀態時複述一次（"被捲成筒握在右手→推向畫左衣襟"），防模型回退默認態 |
| 4.4 | **禁止項補致命傷**：明顯違和的形態（赤膊、透視、裸露類）直接在禁止項點名——但**禁用平台高危詞**（見第八章） |

## 五、方位與軸線軍規（治「放錯側」）

**案例**：鏡4 只寫"自東側【教室後門】進場" → 門被放畫左，而蘇念在畫右，模型讓江野**橫穿整間教室**自洽。

| # | 軍規 |
|---|---|
| 5.1 | **鏡行裡方位必須寫畫左/畫右**：模型對"畫左/畫右"敏感，對"東南西北"無感。場景錨點寫方位，鏡行畫面主體必須落成畫左畫右 |
| 5.2 | **每段首欄給機位映射**："機位主朝向朝東北，畫左=西北、畫右=東南"——一句頂十句（已入《三天》段1【機位與軸線】，沿用） |
| 5.3 | **位移限定步數與終點**："自畫右深處橫向兩步即停"，禁橫穿；位移路徑寫進【站位聲明】，鏡行復用 |
| 5.4 | **軸線鎖定跨段一致**：人物左右關係一段一鎖，跨段不變；"機位反轉 180°"只反機位不反人物關係 |
| 5.5 | **過肩方向規則**：越過 A **右肩** → A 在畫面**左**前景；越過 A **左肩** → A 在畫面**右**前景 |
| 5.6 | **關係詞必須換成點名 + 畫面位置**："越過同桌的肩" → "越過 @沈甜 右肩，同桌佔畫面右前景"——模型不知道"同桌"在哪側 |

## 七、台詞軍規（治「怪」）

**案例**（用戶實測"還是有點奇怪"）：

| 病 | 反例 | 修法 |
|---|---|---|
| 尬語（軍事/公文化） | "野哥，目標已鎖定" | 高中生起鬨味："野哥，正主在這兒呢！" |
| 邏輯不清 | "誰先追到，錢歸誰"（局是賭江野追不追到，沒有"誰先"） | "一個月為期，追到了三千歸你！" |
| 拗口 | "還嫌三千少" | "還嫌三千不夠" |
| 兩個修辭打架 | "你臉上寫著三千呢，別裝了" | "你臉上就寫著倆字，三千" |

**通則**：① 口語化、短句、一次一個信息；② 語氣標籤三件套（情緒·語速·功能）必須與內容匹配；③ 賭約/交易類台詞先把規則寫對再寫味兒；④ 尾鉤句是全劇魂（文件名級），禁改。

## 九、拉片-改稿閉環方法論（AI 助手執行）

用戶拿成片來復盤時，按此流程：

1. **抽幀**：`ffmpeg -i 成片.mp4 -vf fps=1,scale=640:-1 f_%03d.jpg`（25s 視頻 = 25 幀，逐格對稿）
2. **對賬**：每幀標註對應稿內哪一段哪一鏡，輸出三列——**照稿執行 ✅ / 小瑕疵 / 真穿幫 ❌**。除逐鏡對外，**段縫處單獨看一眼**：上一段末幀到下一段首幀之間，內容上斷沒斷（接力棒/反應者/聲音橋/時間錨）——這類「跳脫」在逐鏡對稿裡看不出來，它是段與段之間的病
3. **根因歸類**：每個穿幫必須歸到"稿子哪一句沒寫死"，**不接受"模型問題"這個歸類**——歸到模型問題就等於沒歸
4. **三明治改稿**（順序不能反）：
   - 第一層：**畫面主體**補狀態（接觸點/姿態/位移/人數分配）
   - 第二層：**站位聲明**補憲法（姿態切換點、位移路徑、軸線）
   - 第三層：**禁止項**夾致命傷（禁瞬移/禁串角色/禁多人同動/禁高危詞）
5. **復跑機檢**：`validate_prompt.py --by-segment` + `audit_contract.py`，FAIL/WARN 清零才交付
6. **記錄**：新軍規沉澱回本手冊（本條本身就是第 6 步的產物）

## 十、段間銜接軍規（治「跳脫」）

> **本章跳脫於任何具體劇本**：治的是多段稿的通用病——**每段內部都寫死了，段與段之間卻是兩段各生成各的**。
> 段內管「這一秒發生什麼」，段間接管「觀眾憑什麼走到下一秒」。後者不寫，模型不會補。

**病的樣子**：上一段話音落下，下一段主角直接空降開講/開打——情緒斷在半空、動作沒有由來、空間說換就換。用戶看完的原話是這種感受：「太跳脫了」「連個空鏡都沒有」「前後的關聯性有點差」。

### 10.0 先分檔：橫屏半精品 ≠ 豎屏快節奏（**本節優先於下面所有條目**）

> **「要不要加空鏡」不是風格偏好，是畫幅決定的。** 同一套銜接規則套到兩種劇上，橫屏會顯得「沒接住」，豎屏會顯得「多了很多沒意義的鏡頭」——兩檔必須分開執行。

| 維度 | **16:9 橫屏（抖音劇情 / 半精品劇）** | **9:16 豎屏（紅果類快節奏短劇）** |
|---|---|---|
| 節奏 | 允許停頓、允許留白，情緒要有「落點」 | 節奏堆得極快，**每 3~5 秒必須有一個鉤子**，不能停 |
| 空鏡 | ✅ **該用的表現手段**：教室空鏡、天光、走廊盡頭、無人物入畫的窗——用來卸情緒、立意境、做唯美留白 | ❌ **基本是負資產**：觀眾在手指上，一停就划走；空鏡＝拖節奏 |
| 段間銜接 | 空鏡起手 / 反應者一拍 / 聲音先入 / 時間錨 —— **都要看得見** | **主要靠台詞與衝突**：一句搶白、一個鉤子問句、一個動作被打斷、矛盾直接升級 |
| 台詞密度 | 可以低，允許沉默；台詞之間留呼吸 | 高密度，幾乎沒有沉默；一句話不推進就刪 |
| 語速與停頓 | **3.5~5 字/秒**（標準對白），句間可留 0.5~1s 停頓做情緒落點 | **5~6 字/秒**（快念，短劇常態），幾乎不停頓；停頓只在"憋住/被打斷"時出現。基準見 `sd-feed-engine/references/feed-mode-and-gates.md` |
| 唯美鏡頭 | ✅ 允許（服化道質感、光影、構圖本身就是賣點） | ⚠️ 只在**極短**（≤1s）且**不中斷動作**時可用，不做獨立停留 |
| 判據取向 | 缺銜接 = 斷；缺意境 = 平 | 缺鉤子 = 走人；加空鏡 = 加速流失 |

**執行口徑（寫稿時先問一句「這是幾比幾」）**：

1. **橫屏稿**：§10.1~10.8 全量執行，空鏡/反應鏡/聲音橋都算加分項。
2. **豎屏稿**：只執行**內容接力**（10.1 接力棒、10.2 段尾三問、10.3 禁空降），**手段一律換成台詞與衝突**：
   - ❌ 不加空鏡起手、不加純意境鏡、不加無信息量的反應鏡；
   - ✅ 用「上一段的話沒被答完」直接切進來（一句搶白：*"我話還沒說完。"*）；
   - ✅ 用**動作被打斷**跨段（敲門聲、有人拽住手腕、手機響）；
   - ✅ 用**信息升級**跨段（上一段的疑問，這一段第一句就答/就否）；
   - ✅ 時間跳就靠**一句台詞交代**（"三小時後"由人物說出來），不要給天色空鏡。
3. **兩檔共通、不可省的那一條**：**段與段之間必須有人接過上段的棒**——豎屏省的是「鏡頭」，不是「因果」。省了因果，觀眾照樣覺得跳。
4. 確需在豎屏裡放空鏡的（比如一個關鍵道具的特寫空鏡），在該鏡標註「**刻意空鏡**」並壓到 ≤1s——機檢 C39 認這個標記放行。

| # | 軍規 |
|---|---|
| 10.1 | **接力棒原則**：每段結尾必須向下一段**交出**一樣東西——一句沒被回應的問句 / 一個剛發起了一半的動作 / 一條剛到場的信息 / 一團沒散去的情緒；每段開頭必須**接住**上段交出來的東西。交不出或接不住 = 跳脫 |
| 10.2 | **段尾三問**（每段寫完必問，答不上就補鏡）：① 這段結束時，場上留著什麼**沒解決**的東西？② 下一段的發起方是誰，**為什麼是此刻**發起？③ 觀眾靠什麼從上個空間/情緒走到下一個？ |
| 10.3 | **禁空降**：下一段的主要行動不能憑空發起——它必須是上段某句台詞/某個動作的**直接後果**。確實要跳（時間跳/空間跳）時，用一個**反應者一拍**或一個**動因鏡**（鈴響、廣播、來人、一個目光）把因果補上 |
| 10.4 | **反應者緩衝**：段間最便宜的銜接是**場內第三者的反應鏡頭**——上段主角話音落下，先給反應者一拍（捅肘、對視、吸口氣、筆停在半空），再切下段發起方。一兩秒，承接一整段。主角的話需要有人"接"，觀眾的情緒需要有人"替自己反應"。**豎屏例外**：反應不單獨成鏡、壓進同一鏡的同一拍（一個眼神／一句"啊？"），絕不獨立停留——見 10.0 |
| 10.5 | **聲音橋梁**：換場用**先入的聲音**搭橋（鈴、廣播、腳步、環境聲由遠及近），下一段首鏡從該聲音的延續開始。聲音比畫面更能縫合空間裂縫——觀眾的耳朵會替畫面圓場。**這條兩檔通用**：聲音不佔時長，豎屏同樣該用 |
| 10.6 | **時間錨點**：段間跳躍超過「即刻」時，必須給**時間/事件錨點**（鈴響、天色變化、廣播、來人），否則模型和觀眾都默認「緊接著」，動機斷裂、動作無由來——「她為什麼突然衝出去」這類疑問全是這麼來的。**豎屏例外**：時間錨交給台詞（"都放學了"／"三小時後"由人物說出來），不給天色空鏡 |
| 10.7 | **轉場是後期的事，接力是稿子的事**：閃白、空鏡、疊化可以由剪輯後期加，但「內容上誰接了誰的棒」稿子裡不寫，**生成端不會補**——兩段各生成各的，斷的是敘事不是技術。別用「我後期加轉場」安慰自己，那是遮羞不是銜接。**豎屏同理**：你省掉的是**鏡頭**，不是**因果** |
| 10.8 | **段縫聲明必須寫橋接**：段縫說明不能只寫機位跨度（景別/焦段/換軸——那是 `segment-splicing.md` 的技術參數），必須同時寫**內容橋接方式**：承接什麼 / 反應者是誰 / 什麼聲音先入 / 什麼時間錨。**豎屏寫「台詞鉤/搶白/打斷/矛盾升級」同樣算橋接**。機檢 **C38** 查的就是這個聲明 |

> 📌 機檢：**C38 段間缺橋接聲明**——相鄰兩段之間（非首段）的段縫說明/段首行內，既無橋接詞（承接/反應鏡/先入/時間錨/話頭/遞進/因果/台詞鉤/搶白/打斷…），也未顯式聲明「硬切跳」→ WARN。聲明即放行：真跳切就寫「硬切跳（刻意跳切）」，機檢不攔刻意，只攔**沒想過**。
>
> 📌 機檢：**C39 豎屏空鏡冗餘**——稿內鎖定 **9:16** 且某鏡標了「空鏡／無人物入畫」→ WARN（豎屏節奏裡空鏡＝拖節奏，見 10.0）；該鏡標註「**刻意空鏡**」放行。**16:9 / 21:9 稿永不觸發**——橫屏的空鏡是表現手段，不是問題。

> **與 `segment-splicing.md` 的分工**：那份管段縫的**技術參數**（景別跨度/機位角度/定格幀/接口餘量），本章管段間的**內容橋接**。兩件事都要寫，寫在段縫說明的同一行裡。

## 十三、 （V8.2.0-SLIM 新增 · 參考 guoman-3d-director V2.4.0 與實拍拉片復盤）分鏡邏輯防怪七大硬鎖

> 完整文武三軌時鐘、群像四步調度與戰鬥八階段運鏡映射見唯一權威：`references/wenxi-wuxi-storyboard-logic.md`。

1. **反派/對手禁原地站樁乾喊鎖（防 NPC 化）**：主角破籠突圍、近身壓制或重擊後，鏡頭內開口發號施令（如喊“放箭！”）或反擊的對手必須處於符合當下物理因果的動態受迫狀態（被刀抵喉/被按倒/踉蹌急退格擋/被護衛或距離明確隔開），**嚴禁貼身原地直立乾喊**。
2. **物理屏障破障獨立成鏡鎖**：從囚籠/鎖閉房門/束縛內破出到外部交鋒，**破障必須獨佔 1 個完整動作鏡**，嚴禁與落地逼停反派塞進同一鏡導致穿模瞬移。

4. **單鏡動作容量上限（`C22e`）**：一鏡只完成 1 個完整物理動作——文戲 3–5s 鏡行可數物理動作 ≤3 步，嚴禁 5 秒塞 4 個跨空間動作造成瞬移滑步。
5. **站位聲明 `00:00` 淨初始態鎖（`C17h`）**：`【站位聲明】` 的 `手頭事務` 只寫本段第 0 秒開場時的初始乾淨狀態，嚴禁提前劇透段中/段末的破障、染血、桌案或按印狀態。
6. **多人衝突焦距與靶標鎖（`C50g` / `C20n` / `C20o` / `C42d`）**：在場人數 ≠ 入畫人數（單段全景 ≤2 鏡），強衝突禁給溫吞全景，攻擊動作必鎖死受擊靶標與方向（`C20n`）；過肩背影禁提胸前掛件（`C20o`）；雙人奪械寫明左右握位間距並當鏡奪落清場（`C42d`）；不說話第三人必帶微反應動作（`C40e`）。
7. **跨段換嘴 2 秒氣口鎖（`C18q`）+ 未入畫禁提前聲畫觸發**：上段末鏡角色 A 說完收尾，下段鏡 1（`00:00-00:02`）嚴禁 0 秒由 A 背靠背連說，必須先給對手 2 秒動作/應答氣口；鏡 1 拍單人隱秘動作、鏡 2 他人推門入畫時，鏡 1 正文絕不提門外腳步聲。
