# 真實光線物理引擎與日景防冷光規範 (Lighting & Anti-Fake)

---

## 一、 真實光線物理來源鐵律

嚴禁無來源的情緒假光與廉價棚拍白光，光線必須具備明確的物理發光源：
* **日景白天**：側面窗欞天光、林間丁達爾斑駁陽光、天空自然散射光；
* **夜景室內**：暖黃鎢絲燈、破敗日光燈管頻閃、蠟燭燭火微光、霓虹燈管反射；
* **陰影要求**：陰影必須呈現自然的青灰/暗棕環境漫反射色階，嚴禁死黑或全臉漂浮發白。

---

## 二、 日景防冷光防禦機制 (Daylight Cold-Light Defense)

* **嚴禁詞彙**：在日景/白天場景中，**嚴禁直接使用“冷白光、冰冷藍光、刺眼冷光”**；
* **轉譯規範**：若需要表達白天肅殺、悽清、冷酷的氛圍，必須轉譯為：
  `低飽和度影調，青灰色自然漫射陰影，背光面與高光處形成自然明暗階梯，逆光邊緣光勾勒輪廓`。

## 三、 三點布光與光型體系（Lighting Geometry）

任何一場戲的光，先落**布光三件**，再選**光型**，最後定**光比**（§四）——三者齊備才算寫明照明。

**布光三件（缺一即「光影」字段不合格）**：

| 件 | 作用 | 寫法要點 |
|---|---|---|
| **主光 key** | 定光源方向與人物立體感 | 必須寫方向與來源（窗/燈/火/霓虹/天光），禁「柔和的光」這類無源寫法 |
| **輔光 fill** | 抬起暗部、控制反差 | 寫清是環境漫反射還是反光板；暗部**必須有間接光填充**，禁純灰死黑 |
| **輪廓光 rim / 逆光** | 把人物從背景裡「剝」出來 | 有源才給：窗/燈/火/霓虹；無源的糊黑側臉不合格 |

**光位四件**（與 `sd-combat-engine/references/combat-iron-laws.md` 的光位系統一致，寫進畫面質量基準）：
主光方向 + 輪廓光 + 環境自發光當補光 + 眼神光。**眼神光是人物的「活」**——人物近景/特寫默認給，禁空洞無光點的眼。

**光型速查**：

| 維度 | 取值 | 適用 |
|---|---|---|
| 軟硬 | 硬光（明暗交界線利落）／軟光（過渡綿長） | 硬光＝對峙/威壓/真相；軟光＝日常/回憶/柔情 |
| 方位 | 順光／側光（前側 45° 為默認）／側逆光／逆光 | 側光是敘事默認；逆光是「離別/昇華/揭示」 |
| 高度 | 頂光（壓頂、審判感）／平位／底光（詭異、不安） | 頂光與底光都屬強手段，慎用、不連用 |
| 人像三光 | **倫勃朗光**（側前 45° 高位、暗部臉頰閉合倒三角光斑）／**蝴蝶光**（正前高位、鼻底對稱小影）／**分割光**（正側 90°、半邊受光半邊全暗）／環形光（正前、鼻影環而不交） | 倫勃朗＝性格深沉·權謀·內心掙扎；蝴蝶＝端莊·尊貴·冷豔；分割＝黑化·雙重人格·心理撕裂；環形＝平實·日常 |

- **人像三光屬「主光位」選擇**，與光比（§四）正交搭配：倫勃朗 + `1:4` 是劇情敘事的標準組合；分割光只配 `1:8` 以上，且**僅限單場戲的少數鏡**（半臉全暗極易觸發「欠曝暗調」紅線）。

* 光型必須與情緒匹配，且**一場戲內不來回換**（換就要有敘事理由，如「關燈」這類動作）。
* 光源動機鐵律見 `sd-storyboard-engine/references/scene-space-adaptation.md`；本文件只管照明參數，不重複場景空間規則。

## 四、 光比量化與曝光紅線（Ratio & Exposure）

**光比 ＝ 主光 : 輔光 的照度比**，用 `1:N` 寫法，進【畫幅風格】或鏡行「光影」字段。禁寫「強反差/弱反差」這類不可執行的形容詞。

| 光比 | 觀感 | 適用 |
|---|---|---|
| `1:2` | 平、乾淨 | 日常、輕鬆、信息交代 |
| `1:4` | 立體、有層次 | **常規敘事的推薦值**，與側光 + 倫勃朗光同用 |
| `1:8` | 反差明確、壓得住 | 對峙、壓迫、審問、暗流 |
| `1:16` | 強反差、大面積暗部 | 懸疑、真相揭露、孤立——**僅限單場戲的少數鏡**，不整場鋪 |

**曝光紅線（硬約束 · 全套場景通用）**：

* **曝光必須明亮充足**——暗部可深，但整體不能欠曝。
* **禁欠曝暗調**、**禁全臉漂白**（人臉高光必須留得住五官，不許一片白）。
* **禁死黑**（陰影必須呈自然青灰/暗棕環境漫反射色階，不許純黑無層次）。
* **禁無源情緒假光**（見 §一）。

> **與風格指數的邊界**：`film_stock / grain / halation / palette / saturation` 屬**色調字段**，不是照明；照明只管**光源·方向·光型·光比·明暗台階**。風格指數寫法見 `sd-storyboard-engine/references/short-drama-camera-system.md` 分鏡「色調」字段與 I 畫風鎖段 8。

## 五、 雙色溫冷暖對沖（Kelvin Contrast）

高質感畫面的縱深，一半來自**冷暖對抗**：主光一側暖、輪廓/環境一側冷（或反之），人物立刻從背景裡「浮」出來。全片只有一種色溫，畫面就掉進棚拍感（一片暖＝廣告、一片冷＝鬼片）。

| 戲劇場景類型 | 主光源色溫（key） | 背景 / 輪廓對沖色溫（rim · ambient） | 視覺心理效果 |
|---|---|---|---|
| 懸疑 / 諜戰 / 暗殺 | 3200K 室內暖鎢絲燈·燭火（暖橙黃） | 6500K 窗外冷月光·冷雨夜天光（深冷青藍） | 逼仄孤立、危機四伏的生存壓迫 |
| 賽博 / 現代都市 | 4000K 慘白日光燈管（工業青綠） | 霓虹粉紫 / 飽和鈷藍點光強反射 | 工業冷酷與迷幻慾望衝撞 |
| 仙俠 / 宗門 / 大殿 | 5000K 天空純白天光漫射 | 2800K 神佛法相神光（純金暖芒） | 莊嚴神聖、超凡脫俗的威壓 |
| 廢土 / 破廟 / 殘垣 | 5500K 陰霾慘灰自然天光 | 1800K 焦黑戰火餘燼（猩紅微弱火光） | 蕭條絕望與未熄殺意對沖 |

- 寫法：色溫寫進【畫幅風格】或鏡行「光影」字段，一句寫清「主光 X 色溫 + 對沖 Y 色溫」，禁只寫「冷暖對比」這類不可執行的形容詞。
- ⚠️ **對沖不得突破 §四 曝光紅線**：冷側再冷，也必須是**可辨識的青灰/暗棕環境漫反射色階**，不許壓成死黑；暖側不許過曝漂白。**色溫解決「色」、不解決「亮」**——用冷暖分色，不用明暗分色。
- 與打戲域的關係：`sd-combat-engine/references/combat-iron-laws.md` 的「五色調色板 · 禁統一色溫」是**打戲域內特化**（含能量自發光），本表是**通用敘事照明**的默認檔；域內可加嚴，不可放寬。

## 六、 空間物理介質與微物理渲染（Atmospheric Mediums）

畫面「有空氣厚度」靠的是**光在介質中的散射**——空場無介質＝渲染感（假），有介質＝空間感（真）。四類介質按場景調用，不必每鏡都寫，一處寫準即可：

* **丁達爾體積光（Tyndall Volumetric Light）**：天光穿過窗欞格柵 / 林木枝椏，在空氣中形成**肉眼可見的實體光柱**——室內大窗、林間、破廟殘垣的定場首選。
* **懸浮塵埃微粒（Suspended Dust）**：光柱中可見微細塵埃隨氣流緩慢翻滾——賦予時間沉澱感與密閉空間的靜謐張力。
* **溼度漫反射（Moisture Sheen）**：雨後石板鏡面水漬倒影、溼潤髮梢貼額帶微光——增加通透度；雨戲收尾鏡必寫。
* **熱浪空氣擾動（Heat Distortion）**：高溫火源 / 大招能量凝聚處，後景空間呈現熱空氣波紋折射與微弱火星飄散。

- ⚠️ **介質不替代光源動機**：丁達爾必須有來源（窗 / 林隙），無源的光柱就是假光（見 §一）。介質是「光源的可見載體」，不是獨立光源。
- ⚠️ **不許為氛圍硬加介質**：與敘事無關的塵埃 / 霧氣只是噪點（霧一多，人臉就糊），介質必須服務於這場戲的空間質感。

## 六·補、 陰影側取景（Shadow-Side Shooting）與純實用光防溢染鐵律（2026-10-14 粉絲 shotlist-builder 吸收）

> 📌 **為什麼運鏡好壞與布光強綁定？** 正面平光下，攝影機微移時人臉光影毫無變化，像紙片平移；唯有攝影機站在**人物陰影側（shadow side）**取景，鏡頭哪怕只做 10~15 釐米微移，面部明暗交界線與高光輪廓就會產生真實的立體光影流動。

1. **陰影側取景鐵律（Shadow-Side / Upstage Shooting · Lubezki × Deakins 核心法則）**：
   - **攝影機優先在人物的陰影側（shadow side）拍攝**——讓人物面部朝向主光源自然受光，而攝影機從較暗的背光 / 側逆光一側取景；
   - 利用場景實用光（practicals）照亮面部輪廓線與溼潤眼神光（catchlight），配合全程薄霧（atmospheric haze）增加景深層次（嚴禁無源刺眼可見光束 god rays）。
2. **純現場實用光源鎖定與防藍光色溢（Practicals-Only & Anti-Blue Spill）**：
   - 寫實 / 權謀 / 沉浸向場景優先聲明**僅使用場景內實際存在的光源（practicals：窗戶天光、燭火、宮燈、檯燈、器物漫反射）**，嚴禁無源正面柔光箱、反光板把暗部拍平；
   - **防屏幕 / 冷光源色溢汙染（Anti-Blue Spill）**：若場景內含發光屏幕、法陣或冷藍光源，須顯式聲明 `僅作為背景元素髮光，禁止冷藍色溢（blue spill）直接汙染人物面部皮膚與服裝固有色`。
3. **60:30:10 情緒色彩配比公式（可併入【畫幅風格】或分鏡色調欄）**：
   - 按場次情緒鎖死 `60% 主色 : 30% 輔色 : 10% 點綴色`（冷冽權謀對峙：`60% 冷青灰 + 30% 暗檀褐 + 10% 硃砂紅點綴`；溫暖內室：`60% 暖鎢絲琥珀 + 30% 深胡桃木褐 + 10% 鎏金高光`；危機壓迫：`60% 暗緋紅 + 30% 墨黑 + 10% 燭火橙`）。

## 七、 權威邊界（一個規則域一個權威）

* 本文件 ＝ **照明規則唯一權威**：光源來源、布光三件、光位四件、光型、光比、曝光、色溫對沖（§五）、氣氛介質（§六）。
* `sd-combat-engine/references/combat-iron-laws.md` 的「五色調色板 + 光位四件 + 丁達爾 + 禁白色體積光 + 禁統一色溫」屬**打戲域內特化**（含能量自發光），與本文件不衝突：**色板歸色調，光位歸本文件**；域內文件可加嚴，不可放寬。
* `sd-asset-engine/references/character-portrait-templates.md` 等資產側的色溫/光照方向/SSS 是**生圖參數**，不是場記照明規則；兩邊數值不衝突即可，衝突時以本文件為準。
* 本文件未覆蓋的照明細節，按上游域內文件執行。

## ★ 世界座標光源 · 粒子五要素 · 背景非平面鐵律

1. **光源固定在世界座標，不為反打搬太陽**：先鎖定太陽、窗戶、室內燈或街燈的**絕對世界方位與遮擋物**，再寫各機位看到的亮暗面；反打只改變光源在畫框的左右位置，絕不每鏡重設光源方向。夕陽只溫暖受光邊緣，不把灰牆、藍衣與陰暗面全染橙；陰天或弱夜空不憑空強加高強度輪廓光。
2. **空氣粒子寫清五要素（來源 / 位置 / 運動鏈 / 可見度 / 連續）**：
   - ① **來源**（清土餘塵、熱食蒸汽、門縫霧氣、雨滴水汽）；② **位置**（鏡頭前/人物後）；③ **運動鏈**（揚起 → 慣性 → 風向 → 重力沉降，溼水泥不揚幹塵、不同材質受風幅度和延遲各不相同）；④ **可見度**（僅在逆光與暗背景下可見，不每粒發白光）；⑤ **連續性**（人物定住時空氣與風仍自然流動，切鏡不凍結重置）。
3. **背景非平面與景深真實感**：不用無腦 `f/1.2` 把背景全抹成色塊；按需要選用 `f/5.6~f/8` 保留建築結構，動態來自風吹葉動、煙霧流動或已確立的遠處人物，嚴禁靠牆面/傢俱呼吸變形或平移製造假動感。
