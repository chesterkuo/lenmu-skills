## 一、 物理硬約束與時長預算協議

1. **單單元時長約束**：**組數與時長一律按 `model-adapters.md` §5 模型契約表執行**（2.5 默認 25~30s / 2.0 上限 15s；下限 12s、禁 16~24s 碎段區）——⚠️ **本節不再寫「嚴格 4~15 秒」**，該值僅適用 2.0；單鏡 3~5 秒、一組 3~4 鏡為**節奏參考**而非硬性分組上限。
2. **時長前置預算公式**：
   $$\text{目標視覺單元組數} = \frac{\text{預估成片總時長（秒）}}{12\sim 15 \text{ 秒 / 單元}}$$
   * 3 分鐘（180 秒）成片必須拆解為 **14~15 組** 獨立提示詞，嚴禁場景 1:1 機械壓縮！
3. **單組即成品交付**：每組自帶時間軸（從 `00:00` 開始）、畫幅風格、資產短錨點、分鏡詳情與負面詞，用戶可直接整組複製投餵。

## 二、 三層信息解耦框架 (3-Layer Decoupling)

* **Layer 1 全局不變量**：畫幅比例（16:9 橫屏 / 9:16 豎屏）、模型版本（`Seedance 2.5` / `Seedance 2.0` 強制二選一）、美術渲染風格、色調基調、核心角色/場景資產短錨點。
* **Layer 2 空間與鏡頭變量**：秒級時間軸（官方原生 `[起-止秒]` 分段，見 `model-adapters.md` §5）、鏡頭規格五要素、主體物理發勁動作、接觸點受力（Hit-Stop 頓挫感）、台詞與聲音標記（官方字符：音效 `<>`、台詞 `{}`、音樂 `()`、字幕 `【】`；社區兼容寫法 `[SFX: ...]` 仍可被識別）。
  * **Hit-Stop 三件套（打擊硬度必寫）**：兵刃/肢體相碰瞬間 = ①1~2 幀微停頓（打破平滑插值，杜絕“滑步/空氣假打”）+ ②接觸點微觀火花迸射（槍尖紅寶石與劍刃相交處火星）+ ③雙刃咬死高頻震顫聲（Metallic Screech）。三件缺一，打擊感發飄。
* **Layer 3 分層負面排除**：畫面防崩 + 題材專項排除 + 鏡頭動態排除。

> ⚠️ **組內過渡鐵律（官方限制）**：模型**一鏡生成、不支持硬剪輯切換鏡頭**——一組內的 3~4 鏡必須寫成連續運鏡銜接（推/拉/搖/移/穿透/遮擋過渡），真硬切必須拆成多段獨立生成、後期剪輯拼接。

## 二·五、 微步進時間軸切片四要素公式（長段高動態專用）

> ⚠️ **畫幅鐵律（B 鎖·高於一切模板）**：最終畫幅以**用戶指令為準**。畫幅強制三選一——16:9 / 9:16 / 21:9（1:1 僅明確指定時採用），用戶未指定 = 停下詢問，**禁止默認 9:16**。用戶指定 16:9 → 一律走橫屏模板，禁套豎屏模板、禁示例裡的 `aspect_ratio=9:16`；用戶指定 9:16 → 走豎屏模板。**每條提示詞/每個 API 參數都必須回填用戶指定的畫幅，禁止默認回落。**
>
> 📐 **全流程橫/豎屏構圖路由、時間軸模板選擇、API 參數回填 → 以 `aspect-ratio-adaptation.md`（★權威）為準**。

單段 15s（或 30s 連續打鬥）內若動作密度高，為避免模型“動作抽搐、四肢變形、換臉漂移”，時間軸描述強制採用 **0.5s~1.0s 微步進切片**，每片四要素齊全：

$$\text{切片} = [\text{時間區間}]: [\text{運鏡機位動詞}] + [\text{主體力學動作}] + [\text{雙色對沖粒子特效}] + [\text{環境物理介質破壞與受力反饋}]$$

### 1. 常用切片動詞表
* **運鏡動詞**：極微距鎖焦、無人機超廣角暴力快推、貼身平行極速橫移、碰撞點微環繞、低角度仰跟上擺、360° 環繞急推（≤180°）、垂直拉昇至鳥瞰。
* **力學動作動詞**：輕推刀鐔、反手拔刀出鞘、正面突破音障衝刺、機槍高頻對攻、滑步下潛、側蹬反關節格開、拔地暴起凌空反切。
* **粒子特效**：赤紅流光拖尾、幽藍燃燒烈焰、纏繞黑煙、自發光火星微觀纖維、空氣激波環形擴散。
* **環境受力**：成排竹木攔腰震斷、碎石浮空、地面犁開深溝、漫天枯葉捲成海嘯漩渦、雨水受高溫汽化。

### 3. 雙實體色彩與材質錨定（混戰防混淆·必寫）
> 雙人/多人對峙打鬥，嚴禁只給雙方各一個顏色。必須為**每一方建立一整套錨定**（粒子色 + 材質 + 光效 + 軌跡），雙方高反差互補；遠全對撞時觀眾靠這套錨定分清誰是誰。

$$\text{錨定} = \text{角色}：\text{粒子色/光效} + \text{護甲材質} + \text{招式的軌跡形態}$$

* **錨定必須成體系**：每個角色 = 主色 + 材質 + 專屬特效軌跡，整套貫穿全程；
* **雙方互補對沖**：冷色系 vs 暖色系、光系 vs 暗系，在極速混戰與遠景對撞中保證視線清晰，杜絕畫面混雜與面孔混淆；
* **對照模板**（學自 35s 玄幻秒級拆解）：
  * 黑髮劍客 → 冷銀劍氣 / 水墨黑白 / 玄青輕甲 / 月牙弧光與霜刃拖尾（純粹劍道·極速穿透）；
  * 白髮神將 → 金紅烈火 / 熔岩重鎧 / 陰陽雙龍 / 戰戟犁地火線（神魔偉力·重擊霸體）；
  * 雙方對沖：金紅熔岩流火拖尾 vs 銀白冷冽霜刃拖尾，左右分流。
* **能量貼附物理載體（能量禁懸浮·2026-09-04 吸收）**：一切能量特效必須**貼附在物理載體上**——刀刃、手臂、服裝邊緣、運動軌跡、骨甲、法器內部結構，禁止無附著物的懸浮光團/光霧；
  * **頻率分層**：高頻短電弧（貼附刃緣/指尖，細密噼啪）vs 低頻脈衝（貫注臂膀/軀幹，緩慢鼓脹），兩類疊加出能量"活性"；

### 5. 聲音事件時間線（音效排布規範·2026-09-04 吸收）
- 音效不按"氛圍堆砌"，按**事件排時間線序列**——每個動作事件對應一個音效事件，先後成鏈：`拔劍鳴（0.5s）→ 破空呼嘯（1.2s）→ 交擊爆鳴（2.0s）→ 衝擊波爆破（2.5s）`；
- **空間縱深音**：遠層事件用低頻悶響+混響，近層事件用高頻脆響+乾聲，靠聲場層次強化畫面縱深；
- **死寂轉餘響收尾**：絕殺命中後先留 0.3~0.5s 死寂（抽掉全部音層），再放環境餘響（碎石滾落/風聲/耳鳴），比全程轟鳴更有打擊重量；
- ⚠️ 本節僅適用於 Seedance 2.5（`[SFX:]` 原生標記）；Seedance 2.0 無原生音效標記，音效以文字描述寫入 `聲音：` 欄、默認由模型生成（僅用戶明確指定"不出音效/走後期"時才降級後期配音）。
