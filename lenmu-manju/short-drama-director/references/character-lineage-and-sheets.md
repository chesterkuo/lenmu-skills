# 角色資產板與親緣/多梯隊遺傳推導規範 (Character Lineage & Asset Sheets)

> 🔗 **流程位置：P2 數字資產包·第一批角色出圖（見 `asset-first-pipeline.md` ★權威）**。本規範用於從 T1 男女主基準，推導並**直接出圖** T2 親屬/反派、T3 功能配角（非文字推導），解決群像風格割裂與人臉變異。產出物 = 角色 4 View 資產板，進入《資產圖冊》。

---

## 一、 標準角色 4 View 資產卡構成（CURRENT）

每位 A/B 級核心角色的資產圖必須包含以下要素：

1. **Face Close-up（面部特寫）**：五官骨相、眉眼間距、瞳孔色澤、皮膚肌理。
2. **四格（Face Close-up + 3 Views）**：Face Close-up（頭部近景/面部特寫）+ 無臉 Front View（正面全身）、無臉 Side View 90°（側面全身）、無臉 Rear View（背面全身），**四格等分佈局**（**全圖共 4 格 = 提示詞必須顯式聲明的總數；不設獨立大主圖、任一視角不得重複、不得出現第 5 格**）。🗄️ LEGACY：舊「3/4 斜側三視圖」僅作歷史兼容。**★面部錨點唯一（硬性）**：全圖**僅 Face Close-up 一處渲染清晰五官**，其餘三格一律**「無臉」——頭部完整入畫（不裁頭/不砍頭，保頭身比）、面部不刻畫五官**；三格全身統一**完整頭頂至鞋**（不裁腳、不砍頭、鞋必須畫在全身格內）。**★四格純圖（硬性）**：**圖上除圖底部那行 ≤8 詞英文音色速覽標籤 + 聲紋波形外零文字**——不標視角名/「正面·側面·背面·面部特寫」/臉部處理/角色名/編號；**圖底橫向細節條必須入圖**（2026-10-12 第五輪修正）= **① 聲紋波形 / 頻譜可視化（非文字圖形 · 視覺一致性錨 · 不佔入圖文字名額）＋ ② ≤8 詞英文音色速覽標籤 Voice Description Label（唯一允許入圖的文字）**；**完整版 Voice Description（2–4 句）不入圖**，轉純文本交付。逐格落位表見 `sd-asset-engine/references/character-portrait-templates.md` §七。
3. **Full Body（全身比例）**：身高比例尺（如 180cm / 168cm）、頭身比（6.5~8 頭身）。
4. **Detail Assets（細節材質）——文字描述項，不佔圖格（2026-10-10 修訂）**：以下細節**不再單獨出圖格**，改為寫進四格描述文字 / 複述塊：
   - Fabric Texture（服裝布料肌理，如啞光羊毛、做舊皮質）
   - Hair Style（髮型流向與碎髮高光）
   - Button / Cuff Design（紐扣、袖口與配飾細節）
   - Footwear（鞋履款式與材質——**必須畫在全身格內**，不得依賴特寫格）
5. **HEX Color Palette（標準色值）**：
   - Primary（主色調，如 `#1A1E24` 炭黑）
   - Secondary（副色調，如 `#8C7355` 暖卡其）
   - Accent（點綴色，如 `#C23B22` 暗硃紅）

## 二、 親緣與多梯隊角色推導引擎

為保證群像戲（如家族、親屬、師徒）的視覺統一與真實感，嚴禁孤立生成配角。必須遵循以下推導法則：

### 1. 梯隊劃分
- **第一梯隊（T1 - 核心基準）**：男一號、女一號。率先鎖定臉模與核心畫風。
- **第二梯隊（T2 - 親緣/親密）**：父母、子女、兄弟姐妹、情侶、核心反派。
- **第三梯隊（T3 - 功能配角）**：同門、手下、管家、路人。

### 2. 親緣遺傳推導算法（推導後直接出圖）

當生成 T2 親屬角色時：
- **骨相繼承**：繼承 T1 角色 40%~60% 的下頜骨輪廓或眼眶深淺；
- **五官關聯**：如母親與女兒共享相同鼻型與眉形弧度，僅在眼尾紋理與面部膠原蛋白豐滿度上作年齡化差異；
- **色彩呼應**：家族成員在服裝 HEX 調色板中共享至少 1 個 Secondary/Accent 色值；
- **出圖方式**：按上述繼承參數，直接生成 T2 的 4 View 資產板（複用 T1 的底色/材質描述 + 差異化參數），併入 P2 第一批角色出圖，鎖定後進《資產圖冊》。

## 三、 輸出指令規範

當用戶輸入 `/角色資產板`、`/角色遺傳推導` 或 `/數字資產包` 時，系統按 `asset-first-pipeline.md` P2c·第一批執行：
1. 鎖定 T1 男女主臉模與核心畫風（出圖）；
2. 按親緣推導 T2/T3 並**直接出圖**（非文字描述）；
3. 輸出角色 16 項資產全量描述詞（中英雙語，可直投 Midjourney / 即夢 / SD，作為出圖提示詞）；
4. 交付角色 4 View 資產板 + 親緣推導關係表 + 標準色值清單。
