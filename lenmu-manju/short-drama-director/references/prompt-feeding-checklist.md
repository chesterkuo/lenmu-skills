## 〇、 執行鐵律

1. **A·模型版本鎖定（未指定不動筆）**：寫任何提示詞前，先完成 Seedance 2.5 / 2.0 強制二選一（見 `model-adapters.md` 〇節）；用戶未指定 = 任務不開始，禁止默認跳版本；
2. **B·畫幅鎖定（與 A 同規格）**：先完成畫幅強制三選一——**16:9 / 9:16 / 21:9**（1:1 僅用戶明確指定時採用）；用戶未指定 = 停下詢問，禁止默認 9:16；鎖定後全流程沿用（見 `aspect-ratio-adaptation.md`）；
3. **雙鎖齊備才過檢（多段任務加 D 鎖）**：A、B 兩道鎖全部鎖死，才允許進入下方 6 步序列；**多段任務另鎖 D·段縫銜接方式四選一**（尾幀錨定+畫面鎖/換機位硬切/空鏡過渡/**技巧型轉場**——④ 見 `creative-transition-library.md`），未指定停下詢問；
4. **按序過檢**：以下 6 步按順序執行，每步產出對應校驗結果，全部通過才允許出稿；
5. **語速卡不入正文**：語速自檢卡是內部 QC 附件，默認不寫入投餵正文（避免汙染提示詞），但必須隨交付物一併輸出；
6. **戰鬥檔先定檔再取庫**：先按 `sd-combat-engine/references/tier-and-finisher-system.md` 〇節定 R1/R2/R3，再取對應引擎完整庫——**R1 寫實 → `sd-real-engine`；R2 武俠/現代格鬥 → `sd-combat-engine`；R3 玄幻 → `sd-xuanhuan-engine`**；**三者不混用**；
7. **交付滿額鐵律（不許漏執行項目）**：契約要求的字段/模板段落必須逐條寫滿才算出稿——出圖提示詞按滿血模板（角色 4 View 資產板+16 項鎖定 / 戰鬥場景站位版）、分鏡逐鏡帶在場名單+站位聲明+行內聲音台詞（**段末不寫接續尾行**）；**示例與演示同樣滿血**，禁止簡筆交差（見 SKILL.md 法則 15）；
8. **出稿機檢門（硬性 · 2026-09-15 新增 / 2026-10-10 擴容至 C1~C26 · 子檢查碼共 104 條）**：提示詞寫完後，**必須跑一遍 `scripts/validate_prompt.py <稿>.md --model 2.5|2.0`**（畫幅鎖定時加 `--aspect 16:9|9:16|21:9` 供 C6b 三處互校），`[-] FAIL` 項清零才允許交付（腳本查 C1~C26：時長/切鏡/字符/版本語法/畫幅回填/**畫幅一致性 C6b（字段↔【畫幅風格】↔`--aspect` 互校 + 橫豎構圖詞越界）**/七段式/2.0 禁用首尾幀/高危詞/**接續狀態殘留攔截（C11 反轉：出現即 FAIL）**/規則詞混入/鏡長雷同節奏門/**畫外聲 OS·VO 聲畫分離與配額**/**拉伸湊時**/**對白語氣錯位與缺失**/**擺位必入畫·人物賬連續·跨段站位漂移（C17d）**/**首鏡錨定·姿態回退·視線黏道具·特寫承載空間事件·反光道具光效·景別與表演幅度越界**/**運鏡機檢門 C18g~l（逐鏡必標運鏡·一鏡多主運鏡·無動機運鏡·固定鏡 >10% 或連排 ≥3·運鏡單調·重技法名額超限）**/**段縫景別落差 C18m（相鄰兩段末鏡終點景別 → 首鏡起點景別：末鏡做了收束動作的須同檔〔反向收緊 ≥1 級即報〕、未做收束的 ≤1 級〔≥2 級即報〕，超出且無過渡手段即報）**/**景別佔比預算 C18p（遠/全/中/中近/近/特 六組佔比須落「景別佔比預算表」區間〔文戲/打戲分列〕：鏡數 <10 不判、文戲「特」檔交 C18n 獨管、偏差 <5pp 不報）**/**畫面段最低三要素 C32（每個鏡行畫面段＝`台詞：` 之前須同時含背景元素〔前景/背景各 ≥1〕+ 光線方向〔綁光源錨點〕；純空鏡/微距大特寫/模板骨架行豁免，不設鏡數下限）**/**站位人物賬解析元檢查 C7c（【站位聲明】漏 `@` 時人名解析為空 → C17／C17b／C17c／C17d／C19c 五條判據靜默失效，腳本卻照報 PASSED）**/**裸禁令詞·光路觸發器·首鏡主體優先·具象光源映射·禁止項欄目紀律**/**首鏡單主體錨定·並列主體句式·懸空指代·抽象形態形容·道具光效·道具貼近光源**）。**多段稿（N 組提示詞）逐段自查**——C1/C2/C3/C4/C17/C24 按段獨立判定，防"第一段合規、第二段起人物蒸發"。機檢兜底，人讀規則先行，兩者不互相替代；
9. **禁用清單先行**：出稿前照 `model-adapters.md` §5.1「格式禁寫清單」掃一遍（禁外部括號五要素連寫 / 禁鏡行"跟隨@誰" / 禁末尾參數行 / 禁 ASCII 站位圖 / 禁默認版本與畫幅 / 禁裝飾性長散文 / 禁簡筆出圖詞）——命中任一條即返工。
10. **對白語氣必寫（2.0 / 2.5 同規格）**：**有台詞的鏡行，`台詞：` 字段必須是 `【角色（語氣）："…"】`**——語氣是官方對白三要素之三（HOW THEY SOUND），缺失會讓聲音與表情一併扁平（官方原文點名 `tone_qualifiers`）。**語氣詞只進語氣位、禁寫進畫面段**（寫進畫面段會被當視覺信息渲染成"一張冷笑的臉"）；**道具動作與語氣一致**：把玩/摩挲類閒適動作只配慢悠悠語氣，宣判/嘶吼/質問等強情緒語氣必須換攥緊/捏住/垂手握著（實測宣判時刻"把玩玉佩"出戲）；**音色鎖僅 2.5 且為可選增強**（2.0 無音頻參考通道，只做語氣，不做音色鎖不算缺陷）。規範見 `model-adapters.md` §5.2，機檢 C16 兜底。
11. **人物賬連續·擺位必入畫**：**站位聲明擺了位的每個人，本段鏡行必須至少帶到一次**（正拍/焦外身影/全景群像/反應鏡頭均算），給不了鏡頭就寫明 `段末離畫/退場·去向`；重新入畫要寫明方式；相鄰段沒移動的人站位不漂移。多段任務逐段自查（尤其"背景工具人"：抽菸的爹/縮在身後的妹妹最容易整段蒸發）。規範見 `model-adapters.md` §5.0.1，機檢 **C17（a 擺位必入畫 / b 關係鏡缺失 / c 背景錨點缺失 / d 跨段站位漂移）** 兜底——**多段稿逐段跑，第 2 段起每段都要查**。
12. **首鏡錨定·景別一致·姿態延續·視線指派（單段防廢鏡）**：① 每段第 1 鏡必須帶站位人物（人名或註明歸屬的身體局部），空鏡開場寫明「空鏡：…」且每段至多 1 鏡；② 特寫只裝單一局部主體，暴雨砸漏/塌方/全屋事件由中景以上承載；③ 撐起/坐起之後，後續鏡必須「保持撐坐」或寫明跌回過程，禁無聲躺回；④ 說話鏡寫明「目光落在 XX 臉上」，把玩/舉向道具說話必須補「視線不落在道具上」。規範見 `model-adapters.md` §5.0.2，機檢 C18 兜底。
13. **禁令失效三改法 + 欄目紀律**：**視頻模型對否定不敏感、對詞根敏感**——被禁概念的詞根（發光/笑/空鏡）哪怕掛著"不/禁"也會被當畫面詞渲染（實測三條否定式禁令兩輪全部被無視）。高關聯視覺概念必須：① **換詞**——被禁詞根在提示詞任何位置（含強制禁止項）零出現，改正向描述（道具→「實心啞光石質，玉面呈青玉原色」**零光效**；表情→「雙唇抿緊、嘴角向下壓」；首幀→「畫面主體：<人名>…」單主體開頭）；② **主體優先**——每段鏡1第一個分句即人名/身體局部/「畫面主體：」，禁環境前置詞開頭；③ **觸發器移除**——道具不與燈火共現：只把玩/佩戴，不靠近光源（⚠️ 舊建議「舉到油燈旁，火光從側面照」已廢止——實測同樣點火）。**欄目紀律**：【強制禁止項】只裝負面清單（畫面/文字/音頻三類）——**正向執行指令禁入**（該欄被當規避清單讀，寫進去兩頭不生效），**否定式禁令同樣禁入**（被禁詞根＝畫面詞）；正向指令一律回落鏡行/【畫幅風格】/【站位聲明】。水印/變形等低關聯瑕疵仍走否定式兜底。**具象光源映射（C19d）**：反光道具鏡行禁寫「映出/倒映火苗」，**零光效描寫**只寫材質本色（⚠️ 舊建議"光斑語言"已廢止——光斑句出片玉佩像打火機點了一簇火，見鐵律 15④）。**鏡行少形容詞**：正向描寫每鏡只留必要項（主體/動作/材質各一處），修飾詞堆疊稀釋關鍵信息。規範見 `model-adapters.md` §5.0.4，機檢 C19（a~e 五判據）兜底。
14. **道具光效·表情錨·外觀錨·跨鏡在場（按禁令失效三改法修訂）**：① 玉佩/銀鐲/鏡面類反光道具：**零光效描寫**——只寫材質本色（「玉面呈青玉原色」/「啞光金屬本色」），光斑/受光/照射/照在/亮起類從句與「舉到燈旁」類動作一律不寫（⚠️ 舊寫法「僅表面反射/映出 X 光」「受光處泛光斑」全部廢止——「映著火苗」→ 玉佩變自發光魔法道具；「指甲蓋大暖黃光斑」→ 玉佩像打火機點了一簇火，見鐵律 15④ / 機檢 C20d；⚠️ 【強制禁止項】裡的「XX 不發光、不透光、不懸浮」同樣廢止——被禁詞根＝畫面詞，見 §5.0.4 改法一 / 機檢 C19e-b）；② 冷硬/宣判台詞必顯式寫**面部肌肉動作**「雙唇抿緊、嘴角向下壓、下頜繃緊、眉梢下壓」（模型對年輕女性默認甜笑；⚠️ 寫「面無笑意、唇線平直」已廢止——被禁詞根＝畫面詞，見 §5.0.4 改法一 / 機檢 C19a）；③【核心人物】行寫年齡錨，特寫鏡複述「與鏡N同一張臉」（防跨鏡換臉）；④ 非主體人物鏡行內**錨依託物/背景物即可，嚴禁重複段首已聲明的畫面左右**（2026-10-15 單一方位權威：雙重發位＝用戶實測「東一個西一個/突然出現在身後」，舊寫法「複述畫面右後門邊陰影」廢止，且與 C20f 頂牛）；段末鏡再帶到；⑤ 首鏡錨定靠**鏡行內單主體正向聲明**「畫面主體：<人名>…」（⚠️ 禁止項裡的「禁自行增加鏡頭或空鏡開場」已廢止，「空鏡」詞根本身會汙染畫面；也禁「X 與 Y 同框」並列主體句式——見鐵律 15）。規範見 `model-adapters.md` §5.0.3/§5.0.4，機檢 C18e/C19/C20 兜底。
15. **首鏡單主體錨定與具象化（防"兩張臉"）**：① **首鏡錨定句只許一個具名主體**——**禁「X 與 Y 同框」類並列主體句式**（實測段1 鏡1「首幀即這隻手與她的臉同框」→ 出片**兩張臉**，用戶原話："總共生成了兩張臉，最大的禍首就是這兒"——模型把並列名詞 +「同框」讀成畫面裡有兩個主體）；身體部位一律以「她的/其 + 部位」從屬出現，確需兩人同鏡由【站位聲明】具名雙主體承載（機檢 C20a）；② **指代詞必須帶歸屬**——「這隻手 / 那張臉」無先行詞 → 模型自補一個主體（補出一個頭），一律寫「她的一隻手 / 他的右手」（機檢 C20b）；③ **抽象形態·程度副詞一律刪**——成線/成串/成股/如注/輕蜷/微蜷，模型**無法命名過程形態**（「漏雨成線砸在手背上」→「雨滴砸在手背上濺開」；「手指輕蜷」→ 直接刪）。**判據一句話：這句裡每個詞都能畫出來嗎？畫不出來的就是形容詞。** ④ **反光道具零光效描寫**——光斑/受光/照射/照在/亮起類從句與「舉到燈旁」類動作一律不寫（實測「指甲蓋大暖黃光斑」「舉到油燈旁」出片**玉佩像打火機點了一簇火**），只寫材質本色（「玉面呈青玉原色」/「啞光金屬本色」）（機檢 C20d）。規範見 `model-adapters.md` §5.0.2/§5.0.3/§5.0.4，機檢 C20 兜底。

2. **單鏡時長**：**≤6s**（C10）；按內容倒推，⛔ 不許把氛圍鏡拉長湊滿劇本標註時長；總時長允許比標註短 25%，**寧短勿拉**。
3. **機位不得重複**：同段內相鄰鏡頭的「景別 · 視角 · 運鏡」表述不得完全一致；拆鏡必改機位（越肩 / 反打 / 大特寫）。
4. **C32 畫面段三要素**：背景實物 + 光線方向 + 主體動作，**必須寫在「台詞：」之前**——寫在台詞之後不計入。
5. **運鏡詞表**：只用詞表內詞（橫搖 / 平搖 / 搖鏡 / 推 / 拉 / 跟 / 升降 / 固定）。「快搖」這類**不在詞表**的詞會直接 FAIL（C18g）。
6. **人數用肯定句**：寫「殿內共五人：A、B、C 與兩名弟子」，⛔ 不寫「畫面中沒有其他人」（否定句會被判成群像缺錨）。
7. **段內鏡號從鏡1 起算**：多段稿每段獨立編號；增刪/拆分鏡頭後**整段重編號**，並同步分鏡稿與投餵稿（跨段連續編號會讓 C15/C10 的段內統計錯位）。
8. **段縫換機位 + 換景別**：D 鎖「換機位硬切」不只是挪機位，**景別也要變**（末鏡特寫 → 首鏡大遠景），否則觀眾仍讀作同一個鏡頭。

#### Step 6·補2 · 多段稿機檢口徑（★ 必看）

```bash
python scripts/validate_prompt.py <稿.md> --model 2.5 --by-segment
```

- **凡一稿含 ≥2 段（90s = 3×30s 等），一律加 `--by-segment`**。整份送檢會把三段時長與鏡數累計，讀成「90s 一段 / 多鏡」，從而**誤判打戲檔觸發 C21/C22**，C10 單鏡時長與 C15 特寫佔比也全部失真。
- 分單元模式按「段N/M」標題切段逐段跑，輸出帶 `[段N]` 前綴；整份文本仍走 C31 契約核銷。
- 報告須寫明用哪種口徑；⛔ **不許拿整份模式的 C21/C22 去改本沒有打戲的段**。
