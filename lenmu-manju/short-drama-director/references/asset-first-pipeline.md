# AI 短劇全流程 Asset-First 六階段生產管線 (Asset-First Pipeline)

> ⭐ **全局總控流程（★權威）**：本文件定義本 skill 從立項到成片的**唯一生產順序**。所有模塊（劇本/資產/分鏡/渲染/質檢）都掛載在這六階段上，禁止跳步。
>
> ⚠️ **兩條正交軸，別混談**：本文件管 **A 軸（任務複雜度 → 走不走資產鏈）**；**圖在不在手裡（M0/M1/M2 素材形態）** 由 `asset-delivery-modes.md`（★權威）管——**兩者正交**，A 軸判不清按 A3 處理，**M 軸按用戶實際條件處理，不取最高檔**。
>
> 🔗 聯動：**素材形態與門禁改判 → `asset-delivery-modes.md`（★權威，本文件所有門禁的判定細則以它為準）**；畫幅/風格/平台鎖定 → `aspect-ratio-adaptation.md`；劇本門控 → `screenplay-gate-engine.md`；資產圖執行 → `asset-spatial-ledger.md` / `character-lineage-and-sheets.md` / `production-ledger-handbook.md`；分鏡 → `blocking-direction.md` / `spatial-topview-camera.md` / `sd-combat-engine`；渲染 → `seedance-render-engine.md` / `model-adapters.md`；質檢 → `quality-gate-review.md`。

## 〇、 核心原則（鐵律）

1. **生產順序先於一切**：P0 立項鎖定 → P1 劇本門控 → P2 數字資產包 → P3 空間調度+分鏡 → P4 投餵生成 → P5 質檢，**禁止跳步、禁止倒序**；
2. **默認只出提示詞，不直接出圖（2026-09-16 用戶確認 · 最高優先級）**：本管線默認交付 = 出圖提示詞/文檔，**不調用出圖工具直接生成圖片**（含角色 4 View、場景母版、道具圖、分鏡關鍵幀/首幀圖）。只有用戶**明確逐次下發出圖口令**（"出圖/生成圖片/跑圖"）才執行；執行仍須先過下方門禁 1（資產清單確認）+ 門禁 2（分批逐批確認），禁止把"開始 P2 資產出圖"當默認動作；
3. **圖在哪兒，決定門禁怎麼判（與第 2 條配對）**：本包**不持有圖**——圖由用戶在外部平台自行生成並持有。因此「資產」的合格形態**分三級**：**M0 純提示詞**（不寫圖號）/ **M1 編號佔位**（寫 `圖N` + 必附《素材接線單》，**默認**）/ **M2 已入庫**（用戶交回、登記圖冊）。**每次交付首行必須聲明當前形態**。判定細則與門禁改判表見 `asset-delivery-modes.md`（★權威）；
4. **"名字+裝扮"是否算資產，按形態定**：**M2** 下資產 = 可直接投餵的資產參考圖（角色 4 View / 場景資產圖 / 道具圖），文字描述只是索引標籤；**M1** 下資產 = **編號 + 用途 + 外觀要素檔案 + 接線單一行**；**M0** 下資產 = **外觀檔案複述塊本身**（文字即資產）。**三種形態都算"有資產"，不存在"M0 就等於沒資產"**；
5. **無圖不進分鏡 → 改判為條件門**：分鏡引用的錨點必須有**對應物**，但"對應物"按形態定義——M2 指向已鎖定資產圖；**M1 指向已登記的圖號（在接線單/素材映射表內）**；**M0 指向已寫出的文字檔案**。**"沒有圖"本身永不構成阻斷理由**（原"無圖不進分鏡"絕對門已廢止）；
6. **不索要 · 不阻塞 · 不假裝 · 要聲明**：禁止索要圖片作為繼續流程的條件；禁止因缺圖阻斷任何階段；**禁止寫不存在的圖號、禁止聲稱"與資產圖冊一致/已核驗"而實際從未見過圖**；每次交付首行聲明形態。詳見 `asset-delivery-modes.md` §五；
7. **畫幅、風格、平台在 P0 一次鎖定**，全流程沿用（見 `aspect-ratio-adaptation.md`）；
8. **分批出圖 + 逐批確認**（**僅用戶下發出圖口令後適用**）：資產不一次性堆砌，按 角色→場景→道具 分批產出，每批鎖定後才進下一批；
9. **資產依賴分級（A0~A3 · A 軸）**：Asset-First 能力全保留，但按任務複雜度觸發——**A0** 純文字/單鏡/無角色一致性要求：不強制資產鏈，文字描述可直投（禁用圖號即不受門禁 3/4 約束）；**A1** 單角色單鏡：資產可選（有參考圖更穩）；**A2** 跨鏡角色/場景一致性：啟用相關角色/場景資產；**A3** 多人/多場景/連續劇集/高一致性項目：完整執行六階段（默認檔）。**判定不清按 A3 處理（寧全勿缺）**。

## 一、 六階段總覽

```text
P0 立項鎖定（畫幅 / 風格 / 平台 / 時長）+ ★素材形態初判（M0/M1/M2，默認 M1）
  ↓
P1 劇本五階門控（前提 → 結構 → 節拍 → 實體 → 專業劇本頁）
  ↓
P2 【數字資產包】（本 skill 核心階段 · 按 M 形態分流）
  ├─ 2a 實體提取：從劇本自動提取全部 角色(CHR)/場景(SCN)/道具(PRP)/聲音(AUD)
  ├─ 2b 資產清單：全量編碼 + 16項五官 + 6項材質 + 親緣推導表(T1→T2→T3) + 用戶確認無遺漏
  ├─ 2c 出圖/出詞（★按形態分流）
  │     M0 → 產出「外觀檔案複述塊」供各段複用（不寫圖號）
  │     M1 → 產出「出圖提示詞（用戶外部跑圖）+ 圖號編號 + 《素材接線單》」（默認）
  │     M2 → 分批出圖：①角色 4 View 資產板 ②場景資產圖 ③道具圖，每批確認鎖定
  └─ 2d 交付《資產圖冊》（★按形態降級）
        M0 → 《外觀檔案冊》（無圖，純文字檔案）
        M1 → 《資產編號冊 + 素材接線單》（編號 + 用途 + 外觀要素 + 該掛哪張）
        M2 → 《資產圖冊》（附資產參考圖，單一事實源）
  ↓
P3 空間調度 + 分鏡（錨點按形態指向：M0 文字檔案 / M1 已登記圖號 / M2 已鎖定資產圖；CAM1~4 / 180°軸線）
  ↓
P4 投餵生成（Seedance 2.5 / 2.0 強制二選一，每單元 ≤15s，三層解耦提示詞）
  ↓
P5 質檢（P0/P1/P2 + 一致性：M2 可比圖像；**M0/M1 改判為"與文字檔案一致"**；**修改稿另須跑改動後三步複驗並附《改動複驗報告》，見門禁 6**）
```

## 二、 P2 數字資產包執行細則

### 2a 實體提取（從劇本自動派生）
- 掃描定稿劇本，提取全部**有跨鏡複用**的實體：
  - 角色 CHR：A（核心）/ B（常駐）/ C（群眾，僅需文字描述）；
  - 場景 SCN：核心場景（多集出現 / 關鍵打鬥 / 重場戲）必須建檔；一次性過場場景可僅文字；
  - 道具 PRP：劇情關鍵物證 / 多鏡出現 / 有防穿模風險的道具必須建檔；
  - 聲音 AUD：OS / 對白 / SFX / BGM 四類，進產出冊聲音資產表。
- **判定標準**：該實體是否在 2 個以上鏡頭/場景出現，或在後續劇情中複用 → 是則建檔（**M0 建文字檔 / M1 建編號檔 / M2 建圖檔**）。

### 2b 建檔清單（用戶確認門禁 1）
- 輸出《完整資產清單》：所有實體編碼 + 角色 16 項五官 + 6 項材質 + 親緣推導表（T1→T2→T3 骨相繼承 40%~60%）+ 場景空間屬性 + 道具特徵；
- **必須讓用戶確認"無遺漏、無錯位"後才進入 2c**；
- ⚠️ **本步與出圖無關**：清單是**文字/編號層**的確認，**不要求用戶此時提供任何圖片**（原"未確認禁出圖"在 M0/M1 下改判為"未確認禁進入 2c 建檔"）。

### 2c 出圖 / 出詞（按 M 形態分流 · 每批確認門禁 2）

| 形態 | 本步產出 | 門禁 2 判定 |
|---|---|---|
| **M0** | **外觀檔案複述塊**（發/服裝/體態/年齡感/標誌物五要素，供各段直接複用）+ 場景座標系與 `SET_STATE` 登記 | 複述塊是否**五要素齊全**（缺項 → 回補） |
| **M1**（默認） | **出圖提示詞**（用戶拿去外部平台跑圖）+ **圖號編號** + **《素材接線單》** | 每個圖號是否有接線單行 + "只控制什麼/不控制什麼"是否寫全 |
| **M2** | ①角色（A/B 級 4 View 資產板）②場景（核心場景資產圖）③道具（關鍵道具圖），每批確認鎖定 | 分批資產圖是否全部鎖定 |

> ⚠️ **M0 / M1 下不存在"分批出圖"**——本包不出圖，用戶也不把圖交回，**禁止以"資產圖未鎖定"為由卡住 P3**。

### 2d 交付台賬（★按形態降級命名，禁止混稱）
- **M0** → 產 `《[劇名]_外觀檔案冊.md`：每條 CHR / SCN / PRP 附**外觀檔案複述塊 + 場景座標系 + 狀態變體**，**不含任何圖號**；
- **M1**（默認）→ 產 `《[劇名]_資產編號冊.md` + 《素材接線單`：每條附**編號 + 用途 + 外觀要素 + 該掛哪張 + 只控制什麼/不控制什麼**；**接線單是交付必備件**；
- **M2** → 產 `《[劇名]_資產圖冊.md`：CHR / SCN / PRP 全部附**資產參考圖** + 短錨點，成為 P3/P4 唯一權威事實來源（Single Source of Truth）；
- **三種交付物共同點**：都是 P3/P4 的權威依據——**"有依據"不等於"必須是有圖的依據"**。命名**不得混稱**（M0/M1 稿裡寫成《資產圖冊》即為形態違約）。

## 三、 門禁與確認點

> ⚠️ **門禁按素材形態改判**：下表是**速查版**；**逐形態的完整判定細則以 `asset-delivery-modes.md` §二 為準**（本表與它衝突時以它為準）。

| 門禁 | 位置 | 規則（速查） | 形態影響 |
|---|---|---|---|
| **門禁 1** | P2b → P2c | 建檔清單未獲用戶確認 → 禁止進入 2c | M0/M1 下 = 文字/編號層確認，**不涉及圖片** |
| **門禁 2** | P2c → P3 | 本批產出未確認 → 禁止進入分鏡 | M0/M1 下改判為"複述塊齊全 / 接線單齊全"；**不存在"資產圖未鎖定"阻斷** |
| **門禁 3** | P3 | 分鏡錨點無對應物 → 阻斷並回補 | **對應物按形態定義**：M0 文字檔案 / M1 已登記圖號 / M2 已鎖定資產圖 |
| **門禁 4** | P4 | 投餵稿錨點與映射不一致 → 阻斷 | M0 無圖號；M1 圖號槽位須與接線單**逐條對應**；M2 原樣 |
| **門禁 5** | P5 | 一致性不符 → P0 阻斷 | M0/M1 改判為**"與文字檔案一致"**（發/服裝/體態/年齡感/標誌物逐項）；**M2 才做圖像級核驗** |
| **門禁 6** | P5（修改類交付） | 修改稿未跑「局部驗證 → 聯動衝突檢查 → 全量審核」三步複驗 / 未附《改動複驗報告》 → 阻斷交付（見 `quality-gate-review.md` §三） | **不受形態影響，始終全量適用** |

**形態聲明為交付前置**：交付稿**首行未聲明素材形態（M0/M1/M2）** → 視為形態未定，機檢告警（`sd-feed-engine/scripts/gate_check.py` 閘門 6），**不得交付**。
