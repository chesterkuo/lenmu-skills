# 畫風鎖規程（I 鎖 · 方案文檔通稱「F 鎖」）—— 推薦式選單 → 選定即凍結

> **本文件是 I 畫風鎖的唯一權威**。
> 編號說明：〇節 E~H 已被既有用戶確認鐵律佔用（E 只出提示詞 / F 2.0 時長分配 / G 台詞音效默認內出 / H 素材紅線），本鎖編號順延為 **I**；方案文檔與外部討論中的通稱「F 鎖」= 本鎖。
> **鎖性質（★ 2026-10-13 用戶裁定升格）**：與 C·交付形態同級的**必彈卡鎖**——**動筆前必須推送候選卡、讓用戶在卡上勾選**；卡內**必須包含「按你的推薦走」一項**（用戶不想挑時可主動選它，等價於授權用默認推薦卡），⛔ **但禁止在用戶未表態時自行按默認推薦卡執行**（用戶原話：「**這個還是沒有給我選**」）；**選定後即凍結**，與 A/B/C/D 同規格（全流程只讀、中途改 = 重開任務）。

## 一、設計原則（用戶口徑 · 逐條對應）

| 用戶要求 | 落地設計 |
|---|---|
| 「在前面做成一個選項」 | 插在 **P0 鎖區**（D 鎖之後、E 鐵律之前），與各鎖同一句話問清 |
| 「類似於固定鎖」 | 選定後與 A/B/C/D 同規格：全流程只讀、禁止中途改、中途改 = 重開任務 |
| 「儘量讓他們前面先多選一些」 | 每次給 **4 張候選卡**（含「D 自定義」位），每張卡**必帶易跑偏警告** |
| 「選完那個類型之後給他推薦」 | 候選卡由 **題材 × 素材來源** 交叉推薦，命中題材有**默認推薦卡**（標「默認推薦」） |
| 不能變成攔路虎 | **卡上必帶「按你的推薦走」一項**（一鍵授權，跳過零成本）；⛔ 但**未表態 ≠ 已表態**——未表態 = 停下詢問（★ 2026-10-13 修訂） |

## 二、觸發時機與位置

```text
〇·1 素材來源 → A 模型版本 → B 畫幅 → C 交付形態（強制鎖）
        → D 段縫銜接（多段任務）→ ★I 畫風與視覺風格（本鎖 · P1 劇本之前推送候選卡）
```

- 〇·1 + A/B 鎖定後、**進入 P1 之前**推送候選卡；
- 與 A/B/C 同一句話問清（「模型版本？畫幅？交付形態？畫風想要哪一種？」）——⛔ **禁止說「不指定我就按默認卡走」**；改用「**這幾張卡請挑一張；不想挑就回「按你的推薦走」**」（★ 2026-10-13 用戶裁定）；
- **寫入 P0A 基準表**，P2/P3/P4/P5 只讀；確需改 = 重開任務（與 A/B/C/D 同紀律）。

### Step 3 · 導演卡（每族 1~2 張 · 最多 4 張）

**排序鍵 =（題材親和度, 打鬥★ + 特效★）——親和度優先，能力總分次之。**

> ★**通用教訓（實測三輪抓出）**：推薦排序**永遠不能只看能力維度**。能力（打鬥★/特效★）是**門檻**（用於排除），**不是排序鍵**。排序鍵必須是**題材親和度**——否則都市情感場景會把樸贊鬱（打鬥★★★）頂上 A 卡。引擎 v1/v1.1 兩代都栽在這裡，v2（現行）五用例 A 卡全對。

**收卡規則（一條都不能少）**：
1. **同族不超過 2 張**——4 張卡里同族佔 3 張等於沒給選擇；
2. **必帶能力標籤**——打鬥★ / 特效★ 缺任一 → 不得進候選池；
3. **必帶易跑偏警告**——「我選了它，最可能出什麼錯」是用戶最需要的信息；
4. **必標 AI 落地度**——A 直接用 / B 系統自動補寫法約束 / **C 必須同時給降級方案**（不得只提示風險不給路）；
5. **自動排除清單要明示**——「本次已排除 17 組不適合打戲的風格」，讓用戶知道系統替他做了什麼；
6. **禁出基底衝突卡**——與 Step 1 基底衝突的風格直接不上卡。

**次級操作**（用戶沒選中時）：看全部該族 / 換一批 / 按技法篩 / **D 自定義**（用戶描述 → 按 11 槽位建 STYLE_BIBLE）。

### Step 4 · 可選輔助質感（選完主風格後才問 · 可跳過）

只給能疊加的族（2 個選項 + 「不疊加」）；**未指定 = 不疊加，按主風格執行，不追問不阻塞**。互斥的 6 對見 Step 2 表，不得出現在輔助選項裡。

## 六、四條硬規則（選定即凍結）

- **F-1 一套主原型 + 至多一個輔助原型**（輔助須承擔明確獨立功能，如「主體水墨 + 特效手繪化」）；
- **F-2 多時空走「公共底層 + 明確分支」**，**禁止同一時空串風格**；
- **F-3 選定即凍結**：寫入 P0A 基準表，P2/P3/P4/P5 只讀；確需改 = 重開任務（與 A/B/C/D 同紀律）；
- **F-4 第三方作品名禁入最終提示詞**：參考只作內部解析，須轉譯為可見參數（靈境鐵律第 8 條；判據見 `director-to-prompt-protocol.md` §六 C23d）。
