# 畫風鎖交付規範（選項層 → 交付層 · C23 判據 · 實拍復盤教訓）

> **本文件是 I 畫風鎖的交付層規範**。選項層（用戶選名字）與交付層（提示詞落地）的邊界、C23 判據彙總、以及首輪實拍復盤回寫的硬教訓都在這裡。
> 配套：`style-lock-protocol.md`（鎖規程）· `director-to-prompt-protocol.md`(植入規程) · `director-param-library.md`（11 槽位參數源）· `style-prefix-blocks.md`（成品塊）。

---

## 一、兩層架構鐵律

| 層 | 誰在用 | 名字可用？ | 載體 |
|---|---|---|---|
| **選項層** | 用戶 + 推薦引擎 | ✅ 可以說「徐克」「王家衛」「MAPPA」 | 遞進式選單 / 候選卡 |
| **交付層** | 提示詞 + 視頻模型 | ❌ **絕不出現任何人名、工作室、影片名**（靈境鐵律第 8 條） | 段 8 / 段 9 成品塊 |

**轉譯責任在系統**：用戶選「徐克」，系統從 `director-param-library.md` 取出 11 槽位取值，組裝成段 8/段 9 成品塊（`style-prefix-blocks.md`），**逐字粘貼**進投餵稿。禁止把「徐克風格」這類模糊詞直接寫進提示詞。

## 二、段 8 / 段 9 植入出口

- **段 8【STYLE｜視覺風格 · 全片鎖死】**：11 槽位寫一次（成像底層 / 形體骨相 / 影調區間 / 色彩區間 / 空氣介質 / 光學區間 / 材質響應 / 特效語言 / 針對性禁項），全片風格鎖定，**每段開頭重複引用一次**；鏡頭段取值須落在區間內。
- **段 9【PERFORMANCE｜表演與動作 · 全片鎖死】**：抽幀感 / 慢門拖影 / 機位 / 節奏，僅風格帶表演語法的導演需要（如王家衛抽幀、徐克升格）。
- 成品塊見 `style-prefix-blocks.md`（按卡號逐字取用）。**本庫不提供成稿示例**：交付稿一律按鎖系統與七段式現寫，禁止拿現成稿當參照（P14 起示例整體剔除）。

## 三、三條硬規則（選定即凍結的全流程紀律）

1. **選定即凍結**：I 鎖與 A/B/C/D 同規格——全流程只讀，中途換風格 = 重開任務（改風格會連帶 11 槽位、段 8/9、鏡頭寫法全部重寫）。
2. **成品塊逐字粘貼**：不許自創、不許「差不多意思」改寫；槽位參數是量化區間（如光比 [1:4, 1:7]），改一個數就不再是這個風格。
3. **C23 必過**：`scripts/validate_prompt.py --c23`（或隨 `--combat` 門控自動啟用）校驗交付層零人名 + 11 槽位命中 + 段引用完整。

## 四、C23 判據彙總（機檢側 · 權威定義見 `director-to-prompt-protocol.md` §六）

| 判據 | 內容 | 觸發條件 |
|---|---|---|
| C23a | 缺段 8 STYLE / 段 9 PERFORMANCE，或區間不可解析（含模糊表述「適度的光比」類） | 一律 |
| C23b | **區間越界**：段 1/4/6 取值（光比/焦段/幀率）掉出段 8/9 給出的區間 | 存在跨界槽時 |
| C23c | 單鏡並列視覺特效類 > 3（體積光/霧/塵/炫光/暗角/色散/焦散/流體/電弧…） | 特效詞命中時 |
| C23d① | 段 8/9/1/4/6 出現導演、工作室、攝影師、**影片名** | 一律 |
| C23d② | **轉譯丟失**：STYLE_BIBLE 記了來源風格，但段 8 未落到成組參數組（參數維度 <4/9 或無數值區間） | 有來源登記時 |
| C23e | **★題材越界**：稿含打鬥但來源風格打鬥承載 ★0；或聲明高特效但承載 ≤★1 | 含打鬥時 |
| C23f | **★單鏡超載**：B1 一鏡建立 ≥2 全身人物（引入/交接語義，單人聲明與顯式互動放行）；B2 單鏡動作意圖 > 2（位移/換位/環境崩裂一併計入） | 逐鏡判定 |

> C23e 的打鬥信號詞**必須限定在「畫面動作層」**並排除「聲音：」行與禁止項段落（自檢第 3 輪實測抓到的假陽性）；
> 時碼解析必須兼容小數秒（`2.5s`），否則鏡行全部匹配失敗、C23b/c 靜默失效（自檢第 1 輪抓到的坑）。

## 五、★ 實拍復盤教訓回寫（首輪徐克版 10 秒 · 量化復盤）

> 來源：`style-bible-spec.md §五（實拍復盤教訓回寫）`（ffmpeg 抽幀 + signalstats 客觀量化）。**畫風層 5/5 量化通過（動態範圍 226/255），I 鎖機制被實拍證明有效**；但暴露兩個機檢抓不到的內容問題，已回寫為 C22/C23 擴展判據：

1. **★ C23f（單鏡超載，實拍病機檢化）**：**B1** 不要在 2.5 秒內要求模型同時建立兩個全身人物 + 接觸動作——實測模型會丟棄其中一個角色（只渲染信息量更大的那個）。交接類動作必須拆成單人鏡頭，或每人一鏡（單人聲明/顯式互動語義放行）。與「丟後段動作」病根同源：**超載時模型丟內容，不是做糊**。
2. **★ B2（動作意圖計入 C23f）**：2.5 秒短鏡內動作意圖（含位移/換位/環境崩裂）**≤ 2 項**，不許「擰身 + 掠過 + 換位 + 崩裂 + 碎石」五件事塞一段。原 C22a 只數打擊單元，崩裂/換位不算 → 病漏過，C23f-B2 補上。
3. **量化驗收方法（可複用）**：
   - 密網格抽幀：`ffmpeg -i VID -vf "fps=8,scale=200:-1,tile=8x10" -frames:v 1 grid.png`
   - 亮度量化：`ffmpeg -i VID -vf "fps=4,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-" -f null -`
   - **★ 判光比必須用 YMIN/YMAX，不能用 YLOW/YHIGH**（分位值天然封頂約 100，用錯會假 FAIL）。

## 六、驗收清單（畫風鎖出口自檢）

- [ ] 用戶確認了風格卡（或走了默認推薦並已告知），STYLE_BIBLE 已登記來源
- [ ] 段 8 十一槽位全部來自 `director-param-library.md`，無自創區間（C23d② 成組參數核查）
- [ ] 段 9（如適用）與段 8 特效語言不矛盾（如「幾乎無特效」風格不得出現粒子）
- [ ] 全稿零人名（C23d① 機檢 + 人工過一遍）
- [ ] 鏡頭段光比/焦段/幀率落在段 8/9 區間內（C23b），單鏡特效類 ≤3（C23c）
- [ ] 2.5 秒鏡無雙全身人物建立（C23f-B1）· 動作意圖 ≤2 項（C23f-B2）
