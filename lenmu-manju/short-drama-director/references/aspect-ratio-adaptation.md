# 畫幅自適應路由規範 (Aspect-Ratio Adaptation Router)

> ⭐ **全局總控路由（★權威）**：本 skill 所有環節的畫幅都由此文件統一裁決。**第一步永遠是鎖定畫幅**，鎖定後全流程（資產→劇本分鏡→鏡頭構圖→模板→API 參數→質檢）一律使用該畫幅版本，禁止混用、禁止被示例/模板帶偏。

---

## 〇、 畫幅鎖定流程（任何任務開始前強制執行）

1. **B 鎖·強制三選一**：用戶必須明確選擇 **16:9 橫屏 / 9:16 豎屏 / 21:9 寬幕**（官方另支持 1:1，僅明確指定時採用）；
2. **用戶未指定 → 停下詢問**（與〇節 A·模型版本鎖同規格），禁止默認 9:16、禁止默認回落（舊版"未指定默認 9:16"規則已廢止）；
3. **鎖定後**：在任務產出物開頭顯式聲明 `【畫幅】：16:9 橫屏 / 9:16 豎屏 / 21:9 寬幕`，全流程沿用；
4. **回填**：每條提示詞、每個時間軸分鏡、每個 API 載荷的 `aspect_ratio` 都寫鎖定值，禁止默認回落。

## 二、 橫屏 / 豎屏構圖對照細則

### 橫屏 16:9（用戶指定橫屏時全模塊啟用）
- **空間縱深**：中長焦拉開前後層次，利用走廊/街道/廣場縱深感；
- **站位**：雙人對峙走三分線左右站位，攻防沿對角線推進；
- **位移展示**：騰空橫飛、撞牆橫飛、貼地滑行等橫向軌跡優先；
- **大招**：廣角+低仰蓄力，環形衝擊波橫掃、左右對稱對峙；
- **景別階梯**：極微距→超廣角→宏觀全景→鳥瞰（橫向鋪展環境破壞）；
- **禁**：豎屏式"垂直安全區""上下疊壓構圖"寫法混入。

### 豎屏 9:16（用戶指定豎屏時全模塊啟用）
- **垂直縱深**：高低位落差（高位俯瞰/低位仰視）、前後景疊壓遮擋；
- **站位**：上下對峙、衝鏡特寫（攻擊部位直衝鏡頭）；
- **位移展示**：下劈、跳起下砸、貼地滑行、騰空上衝等縱向軌跡優先；
- **大招**：垂直拉昇+俯衝、法相壓頂、騰空爆發、地面放射狀裂紋向上延伸；
- **景別階梯**：垂直方向的推進與拉昇（俯衝跟隨、拉昇俯瞰）；
- **安全區**：人物佔屏比控制，避免關鍵信息（面部/台詞）被裁切。

## 三、 強約束清單（違反即返工）

1. 用戶說 `16:9` → 任何環節出現 `aspect_ratio=9:16`、豎屏構圖詞（垂直安全區/衝鏡特寫/上下疊壓）均屬違規；
2. 用戶說 `9:16` → 不得套橫屏模板或橫屏構圖詞；
3. 模板/示例裡的畫幅**不是默認值**，只是"參考寫法"，最終以鎖定的畫幅為準；
4. 每份交付物（提示詞組、工作流載荷、分鏡表）頂部必須聲明 `【畫幅】`，質檢時核對一致。
