# 第一部分 · 段縫銜接（段與段之間）

## 一、 病根：模型每段零記憶

AI 視頻模型**單段生成時沒有前段的人物/場景/動作記憶**——每 15 秒（2.0 上限）/ 每段（2.5 上限 30s）數據歸零。前段結尾的人物站位、姿態、人物互動，後一段一概不知。**不補這條記憶鏈，段縫處必然跳切、動作斷層、對白無氣口。**

數據兩類劃分（拼接流暢性的核心認知）：

| 類別 | 內容 | 處理方式 |
|---|---|---|
| **不變數據** | 角色資產圖、場景資產圖（4 View / 母版 / 五宮格） | 全程固定導入，每段重複投餵，一幀不改 |
| **可變數據** | 人物站位、姿態、人物間互動、畫面構圖 | **每段同步更新**——段縫處就是可變數據的換擋點 |

> 常見錯誤做法：**直接拿上一段尾幀截圖、不做任何處理就當下一段首幀原樣硬拼**——**畫面跳切、動作粘連**（兩段變成"一個鏡頭被掐成兩截"）。但這**不等於"截圖法本身是錯的"**——正確用法見下節「尾幀錨定法」：**截圖解決一致性，換機位解決跳切，二者互補而非對立**。

## 二、 尾幀錨定法（粉絲實測反饋併入）

> 📌 **來源**：粉絲「森林」實測反饋（2026-09-24 / 10-07）——「段縫用上一個視頻的尾幀截圖就好，不用重新出圖，現在提示詞跑出來的視頻最後一秒和圖片對不上」「skill 可不可以視頻尾幀加個 0.2 秒、所有人靜止定格幀，下個視頻直接套用這個尾幀」。兩條反饋指向**同一機制**，合併為「尾幀錨定法」。

### 病根：為什麼"重新出圖"必然對不上

當前保險②「按上一段結尾狀態**繪製**段縫分鏡參考圖」是**重畫**——重畫基於**文字描述**，而文字描述無法窮盡視頻末幀的真實像素（光影角度、手指彎曲弧度、衣褶走向、人物間距全都有隨機性）。**重畫 = 重新抽一次卡，必然與真實末幀存在漂移**。這就是粉絲說的"最後一秒和圖片對不上"的根因。✅ 該觀察成立。

### 解法：末幀凍結 → 截圖複用 → 0級同檔景別承接（三步）

**第 1 步 · 段末凍結（P3 分鏡層 · 每段末鏡執行）**

段末鏡按「**0.5 秒收束窗 + 末 1 秒整秒硬定格**」兩段式收尾（**2026-10-12 用戶裁定 · 取代原「1 秒軟穩定窗 + 0.5 秒硬定格」嵌套式**）：

| 層 | 時長 | 性質 | 鏡行寫法 |
|---|---|---|---|
| **收束窗** | 末鏡**末 1 秒之前的 0.5 秒**（15s 段即**第 13.5 秒起**） | **軟要求**（敘事層） | 運動收束——攝影機推/搖趨緩（**末鏡要換景別收束的，景別在此 0.5 秒內拉到位**）、人物停止大幅動作，畫面進入"將要停住"的穩定推進 |
| **硬定格區** | 末鏡**末 1 秒**（**整秒**） | **硬要求**（機檢 C11b 兜底） | 鏡行內顯式寫「**末 1 秒全體人物保持當前姿態與站位、動作完全靜止、畫面定格**」——產出**可截幀的定格尾幀**，**剪輯時整秒剪除**（餘下末幀即定格幀，下一段直接接上） |

> ⚠️ **★ 末鏡台詞靜默預算（2026-10-13 粉絲實測修復 · 硬定格與台詞的衝突）**：**定格與台詞不能同時發生**——人在說話時畫面硬定格 = 視聽分裂（粉絲實測 bug：嘴還在動、畫面凍住了）。實測證據（本項目段1/段2 逐幀差分 + 音頻靜音檢測）：**模型優先級 = 先把台詞說完 > 執行定格指令**——段1 人聲說到 15.10s 最後一幀、畫面末 1 秒運動量與全片持平（根本沒定格）；段2 台詞提前 0.65s 唸完、留出靜默 → 畫面順利收住。故規則不是「要求模型邊說邊定格」，而是**給台詞算夠時間、把末 1 秒真正空出來**：
> - **末 1 秒（硬定格區）禁台詞**——只留環境音（掛鐘 / 燭火 / 呼吸）；台詞最晚須在**定格起點（15s 段即第 14.0 秒）前唸完**；收束窗（13.5–14.0）內允許最後一兩個字的收尾音節，**不得開新句**；
> - **末鏡台詞字數預算 = (鏡長 − 1 − 標點停頓) × 語速檔**——3s 末鏡實際只有 2s 可說話（快速檔 ≈ 11~12 字）；
> - 塞不下的三個解法（按優先級）：**① 台詞前移**到更早的鏡 ／ **② 加長末鏡**（每加 1s 買回 6 字）／ **③ 末鏡改無台詞鏡**（純收束 + 定格，最穩）；
> - 機檢兜底：`sd-feed-engine/scripts/gate_check.py` 閘門2 對**末鏡按 (鏡長 − 1) 判**，超載即 WARN 並點名「定格期被台詞佔用」。

> **為什麼是「末 1 秒整秒硬定格」（2026-10-12 用戶裁定）**：用戶原話——「**最後那一秒我們在剪輯的時候會給它去掉，這樣第二段開始的視頻就可以直接接上了……你最後那一秒就相當於是一個硬定格了……在這一秒的前面的那 0.5 秒你就要開始進行收束了，相當於是 13.5 秒的時候就要開始進行運動的收束**」。三條理由：
> 1. **末 1 秒是主動剪除的冗餘區，不進成片**——舊口徑反對「1 秒硬定格」的兩條理由（「白佔 6.7% 段長」「觀眾能感到畫面卡住」）在**剪除前提**下**全部失效**：它既不佔成片時長，觀眾也永遠看不到那一秒。
> 2. **整秒靜止 = 24 幀任選**（15s 段 × 24fps），截幀必然銳利；0.5s 僅 12 幀，段尾若仍帶慣性，邊界情況依然偏險。
> 3. **收束窗與定格區分離**：收束在定格開始前完成 → 截出的尾幀必然是**已定檔的靜止幀**。
>
> **沿革（勿當現行口徑）**：原為「末 0.2s 定格」→ 2026-10-11 延至「1 秒穩定窗 + 0.5 秒硬定格」→ **2026-10-12 用戶裁定改為「0.5 秒收束窗 + 末 1 秒整秒硬定格」**。


**末鏡景別區間（2026-10-11 新增）**：末鏡須**裝下本段全部在場人物**，以**中全景 / 中景**為主，**最遠不得超出全景**——**禁大遠景 / 遠景**（人物過小、臉不可辨）。理由：可截性只要求「人在場 + 朝向可用 + 錨點可見 + 無壓屏」（下表四要件），**中全景即可滿足**；而大遠景裡主角臉只剩幾十像素，作為下一段參考圖**提供不了臉部信息**，會直接傷到「主角臉一致」這條短劇命門。

> ⚠️ **末鏡"後拉收束"的終點 = 下一段首鏡的承接檔 = 下一段的起手畫面（2026-10-11 新增 · 當日二次確權）**：末鏡允許做後拉/拉遠揭示，但**末鏡收束到哪一檔，尾幀就是哪一檔；而這張尾幀截圖就是下一段的首幀參考圖——所以下一段首鏡必須從同一檔起手（0 級落差，不是"相鄰檔"）**。詳見 §四·補「段縫景別承接律」。
> - **要拉全景收束**，就把下一段首鏡也寫成**全景**起手（段 2 開場即全景，之後段內可自由推回中景/近景——那是段內運動，不受段縫約束）；
> - **做不到就別拉到全景**——末鏡停在中景/中全景即可；
> - **收束窗在末 1 秒之前**：景別收束動作須在**末 1 秒前的 0.5 秒收束窗內**完成、硬定格（末 1 秒）開始前已經到位，這樣截出來的尾幀才是**已定檔的靜止幀**。

**末幀可截性四要件（P3 出稿自檢 / P4 截幀前人眼核對 · 只做判據，不寫進正文、不另起尾行）**：

| 要件 | 判據 |
|---|---|
| ① 人在場 | 本段擺位的**全部**人物都在畫面內，無遮擋、無出畫（漏一個人 → 下段必缺人） |
| ② 朝向可用 | 主要人物面部/身體朝向可辨認；下段若需正臉，末幀不得全背對 |
| ③ 錨點可見 | 每名人物身後/側後方**至少一個可辨識背景物**（牆/門/窗/柱/桌沿/傢俱/燈位）在畫面內清晰可辨 |
| ④ 無壓屏 | 無字幕、水印、Logo、台標壓住人物或背景錨點 |

> 四要件**只在出稿自檢與截幀核對時用**——它是"這一幀夠不夠格當下一段的參考圖"的判據，**不是要寫進投餵正文的字段**（正文仍只寫"末 1 秒定格"一句 + 前置 0.5 秒的收束描述）。

> ⚠️ **與「AI 無靜止表演」鐵律的關係（豁免口徑 · 必須理解）**：本條**不違反**鐵律，因為二者性質不同——
> - 鐵律禁的是「**靜止表演**」：用靜止畫面**承載演出內容**（對峙幾秒、留白、站樁），模型渲染成呆立、節奏拖沓；
> - 本條要的是「**定格截幀**」：末幀靜止**只作為截幀素材**，**不做演出、不進劇情**，且**必須伴隨末鏡的可完成動作**（如"收勢定住/目光定住"）。
> - 判定口徑一句話：**"靜止是為了被截圖，不是為了被觀看"**。末 1 秒凍結是工具幀（**且剪輯時整秒剪除、根本不進成片**），不屬表演幀。

**第 2 步 · 截圖複用（P4 投餵層 · 優先於重新出圖）**

上一段跑完後，**優先直接截取該段視頻的最後一幀**，作為下一段的畫面依據——**取消"重新出圖"這一步**：

- **2.5 首尾幀模式（參考模式②）**：截取的末幀**直接作下一段 `first_frame`**（首尾幀與參考圖互斥，整段走模式②）——一致性 100%，成本 0；
- **2.5 全能參考模式（默認）**：截幀作下一段參考圖組的一員（標註用途：鎖定接續姿態/站位），與資產圖同列；
- **2.0**：**無首尾幀**——截幀作為**單參考圖**綁定形象（每段 1 張，佔 M 軸參考圖名額，注意數量紅線）。

**第 3 步 · 0級同檔景別承接（P3 分鏡層 · 與 §四·補 聯動）**

由於上一段末 1 秒定格幀在剪輯時整秒裁除，截取的真實末幀直接作為下一段的首幀/參考圖依據，因此**下一段首鏡必須以 0 級同檔景別直接承接該末幀**（見 §四·補「段縫景別承接律」），禁止在選 ① 末幀定格承接時強綁換景別硬切。

### 背景錨點鎖（跨段站位的視覺座標 · 2026-10-10 併入）

> 📌 **來源**：粉絲「電影分鏡工作流」的 `character_background_anchor_lock`。
>
> **核心認知**：段縫站位漂移的**真兇常常不是"人物挪了位置"，而是"人物背後的東西變了"**——人相對背景不動，站位就不會漂；人相對背景一換，哪怕人物座標沒動，觀眾也會覺得"換了地方"。所以 **鎖站位 = 鎖"人物與其背景錨點的相對關係"**。

- **綁定**：每段**站位聲明**與**末鏡行**內，為**每名主要人物**寫明其**身後或側後方最可辨識的背景物**（院牆、門框、窗、立柱、傢俱、桌沿、欄杆、燈位、車輛等），作為該人物的位置座標——**禁止只寫"背景不變"這類泛化詞**；
- **不變**：人物未移動、攝影機未移動時，該背景錨點**不得換位、消失、增生、翻轉或改變比例**；
- **移動時**：人物或攝影機移動時，背景錨點的變化必須在**鏡頭內通過視差、遮擋、路徑連續呈現**，禁止切鏡後背景無過程跳換；
- **切景別時**：僅改變景別（中景→特寫）時，背景錨點仍須符合同一**軸線側、空間方位與透視關係**；
- **虛化時**：過肩、淺景深鏡頭可虛化背景，但背景物的**大致方位、色塊、光斑與遮擋邊緣**仍須與上一狀態一致；
- **跨段核對**：下一段首幀的每名人物，其背景錨點須與上一段末幀**同級、同方位**——這是"末幀可截性要件③"在跨段側的延伸。

### 兜底：末幀不可用時的三級處置（2026-10-10 修訂 · 加入「反向重設計」）

**判定末幀不可用**（任一即觸發）：畫質不合格（模糊/穿幫/肢體畸變）/ 被字幕、水印覆蓋 / 無人物入畫（全空鏡結尾，無可錨定的站位）/ 人物朝向不可用（背對鏡頭但下段需要正臉）/ **背景錨點不可辨**（過度特寫或遮擋）。

**處置順序（自上而下，能用上面的就不用下面的）**：

1. **反向重設計上一段末鏡（首選 · 2026-10-10 併入）**——先別急著換圖或重畫，**回頭改上一段最後一鏡的末 1 秒（定格區）與其前的 0.5 秒（收束窗）**：把這一鏡的收勢、構圖與朝向重新設計成"**人物全部在場、無遮擋、無字幕壓屏、背景錨點可辨、朝向可承接下段**"的可截形態。**邊界連續是雙向的**——下一段的首幀質量，一半由上一段的尾巴決定；與其在下段反覆抽卡補救，不如把上一段的尾巴改對。
2. **回退重繪**——依據是**人眼看實際末幀**（不是讀文字），重繪圖納入段縫畫面鎖；
3. **末鏡本身是空鏡**（D 鎖③）——該段縫**本來就不需要人物接續**，直接按換機位硬切處理（空鏡天然就是縫）。

### 與投放側的關係（2026-10-09 修訂）

原「保險① 【接續狀態】文字兜底」**已整條廢止**（見 §三）——跨段對齊**只保留畫面鎖一條腿**。**完整鏈條 = 段末末 1 秒整秒凍結（前置 0.5 秒收束）→ 截圖複用 → 0級同檔景別承接**（三步，無文字環節）。

**末幀不可用時的處置**：見上節《兜底：末幀不可用時的三級處置》——**首選反向重設計上一段末鏡的末 1 秒（定格區）與其前 0.5 秒（收束窗）**（從源頭把尾巴改對），其次回退重繪（依據＝人眼看實際末幀），末鏡本身是空鏡時按換機位硬切。

## 三、 段縫末態繼承（核心規程 · 2026-10-09 由「雙保險」改為「單鎖」）

> ⛔ **變更說明（2026-10-09 用戶裁定）**：原為**雙保險**——保險① 【接續狀態】文字 + 保險② 段縫畫面鎖。**保險① 已整條廢止**（含機檢 C11），本規程改為**單鎖（畫面鎖）**。
>
> **廢止理由**：① 它寫在段尾，模型逐鏡渲染時讀不到／被當摘要忽略，**對"人物站位"類段內問題零作用**——包內「重生70」EP01 實測已證：接續狀態寫了 4 人末態，下一段照樣只拍 2 人；② 與 D 鎖③ 空鏡過渡相沖——空鏡結尾時它承接的不是人物，**主體內容成死信息**（"內容是對的，但對下一段沒用"）；③ 跨段對齊的本質是**畫面**對齊，交給**末幀截圖**比交給文字更可靠。
>
> ✅ **允許留存的等價做法**：若某段確實需要給"下一段起手"一句語義提示，**寫進該段末鏡行的句尾**（與末 1 秒凍結合為一句），**不得另起【接續狀態】欄位**。這樣它一定被模型讀到（鏡行是逐鏡渲染指令），且與末鏡畫面描述**零重複**。

### 段縫畫面鎖（P3/P4 工作流層 · 圖鎖 · 唯一保險）

> **每段生成前，為下一段首鏡準備畫面依據**——只靠提示詞容易反覆抽卡、畫面失控，畫面依據是硬要求。
>
> 🔻 **優先級（見 §二 尾幀錨定法）**：**優先截取上一段真實末幀**（一致性 100%、成本 0）；僅在末幀不合格時（模糊/穿幫/帶字幕/無人物/朝向不可用）才**回退**到"按結尾狀態重新繪製分鏡參考圖"。

- **2.5 全能參考模式（默認）**：畫面依據（截幀 或 重繪參考圖）作為下一段參考圖組的一員投餵（標註用途：鎖定接續姿態/站位），與資產圖同列；上限 30 張內為它留名額；
- **2.5 首尾幀模式（參考模式②）**：上一段**末幀截圖**直接作下一段 `first_frame`（首尾幀與參考圖互斥，整段走模式②）；
- **2.0**：無首尾幀——截幀綁定單參考圖鎖定形象（每段 1 張，佔 M 軸參考圖名額）；
- 段縫參考圖（若走重繪路徑）同樣受 E 鐵律約束：默認只出「出圖提示詞」，用戶明確下出圖口令才執行。

## 四、 段縫換機位鐵律（P3 分鏡層）

> **即便末態鎖死，同機位直接拼接依舊有割裂感。** 段與段的接縫處**強制更換機位/景別**，把兩段做成"兩個不同鏡頭的剪輯關係"，而不是"一個鏡頭被掐成兩截"。

- **禁同機位硬接**：上一段末鏡是中景平視，下一段首鏡禁再起中景平視——至少換視角、換景別其一；
- **段縫六式選用表**（從 `camera-transitions-6types.md` 六式中選段縫適用型）：

| 段縫場景 | 首選接縫式 | 原理 |
|---|---|---|
| 連貫動作被拆段（揮拳→命中） | 一式·動作連續切 | 中景起手 → 特寫命中，視線順動作過渡 |
| 情緒頂點收段 | 二式·反應鏡頭切 | 下段開頭切旁觀者/對手微反應，借反應放大 |
| 段間爆點/轉場 | 三式·景別跳切 或 五式·遮擋過渡切 | 尺度反差或運動模糊無痕轉場 |
| 追逐/位移跨段 | 六式·動勢匹配切 | 物理動量在接縫兩側守恆 |
| **文戲慢段銜接** | **空鏡過渡（見 §五）** | 情緒落地 + 呼吸空間，硬切六式反顯急躁 |

- 分鏡交付時，段縫兩側鏡頭**逐對標註**接縫式別（P3 滿額鐵律，同在場名單/站位聲明同級）。

> **④ 技巧型轉場（★ 2026-10-13 新增）**：除上表六式外，段縫還可用**有設計感的創意轉場**（相似動作 / 形狀匹配 / 前景遮擋 / 甩鏡 / 閃白 / 畫中畫 / J-cut 聲先畫後）——**權威手法庫見 `creative-transition-library.md`**（★權威 · D 鎖 ④）。⚠️ **本文件管"結構化銜接"（①②③），技巧型轉場是第 ④ 類補充，不替代本文件**；④ **按劇情選用、單集 ≤3 處、非每段必用**（法則 20·★）。

### 四·甲、D 鎖②（換機位硬切）接口餘量（★ 2026-10-17 新增 · 粉絲實測反饋併入）

> 📌 **來源**：粉絲轉述反饋（2026-10-17）——「硬切可以，但要在接口留 0.5 秒，方便轉場」。
>
> **裁定**：屬**新補充**。0.5 秒在 D 鎖① 裡已存在，但那是「收束窗」（把運動收到靜止、為了截幀）；本條要的是「接口餘量」（把運動留著、為了剪輯吃轉場）——**同一個 0.5 秒，兩個相反的目的，不可混寫**。

**先分清（寫錯這一格，② 就會被執行成 ①）**：

| | **D 鎖①** 末幀定格承接 | **D 鎖②** 換機位硬切 |
|---|---|---|
| 末 0.5 秒做什麼 | **收束窗**：運鏡趨緩、停大幅動作，並在末 1 秒前把景別**拉到落檔位** | **接口餘量**：**保留未收死的運動**，就停在"將要停住"的前一刻 |
| 末 1 秒 | **硬定格**（整秒凍結，剪輯時整秒剪除） | ⛔ **不寫定格**（寫了就變 ①） |
| 產出 | 可截幀的靜止尾幀 → 下段首幀參考 | 一條帶慣性的活尾巴 → 剪輯端接轉場 |
| 成本 | 剪掉 1 秒 + 人工截幀 + 下段首鏡壓同檔景別 | 0 |

**寫法（選 ② 時）**：

- **末鏡行尾**寫一句「只收勢、不凍住」，例：**「末 0.5 秒運鏡漸緩、人物保留餘勢，畫面不收死」**；
- ⛔ **禁寫**「末 1 秒定格 / 畫面定格 / 人物完全靜止 / 定格尾幀」——那是 ① 的措辭，混寫會讓模型按 ① 執行，**白丟 1 秒且截不出乾淨尾幀**；
- **餘量是剪輯吃的，不是模型吃的**：前段尾巴保持運動，**後段開頭**留 0.5 秒接轉場（疊化 / 閃白 / 遮擋 / 甩鏡），兩段各自不看對方的接口；
- 機檢口徑（★2026-10-18 修）：選 ② 的段**不應**出現末 1 秒定格描述（C11b 判的是①的寫法），出現即口徑混用，按 P3 自檢退回。**反向亦已修**——舊版 `硬切` 誤放在 C11b 定格詞表 `TAIL_FREEZE_WORDS` 裡，造成**雙向誤判**：②末鏡寫「硬切」→ 假 PASS（撞進定格詞表，其實沒定格）；②末鏡只寫「接口餘量」→ 假 FAIL（合法②稿被報警，逼執行者改寫①）。現已把「硬切」移出定格詞表、另立 `SEAM_MARGIN_WORDS`（接口餘量 / 硬切）作②豁免，四種情況（①寫定 / ①漏寫 / ②接口餘量 / ②含硬切）已端到端實測判對。

**為什麼是 0.5 秒**：短劇常規轉場時長——疊化 8~12 幀（0.33~0.5s）、閃白 6~10 幀（0.25~0.42s）、遮擋 10~15 幀（0.42~0.63s）、甩鏡 12~18 幀（0.5~0.75s）。**少於 0.5 秒轉場做不完整，多於 0.5 秒會被觀眾讀成「卡了一下」**，0.5 秒是所有手法的交集。

### 四·乙、段縫性質 → ①/② 分流表（★ 2026-10-17 新增 · 治「默認推薦被當成唯一正解」）

> 📌 **背景**：粉絲「森林」2026-10-17 反饋——「分組組成的投餵稿完全不用做接續動作，因為下一組的第一鏡已經是別的機位了，根本不會出現畫面斷層，放心食用」。
>
> **裁定**：這條**不是新規則，是 D 鎖② 的完整用法**——§四「禁同機位硬接」已經替他寫好了"為什麼不會斷層"（換機位 = 剪輯關係，不是斷層）。但它暴露一個真問題：**① 被寫成「默認推薦」，很容易被執行成「唯一正解」**，於是所有段縫都硬上三步（定格 → 截圖 → 同檔承接），在多機位劇情段裡純屬白做。
>
> **口徑**：① 仍是**默認值**（用戶不表態時按 ① 走，D 鎖選擇權不變）；但**按段縫性質可以也應該改走 ②**，**改走 ② 不需要額外理由**。

| 段縫性質 | 建議 | 理由 |
|---|---|---|
| **跨組長動作**（打戲連招 / 追逐 / 動作被拆段） | **① 末幀定格承接** | 動作要在縫上連續，末幀是唯一能接住姿態的東西 |
| **長對白跨組**（一句話被拆到兩組） | **①** | 口型與氣息要接，換機位會讀成"重說一遍" |
| **單鏡跟拍 / 一鏡到底被切** | **①** | 機位沒變，只能靠畫面接 |
| **劇情段劃分 + 組內多機位**（每組 3~5 鏡、組間本來就要換機位/換場/換時間） | **② 換機位硬切** | 觀眾讀到的是"剪輯"不是"斷層"；再上定格 = 白丟 1 秒 + 白截幀 + 白壓景別 |
| **組間有明確時間/空間跳躍** | **②** 或 **③ 空鏡過渡** | 跳躍本身就需要"斷開感" |
| **情緒段落收尾** | **③ 空鏡過渡** | 呼吸空間，硬切反顯急躁 |

- ⛔ **不要為了"保險"給劇情段上 ①**：末 1 秒會被剪掉、截圖要人工截、下段首鏡還被壓成同檔景別——**三份成本換一個觀眾看不見的接縫**。
- ⛔ **反過來也別為了省事把長動作段改 ②**：動作在縫上必斷，而且斷在動作中段比斷在段末更難看。
- **一條鐵律不變**：無論 ① 還是 ②，**段縫兩側必須換機位/換視角**（§四）——② 靠它成立，① 靠它避免"一個鏡頭被掐成兩截"。

### 四·補、段縫景別承接律（2026-10-11 新增 · 用戶實測反饋 · 當日二次確權）

> 📌 **病根**：§四 只要求「段縫兩側**至少換視角、換景別其一**」——於是「**末鏡拉全景收束 → 下段首鏡切中景**」可以合法通過。但實測觀感是：**剛拉開的空間又被糊回臉上**，景別突然收緊在觀眾端讀作"跳切"而不是"剪輯"。
>
> 🔑 **底層邏輯：尾幀參考不是"給個參考"，而是"給一個必須接住的畫面"（2026-10-11 二次確權 · 用戶口徑）**
> 段縫的畫面依據**不是重繪，而是上一段真實末幀的截圖**（§二 尾幀錨定法）——這張截圖會掛進下段的參考組，**2.5 首尾幀模式下它就是下一段的 `first_frame`**。
> **上一段尾幀是全景 → 下一段開場必然也是全景**——否則這張參考圖根本對不上畫面，"掛了等於沒掛"（用戶原話：「不然我拿來參考個毛線呀」）。
> 所以段縫景別**不是"可以換"，而是"必須同檔"**：上一段的**收束終點檔** = 下一段的**起手檔**。
> ⚠️ **同檔 ≠ 整段同檔**：約束只在「**上段末幀 ↔ 下段首幀**」這一對畫面——下段**段內**照樣可以推回中景/近景（那是 §七E 段內節奏的事）。**別把這條讀成"整段只能用一個景別"**。

**景別階梯（9 級 · 權威 = `sd-storyboard-engine/references/short-drama-camera-system.md` §一）**：

```
大遠景 → 遠景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特寫 → 大特寫
```

**五條硬規則**：

| # | 規則 | 說明 |
|---|---|---|
| **1** | **段落差 = 0 級（同檔 · 硬綁定）** | 段縫兩側**必須同檔**（中景接中景、全景接全景）——依據是**尾幀截圖即下段首幀參考圖，畫面必須逐檔咬合**。同檔不等於同鏡頭：靠**換視角 / 換機位高度 / 換軸線合法側**製造"兩個鏡頭"的剪輯關係，這**不違反** §四「禁同機位硬接」（那條禁的是"同景別**且**同視角"，不是禁同景別）。 |
| **2** | **末鏡做了「收束動作」的，禁任何反向收緊** | 末鏡行寫出「後拉 / 拉遠 / 拉開 / 拉出 / 退至 / 推近 … 至 {景別}」這類**明確落檔**的收束動作時，**下一段首鏡必須 = 該終點檔（0 級）**；反向收緊 **≥1 級**即不合格（這是用戶實測的病徵：末鏡拉全景收束，下段首鏡切中景）。 |
| **3** | **尾幀是首鏡的錨（以收束終點為準）** | **末鏡終點景別 = 下段首鏡起點景別**。末鏡行寫了「後拉/拉遠…至 {景別}」的，以**該終點景別**為準（**不是鏡行頭的起始景別**）；首鏡行寫了「從 {景別}…」的，以該起點景別為準。**收束動作須在末 1 秒之前的 0.5 秒收束窗內到位、硬定格（末 1 秒）開始前完成**——否則截出的尾幀不是穩定幀。 |
| **4** | **未做收束的段縫：落差 ≤ 1 級** | 末鏡景別穩定（無收束動作）時，段縫落差容忍到 **1 級（相鄰檔）**——給「過肩中景 → 全景揭示」這類**自然放寬**留口子；**≥2 級即跳切**。 |
| **5** | **豁免只有一條路：過渡手段** | 確需跳檔（爆點 / 轉場 / 時間跳）時，**必須在末鏡或首鏡行內寫出可見的過渡手段**——遮擋、甩鏡、運動模糊、疊化、黑場。**"遮擋過渡切 / 景別跳切"是 §四 段縫六式裡的正式招式，但它得靠畫面裡的過渡動作兌現**；只跳不給過渡 = 跳切。 |

**收束窗 = 段縫景別過渡的緩衝帶（用戶剪輯口徑 · 2026-10-12 修訂）**：

- 上一段**主體景別是 X**（如中景），**收束窗內拉到 Y**（如全景）——收束窗 = **末 1 秒之前的 0.5 秒**（15s 段即第 13.5 秒起）→ **尾幀 = Y**（末 1 秒整秒定格，取定格區任一幀即為 Y 檔）；
- 下一段**首幀 = Y**（承接尾幀參考），**段內**可自由推進回 X；
- **剪輯接點落在「末 1 秒定格區」的起點**（15s 段 ≈ 第 14s）——**這 0.5 秒的運鏡過程把景別變化吃掉**，觀眾看到的是"一次拉開"，而不是"一刀切的跳檔"；其後的整秒定格在剪輯時被剪除。

**尾幀參考必進參考組（硬要求，與 §二 §三 同源）**：

- **不是可選項**——下一段必須**實際掛上**上一段末幀截圖，掛法由 A 鎖版本決定：
  - **2.5 首尾幀模式**：末幀截圖直接作 `first_frame`；
  - **2.5 全能參考模式（默認）**：末幀截圖作參考圖組一員，登記時標註用途＝**鎖定接續姿態 / 站位 / 景別檔**；
  - **2.0**：無首尾幀——末幀截圖作**單參考圖**綁定形象（佔 M 軸參考圖名額，注意數量紅線）；正文內**禁寫**「首幀 / 尾幀 / 參考圖綁定」（C8）。
- **在《素材接線單》裡落位**：末幀截圖按 `圖SEAM-{段號}` 登記（用途列寫"段縫接續"）；**不入組 = 段縫畫面鎖失效**；
- **尾幀不合格時**：走 §二 三級處置（反向重設計 → 重繪 → 空鏡硬切），**但不得因此放棄景別承接**——重繪的參考圖同樣要按承接檔出。

**交付格式（P3 滿額鐵律 · 段縫兩側逐對標註）**：

```
段縫 {n}→{n+1}｜末鏡終點景別 {X} → 首鏡起點景別 {Y}｜落差 {0 = 合格 / ≥1 = 待辦} 級｜接縫式別 {§四 六式之一}｜尾幀參考 {圖SEAM-n ✅已入組 / ⛔豁免+理由}
```

**與 §七E 的分工**：**跨段**用本律（默認且必須 **0 級**；未做收束的最多 1 級）；**段內**鏡頭與鏡頭之間用 §七E 景別跳躍節奏（一級跳最自然、兩級跳用於情緒爆發點）。**不要把段內那句"兩級跳 = 強衝擊"借到段縫上**——段縫是兩段獨立生成的接縫，沒有段內那種動作/視線連續性兜底，跳了就是跳了。

> 🔧 **機檢兜底**：`validate_prompt.py` **C18m**（相鄰兩段「前段末鏡終點景別 → 後段首鏡起點景別」——**末鏡做了收束動作的要求同檔〔反向收緊 ≥1 級即報〕**、**未做收束的要求 ≤1 級〔≥2 級即報〕**，超出且兩側鏡行都無過渡手段 → WARN）。

### 四·補二、段縫人物進出場律（2026-10-13 新增 · 用戶實測反饋）

> 📌 **病根**：§二~§四·補 管的都是「**同一個人的位置/景別接不接得上**」（背景錨點鎖 = 人相對背景不動；景別承接律 = 畫面檔位咬合）。**但完全沒有一條規則管「人數變化」**——於是實測出現：**段1 場上只有大哥 + 二姐兩人 → 段2 開場直接四個人圍桌，另兩人憑空出現、零交代**。觀眾讀作"跳了一段"。（用戶原話：「段一到段二沒有任何邏輯的過渡，**它得有一個過渡吧**」。）

**適用**：相鄰兩段（段縫）之間，**後段的在場人物集合 ≠ 前段**（有人新增 / 有人消失 / 人數變化）時，**必須寫過渡交代**。

#### 判定：先取「人數賬」，再看差集

| 項 | 口徑 |
|---|---|
| 取誰 | 各段【核心人物】名單（含 `（在場）` 標記者） |
| 比什麼 | **後段新增（前段沒有的人）** + **前段有而後段消失的人**（消失走 §四「擺位必入畫」的 `段末離畫 / 退場·去向` 口徑） |
| 誰要寫 | **凡是「新增」的人，都必須在本段（或上段末鏡行句尾）有可見的進出場交代**；「消失」的人須在上段末鏡行句尾或本段寫明去向 |

#### 四種過渡寫法（按素材形態選）

| # | 寫法 | 落地要求 | 適用 |
|---|---|---|---|
| **①** | **畫內入畫** | 本段**前 1~2 秒**把「新面孔怎麼進來的」寫進鏡行——`自畫面外走入畫框` / `從裡屋跨門檻進來` / `從走廊門洞走進` / `推門而入`；帶**入畫方向**（自左 / 自右 / 自縱深） | 新人物**首次進入**該場景，同鏡頭能裝下時首選 |
| **②** | **畫外先聲** | 上段末鏡行句尾 或 本段首鏡行寫「**聲先入**」——`畫面外傳來 @某人 的 <腳步 / 推門 / 一句半截話>`，新人物**下一鏡才入畫** | 場景人多 / 窄、同鏡塞不下；J-cut（聲先過段、眼後過段），接縫感最低（= §五 用法②） |
| **③** | **空鏡轉場層** | 用 §五「用法③ 時空轉場空鏡」把兩段在**空間/時間上縫住**（走廊空鏡 / 門洞空鏡 / 堂屋外的電動車停住），新人物在空鏡後的首鏡已就位 | 兩段之間確有時間/空間跳（**本測試稿正屬此列**：段1 只兩人對峙 → 段2 全家人圍桌談判，中間隔著"母親從裡屋被扶出來坐定、三弟趕回來"這段過程） |
| **④** | **末鏡行句尾一句過渡** | 上段末鏡行的**句尾**（與末 1 秒凍結合為一句）寫一句起手預告——`門外傳來椅子拖地聲` / `腳步聲由遠及近`；**不得另起【接續狀態】欄**（該欄已整條廢止，見 §三） | 任何情況的最小兜底，成本一句 |

⚠️ **寫法②③的聲/畫口徑**：**聲先入的那一聲必須寫進該段【音效】行**（否則模型不生成）；②的入畫方向與①同源，**不得只寫"有人來了"**——要寫**誰、從哪、怎麼來**。

#### 與 §二/§三/§四 的關係（不替代，疊加）

- **與背景錨點鎖（§二）**：新人物入畫後**同樣要綁背景錨點**（身後是××），且其位置**不違反軸線**（同段軸線鎖定條約束）；
- **與景別承接律（§四·補）**：**兩律正交**——景別承接管「末幀↔首幀畫面檔位」，本律管「人從哪來」；**段縫兩側人數不同時，兩條一起過**（本測試稿段1→段2：景別要同檔 **且** 新面孔要有交代）；
- **與 §三【接續狀態】廢止**：本律**只允許寫進末鏡行句尾或段內鏡行**，**不恢復舊欄位**。

#### 📏 簡化寫法（軟口徑 · 默認 · 只出不入 / 只入不出的旁支）：

- **有台詞 / 有動作的具名新人物** → **硬性**必須有①~④之一；
- **僅為`（在場）`標記、無台詞無反應的背景人物**（如母親靜坐一角）→ **可用「時空空鏡 / 首鏡一句"已在場"交代」軟口徑**（`@她（… · 已於開場前坐定在被扶到的位置 · 身後是××）`），**不必單獨給入畫鏡**。

#### 🔧 機檢兜底

`validate_prompt.py` **C17e**（相鄰兩段【核心人物】名單比對：**後段出現前段沒有的新具名人物**，且該段**無①~④任一過渡類詞**〔入畫 / 走進 / 進門 / 跨門檻 / 推門 / 從外 / 聲先入 / 傳來 / 空鏡 / 轉場〕→ **WARN**，點到人名）。**WARN 參考級**——`（在場）`靜默人物與段間時間跳有天然誤報，人工複核；判「段縫合法」以本節四種寫法是否落地為準，不以 C17e 是否告警為準。

## 五、 空鏡過渡三用法

> 空鏡（無人物的場景鏡頭）不是缺陷，是**段縫呼吸工具**——`quality-gate-review.md` P2 攔的只是"無戲劇任務"的空鏡。三類正當用法：

### 用法① 情緒空鏡 + BGM（不搭人聲）
- 段末情緒落地後切 1~2s 環境空鏡（雨中的電動車 / 熄滅的灶台 / 關上的門），BGM 延續、**無任何 人聲/台詞/旁白**；
- 任務：給上一段情緒留髮酵空間（對齊 `wenxi-micro-expression.md` 金句後 0.3~0.8s 反應鏡的段間放大版）。

### 用法② 音效橋空鏡（搭聲音 · 聲先入）
- 空鏡畫面 + **下一段的聲音先入**（下一場的對白半句/腳步聲/開門聲先於畫面出現，J-cut 思路），或上一段關鍵音效延續（警笛由遠及近）；
- 任務：把兩段在聽覺上縫住——觀眾耳朵先過段，眼睛後過段，接縫感最低。

### 用法③ 時空轉場空鏡（搭聲不搭皆可）
- 日夜交替（夕陽空鏡→夜景空鏡）、地點切換（車站牌特寫→新場景全景）、時間流逝（日曆/鐘錶/四季元素）；
- 搭聲音：環境音疊化；不搭：硬切配 BGM 轉折。

### 限額與硬約束（防濫用回 P2 缺陷）
- **單集 ≤3 處、單處 1~2s**（段內空鏡佔時計入該段時長預算，不得超 C1）；
- 每個空鏡必須**寫得出現實畫面**（[鏡頭N] 景別 · 視角 · 運鏡 + 聲音 + 台詞：無），禁"氛圍空鏡一片"式懶寫；
- 空鏡**不得替代衝突**——該有攻防的戲切空鏡充數 = P1 結構缺陷，不是過渡。

## 六、 相鄰段邊界推薦表 + 5 種連續性模式

> **來源**：原 `sd-feed-engine/references/segment-continuity-strategy.md`，融 script-writing-studio 06-core-format 6.2/6.3。
> **定位**：§一~§五 定"**用哪種**段縫方式（D 鎖）"；本節定"**怎麼寫**"（投餵側的連續性模式選擇）。

### 〇 三層判斷（每次轉投餵前必做）

| 層 | 內容 | 是否默認 |
|---|---|---|
| **① 基礎銜接層** | 保留「下一段銜接」、高收益通用後綴、段末狀態 | ✅ 所有段落默認保留 |
| **② 相鄰段邊界推薦層** | 多段輸出時，先判斷相鄰段之間用什麼連續方案，**正式提示詞前給用戶一張簡短建議表** | ✅ 多段時必做 |
| **③ 強連續增強層** | 只有同場景連續、同場景隱含跳秒、切走後回到同一場景且狀態未變化、場景首現多人調度複雜時才疊加 | ⚠️ 按需 |

⚠️ **切換新場景後默認不繼承**上一場點位表、調度圖、場景角度圖和視頻延長邏輯。

### 一 相鄰段邊界推薦表（標準格式）

```markdown
| 邊界 | 場景關係 | 連續風險 | 推薦方案 | **段縫景別（末鏡終點 → 首鏡起點）** | 理由 |
|---|---|---|---|---|---|
| A → B | 同場景順延 / 同場景非順延 / 新場景首現 / 換場景 | 高 / 中 / 低 | 視頻延長 / 首幀圖+調度圖 / 只首幀圖 / 只調度圖 / 普通銜接 | 如「全景 → 全景（落差 0）」「中景 → 中全景（落差 1）」；**≥2 級須寫過渡手段** | ____ |
```

**推薦規則（6 條）**

| # | 情況 | 推薦方案 |
|---|---|---|
| 1 | **同場景順延**（B 是 A 的自然繼續，動作/鏡頭方向/光線/道具狀態都不重置） | **視頻延長** |
| 2 | **同場景複雜空間**（第 0 秒構圖、站位、內外關係容易穿幫） | **首幀圖 + 調度圖** |
| 3 | **只鎖起點**（風險在第 0 秒構圖/人物初始位置/道具位置，後續動作不複雜） | **只首幀圖** |
| 4 | **只鎖調度**（風險在走位/軸線/內外側/遮擋/攝影機安全區，第 0 秒不複雜） | **只調度圖** |
| 5 | **場景首現多人調度**（新場景首次出現且人物多、站位複雜） | **首幀圖 + 調度圖** |
| 6 | **換場景普通段** | **普通銜接**（不啟用上一場視頻延長/強連續空間/點位表/角度圖/調度圖） |
| 7 | **任意段（景別承接 · 硬性）** | 先定「**末鏡終點景別 → 下段首鏡起點景別**」：**默認且必須同檔（落差 0）**——尾幀截圖即下段首幀參考，畫面須咬合；**末鏡做了收束動作的，反向收緊 ≥1 級即扣**；**未做收束的最多容忍 1 級**（自然放寬），≥2 級即跳切；**豁免只有過渡手段一條路**（遮擋/甩鏡/運動模糊/疊化/黑場）。與本表 1~6 條**疊加**使用，不替代（§四·補） |

### 二 連續性與參考素材使用模式（5 種）

| 使用模式 | 適用情況 | 用上一段視頻/尾幀？ | 輸出重點 |
|---|---|---|---|
| **普通銜接模式** | 常規段落、跨場景、蒙太奇、普通連續段 | 否 | 正常寫可見轉接和段末狀態 |
| **獨立批量強連續模式** | 同場景強連續/回切強連續，但要批量生成，未上傳上一段視頻/尾幀 | 否 | 直接寫本視頻第一幀狀態、點位、正確限制和禁止錯誤點位 |
| **首幀增強模式** | 必須首幀或建議首幀，且已提供首幀圖 | 否 | 首幀圖只作第 0 秒參考；仍繼續寫動作過程、空間鎖定、光影、限制、段末狀態 |
| **調度增強模式** | 同場景多人走位、場景首現多人調度、軸線/遮擋風險高 | 否 | 寫清調度圖用途、人物點位、移動路線、攝影機安全區、禁止錯誤站位 |
| **視頻延長強連續模式** | 同場景順延，下一段是上一段動作和鏡頭的自然繼續 | **是** | 純淨提示詞最前面寫視頻延長啟動句，再接對應結構 |

**選擇規則（7 條）**

```
1. 默認走"普通銜接模式"；用戶明確要求完整字段或高精度控制時才用詳細版
2. 同場景順延、A→B 像繼續拍 → 優先"視頻延長強連續模式"
3. 同場景強連續但不適合視頻延長，或需批量獨立生成 → "獨立批量強連續模式"
4. 必須/建議首幀且已有首幀圖 → "首幀增強模式"
5. 多人走位、軸線、內外側、遮擋、攝影機安全區是主要風險 → "調度增強模式"
6. 場景首次出現且人物很多、站位複雜 → 建議"首幀增強 + 調度增強"
7. 換場景後默認回到普通銜接，不沿用上一場強連續邏輯
```

### 三 視頻延長啟動句（固定寫法）

同場景順延優先建議視頻延長。**純淨提示詞最前面寫固定啟動句**：

```
使用 視頻1 作為上一段成片視頻，只從上一段末尾繼續自然延長 X 秒，接入本段動作。
不重置角色身份、服裝、髮型、場景空間、光線方向、鏡頭方向和道具狀態。
```

後面繼續保留對應的提示詞主體結構。

### 四 獨立批量強連續的硬要求

如果是同場景強連續/回切強連續，但**沒有使用視頻延長**，純淨提示詞**必須直接寫"本視頻第一幀狀態"**：

```
❌ 禁止依賴上下文：
  "承接 B01" / "上一段" / "仍然" / "繼續" / "同一客廳"

✅ 必須直寫：
  本視頻第一幀狀態：<具體描述人物位置、姿態、道具狀態、光線方向、攝影機位置>
```

### 五 尾幀延續（增強選項 · 非默認）

**只在用戶實際上傳上一段視頻/末幀/首尾幀參考時**才使用：

```
"從 視頻1 末幀繼續" / "使用 圖1 作為首幀"
```

⚠️ **不要把尾幀當成默認流程**（默認流程見 §二 尾幀錨定法）。

# 第二部分 · 段內銜接（鏡頭與鏡頭之間）

> **來源**：原 `sd-storyboard-engine/references/segment-linkage.md`，融 script-writing-studio 04-field-methods 第 11/12 節。
> **適用範圍**：約束**同一大分鏡內部相鄰鏡頭間的銜接**（段內）。跨大分鏡銜接（段間）見第一部分。
> **核心原則**：銜接 = 讓相鄰兩鏡在視覺/動作/空間上"接得上"。**銜接錯亂 = 觀眾出戲。**

## 七、 五大銜接維度（段內 · 必過）

### A. 空間連貫性（180° 軸線規則）

兩人對話場景中，**攝影機不能跨過兩人之間的假想軸線**。

```
   A ─────●───── B
            ↑
       這條線 = 軸線

   ✅ 攝影機在線的同一側切換（無論怎麼換景別/角度）
   ❌ 跨到另一側 → 觀眾感覺"兩人換位置了"
```

**例外**：儀式性越軸（如 A 起身追到 B 身後，鏡頭跟著越過去）允許。

### B. 視線匹配（Eyeline Match）

```
✅ A 看畫面右 → B 從畫面左入畫 + 視線看左（與 A 對望）
❌ A 看右 → B 從右入畫 + 看右（變成兩人都看同一側）
```

### C. 動作銜接（Match Cut on Action）

**A 鏡末尾的動作 = B 鏡開頭動作的延續 60-80%。**

```
✅ A 鏡：抬手到嘴前 → B 鏡（切長焦特寫）：手已經在嘴前
❌ A 鏡：抬手到嘴前 → B 鏡：手已經放下了（動作跳躍）
```

### D. 道具/物件狀態連貫

```
✅ A 鏡：杯裡有半杯奶茶 → B 鏡：杯裡仍是半杯（即使換角度）
✅ A 鏡：煙燃了一半 → B 鏡（幾秒後）：煙應短一些，菸灰應長一些
❌ A 鏡：杯子在桌上 → B 鏡：杯子在角色手裡（無中間動作）
```

⚠️ **AI 視頻模型最容易在此處出錯**，必須用「限制」字段強制約束：
```
限制：杯中奶茶量保持半杯，與上一鏡一致
限制：菸頭長度比上一鏡短 1cm，菸灰更長
限制：角色服裝/髮型/位置與上一鏡完全一致
```

### D2. 小道具朝向鎖定（手機/照片/證件等）

AI 模型經常把手機、照片、證件、信封等**自動轉成"正面朝鏡頭"**，甚至把手機背面也生成成屏幕。凡道具有正反面/信息面/穿幫面，**必須寫清朝向**。

```
✅ 限制：手機背面朝鏡頭，黑色玻璃背板和斜排雙攝可見；屏幕正面朝向角色手心，不可見。
✅ 限制：手機屏幕正面朝鏡頭，只允許顯示指定微信 UI；背面不可見。
✅ 限制：照片正面貼在桌面上不可見，觀眾只看到照片背面。
❌ 手機在角色手裡，但沒寫朝向（模型常自動把屏幕懟給鏡頭）
❌ 手機背面出現發光屏幕、微信氣泡或隨機文字
```

**手機類道具必寫**：
- 正面 = 屏幕面；背面 = 攝像頭/玻璃背板面。
- 劇情不需要看屏幕時 → 優先讓**屏幕朝向手心/桌面/身體**。
- 劇情需要看 UI 時 → 必須明確"屏幕正面朝鏡頭"+ 寫清只允許出現哪些中文 UI/數字/圖標。
- 限制字段必須禁止：手機背面變屏幕、正反面同時是屏幕、隨機 UI、隨機文字。

### D3. 道具單實例鎖

如果關鍵道具**已出現在場景母版/角度圖/首幀圖**裡，同時資產庫又提供了**同一件道具的參考圖**，分鏡必須當作"同一個物體實例"，**不要讓下游誤寫成新增道具**。

必寫：
- 參考圖對應畫面裡哪一件可見道具
- 本段/全片只允許出現幾個
- 參考圖只用於外觀/材質/顏色/屏幕狀態，**不新增第二件**
- 若角色拿起/放下/移動該道具，**原位置和手中狀態必須互斥**

```
限制：圖4 碎屏手機就是首幀中桌面右下角那一部手機，本段只允許出現這一部；
圖4 只補裂紋和機身外觀，不新增第二部手機。角色拿起手機後，桌面原位置必須變為空，
不得桌上和手裡同時各有一部手機。
```

### E. 景別跳躍節奏

| 跳躍幅度 | 效果 | 適用情境 |
|---|---|---|
| 同景別切同景別 | 跳切感（jump cut） | 慎用 / 用於焦慮感 |
| 一級跳（中→近 / 近→特） | 最自然 | 默認推薦 |
| 兩級跳（全→近 / 近→大特） | 強衝擊感 | 情緒爆發點 |
| 三級跳（遠→特） | 極強衝擊 | 關鍵情緒命中 |
| 反向跳（近→全） | 抽離感 / 沉澱 | 情緒餘韻 |

⚠️ **紅線：不要連續 3 鏡以上同景別**——觀眾會感覺"攝影機懶"。

> ⚠️ **本節只管「段內」（同一投餵單元內部的相鄰鏡頭）**；**跨段（段與段之間）的景別落差走 §四·補「段縫景別承接律」——跨段默認且必須 0 級（同檔），比段內更嚴**（段縫是兩段獨立生成的接縫，沒有段內那種動作/視線連續性兜底；且尾幀截圖就是下段首幀參考圖，對不上就是沒接上）。

## 八、 銜接錯誤自查清單（生成完每個大分鏡後內部過）

```
□ 是否跨過 180° 軸線（除非有意越軸）
□ 視線方向是否互相匹配
□ 上一鏡末尾動作 + 下一鏡開頭動作能否 60-80% 重合
□ 物件狀態是否延續（必要時加"限制"字段約束 AI）
□ 手機/照片/證件等小道具朝向是否寫清
□ 場景/首幀已有道具 + 參考圖同時存在時，是否啟用道具單實例鎖
□ 連續 3 鏡是否同景別
□ 角色服裝/髮型/位置是否突變（AI 易錯）
□ 公共空間是否判斷人群密度；如啟用人群，是否寫清前/中/遠景人數、類型、移動和遮擋規則
□ 私密空間或無路人需求段落，是否在限制裡禁止額外人物、路人、群演
```

## 九、 運鏡銜接五大模式

> 運鏡銜接 = 決定"剪輯節奏"和"情緒流向"。不僅是"一個鏡頭怎麼動"，**更是"兩個鏡頭之間能量如何傳遞"**。

### A. 同向銜接（能量持續）

```
B01-S01：緩慢推鏡 → B01-S02：繼續推鏡（切換景別但不停止能量）
效果：觀眾感覺"我們正在不可阻擋地接近某個東西"
適用：揭示真相 / 情感升溫 / 恐懼累積
```

### B. 反向銜接（心理張力）

```
B01-S01：推向角色面部特寫 → B01-S02：從角色背後拉出大全景
效果：情緒"被推近"再"被拉離" → 抽離/孤獨感
適用：決斷後的孤獨 / 高潮後的餘韻
```

### C. 靜切動（情緒激發）

```
B01-S01：固定·面部特寫（角色凝視）→ B01-S02：手持呼吸感·全景（角色突然起身）
效果：情緒從"凝固"被"激活"
適用：決斷瞬間 / 轉折點
```

### D. 動切靜（情緒沉澱）

```
B01-S01：手持快搖 → B01-S02：固定·物件特寫（被丟下的物件）
效果：情緒從"混亂"被"凝固"
適用：戲劇動作完成後的靜默 / 餘味
```

### E. 同質運鏡疊加（風格強化）

| 運鏡組合 | 風格效果 |
|---|---|
| 多個手持呼吸感 | 焦慮/紀錄片感（《黑天鵝》《夜行者》風格） |
| 多個長鏡頭 | 沉浸感（侯孝賢/小津風格） |
| 多個快切 | 節奏暴烈（《疾速追殺》/抖音爽劇） |
| 多個固定鏡頭 | 儀式感/剋制（侯麥、《花樣年華》部分） |
| 推 + 拉 + 推 + 拉 | 心理博弈感（希區柯克對話戲） |

## 十、 運鏡銜接紅線

```
❌ 三個連續手持呼吸感 + 第四個突然變固定（除非戲劇動作要求）
❌ 搖 + 推 + 拉 + 升 + 搖（一段戲內運鏡方式過多 = 風格混亂）
❌ 大角度運鏡（如滑動變焦）連續使用 ≥ 2 次（炫技感）
❌ 每個鏡頭都運動 + 每個鏡頭都不一樣（觀眾會暈）
❌ 同向銜接超過 4 鏡（能量過載，觀眾疲勞）
```

## 十一、 一段戲的運鏡節奏建議

```
開場鏡頭：固定 / 緩慢運鏡（建立空間）
中段鏡頭：動 + 靜交替（推進情緒）
情緒命中鏡頭：可啟用大幅運鏡（滑動變焦 / 環繞）
收尾鏡頭：靜止 / 反向運鏡（沉澱）
```

## 十二、 風格選擇需服從劇本氣質

**不是"挑一種風格用到底"，而是劇本氣質決定運鏡組合**：

| 劇本氣質 | 推薦運鏡組合 |
|---|---|
| 冷靜剋制（如茶餐廳戲） | 固定為主 + 少量手持呼吸感 + 1-2 個反向銜接 |
| 緊張焦慮（追逐/逃亡） | 大量手持呼吸感 + 快切 + 靜切動 |
| 浪漫夢幻（愛情/回憶） | 長鏡頭滑軌 + 同向銜接 + 慢速推/拉 |
| 暴力對抗（打鬥/槍戰） | 快切 + 慢動作 + 同質疊加（密集快切） |
| 懸疑揭示 | 同向推進 + 突然反向拉遠（揭示瞬間） |
