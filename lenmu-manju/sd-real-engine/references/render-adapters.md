## 一、 時長預算協議

1. **單組時長**：**按總控模型契約表執行**（`model-adapters.md` §5：2.5 默認 25~30s / 2.0 上限 15s；下限 12s、禁 16~24s 碎段區）——⚠️ **本節不再寫「推薦每組 ≤15s」**，該值僅適用 2.0；單鏡 3~5 秒、一組 3~4 鏡為節奏參考。**打戲例外條款**：快節奏打鬥/單段信息量小時允許下探至下限 12s（見 `model-adapters.md` §5 鐵律）；
2. **2.0 時長鐵律**：2.0 單段上限 15s，**不是 10s 也不是固定值**——按劇情內容量倒推（台詞 3.5~5 字/s + 動作節拍），禁卡 10s、禁全片統一段長、禁"段長÷鏡數"機械等分；
3. **時長前置預算**：`目標組數 = 預估成片總時長 ÷ 模型契約表對應單組時長`（2.5 按 25~30s/組 → 180s 約 6~8 組；2.0 按 ≤15s/組 → 180s 約 12~15 組）；
4. **單組即成品**：每組自帶時間軸（00:00 起）、畫幅風格、資產短錨點、分鏡詳情與負面詞，整組複製即投餵；
5. **長段**：15s 以上必須用官方 `[起-止秒]` 時間戳分段且一鏡連貫運鏡過渡（模型不支持組內硬切）。

> ★ **段7 極簡口徑（2026-10-13）**：默認只寫上面四項。舊長清單（角色變形 / 手部異常 / 慢動作升格 / 分身…）已廢——按 §5.0.4「禁令失效三改法」，被禁詞根本身就是畫面詞，長清單等於給模型遞畫面詞表。打戲段若確有某類穿幫史（如多人場面分身高發），最多**按需追加 1~2 條**並在交付說明寫理由（權威見 `short-drama-director/references/model-adapters.md` §5）。

### 鏡行書寫規則（硬約束）
- 鏡行格式：`00:00-00:05 [鏡頭N] 景別 · 視角角度 · 運鏡。動作描述。聲音：…。台詞：…。`；
- **每鏡行尾必帶行內 `聲音：` 與 `台詞：`**（無台詞寫"台詞：無。"）；
- 鏡行**不寫"跟隨@誰"**（跟隨目標融進動作描述，如"鏡頭隨其位移橫移"）；
- 動畫中帶神態：`他甩棍轉身的瞬間冷笑，棍梢帶出一道風聲`（神態掛動作上，禁獨立靜止特寫）；
- **段末定格（取代原接續狀態尾行，2026-10-09 · 時長 2026-10-12 用戶裁定為「末 1 秒整秒硬定格」）**：每段末鏡行內寫 `第 13.5 秒起運動收束、末 1 秒全體人物保持姿態與站位、動作完全靜止、畫面定格`（**人物全部在場、無遮擋、無字幕壓屏**，確保末幀可截；末鏡景別禁大遠景）；**末 1 秒在剪輯時整秒剪除**（餘下末幀即定格幀）；終段按 R1 寫 `勝負收勢/懸念收尾（定鏡收束）`。
  > ⚠️ **本條僅 D鎖①末幀定格承接適用（2026-10-18 補 · 粉絲實測踩坑）**：本段若選 **D鎖②換機位硬切**，**本條整條不寫**——②法定不寫末 1 秒定格，末鏡改寫 `接口餘量 0.5 秒：保留未收死的運動，供剪輯吃轉場`。機檢 `C11b` 已按②豁免（末鏡含「接口餘量 / 硬切」即不報），**不會因為沒寫定格而報警**。①/② 選哪條見總控 `short-drama-director/references/segment-splicing.md` §四·乙 分流表。

### 站位聲明（一行式 · 每段必寫）
- 四要素（每人一段括號）：位置（畫面左/右/中）+ 依託物（空間錨點）+ 朝向 + 姿態；
- 軸線行：多鏡同場景必寫 `左A右B`（或對調後全段保持），聲明後全段禁越軸；
- 位移行：逐人寫 `起點→終點`，每步有動作原因（攻擊/閃避/擊退），**禁瞬移**；
- 靜態段寫 `全員原位，無位移`；
- **禁畫圖**：禁 V3 俯視 ASCII 空間圖/座標表/初始圖+位移因果鏈（太複雜模型理解不了）。
- **多人同場（2~4 人）升級為三行制**（主軸行 + 從軸行 + 全員動態行），格式與範例見 `multi-opponent-rules.md` §八；1v1 場景仍用本節一行式。

## 四、 音效與聲音排布（2.5 / 2.0 分版）

### Seedance 2.5（官方字符）
- 音效 `<>` 疊在時間軸對應秒段，必須具體，禁"震撼音效"；
- R1 可用音效詞庫（寫實向）：

| 場景 | 可投餵音效 |
|---|---|
| 破空拳/掃腿 | `<Air-cut Whoosh 重型破空呼嘯>` |
| 拳腳命中 | `<Impact Thud 沉重受擊悶響>` / `<Bone Snap 骨骼受力脆響>` |
| 格擋/架招 | `<Block Clash 格擋碰撞悶響>` |
| 近身纏鬥 | `<Scuffle Grunt 纏鬥喘息悶哼>` |
| 環境破壞 | `<Shatter 玻璃碎裂>` / `<Crack 地面龜裂>` / `<Rubble 碎石滾落>` |
| 摔投 | `<Body Slam 重物砸地悶響>` |
| 追逐腳步 | `<Running Footsteps 急促腳步>` |

- **聲音事件時間線**：音效按事件排時間線序列，每個動作事件對應一個音效事件：`拔刀鳴（0.5s）→ 破空呼嘯（1.2s）→ 交擊爆鳴（2.0s）→ 衝擊爆破（2.5s）`；
- **空間縱深音**：遠層事件用低頻悶響+混響，近層用高頻脆響+乾聲；
- **死寂轉餘響**：絕殺命中後先留 0.3~0.5s 死寂，再放環境餘響（碎石滾落/風聲/耳鳴），比全程轟鳴更有打擊重量。

### Seedance 2.0（文字描述 · 默認視頻內出）
- 音效/台詞以文字描述寫入鏡行 `聲音：`/`台詞：`，**默認由模型生成**；
- 禁 `[SFX:]` 標記、禁頓挫詞；
- 台詞文本寫入台詞欄鎖口型節奏；僅用戶明確指定"不出台詞"才寫後期配音說明。

## 五、 資產錨點規則（@CHR/@SCN）

- 使用 `@CHR_name` / `@SCN_name` 明確對應資產圖，**嚴禁無主代詞**（"他/她/神秘人"）；
- 多參考圖（角色+服裝+場景混投）必須**逐實體**寫綁定：`嚴格保持 @CHR-A 的臉型與髮型（參考圖1），只改變服裝為……（參考圖2）`；
- **真人臉紅線（官方硬約束）**：參考圖嚴禁含真人人臉，一律動漫/CG/繪畫風格；
- **素材標註用途**：每份參考素材標註（鎖定外貌/動作/音色/運鏡），禁只丟圖不說明；
- **2.0 參考圖僅鎖定形象**：禁投 `first_frame`/`last_frame`，禁寫首尾幀相關。

### S5 機檢清單（出稿前逐項過）
1. **字數門禁（分鏡段粒度 · R1 檔內）**：**只計【時間軸分鏡】段正文**的中文 ≤500 字/組，不含另六個模板段——**本條是「分鏡段正文」這一粒度的唯一真源**。⚠️ 它與總控閘門3 的**整單元**口徑並存、不衝突：閘門3 計七段合計（2.0 ≤2900 / 3000 硬上限；2.5 ≤3600 / 4000 硬上限），本條只管鏡行本身的信息密度；兩者都超時，先按本條壓鏡行描述，再按閘門3 壓管理話術。來源：Seedance 官方指南建議提示詞 ≤500 中文字 / 1000 英文詞（**官方建議值，非平台硬字段上限**，各入口字段上限實測在 800~2500 字符量級），動機是文本過長會分散模型注意力致元素丟失。參考區間（貼門禁線）：4 鏡稿 320~480 字、5 鏡稿 400~500 字；超限時**壓縮描述而非刪鏡**，因果鏈不斷；
2. **時長**：**按總控模型契約表**（`model-adapters.md` §5）——2.5 默認 25~30s、2.0 ≤15s；本行不再另寫死值；
3. **版本語法**：2.0 無 `[SFX:]`/頓挫詞/首尾幀；2.5 用官方字符；
4. **畫幅一致性**：所有鏡行/構圖詞與鎖定畫幅一致（16:9 禁"垂直安全區/上下疊壓"豎屏詞，9:16 禁橫屏構圖詞）；
5. **七段式完整**：七段齊 + 每鏡行尾帶聲音/台詞（**段末無接續尾行**，2026-10-09 廢止；末幀定格寫在末鏡行內）；
6. **站位聲明**：四要素+軸線+位移行齊全，禁 ASCII 圖；
7. **鏡長節奏（C13）**：同段 ≥4 鏡且同值鏡長佔比 ≥70% → 重排鏡長（快慢呼吸交替，覆蓋 ≥3 個取值）；
8. **高壓詞掃描**：無"對峙/蓄勢/懸停/站立靜止"類靜止段、無抽象打鬥詞、無特效詞（光波/衝擊波/法陣）、無直白血腥詞（對照 impact-physics.md §五 詞典）。
9. **多人增項**（同場 ≥2 人時疊加）：同鏡交手 ≤3 人、特寫 <3 人、無「站等」角色、主角每鏡在場、主軸唯一、每人 ≥2 項外形差異、分身負面詞已寫入 —— 細則見 `multi-opponent-rules.md` §十。
