# 打鬥鏡頭規格與空間鐵律 (Camera & Action Specs) · ★權威總控

> 鏡頭是打鬥的骨架。每個鏡頭必須把 5 維參數想清楚（設計檢查表），落到鏡行時只寫三要素 + 動作 + 聲音/台詞。本文件含空間鐵律、景別階梯、機位-動作語義綁定、三手法六式銜接。

---

## 一、 鏡頭規格五要素（設計檢查表 · 每次鏡必想）

$$\text{格式}：[\text{景別}] · [\text{拍攝視角}+\text{角度}] · [\text{運鏡方式}] · [\text{跟隨目標}]$$

| 要素 | 標準選項 | 正確寫法示例 |
|---|---|---|
| ① 景別 | 特寫 / 近景 / 中近景 / 中景 / 全景 | `近景` / `中景` |
| ② 拍攝視角 | 正面(0°) / 側面(90°) / 斜角(30°-60°) / 俯拍 / 仰拍 | `45°斜側` / `正面0°` / `30°仰視` |
| ③ 角度 | 平視 / 仰視(N°) / 俯視(N°) | `平視` / `30°仰視` |
| ④ 運鏡方式 | 跟拍跟鏡 / 急速推鏡 / 急速拉鏡 / 甩鏡閃切 / 升降運鏡 / 環移(≤180°) / 定鏡收束 | `急速推鏡` / `跟拍跟鏡` |
| ⑤ 跟隨目標 | 角色、肢體或具體接觸點 | `跟隨右拳推進至心口接觸點` |

> ⚠️ **鏡行書寫口徑（落稿只寫三要素）**：五要素是**設計檢查表**；落到【時間軸分鏡】鏡行時只寫 `[鏡頭N] 景別 · 視角角度 · 運鏡。動作描述。聲音：…。台詞：…。`——不寫"跟隨@誰"（跟隨目標作為運鏡策略自然融進動作描述，如"鏡頭隨其位移橫移"），不用括號五要素連寫的外部變體。

## 二、 空間感兩大鐵律

1. **中景/全景禁 90° 側面正拍**：中景及全景（看到雙人全身或大半身）**嚴禁 90° 側面正拍**（街機橫版廉價感）。必須 30°~60° 斜角拍攝，借前後人物遮擋與背景縱深製造對決壓迫感。
   - **唯一例外**：近景/特寫（胸部以上或手部細節對招）允許 90° 側拍。
   - **多人同場注**：中景/全景改為「主角 + 當前對手 + 一人作前景遮擋」的 30°~60° 斜角分層構圖；**特寫禁 ≥3 人同焦**（臉崩 / 分身高發）。見 `multi-opponent-rules.md` §六。
2. **景別與動作幅度絕對匹配**：
   - 大幅動作（騰空/大步崩拳/飛踢/過肩摔/翻滾位移）→ 必須配 **全景/中景**，展現舒展身形與空間位移；
   - 小幅動作（短橋寸勁/指探面門/卸力擒拿/肘擊）→ 必須配 **近景/特寫**，放大擊打密度與受力細節。

## 三、 雙畫幅構圖（B 鎖鎖定後按此執行）

### 16:9 橫屏
- 中長焦空間縱深與環境壓迫；雙人對立位三分線站位；攻防推進沿對角線動勢；
- 騰空橫飛/撞牆橫飛/貼地滑行等橫向軌跡優先展示；
- 重擊用廣角+低仰，橫向軌跡橫掃、左右對稱構圖（R1 只寫真實受力反饋與環境破壞，不寫氣效）。

### 9:16 豎屏
- 垂直高度落差：騰空下劈、貼地滑行、跳起下砸、衝鏡特寫；
- 前後景疊壓（前景遮擋製造壓迫）；俯仰角對立位；
- 位移展示縱向優先（下劈/貼地/上衝）。

### 21:9 寬幕
- 橫向展開最大化，雙人長距離對沖/追逐戲優先；
- 參考 16:9 構圖法則，強化左右端縱深。

> 畫幅細則路由：使用上游 `short-drama-director/references/aspect-ratio-adaptation.md` 對應畫幅章節（同款規則可複用）。

## 四、 景別階梯躍遷（防平鋪重複）

連續鏡頭景別/機位嚴禁平鋪重複，按階梯躍遷製造視覺推進感：

$$\text{標準階梯} = \text{極微距特寫（發力微觀）} \to \text{超廣角/低角度中景（攻防位移）} \to \text{宏觀全景（環境破壞）} \to \text{鳥瞰/過肩收鏡}$$

1. **嚴禁連續兩個鏡頭使用相同景別+相同機位**；
2. **動作高潮前插入極微距特寫**（指尖發力/肌肉繃緊/眼神聚焦），淺景深虛化背景；
3. **重擊/終結技用宏觀全景**展示環境破壞（牆面崩裂/桌椅掀飛/塵土揚起）；
4. **收尾用鳥瞰或過肩收鏡**，配合煙塵/落葉遮擋轉場（Occlusion Wipe）。

### Eye-Trace 視線流
- 相鄰鏡頭的主體高光/視覺焦點保持在屏幕**同一象限**或沿動勢方向連續過渡；
- 例：鏡頭1 右側出拳 → 鏡頭2 自右向左的受力者，避免觀眾視線滿屏搜索。

## 五、 機位-動作語義綁定表（先定動作語義，再定機位）

> ⚠️ 鐵律：**機位不是隨便選的，必須與發力方向/受力點/體量綁定**。先問"這個動作的語義是什麼"，再查表選機位；嚴禁機位與動作語義錯配。

| 動作語義 | 機位選擇 | 為什麼對 |
|---|---|---|
| 貼地橫掃 | 低機位貼地跟拍 | 看到腿/武器水平切過，高度差製造切割感 |
| 重拳砸地/砸牆 | 大仰角中景 | 體量壓迫感拉滿 |
| 側閃/繞背 | FPV 第一人稱跟隨或過肩 | 代入感最強，看穿動作軌跡 |
| 升空/跳起 | 俯拍起跳 → 仰拍升空 | 先壓後升，力學過程可見 |
| 摔投貫地 | 低機位全景側拍（30-45°） | 完整看到被摔者弧線舒展 |
| 近身纏鬥 | 肩後過肩鏡頭 | 看兩人重心的撕扯 |
| 挑釁/神態 | 特寫淺景深 | 表情記憶點（必須掛動作上，禁靜止） |
| 環境破壞 | 中景快速拉遠 | 破壞結果整體呈現 |

## 六、 受擊鏡頭工具箱（捱打方怎麼拍）

> 受擊不是"被打飛"三個字了事。按受擊強度選用，讓捱打方也有鏡頭語言：

- **短促徑向震動**：命中瞬間鏡頭沿受力方向短促震一下（1~2 幀），模擬受力衝擊傳遞到攝影機；
- **輕微軸向受力**：鏡頭隨受擊方向小幅偏轉/傾斜，傳遞"攝影機也被波及"的重量感；
- **瞬時焦點變化**：受擊瞬間焦點從攻方急切到受擊方面部（痛苦細節），或隨擊飛目標快速轉移；
- **動態模糊與速度匹配**：擊飛/震退段加徑向動態模糊，模糊方向與位移方向嚴格匹配，禁全屏均勻模糊；
- **Time Ramp 變速**：僅限極短受擊瞬間（命中幀前後 0.2s 內加速/減速切換），禁整段升格慢鏡。

## 七、 三手法六式鏡頭銜接（多鏡剪輯階段）

### 三手法
1. **換機位**：改變拍攝角度與視角，保持主體動作連續；
2. **切景別**：特寫切中景，中景切全景，由微觀入宏觀；
3. **跨段反應**：攻擊擊出瞬間切受擊方防禦或受創表情。

### 六式
- ① 動作連續切（揮招前半段切命中後半段）；
- ② 反應鏡頭切（攻方重擊切守方瞳孔驟縮/咬牙/咳血）；
- ③ 景別跳切（長距離突進由全景跳入近景）；
- ④ 視線引導切（主角轉頭看向右側，順視線切右側出現的威脅）；
- ⑤ 遮擋過渡切（前景立柱/人影掠過遮擋瞬間完成場景切換）；
- ⑥ 動勢匹配切（上一鏡向右翻滾，下一鏡向右滑步衝拳）。

## 八、 組內過渡鐵律（視頻模型硬約束）

- 視頻模型**一鏡生成、不支持硬剪輯切換鏡頭**：一組內的 3~4 鏡必須寫成連續運鏡銜接（推/拉/搖/移/穿透/遮擋過渡）；
- 真硬切必須拆成**多段獨立生成**、後期剪輯拼接（每段單獨投餵）；
- 一鏡長鏡頭（ONER）：整段只寫一條運鏡軌跡，機位變化寫成"鏡頭隨動作自然運動"（貼地→抬升→環繞→拉遠），禁止寫分鏡號；動作放在同一條軌跡上展開。
