# 防守三態與閃避大幅化 (Defense 3-States & Evasion) · ★權威總控

> 打鬥的"好看"一半在捱打方。防守方被破防後必須經歷真實的失衡過渡過程，**嚴禁被重擊後下一幀立刻原地滿血架防**。閃避必須大幅化——小幅微移在畫面上等於沒動。

---

## 一、 防守三態潰敗鏈條

```text
┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
│  1. 完整態 (Full) │ ───>  │ 2. 崩防線 (Break) │ ───>  │ 3. 過渡態 (Mess)  │
│ 樁步穩固,架橋封門 │       │ 招式被破,雙臂彈開 │       │ 狼狽側閃,零碎抵抗 │
└──────────────────┘       └──────────────────┘       └──────────────────┘
```

### 1. 完整態 (Full Defense)
樁步穩固，雙臂架橋護頭護胸，姿態從容。**此態最長 1.5~2s**，隨即必須進入變化（模型無法長時間保持姿態）。

### 2. 崩防線 (Break Line) · 0.3~0.5s
被重拳/掃腿直接震散格擋：雙臂向兩側彈開，中線與要害徹底大開。
- 寫法：`重拳砸在格擋雙臂上，雙臂被震得向兩側彈開，中路門戶大開`。

### 3. 過渡態 (Messy Transition) · 0.5~1s
來不及重新架防，只能靠狼狽本能零碎抗爭：
- 狼狽極低下潛 / 鐵板橋大後仰彎腰 / 單臂倉促向外亂拍 / 碎步踉蹌後撤。

> ⚠️ 寫防守潰敗時，**三態必須連續發生**，禁"破防後立刻復原"。

## 二、 閃避大幅化法則

**嚴禁小幅平移**：禁止寫"微微側身一讓""輕輕偏頭""稍稍後退"。

必須是大幅度肉體運動：

| 閃避方式 | 寫法要點 | 視覺特徵 |
|---|---|---|
| **極低位下潛** | 身形驟降貼地 | 重拳擦著頭皮削過，削斷髮絲/帽簷 |
| **鐵板橋大後仰** | 腰身向後摺疊 ≥45° | 腿風自面門上方兩指處呼嘯而過 |
| **側空翻/360°旋轉跳開** | 閃避即位移 | 閃避+換位一步完成，落地即蓄力 |
| **大步滑移/滑步** | 大幅橫向/斜向位移 | 重心低、幅度大，瞬間拉開距離 |
| **貼地滑鏟** | 下盤突破/避險 | 從腿間滑過或滑至側後 |

**閃避即位移、位移即蓄力**：閃避落地的瞬間身體已進入下一招的起手（借勢反擊/拉開距離），禁止"閃開→站定→再出手"。

## 三、 防守方零碎抵抗寫法（過渡態彈藥庫）

- 單臂倉促拍開：`守方單臂斜拍，勉強改變拳路方向，拳鋒擦耳而過`；
- 縮身下潛：`守方縮身下潛，攻方重拳自頭頂呼嘯而過`；
- 碎步後撤：`守方碎步連連後撤，腳下踉蹌，險些絆倒`；
- 本能格擋：`守方雙臂胡亂格擋，每擋一下都被震退半步`。
