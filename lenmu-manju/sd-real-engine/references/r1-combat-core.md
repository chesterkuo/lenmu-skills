## 一、 R1 寫實剋制檔定位

| 項 | R1 寫實剋制（唯一檔位） |
|---|---|
| 適用題材 | 寫實格鬥、警匪追逐、懸疑暗殺、喜劇打鬥、兒童向打鬥 |
| 動作美學 | 「輕≠弱，輕=快而重」；以真實受力反饋為先，特效讓位於物理 |
| 開局硬撞 | **不強制**，1.5s 內發生攻防接觸即可（第一幀建議雙人同框中近景，禁遠景慢熱鋪墊） |
| 近景機槍對招 | 可選（有則走序列化招式鏈，見 `real-fight-techniques.md`） |
| 氣爆/特效 | **不強制**，以真實受力反饋為主（肌肉凹陷/骨骼脆響/腳步犁地/環境破壞） |
| 終結收尾 | **允許剋制收勢或懸念收尾**（反派踉蹌後退、主角收拳喘氣、勝負留白） |
| 升格/慢鏡 | **默認禁用**（實測破壞節奏）；僅用戶明確要求且 ≤1s 可用 |
| 站樁式對打 | **嚴禁**（所有招式必須掛在步法位移/重心轉換上；禁"兩人站定輪流出招"） |
| 打鬥最低線 | 快慢呼吸交替，同節奏連續 ≤5 秒 |
| **多人同場（2~4 人）** | 走 `multi-opponent-rules.md`（★多人唯一真源）：主角唯一錨點 · 同鏡交手 ≤3 人 · 三拍輪轉禁站等 · 1v2 用 4~5 鏡 / 1v3 用 5~6 鏡 |

## 二、 R1 完播潛力評分（啟發式自檢）

$$\text{評分} = 0.20 \times \text{開局吸引力} + 0.30 \times \text{節奏呼吸} + 0.25 \times \text{運鏡豐富度} + 0.25 \times \text{情緒拐點}$$

| 維度 | 權重 | R1 執行指標 |
|---|---|---|
| 開局吸引力 | 20% | 1.5 秒內發生攻防接觸；第一幀雙人同框中近景 |
| 節奏呼吸 | 30% | 快慢交替，同節奏連續 ≤5 秒；禁全程同一強度平推 |
| 運鏡豐富度 | 25% | 同運鏡 ≤2 秒，同景別 ≤3 秒（近景/特寫除外）；15 秒 5~8 次精準切換 |
| 情緒拐點 | 25% | 8~12 秒區間出現一次局勢逆轉/破防爆發/破綻抓取 |
| 收尾 | 核心 | 剋制收勢（踉蹌/喘氣/收拳）或懸念收尾（勝負留白/威脅未除） |

## 三、 單場戰鬥節拍弧（防平推）

禁止從頭到尾同一強度平推。按節拍弧推進，強度有起落：

```text
接敵（試探接觸）→ 試探（互探虛實）→ 施壓（一方佔優）→ 破防（防線崩潰）→ 逆轉/收勢
```

- 每一節拍 2~4s，節拍之間必須換節奏（快→慢→快）或換機位（見 `camera-action-specs.md`）；
- 喜劇打鬥可把"逆轉"換成"巧合翻盤"（如誤傷自己/道具背叛），但同樣要節拍弧。

## 四、 情緒拐點寫法（8~12s 區間必有一處）

- **破防爆發**：守方防線被硬生生震開 → 攻方趁勢連擊；
- **破綻抓取**：攻方招式用老收不回 → 守方抓住空檔反打（局勢逆轉）；
- **威脅升級**：對手亮出第二形態/援手入場/新武器（體現為畫面內可見新元素，禁旁白解釋）。

## 五、 中段留白與神態記憶點（R1 適用版）

> ⚠️ 實測鐵律：**"留白/對峙/靜止/懸停"字眼 = 模型渲染成呆立**。留白必須靠運動或環境動態實現。

1. **運動中換檔替代靜止留白**：兩波高潮之間的緩衝段，角色保持位移（滑步調整距離/環繞換位），節奏由密集對招降到試探性步法，但**動作不中斷**；
2. **神態掛載在動作上**：禁止獨立靜止特寫（"她冷笑（靜止）"）。必須寫成"她側身讓過拳鋒的瞬間冷笑/甩棍轉身時啐了一口"——神態是動作的附屬屬性，不單獨成段；
3. **唯一可用的短停**：命中瞬間 1~2 幀微停頓（Hit-Stop，僅 2.5）；或用戶明確要求的 ≤1s 慢鏡（必須配環境動態：汗水飛濺/衣襬甩動/灰塵揚落），禁止人物靜止全身。

## 六、 開局寫法（R1 無硬撞版）

- 第一幀 = 雙人同框中近景（人物佔畫面 ≥1/3），禁大遠景風景慢熱；
- 1.5s 內發生**接觸**即可，不必硬撞：探步搶中線、刺拳試探、側閃下一步逼進都算有效接觸；
- 例：`00:00-00:01.5 [鏡頭1] …兩人幾乎同時向前搶步，右手刺拳虛晃，隨即各自側閃錯身，距離重新拉開。`
- **多人場景例外**：第一幀改為「主角 + 至少一名對手」同框中近景（人物合計佔畫面 ≥1/3），其餘人以動態從畫面邊緣進入；軸線與景別按 `multi-opponent-rules.md` §六。

## 七、 收尾寫法（R1 剋制版）

- **允許**：收勢收鏡（收拳喘氣、甩手中淤血）、懸念收鏡（勝者轉身、敗者扶牆站起）、局面留白（交戰被第三方打斷）；
- 決勝一擊仍然需要把"命中受力"寫完（見 `impact-physics.md`），只是不強制衝擊波/嵌牆等誇張餘震；
- 例：`00:13-00:15 [鏡頭4] …一記低位掃踢命中對方膝彎，對方單膝砸地；勝者後退半步收拳，呼吸急促，鏡頭緩慢拉遠收鏡。`

## 八、 外部招式庫的從屬地位（★取神不取形 · 節奏硬口徑）

> `martial-styles-extended.md`（武學詳解擴展庫）與 `technique-combo-library.md`（技法合規庫）是從外部源包移植的**招式素材庫**，不是動作劇本。二者與本文件衝突時，**一律以本文件為準**。

**招式庫只提供三樣（神）**：① 招式名與外形特徵；② 勁力原理與發力方向；③ 打擊部位與受力反饋。

**招式庫不提供四樣（形）**：

| 不取 | 本包替代真源 |
|---|---|
| 套路順序（12 式表排列 = 門派拳套固有順序，非戰鬥順序） | 本文件 §三 單場戰鬥節拍弧 |
| 銜接方式（庫內「A→B→C」箭頭鏈只表勁力流向，非拍攝順序） | `kinetic-chain-11.md` 11 環動力鏈 |
| 節奏與時值（庫內「節奏特徵」行屬門派演練節奏） | 本文件 §二 節奏呼吸 + 本節三條硬口徑 |
| 起勢 / 收勢（套路首尾動作，不得單獨成鏡） | 本文件 §七 R1 剋制收尾寫法 |

### 三條節奏硬口徑（違者 P0 阻斷）

| # | 口徑 | 執行標準 |
|---|---|---|
| ① | **機關槍式近景對招** | 近景對招段一律用**序列化招式鏈**（`real-fight-techniques.md` §五）：全鏈 **2~3 秒內 6~10 擊**、**擊與擊之間零間隔**（打出即收、收即出）、守方逐擊反應不同並帶步法位移。禁「兩人快速對打」這類模糊寫法。 |
| ② | **禁多餘升格 / 慢動作** | 升格慢鏡**默認 0 處**；僅用戶明確要求且全片 ≤1s 可用。命中瞬間 1~2 幀微頓（Hit-Stop）**僅 2.5 可用**、不計入升格。庫內鏡頭列的「緩慢拉遠 / 慢速推近」**只指運鏡速度、不等於時間升格**；成片運鏡一律按 `camera-action-specs.md` 重寫。 |
| ③ | **嚴禁站樁式對打** | 兩人站定輪流出招、或原地打完整套 = **P0 阻斷**。所有招式必須**掛在步法位移或重心轉換上**（搶步 / 繞側 / 撤步 / 換位 / 低伏）。庫內「穩紮不動 / 定馬 / 原地」類字樣說的是**下盤結構**、不是「人不動」——成稿一律寫成「下盤扎穩的同時步法仍在切進 / 換位」。 |

### 附 · 騰空口徑（★唯一真源）

- **跳踢 / 騰空**：離地 ≤1.2m、單次 ≤0.6s、**落地即卸力並續接下一動**；禁「空中不落地」「懸停幀」；庫內「凌空 / 空中不落地」字樣**禁止照抄進成品稿**；
- **被動離地**（被擊飛 / 被摔倒）不受上述時長限，但落地須寫清受力與慣性延續；
- **旋身角度**：單次旋身 ≤360°（禁多周旋轉）；各招式表內的 `(≤360°)` 標註為本口徑的**回聲**，真源在本節。

### 附 · 「定格」與「定鏡收束」分工鐵律（與總控 D鎖①及 C11b 互鎖 · 2026-10-14 消除左右互搏）

- **打鬥過程鏡（第 1 鏡 ~ 倒數第 2 鏡）**：**嚴禁寫「定格 / 靜止 / 對峙不動」**（過程鏡寫定格 = 人物打到一半卡死呆立 = P0 阻斷）；唯一允許的短停是命中瞬間 1~2 幀物理阻尼微頓（Hit-Stop，僅 2.5）；
- **段末最後 1 鏡的結尾 1 秒（D 鎖①末幀定格承接）**：為供下一段截取清晰尾幀，段末最後 1 秒**法定寫** `第 X 秒起運動收束，末 1 秒兩人保持姿態與站位、動作完全靜止、畫面定格`（或寫 `定鏡收束`，機檢 `C11b` 均予放行；該末 1 秒在剪輯拼接時整秒裁除，不進成片）。
  > ⚠️ **僅 D鎖①適用（2026-10-18 補）**：本段若選 **D鎖②換機位硬切**，**本句整條不寫**——②法定不寫末 1 秒定格，末鏡改寫 `接口餘量 0.5 秒：保留未收死的運動`；機檢 `C11b` 已按②豁免（末鏡含「接口餘量 / 硬切」即不報），**不寫定格不會報警**。①/② 分流見總控 `segment-splicing.md` §四·乙。

### 負例與正例（P0 判據）

- ❌ 兩人站定，甲出拳 → 乙格擋 → 甲再出拳（**站樁式對打**）；
- ❌ 把某門武學的 12 式表按順序拍成 12 個鏡頭、以「收勢X」收尾（**照搬套路**）；
- ❌ 照箭頭鏈逐鏡拍 A→B→C→D（**照搬套路順序**）；
- ❌ 全片出現多處長升格 / 慢動作（**破壞節奏**）；
- ✅ 甲搶步切入偏門，日字衝拳連射三擊（**擊間零間隔**），乙邊退邊拍手化解、第三擊下潛避開並順勢掃腿（本包口徑）。

## 八、 （V8.2.0-SLIM 新增 · 吸收仿真人 V1.10.7）F1~F7 七層打鬥導演架構與防假綠門禁（C86）

1. **F1 戰鬥意圖與五階節奏曲線**：試探 ➔ 爆發 ➔ 受力調整 ➔ 反制爆發 ➔ 終結，廢除全程勻速亂揮。
2. **F2 動作因果短鏈（2~3 拍）+ 動作前後態連續性**：上一拍的失衡後態直接作為下一拍起勢前態，嚴禁切鏡後滿血站直復位。
3. **F3 四維物理受力與部位差異化**：交代「發力源 ➔ 接觸點 ➔ 受力方向 ➔ 動作後果」，區分頭/胸腹/下盤/手腕受擊反應，禁千篇一律倒飛。
4. **F4 多人三態威脅調度**：`Active Threat（主交鋒1對）+ Positional Threat（滑步封路/遞劍切角）+ Temporarily Disrupted（受阻/失衡）` 同時間線並存，替代排隊輪轉。
5. **F5 動作優先攝影配比**：`Action Master（中景/中全景 2~4s 看完整攻防短鏈，佔 60%）+ Impact Insert（近景/特寫 1~2s 釘重擊咬合，佔 20%）+ Reaction & Shift（中近景 2~3s 看失衡轉換，佔 20%）`。
6. **F6 實戰防穿幫四鐵律**：
   - **反一招秒**：劇本簡短動作行嚴禁直譯成 1~2 招放倒，必須 100% 保留劇本結果與台詞，同時展開為 **3~4 回合攻防互搏**（拆招滑刃 + 貼身掌肘腿 + 互相吃招反打）。
   - **坐姿轉打戲提前起身**：坐姿角色必須在對手攻擊落下的**前一鏡**就起身拔出明刃，嚴禁等到受擊鏡才動作（防模型鎖死抱臂坐姿）。
   - **一手一物去鞘防雙刀**：交戰鏡剔除一切「刀鞘 / 裹布」與複數兵器總稱（`雙刀/雙刃/兩柄`），統一寫明 `右手單手握明鋼刀身，左手空手配合身法`。
   - **跨段正背撤步**：段尾邊緣前景恢復角色統一採用 `畫左/右前景完整背影后撤一步起身立定，不露正臉或側臉`，並與下段對角進攻矢量對齊，根治回頭扭脖和眼線錯位。
7. **F7 打戲密度下限與 `C86` 防連續定格鏈**：攻防鏡佔比 ≥40%、靜止/收勢 ≤35%、獨佔靜止鏡台詞 ≤2 句；**`C86` 嚴禁連續 ≥3 鏡且 ≥10s 出現「畫面主體開頭無位移」的持械定格鏈**（避免“機檢假綠但成片定格 10 秒”）。
