# 小規模多點戰鬥調度 (Multi-Opponent Choreography) · ★多人戰鬥唯一真源

> 本文件是 **小規模多點戰鬥（同場 2~4 人）的唯一真源**：1v2 / 1v3 / 2v2 / 3v3。
> 凡任務中出現「兩人以上同場交手」，本文件的規則**覆蓋** `r1-combat-core.md` / `camera-action-specs.md` / `render-adapters.md` 中的 1v1 默認寫法（軸線鎖定、開局構圖、站位聲明、景別策略）。
> **鐵律 1~6 全部繼續生效**，本節只做多人場景的補充與例外。本文件未寫到的部分，回到 `r1-combat-core.md`。

---

## 一、 適用邊界與人數上限（硬約束）

| 項 | 口徑 |
|---|---|
| 覆蓋範圍 | **同場 2~4 人**：1v2 / 1v3 / 2v2 / 3v3 |
| 同鏡「正在交手」人數 | **≤3 人**（含主角）；第 4 人及以上只能是「未交手的施壓位」或「背景人物」 |
| 同框人數 | 中景 / 全景可 4 人；**特寫禁 ≥3 人** |
| 超出範圍 | 5 人以上群毆混戰**不在本包範圍** → 拆成若干 2~4 人子場，逐段生成後剪接 |

**為什麼有上限**：視頻模型對同框角色的注意力是有限的——同框 4 人以上同焦，必然出現糊臉、動作融合、分身。**人數上去了但每張臉都糊，觀感遠差於兩個人打得好。**

---

## 二、 主角唯一錨點法則（★核心，違者 P0）

多人場景**必須指定唯一視覺主錨點**（主角 `@CHR-A`）：

1. **全部運鏡與焦點圍繞主角**；其餘角色一律是「主角的對手」，**禁平均分配鏡頭**；
2. **主線鏡頭裡主角必須在場**（可被遮擋、可背對、可出畫半身），**禁整鏡只拍配角互毆**；
3. **焦平面上限 2 人**（主角 + 當前對手）；第三人只能作為**移動前景 / 遮擋物 / 焦外剪影**。

- ❌ **反例**：鏡頭 2 單獨拍兩個配角互相打，主角不在畫面 → 觀眾立刻失去追蹤目標，人多反而更亂；
- ✅ **正例**：鏡頭 2 過肩拍主角正面，畫面右下角是第二人持械的**焦外剪影**正在壓上。

## 三、 多軸管理（替代 1v1 的單軸鎖定）

`render-adapters.md` §三 的「左A右B · 全段禁越軸」是 **1v1 口徑**；多對多改為 **主軸 + 從軸** 兩層：

| 層 | 定義 | 規則 |
|---|---|---|
| **主軸** | 主角 ↔ **當前主要對手**（同一時刻只有一個） | 全段穩定、**禁越軸**、承載 8~12s 情緒拐點 |
| **從軸** | 其餘人相對主角 / 主要對手的側位 | 可隨位移自然變化；**同鏡內不得反向** |

**主軸切換三時機**（只有這三種合法）：

1. 當前主要對手**被擊退 / 倒地 / 出畫**；
2. 主角**主動轉身換向**（必須寫清轉身動作）；
3. **新威脅介入**（從畫面外進入）。

**禁瞬切**：切換必須寫清動作因果。
`✅ 主角側身讓過左側來拳，順勢轉身面對右側撲來的第二人。`

## 四、 三拍輪轉制（★本檔第一大廢片來源）

> **多人戰鬥最容易出站樁** —— 模型會讓「沒輪到的角色」原地待命。這是本檔 **P0 最高發項**。

同一時間**最多一人**與主角發生實際接觸；其餘人必須處於以下三種**可見動態**之一，不得靜止：

| 狀態 | 含義 | 寫法 |
|---|---|---|
| **壓上** | 正在接近 | 大步切入 / 搶位 / 舉起兵器 / 從畫面邊緣進入 |
| **被擊退** | 剛挨完打 | 踉蹌後撤 / 撞翻物體 / 扶牆 / 武器脫手飛出 |
| **繞位** | 在找角度 | 側向圍繞 / 換位 / 封住退路 / 撿起掉落物 |

**P0 判據**：任一角色連續 **≥1s** 既無位移也無受力動作 → 判「**站等**」= P0 阻斷。

- ❌ **反例**：主角打甲的時候，乙站在原地舉著刀看；
- ✅ **正例**：主角打甲的同時，乙從左側壓上；主角餘光掃到，**以甲的身體為屏障頂住**（甲被推得撞向乙）。

**被圍 ≠ 打不完**：1v3 必須走 **破圍點** —— 主角始終在移動中尋找並擊穿最弱的一環（站位重疊 / 背光 / 持械遲鈍的那個），**不是原地輪流對招**。

## 五、 節拍弧（多人版，替代單挑弧）

- **單挑弧**（`r1-combat-core.md` §三）：接敵 → 試探 → 施壓 → 破防 → 逆轉 / 收勢
- **多人弧（本檔採用）**：

```text
接敵（接觸第一個）→ 被圍（形成人數劣勢）→ 破圍點（擊穿最弱一環）→ 逐個擊破（連續清算）→ 收勢
```

1. **8~12s 情緒拐點從「逆轉」挪到「破圍點」**——主角從被壓制轉為反制的那個瞬間；
2. **逐個擊破必須節奏加速**：後續對手的解決速度**明顯快於**第一個（體現「打通了」），**禁三人打三遍同樣長的時間**；
3. **收勢用動作表達「不敢上了」**：剩餘敵人**停步 / 後退 / 轉頭看同夥**；禁旁白解釋。

## 六、 群像鏡頭規則（與單挑相反：人越多，鏡頭越收緊）

| 場景 | 鏡頭策略 | 禁 |
|---|---|---|
| 建立空間（本組第 1 鏡，可選） | 全景 / 中景 **30°~60° 斜角**，一次性交代人數與相對位置 | 禁 90° 正側拍（街機橫版感，沿用 `camera-action-specs.md` §二） |
| 主角對單人交手 | 近景 / 中近景，**過肩帶出第二人的存在** | — |
| 主角被兩人以上施壓 | **越肩**：第二人放前景剪影或焦外，避免三人同焦 | 禁三人同焦特寫 |
| 擊退 / 摔倒某一人 | 低機位或斜側中景 | — |
| 多人同框 | 中景 / 全景（借前後遮擋分層） | **特寫禁 ≥3 人**（臉崩 / 分身高發） |

- **視線引導（強制）**：主角**轉頭 / 側目看向新威脅** → 下一鏡**必須**切到該威脅（六式④「視線引導切」在多人場景是**強制項**，不是可選）；
- **Eye-Trace**：多人場景同屏焦點上限 **2 個**；第三人只作移動前景 / 遮擋物。

## 七、 防「分身 / 複製人」（多人專屬）

多人場景觸發分身 / 複製人的概率遠高於單挑——**三個穿同款黑西裝的人，最容易被渲染成同一個人被複制三次**。

**強制差異化錨點**：每人至少 **2 項不同**，寫進【核心人物】段：

> 體型（高 / 矮 / 壯 / 瘦）· 髮型（長 / 短 / 束 / 禿）· 服裝（顏色 / 層次 / 配件）· 兵器（長短 / 形制 / 持法）· 站位習慣（左撇 / 沉步 / 前傾）

**服飾統一時**（如黑衣保安隊）**必須用配件 / 兵器 / 體型做區分**：
`✅ 一人持短棍、一人持長棍、一人赤手；左側者體型偏壯、右側者偏瘦高。`

**負面詞疊加**（在 `render-adapters.md` §六 默認三區基礎上追加）：
`同一人物重複出現、服裝互換、多手多腳、人物融合、同臉複製`

## 八、 站位聲明（多人版格式）

`render-adapters.md` §三 的「一行式」是 **1v1 格式**；多人改為 **三行制**：

```text
【站位聲明】
主軸：@CHR-A（畫面左·背靠牆面錨點·側身45°朝右）↔ @CHR-B（畫面右·朝左），全段禁越軸；
從軸：@CHR-C 位於 B 外側（畫面右後），@CHR-D 位於 A 外側（畫面左後）；
全員動態：A 錨點→中央對決區（搶攻）；B 右位→中央（迎擊）；C 右後→切入中央（壓上）；
         D 左後→退至門邊（被擊退，武器脫手）
```

- **三條線缺一不可**：主軸行（含軸線鎖定）+ 從軸行（其餘人相對側位）+ 全員動態行（逐人 `起點→終點` + **動作原因**）；
- **禁瞬移**（沿用 1v1 口徑）：每一步位移必須有攻擊 / 閃避 / 擊退的因果；
- **禁畫圖**（沿用 1v1 口徑）：禁俯視 ASCII 空間圖 / 座標表。

## 九、 時長、鏡數與拆組

| 人數 | 單組鏡數 | 組時長 |
|---|---|---|
| 1v1 | 3~4 鏡 | ≤15s |
| **1v2** | **4~5 鏡** | ≤15s |
| **1v3** | **5~6 鏡** | ≤15s |
| **2v2 / 3v3** | — | **直接拆 2 組**（每組聚焦一條主軸線） |

1. **每人至少一個「受力鏡頭」**：每個交過手的對手都必須被**清晰地打中一次**（有完整受力反饋），否則觀眾記不住「有幾個人」，也感受不到人數劣勢被解除；
2. **拆組邊界**寫在「破圍點」或「擊退一人之後」——**禁止在交手中間拆**，否則跨段末幀對不齊（段縫畫面鎖依賴可截的末幀；【接續狀態】文字腿 2026-10-09 已廢止）；
3. 字數門禁（唯一真源見 `render-adapters.md` §六）在多人場景**照常適用**：人多信息量大，優先**壓縮單鏡描述**、必要時**拆組**，**禁刪掉某個對手的動作**。

## 十、 S5 機檢增項（多人場景疊加，與 SKILL.md 三·S5 並行）

1. **人數核對**：同鏡「正在交手」≤3 人；特寫內 <3 人；總同場 ≤4 人；
2. **站等掃描**：逐鏡檢查每個在場角色是否有位移或受力動作，出現 `原地 / 站立 / 旁觀 / 等待 / 不動` 類描述 → 判 P0；
3. **主角在場**：每個鏡行主角必須在場或被明確交代去向；
4. **主軸唯一**：同一時刻只有一條主軸，主軸切換均有動作因果；
5. **差異化錨點**：每個非主角角色在【核心人物】段有不少於 2 項外形差異；
6. **分身負面詞**：`同一人物重複出現 / 服裝互換 / 人物融合 / 同臉複製` 已寫入【強制禁止項】；
7. **受力完整**：每個交手對手至少一次完整受擊描寫。

## 十一、 負例與正例（P0 判據）

- ❌ 主角站定，甲出拳 → 主角擋 → 甲退回，乙再出拳 → 主角擋 → 乙退回（**輪流出招 = 多人版站樁**）；
- ❌ 三個對手同時撲上來亂成一團（模型會把動作糊成一坨，看不到任何有效接觸）；
- ❌ 三人同框近景 / 特寫（**臉崩 / 分身**）；
- ❌ 打甲時，乙丙原地舉械旁觀（**站等**）；
- ❌ 三個對手平均分配鏡數、解決速度一樣（**無進度感**）；
- ❌ 鏡頭只拍配角互毆、主角不在畫面（**丟失主錨點**）；
- ✅ **1v3 正例全鏈**：主角背靠牆搶先接觸甲（接敵）→ 乙丙從兩翼壓上、封住退路（被圍）→ 主角側身讓過甲、順勢把他推向乙製造衝撞（破圍點）→ 趁乙被撞歪一記低位掃腿放倒丙（逐個擊破·加速）→ 轉身面對甲，甲後退未再上前（收勢）。
