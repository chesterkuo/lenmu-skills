# 打戲激烈度硬護欄與節奏零件庫（拉片實證層）

> **定位**：本庫是**打戲"到底打沒打起來"的工程底線**，管的是**節奏與激烈度**——
> 我們已有的一整套（完播率黃金律 / 2~3 秒細切 / 模式 K 雙向受力 / 收束協議 A~D / 尺度四件套）
> 管的是"**每一鏡怎麼寫**"；本庫管的是"**整場打戲的骨架有沒有塌**"。
>
> **來源**：吸收自外部包 `huhe-combat-director V2.1` 的**拉片實證層**（該層是對實際出片逐幀復盤後
> 校正出的手感規則）。該包的"工程底座層"承襲 `xuanhuan-combat-director V2.6.0 Ultimate`——
> **與本套裝同源**，故其底座規則（黃金顆粒度 / 模式 K / 協議 A~D / 鏡頭五要素 / 雙檔引擎）
> 本包已全部具備且更全，**不重複收錄**；本庫只收它**多出來的實測校正部分**。

## 一、第一原則：分層管理「能變的」和「不能變的」

> **實測痛點**：把配比寫死後生成物反而僵（節奏被公式框住、每場打戲長得一樣）；完全不給約束又會退回"不激烈 / 穿幫"。
> 解法不是二選一，而是**分層**——

| | **自由組合區（隨戲份自由變）** | **硬護欄區（工程底線 · 不可動）** |
|---|---|---|
| **節奏零件** | 取用哪幾個零件、順序、次數、各自佔比；情感段有無；反轉幾次 | 起手有形 / 中段有來有回 / 結尾有落點（§四·三鐵律） |
| **時長** | 各零件時長分配、快慢交替的具體落點 | 整數秒時間戳、2~3 秒細切、**【快】總時長 ≥ 片長 40%**（下限護欄，§四·二） |
| **減速器** | 慢鏡 / 定格放在哪一拍 | **黑白閃、定格幀、慢鏡的次數配額上限**（§三） |
| **收束** | 四協議 A~D 擇一（玄幻檔另見 `sd-xuanhuan-engine` 收束四協議） | 必須有收束協議、嚴禁平緩收尾 |
| **時序** | 大招何時起手（按比例） | 大招釋放完整展開、視覺主客反超不壓縮 |
| **激烈度** | 每一段具體怎麼打、怎麼位移 | **§二 六條硬護欄——一條都不許破** |

> ⚠️ **別把下限當上限用**：【快】≥40% 是**防"打鬥不激烈"的下限**，不是目標值。
> 快打碾壓型天然能到 70%+，完全合法；蓄勢一擊型靠"靜"造壓強，只要【快】總量仍 ≥40% 即可。

## 二、★ 對抗激烈度硬護欄【實測校正 · 治"站樁擺拍" · 機檢 C21 載體】

> **實測病徵**：出片後逐幀看，**每 2~3 秒只有一個靜態構圖**——`對峙 → 特效 → 對峙 → 特效`，
> 全程零貼身對招，看著"燃"其實什麼都沒發生。
> **根因**：提示詞給了時碼分段，但**沒強制"同一段內必須有位移與接觸"**，模型遂把每個時間區間理解成一張畫。

| # | 護欄 | 判據 | 機檢 |
|---|---|---|---|
| ① | **每段必含"位移 + 接觸"** | 每個時間區間內，攻守雙方**都必須發生身體位移**（衝刺 / 滑退 / 翻滾 / 騰空 / 被擊飛），且**至少一次實體接觸**（兵器交擊 / 拳腳著肉 / 抓握 / 撞擊）。⛔ 嚴禁某區間只有"站著 + 發光" | C21a / C21b |
| ② | **相鄰兩段不許同構圖** | 相鄰時間區間的**機位或雙方相對位置必須變化**。⛔ 嚴禁連續兩段都是"兩人隔著距離對視" | C21d |
| ③ | **貼身對招佔比下限** | 15 秒片**真正貼身纏鬥**（身體距離 < 1 個身位、有接觸）**不得少於 5 秒**；30 秒片不得少於 10 秒。**"隔空對波"不計入貼身對招時長** | C21c |
| ④ | **禁止擺拍動詞** | ⛔ 嚴禁「兵器抵住對手面部」（純擺拍）→ ✅ 改為「兵器捅入對手肋下，對手橫飛撞塌半面牆」 | AI 自檢 |
| ⑤ | **自檢判據：抽掉特效** | **抽掉所有特效後，剩下的純動作應能連成一段打得起來的武打**；若抽掉特效後只剩倆人站著 → 激烈度不達標 | AI 自檢 |
| ⑥ | **"隔空對波"的定位**（術語澄清） | **隔空對波 = 雙方站立不動、各放能量光束在空中相撞**（Beam Struggle）。它看著燃，實則零接觸、零位移，屬"用特效冒充激烈"。**僅允許用在兩處**：㈠ 高潮大招釋放瞬間（1~2 秒，作收束點）；㈡ 短暫反制瞬間（≤0.5 秒，且**緊接著必須貼身**）。⛔ 嚴禁用它填充前中段本該貼身對招的時間 | AI 自檢 |
| ⑦ | **【快】拍佔比下限** | **【快】拍總時長 ≥ 片長 40%**（防"打鬥不激烈"的通病）。意即：全片至少 **4 成時長**處於近身攻防對拆狀態 | AI 自檢 |

> **C21 觸發門**：本組護欄**只對打戲稿生效**。機檢腳本自動探測打戲信號詞，也支持 `--combat on`
> 強制啟用 / `--combat off` 關閉——**文戲稿不跑本組**（防誤報拖垮整包機檢可信度）。

## 三、減速器配額（上限護欄 · 與下限成對）

> **黑白閃、定格幀、慢鏡都是"減速器"**——用一處就從【快】拍時間裡扣一處。

| 片長 | 黑白閃 | 定格幀 | 慢鏡 |
|---|---|---|---|
| 15 秒片 | ≤1 | ≤1 | ≤1 |
| 30 秒片 | ≤2 | ≤2 | ≤2 |
| 短於 8 秒 | 允許 1（招牌不省） | 建議全砍 | 建議全砍 |

- **黑白閃寫法硬條**：必須寫成**自然畫面句**且帶**手繪墨線屬性**（見 `vfx-rendering-mandate.md` §五）；
  嚴禁術語標籤 ⛔ `★插入黑白閃 #1`、`<黑白閃 2幀>`。
- 上限護欄（本條）與下限護欄（§二·⑦ 【快】≥40%、§四·二 中段雙向受力）**成對使用**：
  只壓下限 → 節奏失控；只壓上限 → 打戲發悶。兩者缺一不可。

## 四、打戲節奏零件庫（本包命名 · 勿與「情緒節拍」混用）

> ⚠️ **術語避撞聲明（重要）**：外部原名為"七段式情緒節拍元件庫"。本包內
> **"節拍"一詞已被 `sd-decision-engine/references/emotion-anchor-table.md` 的「情緒節拍」佔用**
> （閒聊試探 / 害羞猶豫 / 鼓起勇氣… 文戲情緒錨點，二義會造成同一個詞兩種法律）。
> 故本庫統一命名為 **「打戲節奏零件」**，與情緒節拍**井水不犯河水**：一個管打戲骨架，一個管文戲情緒。

### 4.1 零件表（看清"必選 / 可選"）

| # | 零件 | 功能 | 內容要點 | 取用建議 |
|---|---|---|---|---|
| 1 | **蓄** | 對峙蓄勢 | 低機位暗部起畫、環境先到、氣機鎖死；**0.5 秒內兵刃必須已破空逼近**（嚴禁風景慢熱鋪墊） | ◇ 推薦起手；**很短的片可直接用【快】起手** |
| 2 | **快** | 貼身交鋒 | 近身攻防對拆、火花飛濺、**雙向受力（模式 K 強制）** | ★ **必選**，且**可重複取用多次**（連招加劇 = 再次取用【快】） |
| 3 | **停** | 戰局反轉 | 變招破防 / 主角掛彩 / 底牌掀開，台詞點火 | ◇ 可選——**有反轉才用**；勢均力敵可停—快—停反覆取用 |
| 4 | **慢** | 情感昇華 | 升格慢鏡聚焦決然眼神，色彩壓深/切紅，悲壯感 | ◇ 可選——**屬"減速器"**，15 秒以內建議不用或 ≤1 秒；30 秒以上才給足額空間 |
| 5 | **靜** | 萬籟俱寂 | 完全靜止定格 + **黑白閃** + 虛空銀線起筆，聲浪歸零 | ◇ 可選——**大招前想製造壓強就用**；短平快的秒殺戲允許【快】直接切【爆】 |
| 6 | **爆** | 絕殺降臨 | 全屏閃白 + 空間貫穿 + **收束協議（A~D 擇一）**，定格最燃瞬間 | ★ **必選** |

> **沒有第 7 個獨立零件**——**【快】會在中段被第二次取用**（連招加劇 / 大範圍身法 / 器物形變 / 場景大破壞），
> 它仍是同一個零件，只是加碼。**戲需要就取用 1 次，需要就連用 3 次。**

### 4.2 組合三鐵律（★唯一不可動的骨架 · 只管首中尾）

任何時長、任何戲，只要求這三條成立，**其餘全部自由**：

1. **起手必須有形**：開場 0.5~1.5 秒內必須出現**兵刃破空逼近或雙人同框的物理接觸**——禁止全景無人風景慢熱；
2. **中段必須有來有回**：至少取用 1 段【快】，且必須**雙向受力（模式 K）**——禁止單向毆打沙包；
3. **結尾必須有落點**：必須取用【爆】並配收束協議（A~D 擇一）——**嚴禁平緩收尾幀**（收刀入鞘、微風吹髮）。

### 4.3 參考組合範式（★可拆可改 · 按戲份選用，禁止當模板照套）

**以下範式只是若干條合法組合，不是必答題**——出稿時可跨範式混拼，也可自創（滿足 §4.2 三鐵律即可）。

| 範式 | 零件序列 | 適合什麼戲 | 備註 |
|---|---|---|---|
| **A. 經典反殺型** | 蓄 → 快 → 停 → 快 → 慢 → 靜 → 爆 | 強者壓境 → 主角受創 → 絕境覺醒 → 大招終結 | 六件齊全的重裝組合，信息量最大，適合 15~30 秒；**不是唯一解** |
| **B. 快打碾壓型** | 快 → 快 → 停 → 爆 | 實力碾壓、秒殺、開場立威 | 幾乎全程對攻，無情感段；"打來打去"感最強 |
| **C. 雙強對攻型** | 快 → 停 → 快 → 停 → 爆 | 勢均力敵的宿敵對決 | 多輪攻防互換，【停】可循環多次 |
| **D. 蓄勢一擊型** | 蓄 → 靜 → 爆 | 極短殺手鐧、一擊必殺、狙擊式偷襲 | 靠極靜製造壓強、靠爆釋放；**適合 5~8 秒超短片** |
| **E. 群戰亂鬥型** | 快 → 快 → 快 → 停 → 爆 | 多人混戰、圍殺、突圍 | 靠鏡頭快切與空間調度替代情感段 |

**組合的三個自由度**：
- **循環**：`快-停-快-停-…-爆`——勢均力敵的戲就該這麼排，不必湊齊慢/靜；
- **合併**：`慢+靜` 可合為一拍（短片常見）；`靜+爆` 直連是最兇的排列（壓強最大）；
- **省略**：沒有情感訴求就砍【慢】；沒有反轉就砍【停】；追求極速就砍【蓄】——**砍掉的時長全部並進【快】**。

## 五、交付前自檢（本庫專屬四問）

出稿前逐條過一遍，**任一條答"否"即回爐**：

1. **抽掉全部特效**，剩下的純動作能連成一段打得起來的武打嗎？（§二·⑤）
2. **逐個時間區間**數位移與接觸：有沒有哪個區間只有"站著 + 發光"？（§二·①）
3. **相鄰區間**的機位/相對位置變了嗎？有沒有連續兩段都是"隔空對視"？（§二·②）
4. **貼身纏鬥總時長**夠不夠片長的 1/3 嗎？"隔空對波"是不是混進來充數了？（§二·③⑥）

> 機檢：`python scripts/validate_prompt.py <稿件> --combat on`（C21a~d 兜底可機械判定的三項）

## 六、檔位豁免（★讓行 · 2026-10-12 用戶裁定）

> **本庫 §二 是「默認參考護欄」，不是打戲引擎之上的硬閘**。§二 的判據原型全部取自
> **現代近身肉搏**（見 §〇 病徵：`對峙 → 特效 → 對峙 → 特效`），對**非肉搏戲型**外推會失真。
> 與打戲引擎本檔規則衝突時，**以引擎本檔為準**（聯動條款見
> `combat-rhythm-and-load-guardrails.md` §七「檔位豁免與放行條款」）。

| 戲型（先定檔） | 不適用的護欄 | 說明 |
|---|---|---|
| **R1 寫實 · 槍戰 / 狙擊 / 暗殺 / 追車 / 兒童向** | §二·① 相對位移+接觸、§二·③ 貼身下限、§二·⑥ 隔空對波定位 | 交火本質是**中遠距**：允許一方靜止（據槍/瞄準/潛行），允許**零實體接觸**；不得硬塞貼身 |
| **R1 寫實 · 多人輪轉**（1v2/1v3/2v2/3v3） | §二·③ 貼身下限 | 按 `sd-real-engine/references/multi-opponent-rules.md` 的三拍輪轉與景別策略 |
| **R3 玄幻 · 術法對轟 / 遠程法術 / 法陣 / 萬劍歸宗** | §二·③ 貼身下限、§二·⑥ 對波"僅兩處" | 對波/對轟是玄幻檔**合法主武器**；只保留"不得整篇只有對波、必須有點上活" |
| **R3 玄幻 · 大場面檔**（法相 / 法天象地 / 巨獸 / 對軍清場） | §二·①、§二·③ | 大場面是**宏觀調度**：允許整段大遠景/全景；"站定施展術法"是**施法**，不判"站著發光" |
| **R2 通用武俠 · 群戰亂鬥 / 對軍** | §二·①、§二·③ | 靠鏡頭快切與空間調度，不按單人貼身戲模板 |
| **全部檔位 ·【靜】【慢】零件**（本庫 §四） | §二·① "站著發光" | 【靜】＝完全靜止定格、【慢】＝升格——**是設計**，不判躺平 |

**保底（不放行）**：① 不得整場零位移、零接觸、無收束（空轉模板）；② 相鄰區間機位不得完全相同連排 ≥3 段。
**一句話**：豁免的是"**肉搏幾何模板**"，不是"**打得起來**"。
