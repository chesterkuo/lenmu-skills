# 八類自然句母版（唯一輸出句式標準）

🔴最終輸出的每一句都必須是這八類自然句之一或其咬合，禁止關鍵詞袋、禁止豎線串、禁止"內容｜內容｜"、禁止字段羅列；字段只准存在於腦內。

---

## 1) 宏觀揭示句

**語序公式**：機位焦段景別 → 畫框分區(天空/地面/上中下層各佔幾成) → 大環境 → 特效主體(材質+規模四件套) → 極小人物位置 → 鏡頭運動反應。

用途：證規模。開場鋪規模、大招成型全景、EWS 展示。


## 2) 動作-特效釋放句

**語序公式**：人物發力鏈動作 → 特效從肢體/武器長出(材質+形態) → 沿明確軸線飛行 → 命中目標 → 三層反饋 → 環境結果。

用途：證招式與軌跡。每鏡核心句。


## 3) 打擊反饋句

**語序公式**：接觸瞬間+頓幀衝擊幀 → 受力體形變 → 位移 → 三層粒子 → 環境連鎖 → 鏡頭受力。

用途：證力量。每次命中必用，與鐵律11物理反饋鏈同構。


## 4) 蓄力壓縮句

**語序公式**：手/眼/刃特寫 → 粒子從八方螺旋匯聚 → 材質微觀細節 → 臨界萬物懸停(升格/子彈時間) → 鏡頭微震蓄壓。

用途：大招前必用。打戲交鋒段蓄力只能在高速位移或連段中完成（邊衝邊蓄力、借格擋反彈蓄力），≤0.25秒；蓄力期畫面不許靜止（法陣邊緣自動絞殺+敵方遠程砸屏障+角色微沉浮/衣發狂舞）。


## 5) 尺度證明句

**語序公式**：先給參照物/畫框鎖規模 → 讓特效做一個能對比的動作(掃過雲層/切開雪霧/吞沒建築/壓過山嶽巨物) → 再給極小人物位置二次確認。

用途：證規模。禁止只喊"巨大/終結級"；與鐵律19尺度四件套配套，規模必須持續證明、不是一幀喊大。


## 6) 追尾位移句

**語序公式**：位移起法(蹬/踏/借力點+碎裂反饋) → 長距離方向跨度 → 拖尾殘影 → 原位置被追來的攻擊打爆 → 鏡頭滯後追趕/被甩出畫框。

用途：證速度。瞬移/高速位移/突圍段專用（與鐵律28態四、鐵律34瞬移甩鏡配套）。


## 7) 群體結構句

**語序公式**：先定義群體組織結構(幾路/幾層/前部中部尾部) → 整體運動方式(魚群/潮水/星河同相位) → 個體在結構裡分工 → 鏡頭停在群體外部看整體輪廓不追單個。

用途：群戰/萬劍/妖潮必用（與鐵律27③配套）。禁止"密密麻麻糊一團"；個體只在命中瞬間給近景。


## 8) 收勢/延遲揭示句

**語序公式**：動作收束(入鞘/合扇/咔噠) → 極短時間凍結 → 裂紋/效果延遲蔓延 → 延遲爆發或粒子逆流回收 → 鏡頭勻速拉遠留動態背影與被改變的世界。

用途：結尾必用，禁止雙方同框擺pose（與鐵律10、7種標準收束模式銜接，收束模式表見 syntax-corpus.md）。

## 出稿前每鏡自問清單（任一答不上這句就是空話、重寫）

1. 這鏡任務是什麼？（證規模/證力量/證速度/證招式/證軌跡/證情緒，一鏡一主任務）
2. 觀眾站哪？（機位此刻在哪個空間位置、對準什麼、運到哪）
3. 特效什麼材質、分幾層、佔畫框多少、對照什麼參照物、人物在畫框哪個位置？（鐵律19四件套）
4. 力從哪起、收到哪三張回執？（發力鏈完整；命中→身體→環境→鏡頭）
5. 鏡頭被什麼事件推動？（運鏡方向=事件方向）
6. 和上鏡怎麼接、給下鏡留什麼？（末幀接首幀；隱形剪輯點/鉤子）

## 配套硬規矩

- **詞彙回落句**：每個強詞（炸裂/吞沒/坍縮/翻湧/螺旋/音爆環/犁溝/蟲視/暴拉/Whip Pan）必須帶①搭配對象②句中位置③服務的畫面，回落到完整句。腦內詞庫只負責供詞，成句必須走八類母版。
- **句法養料**：寫鏡前按任務類型（題材/運鏡/收束/節奏）查 `syntax-corpus.md` 提取骨架、替換參數、熔成自然句，參考不抄襲。
- **優先級**：字段式vs自然句——腦內可以按字段想，落字一律自然句（用戶硬要求，無例外）。
