# 衝擊幀分級與戰鬥負面詞庫

> **來源**：吸收自用戶提供的玄幻一鏡到底參考稿。
> **定位**：本文件是 `combat-cheatsheet.md`（打戲速查庫）的補充，管兩件**全打戲通用**的事——**打擊反饋分級**與**戰鬥段負面詞庫**。R3 玄幻的陣營色鎖/Z型移位/群戰遞增/武器變形見 `sd-xuanhuan-engine/references/epic-battlefield-protocols.md`（本文件不重複）。

## 一、衝擊幀分級（Impact Frame Grading）

> **一句話：打擊的"分量"要靠畫面的衝擊表現分級，讓觀眾用眼睛"聽懂"這一下有多重。**

| 級別 | 觸發 | 表現 | 白閃 |
|---|---|---|---|
| **一級** | 普攻、普通命中、格擋 | 單幀硬直 / 局部火花 / 輕震屏 | 無 |
| **二級** | 技能命中、落地、多殺、破防 | 明顯震屏 + 衝擊波環 + 介質飛散（碎光/碎屑/煙塵） | 無 |
| **三級** | 大招爆發、終結技、全屏清場 | 強震屏 + 大面積衝擊波 + 光爆 | **3 幀連續白閃** |

**三條規則**：

1. **分級 = 敘事權重**：一級是節拍（敘事裡的"點"），二級是重音（"頓"），三級是爆點（"轟"）。**同一場戲裡三級只給 1 次**（大招/終結技那一下），濫用即失效；
2. **白閃只屬於三級**：一級/二級不要白閃（白閃是"過曝式衝擊"，用多了廉價）；
3. **特寫 + 衝擊幀的綁定**：關鍵瞬間（如武器形態變化、終結技刺入）給**一幀近景特寫 + 一級衝擊幀**，把觀眾的注意力釘在那個細節上。

**寫法（自然句，禁工程標記）**：
```
✅ "刀鋒切入甲冑的瞬間，畫面一震，碎光沿衝擊環向外炸開"
❌ "★三級衝擊幀 + 3幀白閃"（工程標記，模型不理解）
```

**與總控的關係**：衝擊幀是 `short-drama-director/references/camera-specs-15rules.md`「鏡頭五要素」中"受力反饋"的增強；與 `sd-xuanhuan-engine/references/core-combat-laws.md`「一鏡一動一反饋」的"反饋"對齊——**每個動作都要有反饋，衝擊幀是反饋強度的標尺**。

## 二、戰鬥段負面詞庫（Battle Banlist）

> **用法**：負面提示詞每鏡必含**本鏡最易崩的特點**——**按鏡寫進該鏡的鏡行描法裡**（打戲最易崩點各不相同），**不是把整張詞庫堆進段7**。段7【強制禁止項】**保持極簡四項**（`畫面：禁字幕、禁水印（含 Logo）；音頻：禁背景音樂、禁旁白`，見 `model-adapters.md` §5）；僅當本場確有某類穿幫史（如多人場面分身高發）時，才從下表中挑 **1~2 條**追加進段7 並在交付說明寫理由。**欄目紀律照舊**：禁止項只裝負面清單，正向指令禁入（C19e）。

### 2.1 節奏類（最致命）

```
開場前奏，環境空鏡，建立鏡，緩慢起手，蓄力鋪墊，對峙觀望，原地對峙，站樁打怪，
慢動作，升格，頓幀，凍結幀，卡頓，靜止機位，勻速平推，0幀無動態，人物移出畫面
```

### 2.2 剪輯類（一鏡到底段）

```
硬切鏡頭，多機位剪輯，黑屏轉場，空鏡頭，未殺完的定格，收勢未完成，轉身離開的背影
```

### 2.3 群體/規模類

```
場上只有三五隻敵人，敵人數量越來越少，數量稀少，背景空蕩，主角對著空氣打，
敵人無反應，敵人無前搖
```

### 2.4 特效/受力類

```
特效漂浮無觸發源，特效遮擋面部，特效無受力實體，
Z型軌跡斷裂，音爆缺失
```

### 2.5 武器/形態類（有武器變形時）

```
單劍中途消失，雙刀合併回單劍，強行三刀，憑空多出一把武器，副武器，
武器中途再變形，武器憑空換模，分化演出被省略
```

### 2.6 角色/肢體類

```
角色崩壞變形，肢體扭曲，多指，融圖糊成一團，角色面癱無表情，
畸形手部，多餘手臂
```

### 2.7 色彩串色類（有陣營色鎖時）

```
敵人被染成暖色/主角色，主角光效變成冷色/敵色，陣營色互串
```

### 2.8 平台合規類（通用，見 `short-drama-director/references/platform-safety-compliance-guide.md`）

```
紅色血液，傷口特寫，斷肢，血霧，怪物化為液體
```

### 2.9 畫面瑕疵類（低關聯，走否定式兜底即可）

```
UI界面，字幕，水印，背景音樂
```

> **⚠️ 欄目紀律提醒**：以上詞條寫進【強制禁止項】時，**只列負面**；正向執行指令（如"主角恆為暖色"）**禁入該欄**，回落【畫幅風格】/鏡行（C19e，見 `short-drama-director/references/model-adapters.md` §5.0.4）。**低關聯瑕疵**（水印/變形）與**高關聯視覺概念**（發光/笑/空鏡）處理方式不同：前者否定式兜底即可，後者必須換詞（被禁詞根零出現）。
