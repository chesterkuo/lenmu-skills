# 特效手繪化鐵律與三層分層寫法（拉片實證層）

> **定位**：本庫治的是**"特效不像自己的畫風"**——出片後特效全是**標準 3D 粒子**
> （煙霧就是煙、光柱就是光、星點就是星點），模型默認調用它訓練集裡的**通用粒子特效庫**。
>
> **與既有規則的分工**：`sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md` 管的是
> **"特效分幾層、各層什麼材質、佔比多少"**（13 種三層複合元素 + 三混合配比）；
> 本庫管的是**"這些層用什麼表現手法畫出來"**——**前者定成分，後者定筆法**，兩層疊加使用。
>
> **來源**：吸收自外部包 `huhe-combat-director V2.1` 拉片實證層。適合**水墨、國漫、二次元**風格檔；
> 3D 寫實檔（`sd-real-engine`）默認不套用，除非用戶明確要求手繪化質感。

## 一、★ 特效手繪化鐵律【實測校正 · 治"特效不像自己的畫風"】

> **實測病徵**：提示詞只說了"紫粉妖霧""赤紅槍芒"這類**概念詞**，沒規定**表現手法**。
> 模型於是套最省事的**通用粒子**——永遠出不了"畫出來的"質感。
>
> **根因**：**概念詞 ≠ 表現手法**。不給筆法，就等於把控制權交給了模型的默認粒子庫。

### 1.1 五手法表（寫每一處特效時，五選一或疊加）

| # | 手法 | 寫法（照抄可用） | 用在什麼特效上 |
|---|---|---|---|
| ① | **潑墨 / 飛白筆觸** | `以潑墨飛白筆觸呈現，邊緣毛糙有斷筆與飛濺墨點，筆鋒拖出乾枯飛白` | 意境型法術、水墨系、能量起勢 |
| ② | **漫畫色塊疊加** | `以漫畫式平塗色塊層層疊加呈現，色塊邊緣銳利有手繪感，非平滑漸變` | 爆發、能量填充、大招本體 |
| ③ | **手繪速度線 / 衝擊線** | `手繪漫畫式速度線自接觸點向四周炸開，線條粗細不均、走勢歪扭帶攻擊性` | 高速位移、命中瞬間 |
| ④ | **墨線勾勒** | `如同墨線勾勒，線條有輕重頓挫，非等比均勻描邊` | 黑白閃、輪廓提示、力量紋路 |
| ⑤ | **筆觸拖尾 / 殘影** | `拖出筆觸狀拖尾，拖尾隨時間變淡並崩解為手繪碎點，非平滑粒子消散` | 兵器軌跡、身法殘影、能量尾跡 |

> ⚠️ **按畫質檔分適用（2026-10-12 用戶裁定 · 讓行條款）**：本輪三條與 §一 五手法是**潑墨仙俠 / 二次元 / 手繪國漫檔**的硬約束；**3D 國漫（次世代寫實渲染）/ 寫實仙俠檔**按 `sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md` 的 **13 種三層複合元素 + 三混合配比**執行，**不強制疊加手繪筆法**——把寫實檔硬拉成水墨同樣是"規則層產毒"。是否套用本條，以 `sd-xuanhuan-engine/SKILL.md` §六 與 `sd-combat-engine/SKILL.md` §六 的畫質檔判據 + `combat-rhythm-and-load-guardrails.md` §七 豁免表為準。

### 1.2 三條硬約束（一票否決）

1. **⛔ 禁用孤立概念詞**：嚴禁**只寫**「粒子」「光效」「能量波」「光芒」「煙霧」這類通用粒子概念詞
   ——寫了就等於**交出控制權**給模型的默認粒子庫。
2. **✅ 強制搭配**：每個特效概念詞後面**必須跟一個手繪化手法**：
   - ❌ `紫粉妖霧纏繞周身` → ✅ `紫粉妖霧纏繞周身，以飛白墨霧筆觸呈現，邊緣毛糙帶乾枯飛白`
   - ❌ `赤紅槍芒破空而出` → ✅ `赤紅槍芒以漫畫式平塗色塊疊加呈現，色塊邊緣銳利，沿槍尖拖出手繪筆觸狀拖尾`
3. **★ 黑白閃的真相**：黑白閃**不是"黑白濾鏡"，是"手繪墨線圖層"**——純黑底上那些白色紋路
   **粗細不均、有斷筆、邊緣毛糙、走勢歪扭**，是**手繪筆觸**而非 3D 射線。詳見 §五。

### 1.3 自檢判據（一條速判）

> **把畫面縮到很小看**：特效邊緣**乾淨平滑** = 標準粒子（跑偏）；
> 邊緣**毛糙、有筆觸感、有粗細變化** = 手繪化（對）。
>
> **看邊緣，不看中心**——這是本庫唯一需要的檢查動作。

## 三、★ 三層分層寫法（照抄骨架 · 實測效果最好的特效句式）

> **與"三混合配比"的關係**：三混合配比講**"每層佔比多少"**（如 30/50/20）；
> 本寫法講**"每層是什麼、按外中內怎麼排"**。
> **先用本寫法定結構，再用配比調權重**——兩者是互補而非重複。

### 3.1 結構公式

```text
【特效名】——外層[水墨暈染飛白] + 中層[青藍水浪翻湧] + 內層[白熾冰晶核心]，邊緣附著[金色細碎流光符文]。
```

```
外層(筆觸/飛白)  +  中層(主體材質/動量)  +  內層(核心發光體)  +  邊緣附著(細節/符文)
```

| 層 | 承載什麼 | 注意 |
|---|---|---|
| **外層** | 手繪感來源（飛白、暈染、毛糙邊緣） | **最容易被模型省略，必須顯式寫** |
| **中層** | 主體形態與動量（流體、色塊、能量體） | 與三混合配比的主體層對齊 |
| **內層** | 核心亮度與顏色（白熾、冰晶、熔岩核） | 定光源與冷暖 |
| **邊緣附著** | 加分細節（流光、符文、碎點） | 可選，但性價比高 |

## 四、原型色彩綁定與本包既有規則的接口

> 外部包的"原型色彩綁定"（執筆者紫+墨 / 燃命者紅+金 / 妖物紫粉等）**與本包已有能力重疊**，
> 不整庫收錄。真正需要對齊的只有兩條**色彩紀律**，它們與本包 `sd-xuanhuan-engine/references/xuanhuan-elements-vfx.md`
> 的"冷暖對抗"、`sd-xuanhuan-engine/references/epic-battlefield-protocols.md` 的"陣營色彩鎖"是同一件事，此處只作交叉提醒：

- **同色相撞大忌**：嚴禁"紫電打紫霧"——同色系對轟時，必須用**墨黑 / 白熾**做主角側分離色；
- **三方強分離**：`主衝擊色 vs 敵人主體色 vs 場景基底色` **兩兩可辨**；
- **色彩明暗紀律**：大面積低飽和環境色 + **僅一處高飽和法術色**；嚴禁整畫面糊成鮮豔遊戲 CG。

> 陣營色彩鎖的**硬條與機檢口徑**仍以 `sd-xuanhuan-engine/references/epic-battlefield-protocols.md` 為準

## 五、黑白閃手繪化（★三個必須寫進去的詞）

> 黑白閃屬**減速器**（配額見 `combat-intensity-guardrails.md` §三），且**必須手繪化**。

**三個必須詞**：**手繪 / 墨線（或筆觸）/ 粗細不均（或毛糙）**。
缺任何一個，模型都可能退化成**"去色的 3D 畫面"**（乾淨、均勻、毫無筆觸）。

**與包內既有規則的接口**：黑白閃的**分級與配額**
（一級/二級/三級衝擊幀 + 3 幀白閃 + 同場只 1 次）以
`sd-combat-engine/references/impact-frame-and-banlist.md` 為準；本處只管**寫法必須是墨線筆觸**。


- **爆氣頂點型**：`能量攀升到極限的瞬間，畫面驟然切換成手繪黑白畫稿：純黑的背景上，白色閃電紋路向四周炸裂——線條是手繪墨線，粗細不均、有斷筆飛白、邊緣毛糙，中心一團強光——僅一幀，隨即彩色畫面迴歸。`
- **拳頭型**：`拳頭攥緊的剎那畫面轉為黑白兩色，拳面上白色真氣紋路如同墨線勾勒，線條有輕重頓挫、非等比均勻，黑色背景中炸出放射狀手繪白線，邊緣帶飛濺的乾墨點。`
- **命中型**：`重擊命中的瞬間全畫面褪成手繪黑白稿，只有接觸點的白光刺目，放射線為手繪筆觸所繪、歪扭而尖銳，隨後色彩伴隨火花一同炸回。`

- ⛔ 嚴禁：`★插入黑白閃 #1`、`<黑白閃 2幀>` —— 術語標籤屬工程標記，投餵稿零標記是硬底線。
- **標準三連**：純黑背景極簡構圖（蓄力）→ 黑白閃（頂點）→ 彩色爆發（釋放）。
