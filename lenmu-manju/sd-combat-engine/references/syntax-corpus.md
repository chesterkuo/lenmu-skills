# 分鏡句法母版庫（鐵律0/0.5 的句法骨架源）

**定位**：從多輪實戰分鏡中沉澱的可複用句法模式庫。第一部分六類通用句式是八類自然句母版的案例語料源；第二部分十一類題材句法與打戲文戲法術專項對應；第三部分7種標準收束模式與結尾動態收束規則互補；第四部分運鏡鏈速查與鏡頭語言庫同源；第五部分特效構造速查與附錄A三層複合元素庫（見 moves-library.md）配套；第六部分節奏曲線速查與全局節奏規劃配合。

**用法**：寫分鏡時按任務類型查閱對應章節，提取句式骨架，替換角色/武器/特效/場景參數，熔成自然句輸出。按內容相似度靈活調用（鐵律36②）：分鏡內容與庫內題材/句式相似時才調用對應章節——**提骨架、換參數、熔成自己為這場戲現寫的句子，參考不抄襲**，禁止整段照搬、禁止只換角色名不換寫法、禁止把模板當字段填空。開場必須過鐵律35（開局即超高速激戰中段、禁開場慢鏡、禁首幀碰撞定格）；結尾從7種標準收束模式中選取（禁止雙方同框擺pose）。

🔴鐵律：所有句法最終必須回落到完整自然句，禁止關鍵詞袋、禁止豎線串、禁止"內容｜內容｜"。

## 第一部分 · 通用句法母版（六類基礎句式）

### 1.1 運鏡-動作咬合句（最核心·每鏡必用）

**骨架**：[複合運鏡起手：焦段+機位此刻空間位置+怎麼動(視覺目標)] → [人物在這個鏡頭裡完成發力動作，同句帶出特效+氣場+粒子] → [運鏡再動：運到哪/跟什麼] → [下一動作命中：三層特效+動作與環境同拍炸裂+衝擊幀+鏡頭受力]


**仿寫要點**：①運鏡和動作寫在同一條長句裡，不分成【位移】【運鏡】兩個標籤塊；②每個運鏡動作必須寫清"此刻在哪個空間位置、對準/跟隨什麼、運到哪"；③運鏡方向=事件發生方向（能量上衝鏡頭抬升、火浪逼來鏡頭後撤、命中鏡頭猛沉回彈）；④同一種運鏡持續≤2秒，同一種景別持續≤3秒。

### 1.2 特效三層構造句（每次命中/揮擊必用）

**骨架**：主體層(動態動詞+質感名詞) + 邊緣層(動態動詞+質感名詞) + 表面層(動態動詞+質感名詞) → 沿明確軸線飛行 → 命中：核心強光(白/金最亮) → 中層主色霧化擴散 → 外層暗色碎片遵循重力飛濺


**仿寫要點**：①三層各給一個動態動詞+一個質感名詞；②三混合同框：能量體+水墨+流體必須同一拍同時在場、互相絞纏；③特效尺寸必須走尺度四件套；④首現寫全，後續命中只錨定名稱+寫這一拍獨有變化。

### 1.3 打擊反饋鏈句（每次命中必用）

**骨架**：命中點(肉陷阻滯/形變凹陷/火花能量爆開) → 身體(弓身/後仰/旋轉飛出/雙腳離地拖行) → 武器(回彈震顫/脫手飛出/插入地面) → 環境(地面龜裂/建築崩塌/塵浪碎石) → 鏡頭(震動/後挫/被衝擊波推開/瞬態失焦)


**仿寫要點**：①反饋按鏈條傳導，每層都要有畫面，禁止只寫"打中了"；②震屏方向掛鉤攻擊方向：橫斬左右震，縱劈上下震，大招全向+5°旋轉分量；③環境破壞鏈式因果：拳風颳地→碎石飛→砸裂岩層→炸起塵柱，有先後順序；④輕擊=鏡頭微震+小碎片；重擊=鏡頭短促震動+衝擊環+碎石雨；終結=鏡頭被衝擊波推後飛+劇烈震動+大範圍崩塌。

### 1.4 蓄力壓縮句（大招前必用·≤0.25秒且在高速動作中完成）

**骨架**：手/眼/刃特寫 → 粒子從八方螺旋匯聚 → 材質微觀細節 → 臨界萬物懸停(升格/子彈時間) → 鏡頭微震蓄壓


**仿寫要點**：①蓄力必須有微觀特寫（手部結印/武器刃口電弧/符文流轉/腳步蹬地碎裂/肌肉發力）；②蓄力期畫面不許靜止——法陣邊緣自動絞殺+敵方遠程反擊砸在屏障上+角色自身微沉浮/衣發狂舞；③蓄力越久爆發越狠，但打戲交鋒段蓄力只能在高速位移或連段中完成；④臨界瞬間用升格/子彈時間製造窒息感，與前後晃動形成反差。

### 1.5 群體結構句（群戰/萬劍/妖潮必用）

**骨架**：先定義群體組織結構(幾路/幾層/前部中部尾部) → 整體運動方式(魚群/潮水/星河同相位) → 個體在結構裡分工 → 鏡頭停在群體外部看整體輪廓


**仿寫要點**：①禁止"密密麻麻糊一團"，先定義分幾路、分幾層、每路的前部-中部-尾部；②整體像深海魚群/星河/潮水同相位擺動，鏡頭停在群體外部看整體輪廓與S形/放射動線；③個體只在命中瞬間給近景，不追單個；④清場終結模式：躍起懸空→滯空蓄力→連續數十道月牙劍氣脫手→扇形地毯式覆蓋→每擊獨立爆炸逐次延伸→最後一道體積加倍炸出深壑。

### 1.6 收勢/延遲揭示句（結尾必用·禁止雙方同框擺pose）

**骨架**：動作收束(入鞘/合扇/咔噠) → 極短時間凍結 → 裂紋/效果延遲蔓延 → 延遲爆發或粒子逆流回收 → 鏡頭勻速拉遠留動態背影與被改變的世界


**仿寫要點**：①結尾必須是運動中收束/單方背影/宏觀破壞餘波/遺物定場；②人物越來越小卻始終居中；③最後0.5-1秒可放緩節奏收束，但人物必須在運動中（轉身離開/收刀入鞘/緩步前行/滑行收勢）。

- **模式C·空間法則寫法**：空間法則不寫"能量爆炸"，寫"空間本身在摺疊收縮/撕裂膨脹"——物質被空間摺疊擠壓成極薄一層、碰撞點膨脹成"空間消失的圓洞"、圓洞邊緣是不屬於任何顏色的混沌色。
