## 一、法術輸出五件套（缺一不可）

凡輸出法術/大場面鏡頭，五件套必須齊備，缺一即廢鏡重寫：

1. **特效參數表**——形態／尺寸／顏色／粒子；
2. **視覺比例尺**——人形參照，人物渺小如蟻（詳見 4.0.2 比例尺鐵律，見下第三節）；
3. **EWS 鏡頭**——≥1 秒大遠景展示法術全貌與人形渺小的對比；
4. **聲音五層**——環境／動作／特效／音樂／靜默爆發；
5. **衝擊幀**——法術對沖／命中／爆發瞬間必須觸發（**對沖用終結級，命中用重擊級**，詳見 `combat-iron-laws.md` 鐵律11打擊感體系）。

> 🔴修仙法術輸出必含五件套：特效參數表 + 視覺比例尺 + EWS鏡頭 + 聲音五層 + 衝擊幀。缺一不可。

## 二、法術三段式時序

法術內容一律按三段式展開寫進時間軸，禁止只寫"釋放法術"：

- **蓄力段**：結印／吟唱／舉武器 + 靈力聚集 + 身體變化 + 環境反饋；
- **釋放段**：發力動作 + 法術發射／爆發／展開 + 沿軌跡運動；
- **效果段**：命中／展開效果 + 目標反應 + 環境破壞 + 施法者硬直虛弱。

配套**法術參數表（逐法術必填 11 字段）**：

> 法術名／屬性／等級／能量來源／蓄力時間／釋放時間／冷卻硬直／視覺形態（顏色+形狀+材質+尺寸）／規格尺寸（直徑/高度/覆蓋半徑/電弧跨度）／物理交互／粒子效果

### 3.1 能量消耗與冷卻鐵律（禁止連續放大招）

- 小法術：消耗5%，無冷卻，可連續釋放；
- 標準級：消耗15%，冷卻1-2秒；
- 絕技級：消耗35%，冷卻3-5秒，釋放後硬直1秒（破綻期）；
- 終極級：消耗70%+，冷卻10秒+，釋放後虛弱（靈力迴流，動作遲緩2-3秒）。

❌錯誤示例："A連續放五個焚天火蓮，每個直徑100米，精準命中B，B每次剛好躲開，A不累"（能量消耗不合理、範圍與精度矛盾、無蓄力冷卻）。

## 四、大場面視覺比例尺鐵律（觸發：大範圍特效/範圍傷害/終極技/AOE/天劫/滅城/毀山/萬軍）

違反任一條，該分鏡標記為"生成失敗"，必須重新生成。

- **鐵律6-1 環境描述必須包含"視覺比例尺"**：每次描寫大場面/範圍傷害特效時，必須在環境描述中強制插入至少一處"視覺比例尺"——用一個已知尺寸的人類角色作為參照物，反襯特效的宏大尺度。比例尺參照物必須為人形角色（主角或配角均可），且必須明確寫出角色在特效中的相對位置與視覺佔比。禁止僅用抽象形容詞（如"巨大""宏偉""遮天蔽日""毀天滅地"）描述規模，必須用具體的人體參照來量化。
  - ✅"修士站在雷柱底部，身形僅如芝麻大小，紫藍色天柱雷光直徑超過百米，電弧向四周延伸數百米，人物在雷光映照下渺小如蟻。"
  - ✅"萬千飛劍如銀色洪流從地底湧出，他立於劍陣邊緣，萬千柄飛劍在他頭頂交織成直徑千米的漩渦，他渺小得如同站在暴風雨中的螻蟻。"
  - ❌"雷柱直徑超過百米，威力巨大。"（缺少人形參照物，無法建立視覺比例）
  - ❌"火蓮升騰，遮天蔽日，毀天滅地。"（純抽象形容詞，無具體比例尺）
- **鐵律6-2 10秒時序中必須包含至少1秒的 EWS 鏡頭**：EWS 鏡頭必須滿足——a) 人物佔畫面≤5%，如芝麻/螻蟻/米粒/塵埃般渺小；b) 必須同時包含人形角色（作為比例尺參照）和特效全貌（作為宏大主體）；c) 運鏡必須配合 EWS 使用 PULL（後拉）或 CRANE-U（高空升降）或 AERIAL（航拍）；d) EWS 鏡頭可嵌入10秒時間軸的任何位置（起手/發展/收尾均可），但必須明確標註時間區間，且時長≥1秒；e) 描述必須同時包含"比例尺參照"與"特效全貌"，缺一不可。
- **鐵律6-3 EWS 鏡頭的觸發頻率與去重鎖**：a) 同一場大場面戰鬥中 EWS 鏡頭最多出現2次，避免審美疲勞；b) 繼承段落若上一段已用過 EWS，本段必須使用不同角度（上一段 AERIAL 航拍 → 本段改 CRANE-U 高空升降或 PULL 後拉），禁止重複同一機位；c) EWS 的1秒時長可拆分為更短子鏡頭（0.5s+0.5s），但必須保持 EWS 景別不變且總時長≥1秒；d) 整場戰鬥多個鏡頭都涉及同一場大場面特效時，只有第一個鏡頭需要觸發 EWS+比例尺，後續鏡頭可僅保留比例尺描述（無需 EWS 景別），以保持節奏變化。

### 4.1 巨獸/法相/巨物召喚比例尺鐵律（與 EWS 規則區分使用）

**核心原則：爆炸山崩看 EWS，巨獸召喚看人前獸後正面仰拍。**

- **鐵律7-1**：召喚巨獸/巨龍/法相時，主表現鏡頭必須使用正面低仰角構圖，禁止直接單純切 EWS 大遠景作為主表現鏡頭；EWS 僅可作為補充環境全景。（原因：EWS 會把人物和巨獸都拉遠，削弱"人物站在巨獸前"的壓迫感）
- **鐵律7-2 空間層級強制**：人物位於畫面前景下方中央，巨獸/巨物位於人物正後方，前後層次清晰；禁止巨獸跑到人物側面、身前；巨獸頭顱、巨爪應懸於人物頭頂上空，製造自上而下的壓迫感。
- **鐵律7-3 尺寸強制標註**：寫明巨物絕對高度（如120米/180米/300米），禁止只寫"巨大無比""遮天蔽日"；人物畫面佔比嚴格控制3%-5%；巨獸身體佔據畫面上方70%-80%，頭部高於雲層或接近雲層。
- **鐵律7-4 鏡頭銜接鎖**：切下一鏡必須繼承巨獸朝向、人物站位、主光源方向；巨獸高度/顏色/形態多鏡嚴格一致，禁止中途變色變形態。
- **鐵律7-5 巨獸質感鐵律（禁止貼圖巨獸，必須實體質感+反重力飄動）**：①鱗片/皮膚有清晰紋理、金屬反光、邊緣銳利、層疊排列、縫隙有暗光；②鬃毛/鬍鬚/尾部毛髮有"反重力飄動感"——在靈力場中向上、向四周懸浮飄動，髮梢緩慢波浪起伏；③爪子/牙齒/角有磨損痕跡、角質紋理、指尖反光、生長紋理；④翅膀有翼膜紋理、血管脈絡、翼骨輪廓，扇動時翼膜彈性形變、翼尖慣性延遲；⑤屬性粒子環繞（黑龍=暗紫電弧+黑色能量碎屑+紫色霧氣；火龍=火星+熔岩碎屑+熱浪扭曲；冰龍=冰晶+寒氣+白色霧靄），從鱗片縫隙/鬃毛/口鼻溢出，密度隨動作變化；⑥體積感與重量感（踏步地面龜裂碎石飛濺、尾巴掃過空氣壓縮音爆、翅膀扇動強氣流吹飛碎石塵土、轉身時鬃毛鬍鬚尾部有慣性延遲）；⑦光影層次（主光從一側打來鱗片有明暗面，自身屬性光作補光，環境光有反射，禁止自發光抹平陰影）；⑧呼吸/微動作（胸腔起伏、眼睛眨動、鼻孔噴吐氣息、尾巴無意識擺動）。

**動作軸內標準寫法（直接套用，替換 [X]）**：
"X.Xs 正面低仰角構圖比例尺強制生效：[角色名]站在畫面下方中央，身形如螻蟻，僅佔畫面3%-5%；[巨獸名稱]如山嶽般從[角色名]身後矗立而起，身體佔據畫面上方75%，巨獸頭顱高於雲層，雙眼亮起[顏色]光芒，前爪懸停在[角色名]頭頂前方，形成巨大壓迫感，鏡頭正面輕微上仰，完整保留人物與巨獸前後層級關係，EWS僅作為後續補充環境鏡頭。"

### 4.2 法天象地特殊比例尺規則（與召喚巨獸區分）

**核心原則：法天象地=角色自身巨化，法相佔據畫面主體，周圍環境/建築/山脈/小人物作為比例尺參照。**

- **鐵律8-1**：法天象地主鏡頭必須低仰角構圖，巨型法相佔據畫面主體（60%-80%），法相頭部接近或高於雲層；必須配合≥1秒 EWS 展示法相與周圍環境的尺度對比，人物（法相）在 EWS 中佔畫面10%-20%（比召喚巨獸的3%-5%大，因為法相本身就是主體）；禁止僅用正面平視，禁止法相只佔畫面一半以下。
- **鐵律8-2**：比例尺靠環境參照物，不靠"小人在前"——法相腳踏山脈（山脈僅到膝蓋）、手摘星辰、頭頂雲層、身旁建築如積木、遠處小人物如螞蟻。內部先定絕對高度（標準級百丈/絕技級千丈/終極級萬丈），落字不寫3333米這類精確值，而用"百丈/千丈/萬丈"＋樓層/山/雲參照物＋畫面佔比表達；禁止只寫"巨大無比"。法相面部/胸口/手掌可有原比例角色虛影/法相核心，體現"這是角色自己變大"而非外部召喚。
- **鐵律8-3**：法相必須是角色自身形態的放大版——服裝顏色、面部特徵、武器、屬性特效全部繼承原角色，只是尺寸放大；表面可有屬性特效（金色符文/電弧/火焰/冰晶），但基礎形態必須和角色一致，禁止變成無關巨獸；角色原比例身體可在法相胸口/眉心/丹田處作為"法相核心"發光，體現操控關係。
- **鐵律8-4 法天象地三級尺寸表**：標準級·初階=法相高百丈（約333米），約100層樓高，山脈到膝蓋，建築到腳踝，消耗靈力35%，持續10秒；絕技級·中階=法相高千丈（約3333米），約1000層樓高，山脈到腰部，雲層在胸口，消耗靈力50%，持續15秒，釋放後虛弱3秒；終極級·圓滿=法相高萬丈（約33333米），頭頂天穹腳踏大地，山脈如土丘，城池如積木，消耗靈力80%+，持續20秒，釋放後虛脫5秒。
- **鐵律8-5 法相質感鐵律（禁止發光貼圖）**：①毛髮/髮絲與原角色髮型一致只是等比放大，隨風飄動有體積層次、髮梢慣性延遲（動作時頭髮晚0.3秒跟隨）；②衣料保留原角色服裝細節，有褶皺、重量感、布料紋理，衣襬翻飛有慣性延遲；③皮膚/面部保留原五官特徵，有紋理、光影明暗、微表情變化；④武器/配飾保留金屬反光、寶石折射、磨損痕跡；⑤屬性粒子環繞流動（金光碎屑/電弧跳躍/火焰翻湧/冰晶飄落/墨點飛濺/符文旋轉），密度隨動作變化；⑥可有半透明能量外層，但核心實體必須清晰可辨；⑦體積感與重量感（轉身衣襬頭髮慣性甩動、踏步地面震動碎石飛濺、抬手氣流擾動粒子）；⑧受場景光源影響，有明暗面，禁止自發光抹平陰影。

**三類巨物比例尺規則總區分**：

## 七、國風水墨特效庫（8種·視頻拆解）

### 7.1 核心理念與調用優先級

以下8種特效從國風仙俠視頻中拆解提煉，每種都有明確的物理邏輯和參數規範，不是籠統的"水墨風"。AI 根據劇本場景自動匹配對應特效，禁止所有國風場景都套同一種模糊水墨。

**調用優先級規則·三級**（AI 自動判斷，禁止越級）：

| 優先級 | 劇本信號 | 調用行為 | 示例 |
|---|---|---|---|
| 1（最高） | 出現"XX領域"明確命名 | 展開完整領域，該領域所有子特效全觸發，且雙方被拉入領域 | "文聖領域展開""進入水墨風領域""太極領域·開" |
| 2 | 出現具體特效名 | 只調用那一個特效，不展開完整領域 | "3D漂浮文字升起""鏡面水面""太極圖旋轉" |
| 3（默認） | 無特別要求，只有場景描述 | 自動匹配最合適的單個特效 | "他在水面上行走"→自動匹配鏡面水面特效 |

禁止：只出現單個特效詞時展開完整領域；出現領域命名時只調用一個特效。

**領域共享規則·雙方被拉入**：出現"XX領域"時，領域是雙方共享的封閉空間，不是單方面 buff——領域從釋放者中心向外擴散，擴散範圍內敵方也被捲入，無法脫離（除非有破領域技能）；領域內所有人（含敵方）外觀受領域風格統一影響（畫鏡領域中敵方也變水墨線條，文字領域中敵方周圍也有文字環繞）；領域規則對雙方生效；穩定段後雙方在領域內交戰，特效作為戰鬥環境持續存在；破領域時領域從邊緣向中心碎裂，視覺風格還原，粒子消散。
領域展開鏡頭語言：起手段 CU 釋放者姿勢 → WHIP 甩鏡看領域擴散 → 敵方被捲入反應（驚訝/凝重） → 展開段 EWS 大遠景展示領域全貌+雙方位置 → 穩定段 ORBIT 環繞/正反打，領域特效作為戰鬥背景。

### 7.2 八種特效規格

**特效①：水墨雲海·速度分層視差**
核心理念：雲層不是均勻流動的整體，而是分近中遠三層，每層獨立方向和速度，層間互相遮擋，製造空間縱深感。
關鍵參數（內部定檔，禁止原樣輸出）：層數≥3層（近景濃墨雲/中景灰雲/遠景淡雲）；速度：近景快（5-10m/s）/中景中速（2-5m/s）/遠景慢（0.5-2m/s）；方向：每層可獨立方向（近景左→右/中景右→左/遠景上→下），禁止全部同方向；邊緣：雲層邊緣有墨色飛白暈染（寬度5-15cm），不是硬邊；大小虛實：前景雲大而實（不透明度80-100%），遠景雲小而虛（不透明度20-40%）；遮擋：近景雲遮擋中景，中景遮擋遠景，Z軸層級明確。

**特效②：陰陽雙魚·材質對立統一**
核心理念：對立角色/生物不要只換顏色，要換材質邏輯。共用一個對稱形態模板，材質參數完全相反（硬vs軟、金屬vs玉石、不透明vs半透明），用材質差異強化陰陽對立。
關鍵參數（內部定檔，禁止原樣輸出）：黑魚=金屬鱗片質感（高光銳利/反射率80%）+半透明水墨鰭（不透明度50%）+金色鰭邊（自發光）；白魚=玉石光滑無鱗（漫反射/高光柔和）+絲綢長尾鰭（布料物理飄動）+淡金紋理（亞光）；形態完全對稱（大小/姿態/運動軌跡鏡像）；尾鰭用絲綢布料物理（重量/風力/慣性）；材質對立：硬vs軟 / 金屬vs玉石 / 不透明vs半透明 / 高光銳利vs漫反射柔和。

**特效③：太極圖·流體慣性拖尾【全片最標誌性·優先學】**
核心理念：太極圖不是靜態貼圖，黑白兩色是真實流體模擬。旋轉時有慣性拖尾（流體被甩出），S形分界線有溼畫法暈染混合帶，人物站在魚眼圓台上隨流體一起轉。慢旋轉才有史詩感。
關鍵參數（內部定檔，禁止原樣輸出）：必須真實流體（Navier-Stokes），不是旋轉的圓形貼圖；慣性拖尾長度為半徑的10-20%，拖尾逐漸消散；S形黑白交界處有10%-15%寬度的灰色混合帶（溼畫法），不是銳利分界線；旋轉速度極慢，約20秒一圈（角速度0.05rad/s）；人物腳下白色/黑色圓台，與流體接觸處有漣漪，人物有投影；人物站在圓台上隨流體一起旋轉，不是流體轉人不動。

**特效④：3D漂浮書法·字陣縱深【國風視頻靈魂·優先學】**
核心理念：書法字不是平面字幕，而是豎排有可見厚度的3D物體，在空間中高低錯落漂浮。用景深分前中後三層，鎏金金字自發光有流光沿筆畫遊走，濃墨黑字吸光有飛白。字從流體中"生長/升起"，升起時墨跡未乾有墨滴滴落。字經過人物時字光掃過人物表面。
關鍵參數（內部定檔，禁止原樣輸出）：文字有5-15cm厚度，旋轉時可見側面，不能是平面貼片；景深分層：大字在前（虛焦模糊）/中字在人物周圍（實焦清晰）/小字在後（虛焦模糊）；鎏金金字自發光（亮度200-300nit），流光沿筆畫移動（速度2-5cm/s），金屬鎏金質感；濃墨黑字吸光（亮度<20nit），邊緣有飛白，墨跡未乾質感；從流體中"生長/升起"（0.5-1秒從無到有），升起時底部墨跡未乾，有墨滴滴落（3-5滴/字）；文字經過人物時字光掃過人物表面；豎排從右向左，毛筆書法字體（行楷/草書），有飛白墨暈。

**特效⑤：鏡面墨水面·反射與漣漪【成本最低氛圍感最強·優先學】**
核心理念：水面是純黑色高反射鏡面，能反射天空雲層和人物。不同物體接觸水面產生不同痕跡——腳=同心圓漣漪、魚=V形尾跡、魚躍出=爆炸水花。漣漪物理正確（同心圓擴散、振幅遞減、遇物體反射）。水面用純黑/深灰，反射用亮白，高反差才有水墨感。
關鍵參數（內部定檔，禁止原樣輸出）：水面純黑色高反射鏡面（反射率80-90%），不是透明水；反射內容包括天空雲層、人物倒影、書法字倒影；漣漪同心圓擴散，振幅隨距離遞減（每米衰減30%），遇物體有反射波；赤腳行走=同心圓漣漪（半徑0.5-1米，振幅2-5cm，持續2-3秒）；魚遊動=V形墨色水痕（夾角30-45°，長度為魚身3-5倍）；魚躍出=爆炸水花（墨白雙色，高度1-3米，水滴物理拋物線）；色彩：水面純黑/深灰（RGB 10-30），反射亮白（RGB 200-255）。

**特效⑥：法相凝聚·粒子聚合**
核心理念：大型能量體/法相不要硬切出現，用粒子從雲霧中逐漸聚合成型。聚合過程中周圍環境有互動（雲層被推開、氣流湧動）。關鍵部位（眼睛）用從暗到亮的自發光漸變作為凝聚完成的信號。法相用半透明雲霧材質，不是實體3D模型。
關鍵參數（內部定檔，禁止原樣輸出）：聚合時長3-4秒（從無到完整形態）；粒子為雲霧粒子+能量光點，從四周向中心匯聚，密度從稀疏到密集；巨爪/巨手伸出時把周圍雲層推開（半徑5-10米的清空區），氣流湧動；雙眼從暗到亮自發光漸變（0-3秒從0nit到500nit），作為凝聚完成信號；半透明雲霧材質（不透明度40-60%），邊緣有粒子飄散；法相高度為人物的10-20倍，用 EWS 比例尺展示。

**特效⑦：入畫手勢·負空間儀式感**
核心理念：關鍵技能釋放鏡頭用純黑負空間，只保留主體（手）和光源。光源從主體內部發出（掌心自發光），不是外部打光。背景中用極淡紋理暗示"空間正在變化/展開"，但不完全顯現。結尾用爆閃白屏作為技能釋放的視覺標點。
關鍵參數（內部定檔，禁止原樣輸出）：背景純黑（RGB 0-5），大面積負空間留白佔畫面70-80%；一隻手從上方/前方降下，手指張開，皮膚紋理清晰（青筋/皺紋/老繭）；光源從掌心自發光（暖白#FFF8E7，從下往上照亮手掌），不是外部聚光燈；黑暗中極淡水墨山水紋理（不透明度5-10%），暗示畫卷在黑暗中展開；掌心光爆閃白屏（亮度1000nit，持續0.2-0.3秒）；低角度仰拍，手逐漸佔據畫面中心，緩慢推進。

**特效⑧：水墨遮罩轉場**
核心理念：鏡頭之間不用硬切，用畫面內已有的水墨元素（雲、墨、水花、瞳孔擴散）填滿畫面實現轉場。遮罩元素填滿畫面的瞬間（全黑/全白）切換鏡頭。每個轉場的遮罩元素與前後鏡頭內容有邏輯關聯（瞳孔→魚、水花→太極圖水面）。
關鍵參數（內部定檔，禁止原樣輸出）：遮罩元素必須是畫面內已有的水墨元素（墨龍捲雲/瞳孔墨色擴散/落水水花/墨跡暈染）；遮罩元素100%覆蓋畫面（全黑或全白）的那一幀切換鏡頭；時長0.5-1.5秒；遮罩元素與前後鏡頭內容有因果關係。
四類型：墨雲遮罩——墨龍捲雲湧入填滿畫面→切下一鏡；瞳孔遮罩——角色瞳孔中墨色擴散填滿畫面→切下一鏡；水花遮罩——雙魚落水水花填滿畫面→切太極俯視；墨跡遮罩——書法字墨跡暈染填滿畫面→切下一鏡。
