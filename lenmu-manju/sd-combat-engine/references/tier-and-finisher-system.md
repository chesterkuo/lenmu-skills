> ⚠️ **總綱鐵律（2026-09-02 實測二次翻車後固化）：AI 視頻沒有"靜止表演"能力。** 任何"對峙 2 秒 / 蓄勢待發 / 留白 / 懸停 / 站立 / 特寫定格"類靜止段，模型都渲染成角色呆立幾秒、節奏拖沓。**一切情緒與蓄力必須在運動中完成**：邊打邊蓄、上升途中蓄、後撤中蓄；神態掛載在動作瞬間（甩劍轉身時冷笑），不單獨成段。唯一允許的"定格"是**命中瞬間 1~2 幀微停頓（Hit-Stop）**，其餘靜止段默認禁用。

## 一、 15 秒打戲完播潛力評分（啟發式，非平台預測模型）

$$\text{完播潛力評分} = 0.20 \times \text{開局吸引力} + 0.30 \times \text{節奏呼吸} + 0.25 \times \text{運鏡豐富度} + 0.25 \times \text{情緒拐點}$$

> 說明：該公式是創作者自檢用的**加權啟發式評分**，用於衡量"完播潛力"而非真實完播率預測。**R1 檔可選擇性滿足**（R1 專用版見 `sd-real-engine/references/r1-combat-core.md` §二）。

| 維度 | 權重 | 執行硬指標（R2/R3 檔） |
|---|---|---|
| **開局吸引力** | 20% | **0~1.5 秒內必須發生攻防接觸**（R2/R3 檔：開局 0.5 秒內出現兩種對立招式的正面硬撞 + 命中瞬間微停頓）。第一幀建議雙人同框中近景，避免遠景風景慢熱鋪墊。 |
| **節奏呼吸感** | 30% | 快慢交替，同節奏連續 $\le 5$ 秒。前面極速密集的連打，用**命中瞬間 1~2 幀微停頓（Hit-Stop）**或瞬間加速製造反差，**禁用慢鏡/升格**（2026-09-02 實測破壞節奏）。 |
| **運鏡豐富度** | 25% | **同運鏡 $\le 2$ 秒，同景別 $\le 3$ 秒**。重磅終結招式採用三段式運鏡（低仰蓄力 $\rightarrow$ 俯衝跟隨 $\rightarrow$ 碰撞定格）。 |
| **情緒拐點** | 25% | 在 8~12 秒區間必須出現一次局勢逆轉、破防爆發或破綻抓取，讓觀眾情緒劇烈反彈。 |
| **以高潮收尾** | 核心 | **R2/R3 檔**：禁止 0.5 秒平緩收尾幀（如收腿落地/髮絲飄落/氣焰消散）。最後一幀停留在終結技命中、重創失衡、衝擊波炸裂、碎石掀飛或倒地嵌牆的最高潮定格。**R1 檔**：允許剋制收勢或懸念收尾。 |

### 開局硬撞新變體：零幀瞬移起手 ＋ 彈射迎擊（2026-09-04 吸收）

- **攻方零幀瞬移貼臉**：第一幀即瞬移至對手面門前出招（殘影/空間撕裂作瞬移痕跡），省略衝刺過程，開局衝擊力拉滿；
- **守方彈射迎擊對沖**：守方不是原地捱打——彈射起跳/蹬地迎擊，與攻方在空中或近身位對沖碰撞；
- 仍守開局鐵律：0.5 秒內出現對立招式硬撞 + 命中瞬間微停頓；瞬移必須有視覺痕跡（殘影/黑色空間裂隙/空氣扭曲），禁無來由跳切。

## 二、 視覺巔峰五要素（最高觸發原則）

$$\text{視覺巔峰} = \text{大幅動作} + \text{快節奏} + \text{全景/中景空間} + \text{特效生長} + \text{三段運鏡}$$

* 五者必須在同一時間窗口同時爆發。缺任何一條都會導致視覺降級：
  * 缺大幅動作 $\rightarrow$ 全景畫面空洞；
  * 缺快節奏 $\rightarrow$ 畫面拖沓無力；
  * 缺全景/中景 $\rightarrow$ 局部特寫看不到張力；
  * 缺特效生長 $\rightarrow$ 缺乏視覺爆點；
  * 缺三段運鏡 $\rightarrow$ 像舞台劇擺拍。

## 三、 終結技三幕結構（破局 $\rightarrow$ 綻放 $\rightarrow$ 餘震）

所有大招與終結技必須按三幕邏輯展開，**禁止一擊直接結束**：

```
┌─────────────────────────┐       ┌─────────────────────────┐       ┌─────────────────────────┐
│   第一幕 · 破局 (Break)  │ ───>  │   第二幕 · 綻放 (Burst)  │ ───>  │   第三幕 · 餘震 (Shock)  │
│ 打破攻防平衡, 製造絕對破綻│       │ 大招全力輸出, 視覺巔峰  │       │ 衝擊擴散, 骨肉形變與地裂 │
└─────────────────────────┘       └─────────────────────────┘       └─────────────────────────┘
```

### 1. 第一幕 · 破局（打破當前攻防平衡，0.5~1.0s）
* **化勁/借力破防**：掌心一搭引開對方格擋，防線瞬間向兩側崩開；
* **重擊破格**：全力一擊砸在雙臂上，硬生生彈開防禦架子；
* **下盤破壞**：貼地掃腿/踩腳截腿，直接摧毀對方支撐根基；
* **入身/走圈繞背**：踏入攻擊線內側繞至死角，正面防守全部失效；
* **時空截擊**：在對方出招啟動瞬間以更快速度截斷其前臂，迫使其防禦崩潰。

### 2. 第二幕 · 綻放（大招全力輸出，1.5~2.5s）
* **凌空下劈 / 踏空暴扣**：騰空至最高點，腿/武器如重斧自上而下全力劈落，重力加持；
* **貫穿式寸勁直擊**：半步崩拳/穿心訂橋/寸勁標指，勁力聚於一點直貫心口，空氣被擊穿形成音爆氣穴；
* **多段旋風連斬/連踢**：540°水平旋風腿/千霜環身斬/旋身連環鏟，離心力疊加形成風暴；
* **神兵/神能絕殺**：
  * 劍法：紅紫/冷白巨型滿月劍光波正面貫穿，萬劍歸宗自虛空下墜；
  * 太刀居合：時停霜幕破裂，居合一閃拔刀，空間撕裂出細微電痕；
  * 火焰重斬：火紅刀焰收束為極亮火核後爆燃成巨型彎月火海；
  * 摔投貫地：過肩摔/裡投/雙膝跪壓，將對手整個身軀沿巨大弧線轟入地面。

### 3. 第三幕 · 餘震（終結技後的物理與環境反饋，1.0~1.5s）
* **地面碎裂與塌陷**：命中點地面呈蛛網狀放射性龜裂，碎石受氣浪掀起滯空；
* **環形衝擊波擴散**：以命中接觸點為圓心，高壓氣浪呈環形向外狂暴震盪，掀起塵簾；
* **受擊者形變與嵌入**：受擊者身軀劇烈弓成蝦形，倒飛數米深嵌水泥牆體或砸裂地面；
* **氣血/暗勁透體**：後背衣物"砰"地炸出放射狀微孔，血霧自嘴角/創口呈錐形噴散；
* **終幀定格法則**：視頻以最炸裂的瞬間（衝擊波擴散/骨碎/嵌牆/刀光定格）作為最後一幀，嚴禁加入 0.5s 平靜收勢。

## 五、 特效生長三段論（時間維度）

大招特效絕不能"啪"地直接滿屏，必須呈現由內而外的生長過程：

1. **萌芽期（0.3~0.5s，攻擊啟動）**：出招點（指尖/拳面/刀格）泛起微弱但清晰的高亮星芒或氣旋，預告大招來臨，拉滿觀眾期待；
2. **生長期（0.5~1.0s，位移與蓄力推進）**：能量沿出招軌跡快速膨脹壯大，密度與亮度呈梯度倍增，向攻擊部位核心收束壓縮；
3. **綻放期（0.2~0.5s，命中瞬間）**：能量在接觸點徹底引爆，炸開巨型環形衝擊波、滿月光刃或地裂氣浪，釋放全部張力；
4. **餘韻層（0.3~0.5s，環境留痕）**：地面焦痕冒煙、冰晶碎屑飄散、空氣熱扭曲波紋久久不散。

**段落分配**：前段（0-3s）一招一炸、開局亮眼即收；中段（3-12s）連打零特效保持乾淨、收尾重擊帶特效給節奏感；後段（12-15s）特效生長全開（萌芽 $\rightarrow$ 壯大 $\rightarrow$ 巔峰綻放），衝擊波炸裂收尾。

> 特效**寫法**（手繪化 / 分層 / 負面詞）歸 `vfx-rendering-mandate.md`；本節只管**生長的時間結構**。

## 六、 終結技前呼吸幀與急停彈射法則

$$\text{急停彈射效應} = \text{前置高速密集對攻} (\ge 1.5\text{s}) \rightarrow \text{瞬間極慢/定格呼吸幀} (0.3\sim 0.5\text{s}) \rightarrow \text{絕殺爆發}$$

* **原理**：沒有高速鋪墊的定格是無聊停頓；只有在前段高速機槍對攻後，畫面突然插入 0.3 秒極慢鏡頭（汗珠滯空、眼神精光一閃、髮絲懸停、小腹抱氣），速度差瞬間形成"情緒彈簧"，將觀眾心理預期直接彈射進最終的絕殺大招中！
