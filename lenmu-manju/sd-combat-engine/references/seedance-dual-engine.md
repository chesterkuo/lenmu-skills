# Seedance 雙檔轉譯引擎與雙軌制判定

> 精編自《電影工業級分鏡提示詞生成器 v13.0》

## 〇、中樞定位

本文件是打戲分鏡的**輸出層轉譯底座**：提供【寫實版 vs 修仙版】雙軌制判定，以及【Seedance 2.0（單鏡切片）vs Seedance 2.5（一鏡成片）】的雙檔提示詞轉譯引擎，並彙集打戲特效介質三大鐵律（38／39／44）與 Seedance 2.5 官方規範（鐵律50）。

> 投餵格式權威在總控 short-drama-director 的 model-adapters.md（七段式）；本文件只管打戲分鏡內容按 Seedance 雙檔語法的適配轉譯，不另立投餵格式。

## 一、Seedance 雙檔提示詞轉譯引擎（2.0 vs 2.5）

| 維度 | Seedance 2.0 檔位（單鏡切片模版） | Seedance 2.5 檔位（30s 一鏡成片模版） |
|---|---|---|
| **單段時長** | 5s / 10s / 15s 單鏡頭獨立生成 | 30s 完整長視頻直出，多鏡頭連續敘事 |
| **時序控制** | 鏡頭序號（`Shot 1`、`Shot 2`）或細切時碼 | **嚴格使用整數秒時間戳**（`0-7秒`、`7-15秒`、`15-23秒`、`23-30秒`） |
| **動作密度** | 每 2~3 秒 1 個核心攻防動詞 + 1 個受力反饋 | 遵循「概括動線 + 少數記憶點動作」，嚴禁 3 秒內堆 10 個微操 |
| **音頻控制** | 需外部掛載音頻或後置 BGM | 原生音頻自然句（`生成金屬碰撞聲與風雨聲，無bgm`） |
| **多模態參考** | 1~5 個主體圖/首尾幀參考 | 最多 50 個參考素材，支持多視圖主體圖與連續時間戳編輯 |
| **收束模式** | 協議 A/B/C/D 均可適用 | 推薦協議 C（光粒解構）與協議 D（反向錯車背向出畫硬切） |

**檔位選擇**：總控已鎖定目標模型檔位時跟隨總控；未指定時，單場打戲（≤15秒）走 2.0 檔單鏡切片，完整打鬥段落（20~30秒連續敘事）走 2.5 檔一鏡成片。

## 二、雙軌制判定邏輯與參數替換規則

### 2.1 版本判斷邏輯（按優先級）

**優先級 1 · 角色設定**
- 修仙者／修真者／武者（有內力）／妖／魔／仙／神 → 自動調用【修仙版】
- 普通人／特種兵／拳手／警察／黑幫／現代軍人 → 自動調用【寫實版】

**優先級 2 · 關鍵詞觸發**
- 修仙版觸發詞：靈力、劍氣、法術、宗門、渡劫、元嬰、金丹、法陣、御劍、真元、神識、符籙、魔氣、仙氣。
- 寫實版觸發詞：都市、現代、格鬥、拳擊、武術、散打、搏擊、街頭、擂台、MMA、劍道。

**優先級 3 · 場景描寫**
- 有超自然能力（隔空取物／能量爆炸／虛空懸浮）→ 修仙版；
- 純物理格鬥（拳拳到肉／撞牆碎物）→ 寫實版。

### 2.2 混合場景過渡規則（都市修仙／解封爆發）

- **默認狀態**：使用【寫實版】（日常格鬥／近身肉搏）；
- **爆發切換信號**：靈力升騰、眼睛發光、武器浮現符文、碎石懸浮 → 命中瞬間疊加【修仙版】能量爆炸，運鏡切超廣角大遠景；
- **回落信號**：靈氣收斂、光芒熄滅 → 切回【寫實版】。

> 本模塊是「混合場景（都市玄幻爆發）」的詳細展開，不替代雙軌制：純仙俠/玄幻劇全程用修仙版；純都市/現代劇全程用寫實版；只有"日常寫實+修仙爆發頻繁切換"的混合題材才使用本小節的雙態切換。打戲通用規則（八步鏈/鐵律9特效/招式庫/運鏡五種融合句式/打擊感體系）在能力爆發態中全部適用，本小節只規定態切換和能力受限特例，不改變打戲本身的寫法。

#### 2.2.1 雙態切換信號與過渡

**雙態切換總覽**：

| 維度 | 日常寫實態 | 能力爆發態 |
|---|---|---|
| 特效 | 無超自然特效，純物理 | 法陣/靈力/法術特效（附錄A三層元素） |
| 氣場 | 無 | 每節點綁定一個流動態寫進動作句（鐵律9/26，參數內部化） |
| 畫質 | 膠片顆粒+生活質感+自然光 | 同畫質+特效光+能量粒子 |
| 運鏡 | 手持/斯坦尼康/固定，紀實感 | ACT/FPV/升降，衝擊感 |
| 聲音 | 環境音+Foley | 環境音+法術音效+低頻boom |
| 角色狀態 | 正常穿著/無發光 | 靈力霧氣/眼睛發光/符文浮現 |

**寫實→能力爆發態（觸發信號，出現任意一個即切換）**：
①角色周身靈力霧氣升騰/真氣外露；
②眼睛變色/瞳孔發光/眉心印記亮起；
③武器/飾品發光，表面浮現符文；
④周圍物體懸浮/地面碎石震起/空氣扭曲；
⑤法陣在腳下/空中展開；
⑥角色台詞暗示（"認真了""不再留手""解封"）。

**過渡方式（1-2幀，必須有因果，禁止硬切）**：
- 靈力霧氣從角色身體向外擴散，霧氣所過之處畫面色彩微調（飽和度微升/對比度增強）；
- 法陣從一個光點擴展成完整陣法，光從陣紋中湧出照亮環境；
- 眼睛發光特寫→拉中景，角色已被氣場包圍。

**能力爆發態→寫實態（回落信號）**：
靈力霧氣消散/真氣收回體內；眼睛恢復正常/符文熄滅；法陣碎裂成光點消散；角色力竭/睡著/主動收功；戰鬥結束。

**回落過渡方式**：靈力霧氣迴流身體，最後一絲光從指尖收回；法陣碎裂成光粒向上飄散，光粒消散後畫面恢復日常色調；角色打哈欠→靈力像洩氣一樣從身上漏走→恢復正常。

#### 2.2.2 能力受限角色爆發態降級表

🔴特例聲明：以下特效降級規則**僅適用於劇本明確設定為能力受限的角色**（幼童身體/重傷/封印中/靈力耗盡/修為被廢等），且僅在該角色親自施法時生效。正常修仙角色的打戲仍按全尺寸（上移一檔：常規起手70-100米/重擊100-160米/終結160-310米/滅世310米以上）+周身氣場（半徑5-8米）執行，**不得濫用降級**。

當施法者是幼童/受傷/靈力不足的角色時，能力爆發態特效降級+不穩定：

| 項目 | 正常修仙版 | 能力受限版 |
|---|---|---|
| 法陣尺寸 | 數米至數十米 | 巴掌大到臉盆大，可能只有半個 |
| 法術尺寸 | 攻擊起手即70-100米（上移，重擊100-160/終結160-310） | 縮小到1-5米，甚至只有一束光 |
| 穩定性 | 穩定持續 | 閃爍/忽明忽暗/中途熄滅/顏色不對 |
| 氣場 | 半徑5-8米霧氣 | 半徑0.5-1米微弱霧氣，時有時無 |
| 命中效果 | 三層能量爆炸 | 效果縮水（炸個坑/吹陣風/點亮燈泡） |
| 持續時間 | 整場戰鬥 | 數秒至十幾秒，然後力竭 |

**寫法要求**：
- 特效仍按附錄A三層元素寫，但尺寸用"巴掌大""一束""臉盆大小"等相對描述。
- 必須寫出不穩定感：閃爍、滋滋聲、中途熄滅、顏色偏差、施法者吃力表情（憋紅臉/手抖/咬嘴唇）。
- 翻車時按"不靠譜能力翻車五段式"處理。
- **偶爾靠譜一次**：在情感/危機頂點，受限角色短暫爆發出完整規格的法術（1-2秒），然後立刻力竭，形成燃點。
- 🔴**召喚物不降級**：召喚物/幫手（如被召喚的神仙）若自身戰力正常，其特效按正常修仙版尺寸，**不因召喚者受限而降級**。

#### 2.2.3 旁觀者反應鏡五型

能力爆發時必須穿插普通人/不知修仙者的反應鏡頭，形成"神仙打架+凡人懵逼"的反差喜劇。

**反應鏡類型（各含動作鏈）**：
- **震驚型**：瞳孔驟縮→下巴微張→後退半步→揉眼睛（以為自己看錯了）；
- **吐槽型**：面無表情→扶額→翻白眼→內心OS吐槽（閉嘴微表情+旁白）；
- **難以置信型**：眨眼→再眨眼→掐自己→接受現實（或拒絕接受）；
- **恐懼型**：臉色發白→後退→躲到障礙物後面→只露出半張臉偷看；
- **崇拜型**：眼睛變星星→嘴巴張開→雙手握拳→變成小迷弟/小迷妹。

**規則（5條）**：
1. 反應鏡**走日常寫實態畫質（無特效）**，與爆發態的華麗特效形成反差。
2. 反應鏡在法術爆發後 **0.5-1秒插入，時長≤1秒**，然後切回 ACT/FPV/POV 沉浸運鏡；**禁止在連擊段/交鋒段中間插入反應鏡打斷節奏**，只能在一擊結束後的間隙插入。
3. 反應鏡用 **35-85mm 中近景/特寫，極淺景深奶油散景**，聚焦表情。
4. 反應鏡可以用誇張 Beat 增強喜劇效果。
5. 旁觀者從"不信→震驚→懷疑→接受→崇拜"的態度轉變要有**漸進弧線**，不能一集就全信了。

#### 2.2.4 混合場景節奏配額

- 日常寫實態佔 **60%-70%**（生活/對話/喜劇/賣萌），能力爆發態佔 **30%-40%**（法術/打鬼/召喚）。
- 每次能力爆發態持續**不超過20-30秒**（受限角色更短），然後回到寫實態喘息。
- 爆發態之間**至少間隔1-2分鐘**（2-3個10秒鏡頭）的日常戲，避免審美疲勞。
- 季終/高潮可以連續爆發態，但**必須有旁觀者反應鏡和角色力竭回落做呼吸點**。

### 2.3 雙軌參數替換紀律

- 招式的**發力鏈、軌跡、命中效果照常執行，只換特效介質**（鐵律38轉譯規則）；
- 【修仙版】能量介質從 moves-library.md 三層複合元素調用（三層×三混合×粒子三層）；【寫實版】改用塵土／水霧／火星等物理介質拖尾（鐵律39寫實分支），禁塑料發光特效；
- 版本判定全場鎖定，同一稿內禁止混軌（混合場景按 2.2 過渡規則切換，屬劇情需要而非混軌）。

## 三、特效介質規範（打戲特效三大鐵律）

### 3.1 鐵律38·打鬥分鏡禁光效能量柱·特效一律物理實感

打鬥分鏡**默認禁用一切光效與能量形態特效**——不出現光、光柱、能量柱、能量波、能量球、光刃、光劍氣、發光武器、通體發光、氣場光環、符文發光、粒子光塵、七彩流光等任何「能量可視化」元素。力量感全部用物理實感介質承載。

**允許的特效白名單（物理介質）**：塵土／沙塵暴／塵牆、碎石飛濺／地裂／地面凹坑、木屑／竹屑／紙片、水花／水霧／雨幕激散、雪霧／碎冰屑（物理碎冰，非發光冰晶）、火星／刀刃摩擦火花（瞬間即滅，非持續光效）、布料與髮絲激揚、斷草落葉、煙塵餘燼、汗珠霧化（守 ZeroBlood 協議）、氣浪衝擊的實體漣漪（水面波紋／草伏塵散）、衣物破碎布條、兵器金屬應力白痕。

**轉譯規則**：舊規則／招式庫／附錄A裡出現「能量／光／靈力／劍氣光效」類描述時，調用時一律自動轉譯為物理介質——
- 「劍氣撕裂空氣」→「刀鋒過處塵土被犁開一線、碎石向兩側崩飛」；
- 「能量對沖爆發」→「氣浪對撞掀翻塵牆、地面蛛網狀開裂」；
- 「靈力凝聚」→「周身氣流卷聚塵沙成螺旋」。

招式的發力鏈、軌跡、命中效果照常執行，只換特效介質。

**禁止的寫法**：任何「泛起X光」「湧出能量」「光芒大盛」「光柱沖天」「能量柱轟擊」類表述；武器不發光（劍就是鐵色劍，不是光劍）；不留廉價細絲狀光軌（武器揮動的厚重屬性能量拖尾除外，按鐵律39執行——拖尾是軌跡殘留，武器本體仍不發光）。

**例外通道**：僅當用戶明確點名要「法術／能量／發光」類場面時才解禁，且解禁僅限該次任務、範圍僅限用戶點名部分（如用戶說「最後大招發光」，則只有大招段允許光效，其餘打鬥段仍守本鐵律）；武器揮動的屬性能量拖尾為鐵律39常設白名單，不受本鐵律限制（拖尾≠武器本體發光≠光柱能量柱，兩者並存：拖尾管「揮動軌跡」，本鐵律管「環境與命中介質」）。

口訣：力量不發光，發光必廉價；塵土碎石水花布，物理實感才是真。

### 3.2 鐵律39·武器揮動必拖厚重能量拖尾·燃燒綢緞光帶

凡打鬥分鏡中的武器揮動（劈／砍／斬／刺／撩／掃／格擋反彈皆算），武器必須拖出厚重濃烈的屬性能量拖尾，**五要素缺一不可**：

1. **燃燒態光帶**：拖尾呈燃燒態光帶，不是細線不是薄霧，是厚實濃重的一條實體質感光帶；
2. **厚重如實體綢緞**：質感厚重如實體綢緞，有重量、有垂墜、有翻卷，像被強風扯住的燃燒綢緞；
3. **邊緣高密度粒子流**：光帶邊緣翻滾著高密度粒子流，粒子持續剝落飛散（粒子類型綁定角色屬性，從 moves-library.md 三層複合元素調用）；
4. **消散緩慢+殘像留痕**：消散緩慢，禁止瞬散；拖尾殘留於空氣中形成短暫的視覺殘像軌跡，收束鏡可用「多條拖尾殘留交織」做戰場留痕與收束標誌（C03拖尾殘網收束同源）；
5. **疊加交織成能量網**：連續多段揮擊的多條拖尾可在空中疊加交織成半透明的能量殘像之網（高階對決／大戰收束標誌）。

**顏色與風格綁定角色屬性**：拖尾顏色／材質／粒子按角色屬性定製，角色簽名全劇一致；不同角色拖尾異色（鐵律33分色同源）。

**與鐵律38的銜接（優先級）**：本鐵律是鐵律38的常設白名單例外——武器本體仍不發光（劍仍是鐵色劍，鐵律38繼續管武器本體），但揮動軌跡上的屬性能量拖尾永遠存在、必寫；環境反饋／命中破壞仍按鐵律38物理介質執行（拖尾是「軌跡殘留」，命中是「物理破壞」，兩者並存不打架）。寫實版（普通人雙軌）默認不帶能量拖尾，改用塵土／水霧實體拖尾，除非用戶點名。

**標準句（C03模式B直接套用）**：[武器]揮出，刃後拖出厚重濃烈的[屬性色]能量拖尾，拖尾呈燃燒態光帶、厚重如實體綢緞，邊緣翻滾著高密度[屬性粒子]流，消散緩慢，在空氣中殘留出半透明的視覺殘像軌跡。

口訣：一揮一綢緞，燃燒不瞬散；粒子滾邊緣，殘像留空中；多揮交織網。

### 3.3 鐵律44·取消光柱能量柱·0.5秒超高速·周身高級屬性粒子·移動對碰動態模糊粒子

**①光柱與能量柱表現全面取消（絕對禁令，無例外通道）**：無論何種場面——包括用戶點名法術／能量／發光解禁時——一律不出現光柱沖天、能量柱對轟、柱狀能量體、光刃光柱對頂；力量與招式的可視化全部改由「周身屬性粒子（本條③）+武器能量拖尾（鐵律39）+物理介質反饋（鐵律38）」承載；大招對轟寫成**兩團完全成型的粒子能量體互相撕咬翻湧、接觸面層層剝落**，不寫成兩根柱子對頂。

**②0.5秒超高速**：開場或任意節奏段起手後0.5秒內即達超高速交戰狀態（鐵律35「開局即中段」的量化硬指標）——首0.5秒內必須完成至少一次完整攻防轉換或一次長距離高速位移，幀率即正常全速+強動態模糊，零鋪墊、零加速過程描寫、零起手蓄勢；此後全場速度基準不低於此檔。

**③周身高級屬性粒子**：每個角色渾身（髮絲、衣袂、皮膚周身、武器纏帶）持續散發與自身屬性對應的高級粒子——
- 顏色嚴格綁定該角色能量主色（三層主色已鎖定）；
- 材質有層次（**核心亮粒+中層霧化+外層碎屑三粒層**）；
- 有流向（靜止對峙時緩速上浮、動作加速時向後倒掠成粒子披風／粒子尾跡）；
- 有密度（隨戰鬥烈度增減、大招蓄力時八方螺旋匯聚）。

此寫法替代一切光環、光暈、通體發光的廉價表現，粒子是「穿在身上的屬性」，不是「罩在外面的光殼」。

**④移動與對碰動態模糊粒子**：高速移動／瞬身／突進／踏空變向時，人物本體與殘影之間拉出方向性動態模糊粒子流（沿運動軸線拖出成片粒子帶、邊緣暈散、速度越快帶越長）；兵刃相交／掌拳對碰／能量對沖的瞬間，迸發高密度屬性粒子+放射狀或環狀動態模糊（雙向對沖時兩色粒子對撞絞成渦流再炸散）——粒子必須帶方向性速度感，禁止靜態飄浮光塵。

**與鐵律38/39的分工**：38管環境與命中的物理介質（默認白名單）、39管武器揮動的厚重拖尾、44管人物周身與移動／對碰的屬性粒子——三者並存；屬性粒子與能量拖尾屬用戶欽定常設白名單，不受38默認禁令限制，但三者都禁止退化為光柱／能量柱／光暈／光殼。

口訣：柱子全砍掉，粒子穿全身；0.5秒上強度，一動一糊皆是力。

## 四、鐵律50·Seedance 2.5 官方提示詞工程規範與避坑底線（六條）

1. **單段時長**：Seedance 2.5 原生支持單段最高 30 秒生成（一鏡成片與多鏡頭敘事均可），無需強制拆成 10 秒；但段內子節點必須按整數秒（2~4 秒）有序排列。
2. **時間戳**：嚴禁小數點與冒號時碼（如 00:03.2），必須整數秒（0-3秒 / 3-7秒）。
3. **嚴禁大分鏡嵌套**：30 秒提示詞不得寫成 S01 0-10s / S02 10-20s / S03 20-30s 這類嵌套場次代碼，必須從 0 秒一路連續推進到結尾。
4. **徹底清洗元指令與代碼符號**：嚴禁出現 <音效：…>、★正面重擊、模式K、協議C、【第一段】等給人類看的標記；模型不理解這些行業術語，反而會被特殊符號與尖括號佔滿有效注意力。
5. **原生音頻與負向控制**：音頻直接在結尾寫自然句（`生成金屬刀劍劈砍碰撞聲、肉體受擊悶響與狂暴雷鳴風雨聲，無背景音樂（無bgm）`）；字幕排除寫（`不要字幕，畫面無任何文字與水印`）；在沒有獨立 Negative 框的文生視頻環境下，嚴禁正文大段堆砌負面詞——長篇「禁止站樁、禁止穿模」會誘發粉色大象效應，必須改為正向動作描述。
6. **與鐵律43 A軌配套**：走單文本框時，本條即鐵律43 A軌（默認單文本框模型：只輸出一條連續乾淨的自然畫面流——畫質基準句→角色·場景·核心設定句→整數秒時間流→結尾自然句收束，嚴禁元指令與代碼符號、嚴禁大段粘貼負面詞列表）的執行細則；走三件套 B軌（有獨立負面框／需要分鏡剪輯稿）時，負面清單隻出現在末尾獨立負面塊裡。

口訣：整數秒、別嵌套、洗乾淨、音頻負向都寫自然句。
