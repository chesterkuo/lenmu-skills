# 打戲速查庫（Combat Cheatsheet · 運鏡鎖 / 動作庫 / 類型專庫）

> **本文檔是打戲引擎規則庫 · 權威文件**
> 融合來源：script-writing-studio 04b（攝影機行為鎖 + 情緒運鏡 + 動作戲 + 武俠兵器 + 超能力 + 戰場群戰 + 自由搏擊）
> 定位：**速查工具**，不是規則庫。命中強運鏡/打鬥/追逐/特殊轉場/複雜攝影機行為時查閱。

---

## 〇、使用原則（7 條）

1. **不替代打戲主結構**：最終仍按本引擎既有規則輸出（八步寫作腦 / 一鏡一動一反饋 / 黃金顆粒度等）。
2. **不替代投餵適配**：本文件只幫選鏡頭和動作節奏；最終提示詞由 `sd-feed-engine` 轉寫。
3. **普通文戲不強制使用**：常規對話、簡單反應鏡頭，不要硬套運鏡組合。
4. **一段只選少量組合**：4-8 秒單元最多 1 個核心組合；10-15 秒單元最多 2-3 個組合。**不要把速查表變成炫技清單。**
5. **組合編號不進最終 prompt**：內部標籤而已，最終提示詞必須寫成畫面語言。
6. **運鏡服務情緒或動作結果**：每個運鏡必須回答"**為什麼這麼動**"。不能只因為好看而動。
7. **攝影機行為鎖優先**：選任何運鏡前，先鎖定攝影機類型/位置/距離/高度/方向/穩定度/速度/起止狀態/禁止項。**不要只寫"手持/固定/跟拍"**，要寫成可執行句。

⚠️ **動作密度回填節奏檔位**：命中打鬥/追逐/強鉤子/危機爆點時默認建議 **高密度動作或強鉤子**；普通緊張調度可建議 **短視頻中高密度**；強情緒凝視或儀式感動作才保留 **電影感中速**。**不要把動作段壓回 1-2 鏡。**

## 一、攝影機行為鎖速查（★ 核心）

> 用於把"固定/手持/退拍/跟拍"等模糊詞，轉成可執行攝影機行為句。

| 行為鎖 | 適合場景 | 可寫的攝影機行為句 | 禁止項 |
|---|---|---|---|
| **固定鎖** | 對峙、審判、儀式感、冷靜觀察、權力壓迫 | 攝影機固定在兩人正前方眼平中景，主體保持畫面中央，不推拉不搖移，只讓人物動作改變畫面 | 禁止隨機漂移、自動推近、無動機變焦、突然換機位 |
| **固定過肩** | 冷靜反打、潛台詞對話、壓住情緒 | 攝影機位於角色A左後方，過角色A右肩固定拍角色B近景，肩膀作前景虛化，鏡頭不移動 | 禁止越過肩膀另一側，禁止突然切到背後反方向 |
| **手持微動** | 剋制焦慮、私密不安、輕紀錄片質感 | 攝影機在角色右前方近景距離手持，隨呼吸輕微上下浮動，主體保持畫面右三分之一 | 禁止劇烈晃動、主體出畫、晃成動作戲 |
| **手持跟拍** | 追逐、逃亡、慌亂移動、壓迫主觀感 | 攝影機在角色右側約 1 米處手持側跟，速度與腳步同步，轉彎時短暫甩動後重新穩住 | 禁止突然越軸、跟丟角色、空間方向反掉 |
| **手持快搖** | 暴怒、突發危險、快速發現目標 | 攝影機先貼近角色面部，角色猛然轉頭時快速甩向目標，運動模糊後停在目標中景 | 禁止無目標甩鏡、連續多次亂甩 |
| **穩定器跟拍** | 角色穿場、進入空間、帶觀眾移動 | 攝影機在角色背後三步距離穩定器跟拍，平穩穿過走廊或人群，肩線保持畫面中央 | 禁止手持晃動、穿過牆體桌椅人群 |
| **前導倒退跟拍** | 角色逼近、邊走邊說、壓迫感增強 | 攝影機在角色正前方胸口高度倒退跟拍，保持上半身中近景，角色前進一步鏡頭同步後退 | 禁止速度忽快忽慢、撞到角色臉上 |
| **側跟/背跟** | 同步移動、追蹤目標、行進對話 | 從角色左側平行跟拍保持半身中景；或從背後三步距離跟拍，前方空間逐漸展開 | 禁止跟拍中改變角色左右位置、突然跳到另一側 |
| **退拍/後撤** | 主體逼近、衝擊、驚嚇、揭示空間 | 主體突然衝向鏡頭，接近瞬間攝影機快速後撤到廣角全景，露出身後阻擋物和空間關係 | 禁止無動機後撤、後撤後空間結構改變 |
| **緩推/窒息推近** | 情緒壓迫、真相逼近、眼神聚焦 | 攝影機從中景緩慢推向角色眼睛特寫，速度逐漸變慢，到眼神處停住 | 禁止空泛"電影感慢推"，必須說明推向什麼 |
| **拉遠/後拉揭示** | 孤立人物、揭示環境、反轉信息 | 從手部或物件特寫緩慢後拉，逐漸露出完整房間和隱藏在畫面深處的人 | 禁止拉遠後丟失主體、揭示信息不明確 |
| **橫移揭示** | 多人站位、空間關係、隱藏物出現 | 攝影機沿桌邊從左向右橫移，前景杯子掠過後依次露出三人左右站位 | 禁止橫移中越過軸線、前景遮擋關鍵表情 |
| **半環繞** | 權力變化、人物被包圍、心理轉向 | 攝影機圍繞角色半環繞 90°，從左側移動到正面，最後停在角色眼平近景 | 禁止 360° 炫技連用、繞到錯誤空間側 |
| **升降/俯仰變化** | 從人到環境、權力高低、命運感 | 攝影機從角色胸口高度緩慢升到頭頂俯視，露出角色被人群圍在中心 | 禁止無功能升降、高度變化導致主體比例變形 |
| **視線搖鏡** | 視線引導、發現目標、信息轉移 | 先拍角色面部，視線移向門口後，攝影機跟隨視線搖向門縫並停住 | 禁止搖向無意義空處、目標不清晰 |
| **甩鏡切** | 急促換角度、動作高潮、轉場 | 動作高潮瞬間向畫面右側快速甩鏡，運動模糊遮滿畫面後切到同方向新角度 | 禁止無目標甩鏡、甩後空間方向反掉 |
| **遮擋轉場** | 自然切換、同場換角度、換場 | 前景人物或門框完全遮住畫面，遮滿瞬間切到下一角度，主體重新清晰 | 禁止遮擋物沒有來源、遮擋後人物站位跳變 |
| **焦點轉移（rack focus）** | 信息揭示、暗線物件、心理轉移 | 攝影機固定不動，先讓前景物件清晰，隨後焦點轉到後景角色眼神 | 禁止焦點對象不明確、同時推拉造成混亂 |
| **長焦壓縮** | 壓迫距離、監視感、人群擠壓 | 使用長焦壓縮空間，前景人群和後景角色距離被壓近，角色像被環境擠住 | 禁止主背景黏成一團，必須保留主體輪廓 |

## 二、運鏡選擇流程

```
① 判斷情緒或動作功能（這一動是為什麼服務？）
② 判斷節奏檔位（動作段默認高密度）
③ 從速查表選 1-2 個核心組合
④ 先寫攝影機行為鎖（類型/位置/高度/方向/速度/起止+禁止項）
⑤ 一段內組合數：4-8 秒 ≤1 個；10-15 秒 ≤2-3 個
⑥ 組合編號不進最終 prompt
⑦ 寫進畫面語言（左/右、前/中/後景、攝影機在哪側）
```

## 三、類型專庫索引

| 類型 | 適用場景 | 核心語法 |
|---|---|---|
| **戰場/群戰/軍陣** | 軍陣、盾牆、騎兵衝鋒、弓箭齊射、攻城、伏擊、多人混戰 | **戰場層次 → 主行動線 → 群體壓力 → 關鍵接觸點 → 戰線結果 → 段末狀態** |
| **武俠兵器** | 刀劍、棍、暗器、武器對招 | 兵器物理邏輯 + 招法拆解 + 接觸即反饋 |

| **自由搏擊** | 現代格鬥、拳腳近身 | 打擊點 + 受擊反應 + 體力消耗 |

## 四、戰場動作速查（戰場/群戰專用）

**空間語法（必寫）**：
```
戰場層次 → 主行動線 → 群體壓力 → 關鍵接觸點 → 戰線結果 → 段末狀態
```

❌ **不要只寫**"萬人混戰、戰場慘烈"
✅ **必須寫清**：主角在哪裡、敵人從哪裡來、鏡頭在哪一側、戰線怎麼變

| 類型 | 可寫動作 | 運鏡建議 |
|---|---|---|
| 盾牆推進 | 前排盾牌從畫面右側壓入，中景長槍從盾縫探出，主角被迫後退 | 低機位廣角，保留盾線方向 |
| 長槍陣 | 槍尖形成斜向線壓向前景，第一支槍擦過主角肩側 | 長焦壓縮槍尖密度，禁止槍桿亂向 |
| 騎兵衝鋒 | 馬蹄從遠景煙塵中逼近，前景士兵舉盾下蹲 | 地面低角度，寫清衝鋒方向 |
| 弓箭齊射 | 遠景弓手抬弓，箭雨從上方斜落，中景盾牌接住第一波 | 先遠景建立，再切盾牌接觸點 |
| 伏擊 | 兩側高處旗影晃動，箭矢從側後方射入隊伍 | 鏡頭跟主角視線轉向伏擊方向 |
| 攻城 | 雲梯靠上城牆，守軍推下滾木，前景士兵散開 | 廣角俯拍建立上下空間 |
| 撤退 | 指揮者後退揮手，前排士兵交替掩護，傷者被拖離中景 | 手持側跟，保持撤退方向 |

**戰場動作分層要求**：前景主角動作 / 中景敵我接觸 / 遠景戰線變化。交接時必須給：前中遠景層次、主行動線、群體壓力、關鍵接觸點、戰線結果。

**不適合本庫的**：兩人精細格鬥、純武俠屋頂追逐、強異能鬥法 → 讀對應子庫。

## 五、工程語言 → 畫面語言轉換（交付前必做）

| 給人看的工程語言 | 給模型的畫面語言 |
|---|---|
| 180 度軸線鎖定 | 角色A始終在畫面左側，角色B始終在畫面右側 |
| 不要越軸 | 攝影機保持在兩人正前方這一側，不切到背後反方向 |
| A2 點位 / B2 點位 | 角色站在茶几左側 / 角色坐在沙發右端 |
| 以沙盤為錨點 | 沙盤位於畫面中央，人物圍繞沙盤左右分佈 |
| 高低落差 2 米 | 一人站在高台上俯視，另一人跪在台階下仰視 |

**推薦用**：左側、右側、前景、中景、遠景、畫面中央、畫面深處、攝影機在窗外/正前方、角色向畫面右側移動。
**謹慎用**：東南西北、180 度軸線、錨點編號、A1/B2 等管理編號。若必須保留點位，**必須同時翻譯成可見畫面**。
