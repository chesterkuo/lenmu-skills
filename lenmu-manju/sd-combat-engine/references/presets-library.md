以下五套為①畫質基準的引用塊模版，按項目風格**全場聲明一次**；未指定時默認首選 3D國漫。

## 三、裝配順序速查

1. 選風格 → 引用塊聲明進①畫質基準；
2. 選場景 → 一句式描述擴寫進②段（補可交互物清單）；
3. 配角色 → 查 `moves-library.md` 九大角色資產卡定武學與勁氣視覺；
4. 定雙軌 → 查 `seedance-dual-engine.md` 雙軌制判定；
5. 寫分鏡 → 按 SKILL.md 五步工作流與鐵律體系執行。
