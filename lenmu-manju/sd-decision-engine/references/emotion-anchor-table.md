# 情緒錨點表（Emotion Anchor Table · 6 列標準格式）

> **本文檔是決策層核心輸出格式 · 權威文件**
> 融合來源：script-writing-studio 04-core-workflow Phase 4.5
> 定位：**決策層 → 分鏡層的交接憑證**。分鏡引擎拿到錨點表後，每個鏡頭必須能對應到某個節拍。

---

## 〇、這是什麼 / 解決什麼問題

**問題**：直接從劇本跳到分鏡，中間沒有"情緒依據"。結果是分鏡設計靠 LLM 當場發揮 → 不穩定、跨段不一致、情緒曲線沒規劃。

**解法**：在分鏡前插入**情緒錨點表**，把"這段戲的情緒怎麼走"先釘死，再設計鏡頭。

---

## 一、標準格式（6 列）

```
【大分鏡 #B01 · 情緒錨點表】

| 節拍 # | 情緒關鍵詞 | 服務的劇本動作 | 情境 ID | 核心組合摘要（80%定死） | 解鎖雷區 |
|---|---|---|---|---|---|
| 節拍 1 | 閒聊試探 | 花十假裝隨口問"你等會去哪" | E07 | 長焦+大光圈+過肩靜態 | — |
| 節拍 2 | 害羞猶豫 | 露夏低頭攪奶茶不敢直視 | E08 | 過肩+長焦+手持微動 | — |
| 節拍 3 | 鼓起勇氣 | 露夏抬頭說出邀請 | E09 | 長焦+仰拍+緩推 | — |
| 節拍 4 | 決斷接受 | 花十掐煙起身答應 | E11 | 微距標點+靜切動 | — |
```

**列說明**：

| 列 | 填寫要求 |
|---|---|
| **節拍 #** | 該段戲的情緒節拍序號（3-5 個） |
| **情緒關鍵詞** | 4-6 字，如"閒聊試探""害羞猶豫"（禁空泛詞如"複雜""微妙"） |
| **服務的劇本動作** | 一句話說清"這個節拍裡角色在做什麼"（必須有具體動作） |
| **情境 ID** | 來自 `context-mapping.md` 的 E01-E15（或用戶自定義 EX01） |
| **核心組合摘要（80%定死）** | 從 ID 表**直接複製**，分鏡層不允許修改 |
| **解鎖雷區** | 若該 ID 解鎖 A 類雷區則標註（如"A1 正面居中"），否則填 "—" |

---

## 二、硬約束（違反即重做）

| # | 約束 | 說明 |
|---|---|---|
| 1 | **每段大分鏡節拍數 3-5 個** | 少於 3 = 戲不夠；多於 5 = 該拆成兩段 |
| 2 | **節拍數 × 每節拍承擔鏡頭數 ≈ 段內總鏡頭數** | 便於與分鏡數量對齊 |
| 3 | **每個節拍必須能用一句話說清"角色情緒/動作"** | 含糊的節拍寫不出有效鏡頭 |
| 4 | **節拍之間必須有變化** | 4 個"害羞"節拍 = 戲沒推進，違反核心原則 |
| 5 | **情境 ID 必須從三處之一獲取** | 基礎表 / 進階表 / 用戶自定義；**禁止 LLM 編造** |
| 6 | **同段內 ID 可重複** | 但核心組合的"動態變化"必須由輔助錨點承擔（避免連續多鏡完全一樣） |

---

## 三、錨點表在管線中的作用（三層位置）

```
① 生成前 —— 每個鏡頭在設計時必須明確對應到某個節拍 + 該節拍的情境 ID
② 生成中 —— 內部四問的 Q1（為什麼用這個鏡頭）+ Q4（解鎖理由）答案直接來自錨點表
③ 生成後 —— 成片預演驗證三件事：
     · 實際情緒曲線 = 錨點表預設曲線？
     · 每個節拍至少 1 個主鏡頭滿足 ID 的 80% 核心組合？（輔助鏡頭允許偏離）
     · 解鎖雷區是否合法？（A 類有白名單理由 / B 類不允許出現）
```

## 四、用戶友好版輸出（情境對照表）

> 錨點表是**工程化版本**（6 列表格）。給用戶看時，另出一份**用戶友好版**——一眼看清每個節拍用了哪個情境思路。

**輸出格式**（在分鏡本體之前打印）：

```
【本段情境對照】
- 節拍 1：閒聊試探 → E07 曖昧試探
- 節拍 2：退縮猶豫 → E08 內向退縮
- 節拍 3：鼓起勇氣 → E09 突破內心
- 節拍 4：動作標點 → E11 乾脆決斷
```

**含解鎖雷區時**：

```
【本段情境對照】
- 節拍 1：儀式肅穆 → E10 儀式威嚴（解鎖 A1 正面居中 · 白名單 ② 儀式感）
- 節拍 2：轉身亮相 → E02 反派登場變體（解鎖 A1 · 白名單 ⑥ 權力凝固）
```

**含用戶自定義時**：

```
【本段情境對照】
- 節拍 2：扭曲過渡 → ★ EX01 VR 入境扭曲（用戶自定義 · 本會話內有效）
```

**注意**：節拍號與情境 ID **不寫進分鏡本體**，全部歸集到此表（分鏡稿保持乾淨）。

## 五、分鏡數量決策說明（每段必輸出一句）

每段大分鏡在分鏡本體之前，必須輸出一句簡短的數量說明：

```
本段選擇 X 個分鏡，原因：____。
```

## 七、與總控體系銜接

| 機制 | 關係 |
|---|---|
| 情緒節拍曲線（`short-drama-director/references/emotion-beat-curve.md`） | 錨點表是**段落級細化版**——曲線管全片，錨點表管單段（3-5 節拍） |
| 分鏡設計八重篩選 | 錨點表的"情境 ID + 核心組合"作為篩選的第一重"情緒匹配"依據 |
| 15 秒完播率結構 | 錨點表在 15 秒結構內分配節拍，不改變結構 |
| 機檢 C 系 | 錨點表不參與機檢（機檢針對投餵稿），但**分鏡層自檢須核對錨點表落實率** |

## 八、快速調用語

- "這段戲做情緒錨點表" → 輸出 6 列表格 + 情境對照表 + 數量說明
- "幫我看情緒曲線對不對" → 核對錨點表節拍變化是否合理
- "這段分鏡有沒有落實錨點表" → 逐鏡核對情境 ID 對應關係
