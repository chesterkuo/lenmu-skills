# 情境映射庫（Context Mapping · E01~E15 + 80/15/5 權重）

> **本文檔是決策層核心規則庫 · 權威文件**
> 融合來源：script-writing-studio 04 模塊「情境映射」機制
> 術語口徑：**全部換算為中文景別體系**（特寫/近景/中景/中近景/全景/遠景/大遠景/微距），禁用 CLOSE-UP / LONG LENS 等英文術語。

## 〇、定位與邊界

**本文件解決一個問題：這場戲該用什麼鏡頭？**（原有體系只回答"怎麼拍"——機位規格、鏡長節奏、景別階梯，但沒有回答"選型依據"。）

- **本文件是"選擇依據層"**：輸出「情境 ID + 核心組合」，作為分鏡設計的**輸入**。
- **本文件不是"規格權威"**：機位角度/焦段/運鏡的**具體寫法**仍以總控 `short-drama-director/references/camera-specs-15rules.md` 與 `sd-storyboard-engine/references/short-drama-camera-system.md` 為唯一權威。
- **優先級**：若本文件的核心組合與已有鐵律衝突（如 15 秒完播率公式、景別階梯躍遷），**一律以鐵律為準**，本文件降級為參考。

## 一、80/15/5 權重機制（核心）

每個節拍選定情境 ID 後，鏡頭設計按三層權重分配：

```
┌─ 核心組合（80% 權重 · 鎖死必用）─────────────────────┐
│ 來自 ID 表"核心組合"列，全部必須用上                  │
│ ❌ 不允許 LLM 替換 / 刪除 / 自由發揮                  │
└───────────────────────────────────────────────────┘
┌─ 輔助錨點（15% 權重 · 選 1-2）────────────────────┐
│ 據劇本細節選 1-2 個，用於增強情緒                    │
│ ✅ 選什麼由 LLM 判斷，但只能從該 ID 的輔助錨點裡選     │
└───────────────────────────────────────────────────┘
┌─ 增強項（5% 權重 · 僅情緒峰值）────────────────────┐
│ 一段大分鏡中最多 1 個鏡頭使用                        │
│ 命中點 = 該段戲的最高情緒峰值                        │
└───────────────────────────────────────────────────┘
```

**設計意圖**：把"能自由發揮"的空間從 100% 壓到 20%。核心組合鎖死保證**穩定性**，輔助+增強保留**創作彈性**。

## 四、輔助錨點池（15% 權重選用）

> 使用規則：為每個節拍從**本池**選 1-2 條，與核心組合疊加。禁止跨 ID 混用。

| 錨點類別 | 可用錨點 |
|---|---|
| **焦段變化** | 換用相鄰焦段（長焦→中長焦 / 廣角→中焦）製造呼吸感 |
| **機位高度** | 微仰 / 微俯（幅度小於核心組合的"仰拍/俯拍"） |
| **前景插入** | 前景加虛化物件（門框/樹葉/酒杯）製造縱深與窺視感 |
| **光線調整** | 側逆光/輪廓光強化主體邊緣；主光從暖轉冷或反之 |
| **運動微調** | 緩推→固定 / 固定→微搖 / 手持微動幅度升級 |
| **空間壓迫** | 壓縮留白 / 加大主體佔比 / 前移後景層 |
| **細節插入** | 加一個手部/眼神/道具的插入鏡頭（不佔額外節拍） |

---

## 五、增強項池（5% 權重 · 每段最多 1 鏡）

> 使用規則：**每段大分鏡最多 1 個鏡頭**使用增強項，且必須命中該段**最高情緒峰值**。濫用即失效。

| 增強項 | 效果 | 使用前提 |
|---|---|---|
| **滑動變焦（Dolly Zoom）** | 空間扭曲、眩暈、認知崩塌 | 頓悟/失控瞬間 |
| **環繞運鏡** | 360° 環繞主體，強調孤立或震撼 | 情緒頂點、身份揭示 |
| **極限景別跳躍** | 大遠景 ↔ 微距直跳，製造視覺重錘 | 轉折點、時間跳躍 |
| **升降鏡頭** | 大幅升/降，格局變化 | 命運轉折、視角躍遷 |
| **慢動作定格** | 時間凝滯 | 關鍵瞬間（注意：靜止目的須為"被截圖/強調"，非拖延） |

⚠️ 增強項與總控「重技法名額」共享上限：荷蘭角 ≤1/集、大仰角/大俯角各 ≤3/集、劇烈晃動 ≤3 段落。**增強項不得超配。**

## 六、選 ID 的優先級流程

```
1. 優先在本文件"基礎速查表（12 個）"中找 → 命中即用
2. 找不到匹配 → 查"進階速查表（3 個）"
3. 仍找不到 → 詢問用戶：
   "本節拍情境（如'失憶中的恍惚'）不在標準庫中，
    請提供：期望核心組合（焦段+機位+運鏡）/ 風格參考片"
4. 用戶授權 → 臨時定義 EX01 + 文檔中標註"用戶自定義情境"
```

**硬約束**：情境 ID 必須從 ① 基礎表 ② 進階表 ③ 用戶自定義 三處之一獲取。**禁止 LLM 臨時編造 ID。**

## 七、雷區解鎖標註規範

若情境 ID 解鎖了某條雷區（見 `forbidden-zone-whitelist.md`），必須在情緒錨點表的"解鎖雷區"列**顯式標註**，且：

1. **內部四問 Q4 必須寫明**"解鎖理由 = 來自 ID Exx 白名單第 X 項"。
2. **通用後綴必須配套**（如解鎖 E10 儀式威嚴 → 後綴加"強對稱構圖 / 儀式感"）。
3. **B 類工程性雷區（物體穿身等）永不解鎖** —— 不允許出現在解鎖列。

## 八、與體系的銜接（★必讀 · 防衝突）

| 已有機制 | 本文件的關係 |
|---|---|
| `short-drama-director/references/camera-specs-15rules.md` 鏡頭規格五要素 | **本文件給"選什麼"，規格寫法定法以那份為權威** |
| 景別階梯躍遷鐵律 | 核心組合的景別若違反階梯躍遷 → **以階梯躍遷為準** |

| 短劇視感機位體系（側45度默認/常規≤30%） | 情境核心組合的機位角度須在該體系配額內 |
| `sd-storyboard-engine` 分鏡輸出 | 決策層輸出（錨點表）作為分鏡引擎的**輸入依據** |

**一句話**：決策層決定"為什麼用這個鏡頭"，機位體系決定"這個鏡頭怎麼寫"。**兩層不越界。**
