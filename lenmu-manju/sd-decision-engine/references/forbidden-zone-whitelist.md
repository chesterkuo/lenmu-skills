# 構圖雷區白名單庫（Forbidden Zone · A/B 雙態系統）

> **本文檔是決策層核心規則庫 · 權威文件**
> 融合來源：script-writing-studio 04-field-methods 第 13 節
> 核心機制：**雷區不是絕對禁令，是"默認禁止 + 特定情境解鎖"的雙態系統。**

---

## 〇、兩類雷區的本質區別

| 類別 | 性質 | 可否解鎖 | 處理方式 |
|---|---|---|---|
| **A 類 · 藝術性雷區** | 藝術選擇（庫布里克式正面居中、暴力美學斷關節） | ✅ 白名單情境可解鎖 | 命中白名單 → 配套約束 → 顯式標註 |
| **B 類 · 工程性雷區** | AI 視頻生成的純技術錯誤 | ❌ **永不解鎖** | 強制寫進「限制」字段規避 |

> **判定口訣**：這個"錯誤"有沒有藝術上的理由？有 = A 類；沒有 = B 類。

---

## 一、A 類 · 藝術性雷區（7 條 · 可解鎖）

### A1 · 正面居中

```
默認狀態：禁止
默認理由：舞台感 / 破第四面牆 / 視覺平庸
解鎖白名單（必須命中其一）：
  □ ① 異化時刻（庫布里克式 / 表現精神失序）→ 關聯 ID：E13
  □ ② 儀式感（婚禮 / 葬禮 / 加冕 / 審判）→ 關聯 ID：E10
  □ ③ 對峙瞬間（審訊 / 法庭 / 決鬥的凝固一刻）→ 關聯 ID：E04
  □ ④ 強迫觀眾參與（直視鏡頭 / 第四面牆擊穿）
  □ ⑤ 風格化作者印記（韋斯·安德森式強對稱美學）
  □ ⑥ 權力凝固（君主 / 反派的"被供奉"瞬間）→ 關聯 ID：E02
解鎖後強制約束：
  - 必須配套：對稱佈景 / 靜態運鏡 / 長焦壓縮
  - 通用後綴必須含："強對稱構圖 / 儀式感 / 風格化"
  - 內部四問 Q4 必須寫明"解鎖理由 = 來自 A1 白名單第 X 項"
未命中白名單 → 仍按默認禁止
```

### A2 · 頭頂貼邊

```
默認狀態：禁止
默認理由：視覺壓迫不適
解鎖白名單：
  □ ① 表現"被天花板壓住" / 牢籠感 → 關聯 ID：E14
  □ ② 階級壓迫 / 角色被環境吞噬
  □ ③ 監視感（頂部空間被填滿 = 被注視）
解鎖後約束：
  - 必須配合廣角鏡頭（強化壓迫）
  - 通用後綴加"壓迫感 / 閉塞空間"
未命中白名單 → 留出 headroom（頭頂留白）
```

### A3 · 死壓中線（主體永遠居中）

```
默認狀態：禁止
默認理由：構圖平庸 / 缺少視覺張力
解鎖白名單：
  □ ① 異化 / 程式化（庫布里克 / 艾舍爾式鏡像）→ 關聯 ID：E13
  □ ② 童話儀式感（韋斯·安德森式）
  □ ③ 強對稱美學的明確意圖
解鎖後約束：
  - 整段戲所有鏡頭必須保持對稱美學（不能只這一鏡對稱）
  - 通用後綴加"強對稱構圖 + 風格化"
未命中白名單 → 用三分法 / 黃金分割
```

### A4 · 眼神無空間（視線指向畫面外但該側無留白）

```
默認狀態：禁止
默認理由：空間錯亂 / 視覺不適
解鎖白名單：
  □ ① 凝視虛空 / 失控 / 心理失序
  □ ② 表現角色被"看不見的力量"包圍
  □ ③ 主觀恐懼（看不到的威脅源）
解鎖後約束：
  - 必須配合長焦虛化背景
  - 後綴加"凝視虛空 / 心理失序"
未命中白名單 → 留出 noseroom（視線方向留白）
```

### A5 · 斷關節（框邊切在關節處）

```
默認狀態：禁止
默認理由：視覺不適 / 畫面"殘缺感"
解鎖白名單：
  □ ① 強調局部（手 / 腳 / 嘴）= 微距 / 特寫鏡頭
  □ ② 暴力美學（昆汀式 / 北野武式）
  □ ③ 抽離感敘事（局部代替整體 / 局部蒙太奇）
解鎖後約束：
  - 必須是有意為之的"微距 / 特寫"選擇
  - 不能是中景 / 全景中的"無意切到關節處"
  - 配套微距 / 長焦
未命中白名單 → 框邊切大臂中段、大腿中段、胸口或腰部
```

### A6 · 背景過亮（背景比主體亮，主體被吃）

```
默認狀態：禁止
默認理由：主體不明 / 視覺中心丟失
解鎖白名單：
  □ ① 神性顯現 / 頓悟瞬間 / 死亡 → 關聯 ID：E15
  □ ② 逆光剪影（角色身份被有意模糊）
  □ ③ 回憶 / 夢境的"過曝"質感
解鎖後約束：
  - 必須明示"逆光剪影"或"過曝夢境感"
  - 後綴加"高調過曝 / 神性光線 / 夢境質感"
未命中白名單 → "限制：主體光比背景亮 1-2 檔"
```

### A7 · 多人正面平鋪（所有人正臉朝鏡頭）

```
默認狀態：禁止
默認理由：舞台感 / 靜態合影感
解鎖白名單：
  □ ① 全家福 / 法庭 / 儀式 / 集體宣誓 / 教科書風格
  □ ② 強迫觀眾參與（破第四面牆）
  □ ③ 儀式威嚴（多人朝賀）→ 關聯 ID：E10
解鎖後約束：
  - 必須配合對稱佈景
  - 後綴加"儀式感 + 集體凝視"
未命中白名單 → 用側臉 / 背影 / 半側 製造朝向變化
```

## 二、B 類 · 工程性雷區（7 條 · **永不解鎖**）

> 這些是 AI 視頻生成的**技術錯誤**，**藝術上沒有任何理由保留**。強制用「限制」字段規避。

| 雷區 | 描述 | 強制規避（寫進「限制」字段） |
|---|---|---|
| **物體穿身** | 樹枝/燈柱/路標從角色頭頂或身體長出 | "限制：背景物體不與角色身體重疊" |
| **角色服裝突變** | 上一鏡白衣下一鏡灰衣（同場戲） | "限制：服裝/髮型與上一鏡完全一致" |
| **雜亂前景刺眼物** | 前景虛化中出現光斑/反光板邊緣 | "限制：前景虛化中無刺眼光斑/異物" |
| **比例失調** | 手比頭大 / 透視錯亂 / 多手指 | "限制：身體各部位比例符合解剖學" |
| **重複元素無重點** | 背景多個相同形狀物讓畫面無重點 | "限制：背景元素有主次層次" |
| **空雞蛋構圖** | 主體周圍全空白無視覺支撐 | 加前景物件 / 框架式構圖 |
| **道具狀態突變** | 杯裡水量、菸頭長度突變 | "限制：道具狀態與上一鏡延續" |

> ⚠️ **B 類雷區出現 = 必修 bug** —— 不允許在任何情境下保留。

## 三、多人構圖次級雷區

> 這不是獨立雷區，是 A1/A7 的衍生場景，僅速查用。

| 雷區 | 默認規避 | 解鎖參考 |
|---|---|---|
| **眼睛同高** | 通過站姿/坐姿/俯仰角製造高低差 | 儀式 / 法庭可解鎖（參見 A7） |
| **一字排開** | 三角形構圖 / 前後景縱深 | 儀式宣誓可解鎖（參見 A7） |
| **視線散亂** | 至少 2 人共同看向焦點 | 表現集體困惑 / 失序時可保留 |

---

## 四、微距 / 特寫專屬雷區（無解鎖 · 強約束）

> 不屬於 A/B 分類——是微距鏡頭的**結構性必填項**，無解鎖概念。

| 雷區 | 描述 | 規避方法 |
|---|---|---|
| **主體不明** | 微距構圖未指明主體 | **強制寫明"X 佔滿畫面"** |
| **失焦** | 微距景深極淺，焦點沒對在關鍵點 | 寫明焦點："焦點在菸頭紅色火星" |
| **雜物入畫** | 微距鏡頭裡混入與劇情無關的雜物 | "限制：畫面中只有 [指定物]，無其他物件" |

## 五、類型化構圖雷區

| 類型 | 常見雷區 | 規避 |
|---|---|---|
| **武俠** | 角色站姿過於現代（叉腰/手插兜） | 古典站姿："手負於背"/"劍指在前" |
| **現代都市** | 室內構圖過於"舞台感"（面對鏡頭說話） | 自然朝向，避免破第四面牆（除非命中 A1 白名單 ④） |
| **動畫/漫劇** | 物件比例失調（手比頭大） | "限制：身體各部位比例符合解剖學"（B 類·不解鎖） |
| **懸疑** | 關鍵道具反而構圖弱化 | 關鍵道具至少給一個獨立特寫鏡頭 |
| **愛情** | 雙人構圖距離過遠顯疏離 | 物理空間靠近 + 前景遮擋製造親密感 |

## 六、雷區自查流程（生成完每個大分鏡後過）

```
對每個分鏡檢查：

① 是否觸犯 B 類工程性雷區？
   → 是 = 立即重寫（寫進「限制」字段規避），不允許保留
② 是否觸犯 A 類藝術性雷區？
   → 是 → 繼續：
      ②a 是否命中該雷區白名單？
         → 否 = 重寫（改回默認規避寫法）
         → 是 = 繼續
      ②b 配套約束是否已加？（對稱佈景/後綴/廣角等）
         → 否 = 補齊
      ②c 是否已在錨點表"解鎖雷區"列顯式標註？
         → 否 = 補標
③ 微距/特寫鏡頭是否滿足結構性必填項？（主體明確/焦點寫明/無雜物）
   → 否 = 補齊
```

## 七、與「限制」字段的自動鏈路

**鏈路**：雷區判定 → `限制`字段生成。

```
B 類雷區命中 → 自動生成對應「限制：…」句 → 注入分鏡鏡行的【限制】位
A 類雷區解鎖 → 自動生成配套後綴 → 注入通用後綴
```

**銜接總控**：`限制`字段的**最終寫法規格**以總控 `short-drama-director/references/prompt-feeding-checklist.md` 為準，本文件只負責"判定該寫哪條"。
