# 角色多元化設計引擎（Character Diversity & Anti-Cloning Engine · V8.2.0-SLIM）

> 歸屬技能：`sd-asset-engine`（資產生圖引擎）｜工作流 Step 3（三清單提取後）→ Step 4（人物立繪生成前）強制掛載
> **核心目標**：根治 AI 角色生成「全員網紅臉、同款髮型、同款黑西裝/素長袍、毫無個人辨識度」的模板化病灶；同時守死 **「板式（四格/八格）只管排版格式，畫風與光影 100% 歸 I 鎖」** 的正交邊界。

## 一、 為什麼會跑出「千人一面」？（三大根因與反制原則）

1. **均值詞坍縮**：寫「瓜子臉、劍眉星目、高鼻梁、大眼睛、黑色短髮、深色西裝」這類高頻套話時，生圖模型會直接回歸數據集均值，把全劇所有角色畫成同一張 AI 網紅臉。
2. **缺少全劇橫向排異**：孤立地逐個寫角色，沒有把全劇主要角色放在同一張表裡比對「臉型、髮型輪廓、服裝剪影、主色相、面部記憶點」，導致同性別角色大面積撞車。
3. **模板層隱性鎖死**：皮膚質感段默認“無鬍鬚/無瑕疵”、服裝不寫材質與生活磨損，導致 20 歲學生與 45 歲糙漢、底層工匠與權貴反派長著同一張光滑面皮、穿著同一套嶄新樣衣。

**三原則**：
- **先排矩陣再落筆**：生成任何角色提示詞之前，必須先填完下方 §五《全劇角色視覺差異矩陣》，四項同類排異全部通過才允許進入 Step 4 寫立繪。
- **寫結構、寫不完美、寫生活史**：用具體骨相比例、非對稱微特徵、真實年齡/職業痕跡替代空洞審美形容詞。
- **板式與畫風 100% 正交**：無論用戶選 **① 16:9 四格純圖板** 還是 **② 3:2 八格拼版**，本引擎輸出的角色差異化特徵均原樣適用，**絕不因選了八格就強塞唯美光影/厚塗詞，也不因選了四格就降級人物特色**。

## 三、 面容·髮型·服裝三維差異化詞庫（抽屜式選配，禁止全劇重複抽同一格）

### 3.1 面容與骨相六維分化

1. **臉型與骨相輪廓（按角色氣質與階層拉開）**
   - **硬朗方頜型**：寬下頜、折角清晰、額頭偏方、骨感重（硬漢 / 執法人 / 權臣 / 底層苦力）
   - **窄長清瘦型**：中庭偏長、顴骨微顯、面頰微凹、下巴偏尖（謀士 / 病嬌 / 隱忍復仇者 / 陰鷙反派）
   - **菱形高顴型**：顴弓外擴有記憶點、太陽穴略凹、冷感高級（強勢女高管 / 江湖冷面 / 複雜反派）
   - **圓潤鈍感型**：短圓下巴、蘋果肌飽滿、骨骼包裹感強（市井小人物 / 扮豬吃虎 / 溫和長輩 / 少年感）
   - **厚重飽滿型**：臉寬頰厚、下頜帶肉感或輕微雙下巴（商賈 / 地方官 / 威嚴長輩 / 笑面虎）
2. **眉眼結構分化（決定第一眼辨識度）**
   - **眼型**：狹長單眼皮 / 深眼窩內雙 / 細長上挑丹鳳眼 / 眼尾下垂無辜眼 / 偏圓杏眼 / 輕微三白眼（冷漠壓迫感）/ 眼距微寬（疏離感）
   - **眉形**：眉壓眼濃眉（壓迫感）/ 稀疏淡眉（書卷或涼薄）/ 尾端散開的野生眉 / 細長微挑眉 / 眉尾斷裂舊傷
   - **眼周狀態**：臥蠶明顯 / 熬夜青灰眼袋與淚溝 / 眼尾笑紋魚尾紋 / 長期眯眼形成的眉間川字紋
3. **鼻與唇的性格化分化**
   - **鼻型**：直挺窄鼻梁 / 鼻梁中段微起駝峰（狠厲、精明或異域感）/ 圓潤肉鼻頭（親和、市井、鈍感）/ 鼻梁偏短微翹 / 鼻翼略寬有量感
   - **唇型**：薄唇緊抿（剋制、刻薄）/ 厚唇微張（鈍感、鬆弛或性感）/ 嘴角天然微垂（嚴肅、苦相）/ 嘴角微翹 / 乾裂發暗的唇色（落魄、風霜）
4. **膚色、鬍鬚與歲月痕跡（打破「全員光滑無須」模板）**
   - **膚色**：冷白（長期室內）/ 暖黃自然 / 日曬小麥或古銅 / 粗糙偏紅褐（戶外風吹）/ 缺乏血色的灰白（病弱/陰沉）
   - **鬍鬚與面部毛髮（男性必按人設顯式選定，禁止默認無須）**：乾淨刮淨 / 熬夜青色短胡茬 / 修剪利落的短絡腮鬍 / 唇周短鬚或山羊鬍 / 斑白長鬚（長者）
   - **自然痕跡**：鼻梁與兩頰零星雀斑、曬斑、輕微痘坑/粗大毛孔（寫實糙漢）、深法令紋、抬頭紋、頸紋
5. **唯一面部記憶點（★ 每位主要角色必選 1~2 項，全劇互斥不重樣）**
   - **天然特徵**：眼下淚痣 / 眉尾痣 / 唇角痣 / 單邊酒窩或梨渦 / 微微露出的小虎牙 / 輕微高低眉
   - **經歷印記**：眉骨細短白疤 / 顴骨陳舊淡疤 / 鼻梁小創可貼或擦傷 / 鬢角一縷早生白髮
   - **隨身固定臉部配飾**（脫卸時按 `CHAR_STATE` 登記）：細金絲方框眼鏡 / 玳瑁圓框眼鏡 / 粗黑框舊眼鏡 / 單邊銀質耳骨釘 / 磨損舊耳環

### 3.2 髮型與髮質四維分化（跨題材通用）

描述每個角色的髮型時，必須同時落紙 **輪廓剪影 + 劉海分縫 + 髮質整潔度 + 髮色層次/束髮結構**：

- **現代 / 都市 / 懸疑 / 年代 · 男性**：
  - 極短圓寸或平頭（硬朗、底層、執法人、退伍）
  - 側分背頭配幾縷垂落碎髮（精英、老派、城府深）
  - 蓬鬆自然捲或凌亂中分（技術宅、落魄、文藝、年輕）
  - 齊頸微長狼尾或腦後隨手半扎小揪（叛逆、反派、藝術家、邊緣人）
  - 貼頭皮梳亮的偏分油頭（油膩反派、舊時代商賈）
  - 髮際線略後移＋兩鬢斑白短髮（中年權貴、父親、老警探）
- **現代 / 都市 / 懸疑 / 年代 · 女性**：
  - 齊下頜一刀切短直髮（冷冽、幹練、理智）
  - 超短露耳精靈短髮（酷颯、行動派、不羈）
  - 鎖骨微卷法式碎髮（鬆弛、知性、日常感）
  - 腦後鯊魚夾/皮筋隨手挽起的低丸子頭＋耳側碎髮（真實職場、居家、奔波感）
  - 低雙麻花辮 / 粗單辮 / 貼頸低馬尾（年代、質樸、學生、剋制）
  - 復古手推波紋 / 蓬鬆羊毛卷 / 高顱頂大卷（明豔、張揚、年代名伶）
  - 銀灰或花白盤髮（老年長輩，髮絲蓬鬆有自然碎髮）
- **古裝 / 權謀 / 仙俠 / 武俠（嚴禁全員「高馬尾+兩縷龍鬚劉海」）**：
  - 按身份拆開：**全束高冠**（玉冠/金冠/鐵冠，正統權貴）/ **半束披髮**（江湖散修/世家公子）/ **木簪/布帶低束**（隱士/底層/落魄）/ **編髮入髻或額前小辮**（異域/邊疆/俠女）/ **規整盤髻配步搖或素銀簪**（主母/宮廷/已婚）/ **雙丫髻或垂掛髻**（少女/侍女）/ **散髮凌亂帶灰**（瘋批/囚徒/戰損）
- **髮質與細節**：粗硬蓬鬆 / 細軟貼耳 / 自然微卷 / 乾枯毛躁分叉 / 微微出油結縷 / 髮尾微褪色或挑染（須符合題材與時代）

### 3.3 服裝廓形、材質與生活痕跡四維分化

1. **廓形剪影（Silhouette · 同框主要角色必須互斥）**：
   - **A · 寬肩硬挺長廓形**：墊肩大衣、挺括長風衣、硬質西裝、寬肩大氅/鎧甲
   - **B · 短款利落收束形**：短夾克、工裝外套、收腰短衫、勁裝箭袖
   - **C · 鬆弛垂墜疊穿形**：寬鬆針織開衫、多層次罩衫、寬袍大袖、軟料長裙
   - **D · 貼身修長線條形**：修身旗袍、貼身針織/襯衫配高腰褲、緊身機能服
2. **面料材質對比（禁止全劇“光滑化纖感”）**：
   - 粗紡羊毛呢 / 燈芯絨 / 重磅水洗牛仔 / 做舊磨砂皮 / 粗麻粗布 / 挺括精紡西裝料 / 垂墜真絲綢緞 / 啞光尼龍衝鋒衣 / 提花織錦或素面棉麻
3. **穿法與生活使用痕跡（讓衣服像“穿過三年”）**：
   - 領口敞開兩顆扣露出鎖骨或內搭、袖口隨意卷至小臂、領帶略松歪斜、襯衫下襬半塞、衣肘/膝蓋自然橫向摺痕、袖口與下襬輕微磨白起毛、口袋略鼓、衣襬沾塵或雨漬、補丁與粗針腳走線
4. **全劇主色相排異（Color-Wheel Separation）**：
   - 全劇主要角色的主色相必須錯開，**嚴禁 3 個以上主角同時穿純黑/深灰**；
   - 每名角色採用 **60% 主色 + 30% 輔色 + 10% 記憶點綴色**（如暗鏽紅圍巾、舊黃銅皮帶扣、藏青織帶、亮橙工牌繩），確保遠景與多人同框時僅靠色塊就能區分身份。

## 四、 親緣角色 vs 非親緣角色的差異邊界

- **非親緣角色**：嚴格執行下方 §五 四項同類排異，做到剪影、臉型、髮型、主色相全部錯開。
- **血親/親緣角色**（銜接 `short-drama-director/references/character-lineage-and-sheets.md`）：僅繼承 40%~60% 局部骨相（如眉眼走勢或鼻型）或 1 個副色呼應；**臉部年齡紋路、髮型輪廓、服裝廓形與唯一面部記憶點仍必須清晰區分**，避免長成雙胞胎。

## 六、 真人寫實防假面與景別適配三律

1. **保留自然不對稱（Natural Asymmetry）**：寫實人物資產提示詞顯式加入“保留面部自然不對稱（眼型、眉高、嘴角微差）”，根治 AI 左右絕對對稱導致的蠟像假臉。
2. **分區膚質與按景別取捨**：
   - **特寫 / 近景**：鼻翼與內頰保留微深且不規則的自然毛孔，外頰與太陽穴紋理更細；額頭、鼻梁等凸面保留極剋制的自然皮脂微光；
   - **全景 / 全身格**：只鎖膚色冷暖與受光輪廓，不向小尺寸全身格強塞微觀毛孔或粗大皺紋詞，避免模型把全臉糊成斑駁顆粒。
3. **90° 真側臉單眼鐵律**：描述角色 90° 側臉視角時，寫明“只露近側眼眉與完整前額到下頜側面剪影，不露遠側眼睛與嘴角”，防側臉畫出半隻漂浮遠眼。
