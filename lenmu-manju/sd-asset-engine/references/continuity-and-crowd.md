## 〇、為什麼需要這份文件

**問題**：資產圖做好之後，跨段使用時會出三類問題——① 場景空間方向前後不一致（穿幫）；② 同一道具在多張圖裡出現 → 模型生成兩個實例；③ 人群在每段都不一樣 → 無連續性。

**本文件提供四個連續性工具**：場景空間鎖定、道具單實例鎖、**群像資產卡**、人群調度卡。

---

## 一、場景空間連續性（防穿幫）

### 1.1 空間方向鎖定（必寫）

同一場景多次出現時，**空間方位必須一致**：

```
必寫內容：
① 分界面定義：這個空間的"門/窗/主光源"在哪個方向
② 側別命名：面向某個參照物時，左右各是什麼
③ 人物允許區：人物可以站在哪些位置
④ 人物禁止區：不該出現的位置（如穿牆、懸空）
⑤ 硬約束句：交給分鏡/投餵的固定句
```

### 1.2 場景多角度包（圖N 口徑）

需要多角度展示同一場景時，**每個角度單獨一個圖號**，並寫清"只參考什麼 / 不參考什麼"：

```
圖N（V01 正向）：只參考拍攝方向、空間透視、門窗傢俱相對位置、固定光源
圖N+1（V02 反向）：同上，方向相反
圖N+2（PLAN 俯視）：只參考平面佈局與人物可站立區域
```

⚠️ **角度圖不替代場景母版**——母版定結構，角度圖定方向。

### 1.3 場景光影連續性

同一場景在不同場次若光線變化（白天→夜晚），**必須寫清變化理由**（時間推移/劇情事件），且**光源結構保持一致**（窗在哪、主光從哪來不能變，只能變強度和色溫）。

## 二、道具單實例鎖（★ 高頻出錯點）

### 2.1 問題場景

**同一件道具已經在場景圖、角度圖或首幀圖裡可見，同時資產庫又提供了這件道具的參考圖** → 模型容易生成**兩個實例**（桌上一個、手裡一個）。

### 2.2 鎖定寫法（必寫四要素）

```
① 對應關係：圖N 對應的是畫面裡哪一件可見道具
② 數量限制：本段/全片只允許出現幾個
③ 用途限定：圖N 只用於外觀/材質/顏色/屏幕狀態，不新增第二件
④ 狀態互斥：角色拿起後，原位置必須變為空
```


### 2.3 小道具朝向規則（手機/照片/證件）

**AI 模型經常把手機自動轉成"正面朝鏡頭"**，甚至把背面也生成成屏幕。凡道具有正反面/信息面，**必須寫清朝向**：

| 道具狀態 | 寫法 |
|---|---|
| 不需要看屏幕 | 優先讓屏幕朝向手心/桌面/角色身體；"限制：手機背面朝鏡頭，屏幕朝手心不可見" |
| 需要看 UI | 必須明確"屏幕正面朝鏡頭"，並寫清只允許出現哪些中文 UI/數字/圖標 |
| 照片/證件 | 寫清正面是否可見；"限制：照片正面貼在桌面上不可見，觀眾只看到照片背面" |

**必須禁止**：手機背面變屏幕、正反面同時是屏幕、隨機 UI、隨機文字。

## 三、群像資產卡 + 人群調度卡（兩層 · ★ 2026-10-16 升格為兩層）

> **缺口由來（粉絲「森林」2026-10-16 反饋 · 核驗屬實）**：本包資產體系**只有三族**——角色 `CHR` / 場景 `SCN` / 關鍵道具 `PRP`（見 `short-drama-director/references/asset-first-pipeline.md` §P2：分批出圖「①角色 4 View 資產板 ②場景資產圖 ③道具圖」）。**"一群人"沒有資產位**：`three-list-extraction.md` §七 的「群像/群體角色」只給一段**文字描述**（無圖號、無出圖規範），本節原有的「人群調度卡」又是**投餵層的密度句**（且明文"無路人需求時不新增字段"）——兩者都**不是可跨段複用的資產**。結果：**家族 / 侍衛隊 / 圍觀村民 / 朝堂百官**這類群體，每段長相都可能變，與"每段零記憶"的模型特性疊加 = 必然群像漂移。本節把群像補成**資產層 + 投餵層兩層**。

### 3.0 兩層分工（先判"要不要資產化"，再決定寫法）

| 層 | 產物 | 階段 | 編號 | 職責 | 何時用 |
|---|---|---|---|---|---|
| **① 群像資產卡**（★ 新增） | 《資產圖冊》第四族 **`GRP-N`** + 群像參考圖 | P2 資產層（出圖） | `GRP-N` | 鎖**長相**：統一制式 / 體態 / 年齡構成 —— 跨段複用 | **有辨識度的固定群體**（家族、門派弟子、侍衛隊、朝堂百官、固定班底） |
| **② 人群調度卡**（既有） | 投餵層**人群密度句** | P4 投餵層（寫句） | 無編號 | 鎖**分佈**：前景/中景/遠景幾人、人流方向、遮擋 | **無辨識度的背景人群**（街頭路人、顧客、乘客） |

> **一句話判據**：**這群人"要不要長得一樣"？** 要 → 建 `GRP-N` 群像資產卡；不要 → 只寫人群密度句，**不建資產**。

> **★ 第三維（2026-10-24 P7 新增）**：上述兩層只覆蓋「**長相**」與「**分佈**」，**不覆蓋「行為」**。
> 一群長相一致、分佈合理的人，照樣可以人人站樁不動（用戶實測：教室後排「像殭屍一樣在那兒看著」）。
> **行為是獨立維度，權威在分鏡引擎** `short-drama-director/references/crowd-behavior-direction.md`——
> 本文件 §3.2 的 ⑧ 行為字段只是它在**資產/調度側的落點**，完整判據（A/B/C 開關 + R/P/S 三型 + 停頓恢復曲線）以該文件為準。

### 3.1 群像資產卡（★ 2026-10-16 新增 · 第四族資產）

**觸發門（命中任一即建卡）**：① 同一群體**跨 ≥2 段**出現；② 群體承擔**敘事功能**（侍衛護駕 / 家族列席 / 百官朝拜）；③ 群體在**特寫或中近景**裡入畫（景別越緊，長相越要鎖）。

**卡模板（7 字段 · 缺一即不合格）**：

```
【群像資產 GRP-〔編號〕】〔群體名，如：宋府家丁〕
① 統一制式：服裝/甲冑/髮式/配飾的統一規格（逐項寫清，禁"統一著裝"這類空話）
② 年齡與性別構成：如"25~40 歲男性為主，混 1~2 名中年女性"
③ 體態與身高帶：如"170~180cm，體格偏壯；無過瘦/過高者"
④ 可辨識度分級：**A 級**（有個體臉，須逐個 4 View）/ **B 級**（統一制式無個體臉，一張群體參考圖即可）
⑤ 數量與密度基準：默認同框人數帶 + 允許的稀疏/密集檔
⑥ 場景綁定：常出現於哪些場景（對應 `SCN-`）
⑦ 狀態軌跡：有無換裝/受傷/潰散等跨段狀態變化（`→` 連寫，無變化寫"無狀態變化"）
```

**出圖規範（B 級主力 · 與角色 4 View 同源）**：

- **一張群像參考圖 = 3 格橫向並排**：① **制式細節格**（甲冑/服裝正面特寫）② **3~5 人合影格**（交代體態帶與年齡構成）③ **遠景群像格**（交代密度與遮擋關係）；
- **B 級群體**：②③ 格內**不刻畫個體五官**（統一制式、臉部弱化），避免模型"發明"個體臉 → 下一段變臉；
- **A 級群體**：**必須先按 `character-lineage-and-sheets.md` 把其中出戲的個體升為 `CHR-` 角色**（逐個 4 View）——**禁用一張群像圖硬扛有台詞的個體**；
- 統一參數：〔畫幅〕〔焦段 50mm〕等效無畸變；**禁**在群像圖裡出現主角（主角走自己的 `CHR-` 資產）。

**投餵層錨點**：`@群體名`（如 `@宋府家丁`）——**與 `@人名` 同欄同待遇**，寫在【核心人物】欄末（七段式**不增段**，見 `model-adapters.md` §5）；**M0 形態**（無圖）時按 §三 文字鎖口徑**逐段複述制式**，禁寫"同上/同前"。

**與三族錨點的關係**：`GRP-N` 是**資產層編號**（進《資產圖冊》），**不新增行內錨點前綴族**——投餵層仍走 `@群體名`（與 `@周慕` 同形），故 `@CHR-` / `@SCN-` / `@PRP-` 三族口徑**不變**。

### 3.2 人群調度卡（既有 · 僅用於無辨識度背景人群）

**何時啟用**：公共空間、街道、商場、車站、學校、醫院、營業餐廳等**需要路人真實感**的場景。

**調度卡必寫內容**：

```
① 綁定信息：對應哪個場景（圖N）
② 密度等級：稀疏/中等/密集
③ 景深層次分佈：前景幾人、中景幾人、遠景幾人
④ 人群類型：路人/顧客/學生/乘客……（與場景匹配）
⑤ 移動與遮擋規則：人流方向、是否遮擋主體
⑥ 聲音與氛圍：環境人聲層次
⑦ 禁止項：不允許出現的元素
⑧ 行為字段（★ P7 新增 · 治「背景人殭屍化」）：每人/每層正在做的事——
   前景寫具體事務（動詞+賓語），中景寫事務+穿畫方向，遠景只寫整體傾向；
   禁「站著/看著/在旁/圍觀」等狀態詞，必須落到手上動作
```

> **⑧ 是必填項，不是可選項**：①~⑦ 全是「**有多少人在哪**」，⑧ 是「**他們在幹什麼**」。
> 缺 ⑧ ＝ 模型自配行為，默認產物就是站樁殭屍（用戶 2026-10-24 實測：教室後排「像殭屍一樣在那兒看著」）。
> ⑧ 的完整寫法、三型分級（R 反應人 / P 事務人 / S 密度人）、字數預算與正反示例，
> 權威 = `short-drama-director/references/crowd-behavior-direction.md` §三。

### 3.3 與投餵的銜接（★ 關鍵）

**人群卡必須被翻譯成模型能直接理解的"人群密度"句子**：

❌ **不要只寫**："人群卡001 / 同上一段人群 / 保持之前人流"
✅ **必須寫**："本段可見：前景 2 名路人（模糊）、中景 5 名顧客走動、遠景 10 餘人，人流自畫面左向右移動，不遮擋主角面部"

⚠️ 場景母版如果是**空場圖**，只作為空間結構/燈光/透視/固定物參考；啟用人群時**直接寫本段可見人群**，不寫"不繼承空無一人狀態"這類管理說明。

⚠️ **無路人需求時**，**不新增人群字段**，只在限制裡寫"不允許出現額外人物、路人、群演"。

## 四、視覺風格鎖（簡要 · 圖N 口徑）

> 已有 `short-drama-director/references/aspect-ratio-adaptation.md` 等風格規範，此處僅補充"風格鎖"的寫法。

需要固定項目視覺風格時，建立**風格鎖**（可給圖號），包含：

```
① 風格身份：媒介質感、整體調性
② 人物審美鎖：臉型/體態/皮膚質感標準
③ 場景審美鎖：空間質感/材質/年代感
④ 畫面質感鎖：顆粒/渲染方式/反差
⑤ 正向詞：必須投餵的詞
⑥ 負面詞：防跑偏詞包
⑦ 轉譯短句：交給分鏡/投餵的短句
```

⚠️ **風格鎖編號不進最終投餵提示詞**——必須翻譯成自然語言（詳見 `sd-feed-engine/references/engineering-language-cleanup.md` §三）。

⚠️ **風格光影衝突時融合不覆蓋**：風格鎖的默認光影與當前分鏡真實光源衝突時，**以當前鏡頭真實光源為準**，但保留風格的媒介質感、反差控制、顆粒方式。

## 五、資產紅線

| # | 紅線 |
