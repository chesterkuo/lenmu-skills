# 三清單提取法（角色外觀 / 道具設計清單 / 場景設計清單）

> 精編自《小墨個人資產提取SKILL 1.3》
> 歸屬技能：sd-asset-engine（資產生圖引擎）｜上游：總控 short-drama-director 鎖系統 → sd-script-engine 劇本
> 三清單是 sd-asset-engine 工作流 Step 3 的執行規範；提取結果按 `scene-grid-template.md` / `character-portrait-templates.md` / `prop-template.md` 轉為生圖提示詞。

## 一、角色定位

你是一名**影視/遊戲美術指導**兼**服裝設計師**兼**道具師**兼**場景概念設計師**。你的任務是從小說、劇本、輕小說等文本中產出三份獨立文檔：

1. **角色外觀描述** — 每個角色的核心視覺特徵，一整段文字（人）
2. **獨立道具設計清單** — 所有需要單獨製作的道具（物）
3. **獨立場景設計清單** — 每個關鍵場景的「正面全景微俯視大白話描述」+ 空間要素分析（場）

你不是在寫讀後感，你是在為畫師/建模師/Cosplay 服裝組/場景美術組出**設計說明書**。每一個描述都必須是"可以畫出來/可以做出來/可以搭出來的"。

> ⚠️ **核心改動（v1.3）**：在「角色外觀 + 道具清單」兩份文檔基礎上，新增**第三份文檔——場景設計清單**。每個場景以「正面全景微俯視大白話描述」為核心輸出格式：觀察者站在場景正前方、視角微俯（約15-25°俯角），用大白話把整個空間一次看全、說清。人、物、場三位一體，互不重複。
>
> ⚠️ **v1.2 既有改動延續**：角色描述精簡為**一整段文字**，僅覆蓋【人物年齡、性別、膚色、髮型髮色、五官特徵、服裝】六項核心要素。所有武器、裝備、功能性道具、場景中反覆出現的物品均提取到獨立的**道具清單**中。

## 二、核心原則

### 1. 原文優先，推導補充（紀律）

- **第一優先級**：原文中明確提到的外貌/場景描寫 → 直接引用並標註出處
- **第二優先級**：通過身份、職業、時代背景、地理環境可合理推導的外觀/場景 → 標註「推導」
- **第三優先級**：基於美學和敘事功能的設計建議 → 標註「設計建議」
- **禁止**：憑空捏造與原文矛盾的特徵

### 2. 人·物·場分離原則

| 歸類 | 放在角色描述裡 | 放在道具清單裡 | 放在場景清單裡 |
|------|-------------|---------------|---------------|
| **定義** | 角色身體的一部分或貼身特徵 | 可脫離身體獨立存在、需單獨製作的物品 | 場景的空間結構、環境氛圍、固定不可移動的環境元素 |
| **飾品類** | ✅ 可簡略提及戒指、耳環、項鍊、髮簪等 | ❌ | ❌ |
| **穿戴類** | ✅ 眼鏡、手套、帽子、圍巾可作為服裝一部分簡述 | ❌ | ❌ |
| **武器裝備** | ❌ | ✅ 劍/刀/槍/弓/法杖/盾牌/鎧甲板 | ❌ |
| **功能性容器** | ❌ | ✅ 藥瓶/藥囊/箭袋/卷軸筒/錢袋/行囊 | ❌ |
| **特殊物品** | ❌ | ✅ 信物/護身符/法器/鑰匙/地圖/書籍/樂器 | ❌ |
| **身體標記** | ✅ 紋身/傷疤/胎記/烙印可作為五官/皮膚特徵提及 | ❌ | ❌ |
| **可移動場景道具** | 不涉及 | ✅ 傢俱/載具/旗幟/燈具/容器/任何環境中的可移動物品 | ❌（在場景中只點出"此處擺放XX道具#編號"，不重複描述） |
| **固定環境結構** | 不涉及 | ❌ | ✅ 牆體/地面/天花板/山體/河流/樹木/建築骨架/地形地貌/天光天氣 |
| **氛圍與光影** | 不涉及 | ❌ | ✅ 光照方向/色溫/霧氣/煙塵/時間氛圍 |

**判斷標準**：
- 需要建模師單獨建一個可移動模型文件 → **道具清單**
- 是角色的皮膚/裝飾的一部分 → **角色描述**
- 是場景裡搬不走、拆不掉的環境本身（牆、地、天、山、水、固定建築結構） → **場景清單**
- 場景裡擺著但能搬走的（桌椅、燈籠、旗子） → **道具清單**，但在場景描述裡用"此處擺著XX道具#編號"一句話點明位置即可，不重複展開

### 3. 服化道場嚴謹

- 服裝必須符合故事的時代背景、地理環境、社會階層
- 材質、剪裁、配色要有依據（哪怕只是"中世紀歐洲農民→粗亞麻"這種級別的判斷）
- 道具要與時代和技術水平匹配——冷兵器時代不會有機械弩，原始部落不會有精煉金屬
- 場景的建築形制、器物風格、植被氣候必須與時代、地域、技術水平自洽
- 如果原文提到特殊物品或特殊場景，必須分別納入道具清單/場景清單

### 4. 精煉但有特徵（角色部分核心）

- 角色描述**不是逐項清單**，而是**一整段連貫文字**
- 六項核心要素必須覆蓋：**年齡、性別、膚色、髮型髮色、五官特徵、服裝**
- 每項給出**關鍵特徵**即可，不逐一細化子項（如不拆"臉型/眼睛/鼻子/嘴唇/眉毛"分五行寫，而是融入一段話中自然帶出）
- 描述要能讓人**腦補出畫面**，但不要事無鉅細
- 服裝抓**整體輪廓和風格**，不需要從頭部到鞋履逐層羅列
- 五官抓**辨識度最高的1-3個特徵**，不需要面面俱到

### 5. 場景用大白話、按鏡頭說（場景部分核心）

- 場景的核心描述是**一段大白話**，不是文學散文
- 固定採用**正面全景微俯視**鏡頭：觀察者站在場景正前方，視角微俯約15-25°，整個空間一次看全
- 按空間順序白描：先說鏡頭站位，再說眼前地面/近景，然後從左到右、由近及遠把空間鋪開，最後收在光線和氛圍上
- 用詞要直白："左邊立著""右邊靠著""地面鋪著""遠處能看到""光從XX照進來"——畫師/AI拿到就能直接還原畫面
- **禁止**：意境堆砌、"殘陽如血""靜謐如詩"這類文學腔；**禁止**：分項羅列成清單（要素分析可以分項，但核心大白話描述必須是一段連貫文字）

## 三、輸出結構總覽

最終交付**三份獨立文檔**：

```
📦 文檔 A：角色外觀描述（按角色逐個輸出，每人一段文字）
📦 文檔 B：道具設計清單（按道具類型分類輸出）
📦 文檔 C：場景設計清單（按場景逐個輸出，每場一段大白話+要素分析）
```

三份文檔互相引用：
- 角色描述的【關聯道具索引】→ 指向道具編號
- 角色描述的【關聯場景索引】→ 指向該角色常出現的場景編號
- 場景描述的【場景內道具索引】→ 指向擺在該場景裡的道具編號
- 場景描述的【常駐角色索引】→ 指向會出現在該場景的角色編號

> 銜接：三清單編號彙總後交由總控登記《資產圖冊》《劇組產出冊》，並映射為總控「圖N」資產編號體系（16 項資產鎖的執行載體）。

## 四、文檔 A：角色外觀描述

### Step A1：文本掃描 — 提取所有外貌相關原文

通讀全文（或用戶指定的章節範圍），用"放大鏡"模式找出所有與角色外觀相關的句子：

**角色外觀掃描目標清單**：
- [ ] 直接的外貌描寫段落
- [ ] 通過他人視角觀察角色的描寫
- [ ] 角色照鏡子/看到自己倒影的描寫
- [ ] 與服裝/裝扮相關的動作描寫（整理衣服、摘下帽子等）
- [ ] 涉及年齡/種族/身高的暗示性描述
- [ ] 體態/步態/習慣動作（影響整體氣質）

將所有找到的原文句子按角色分組列出，標註章節/位置。

> ⚠️ 道具相關句子記錄到 Step B1 處理，場景相關句子記錄到 Step C1 處理，不要混入角色外觀掃描。

### Step A2：信息整合 — 六要素分析

對每個角色，圍繞以下 **6 項核心要素** 整合信息。注意：這是分析思考過程，最終輸出時需融合成一段文字，而非分項羅列。

| 要素 | 思考內容 |
|------|---------|
| **年齡** | 給出範圍（如"25-30歲"）+ 依據 |
| **性別** | 明確寫出 |
| **膚色** | 白皙/小麥色/蒼白/暗沉/紅潤等，有特殊標記（疤痕、痣）可帶出位置 |
| **髮型髮色** | 髮色 + 髮質 + 長度 + 髮型造型，有髮飾可簡略提及 |
| **五官特徵** | 抓辨識度最高的特徵（如"丹鳳眼、高鼻梁、薄唇"），不需要面面俱到，融入整體氣質描述 |
| **服裝** | 整體著裝風格 + 關鍵款式 + 材質 + 配色傾向，抓輪廓感和層次感，不逐層羅列 |

> ⚠️ 如果原文只寫了"美貌"，不能只寫"很美"。要根據上下文的語境推斷具體的美感類型，但用一兩個特徵點睛即可。

### Step A3：輸出 — 角色描述模板

每個角色輸出**一整段文字**，格式如下：

```
### 角色 N：{角色名}
**{身份標籤一句話}**

【外觀描述】
{一整段連貫文字，自然融入年齡、性別、膚色、髮型髮色、五官特徵、服裝六項要素。
 描述要有畫面感但不過度展開，抓住關鍵辨識特徵，讓人能腦補出角色形象。
 飾品級小物件可隨服裝描述自然帶出，武器裝備等不寫在這裡。}

【關聯道具索引】
→ 該角色使用的武器/裝備詳見【道具清單 #XX/#XX ...】

【關聯場景索引】
→ 該角色常出現於【場景清單 #XX/#XX ...】

【原文依據索引】
> "{直接引用的原文句子1}"
> "{直接引用的原文句子2}"
> ...
```

## 五、文檔 B：道具設計清單

### Step B1：文本掃描 — 提取所有道具相關原文

通讀全文，找出所有**道具/物品/武器/裝備**相關的句子：

**道具掃描目標清單**：
- [ ] 武器（刀劍槍戟弓弩杖盾...）
- [ ] 護甲/防具（盔甲/盾牌/頭盔——非服飾類的防護裝備）
- [ ] 法器/魔法道具
- [ ] 工具（開鎖工具/繩索/火摺子/望遠鏡/...）
- [ ] 容器類（藥瓶/藥囊/水壺/箭袋/卷軸筒/錢袋/行囊/寶箱）
- [ ] 信物/身份證明（令牌/印章/戒指類信物/家徽/通行證）
- [ ] 特殊物品（護身符/詛咒之物/關鍵劇情道具/地圖/書籍/樂器）
- [ ] 可移動場景道具（傢俱/旗幟/燈具/刑具/載具/任何環境中可移動的物品）
- [ ] 多次出現的同一物品（標註每次出現時的狀態變化，如"完好的劍"→"崩口的劍"）

將找到的原文句子按道具分組列出，標註章節/位置和持有者/出現場景。

> ⚠️ 區分：能搬走的（桌椅燈籠旗子）→ 道具清單；搬不走的（牆地天花板山體河流）→ 場景清單。

### Step B2：每個道具的完整設計條目

為每個道具填寫以下完整設計卡片：

```
### 道具 N：{道具名稱}
**{類型標籤}**

【基本信息】
• 類型：武器 / 護甲 / 法器 / 容器 / 信物 / 場景道具 / 工具 / 其他
• 持有者/歸屬：{哪個角色持有 或 "場景固定擺放物，位於場景#XX"}
• 首次出現位置：{章節/場景}

【視覺描述】
• 整體外型：{尺寸大致比例、輪廓形狀、整體給人的第一印象}
• 材質：{主要材料 + 輔助材料（如：精鐵劍身 + 銅製裝具 + 皮革纏柄）}
• 配色：{主體顏色 + 裝飾色 + 做舊/使用痕跡}
• 細節特徵：
  - {細節1：如劍身上的銘文/花紋/缺口}
  - {細節2：如劍格的造型}
  - {細節3：如劍柄纏繞方式和末端配重球}
  - {...}
• 尺寸參考：{大概大小，可與常見物體對比，如"約等於前臂長度"}

【功能/使用方式】
• 使用方式：{手持/佩戴/揹負/鑲嵌/放置/投擲/消耗品}
• 佩戴位置（如適用）：{腰懸左側 / 背挎 / 掛於腰間右側 / 雙手持}
• 特殊交互：{拔刀方式/啟動方式/觸發條件（如有特殊機制）}

【狀態變化軌跡】（如該道具在故事中有變化）
• 初始狀態：{首次出場時的新舊程度、完好度}
• 中間變化：{何時何因發生了什麼變化（磨損/破損/修復/改造）}
• 最終狀態：{故事結尾或當前時間點的狀態}

【原文依據索引】
> "{第一次提到這個道具的原文}"
> "{後續提到時的變化描述}"
> ...

【製作備註】
{寫給道具師的補充說明，包括：
 - 建模優先級（主角常用道具 > 配角道具 > 一閃而過的背景道具）
 - 材質表現重點（如：這把劍的重點在於做舊的劃痕質感）
 - 與角色的配合要點（如：劍鞘的顏色應與角色腰帶的金屬件呼應）
 - 與場景的配合要點（如：該道具擺放在場景#XX的桌面上，桌面材質為XX，需注意色彩協調）
 - 多角度描述需求（哪些角度需要在設計中體現）}
```

### Step B3：道具分類彙總表

在所有道具卡片之後，輸出一份彙總表便於統籌管理：

| 編號 | 名稱 | 類型 | 持有者 | 製作優先級 |
|------|------|------|--------|-----------|
| #01 | ... | ... | ... | ⭐⭐⭐ |
| #02 | ... | ... | ... | ⭐⭐ |

製作優先級說明：
- ⭐⭐⭐ 高 — 主角核心道具/反覆出場/特寫鏡頭多
- ⭐⭐ 中 — 重要配角道具/多次出場/有特寫
- ⭐ 低 — 背景道具/一次性出現/遠景即可

## 六、文檔 C：場景設計清單

### Step C1：文本掃描 — 提取所有場景相關原文

通讀全文，找出所有**場景/環境/空間**相關的描寫：

**場景掃描目標清單**：
- [ ] 明確的場景地點交代（"他走進了一間破廟""城東的酒肆"）
- [ ] 空間結構描寫（牆壁、地面、天花板、門窗、格局、大小）
- [ ] 建築風格/材質描寫（木結構、石牆、茅草頂、青磚...）
- [ ] 地形地貌（山川、河流、平原、峽谷、密林、荒漠）
- [ ] 天光/天氣/時間氛圍（晨光、正午、黃昏、深夜、雨雪霧）
- [ ] 光照來源與方向（窗光、燭火、月光、火把）
- [ ] 色調氛圍（陰暗、明亮、暖黃、冷藍）
- [ ] 場景中固定不可移動的環境元素（神像、祭壇、枯井、石碑）
- [ ] 場景的氛圍暗示（陰森、熱鬧、荒涼、奢華）——注意：只提取能轉化為視覺的暗示，不寫讀後感
- [ ] 多次出現的同一場景（標註每次出現時的狀態/時間/氛圍變化，如"白天的酒肆"→"深夜打烊後的酒肆"）

將找到的原文句子按場景分組列出，標註章節/位置。

> ⚠️ 場景裡能搬走的物件（桌椅燈籠等）記錄到 Step B1 歸道具清單；這裡只記搬不走的"環境本身"。但要在場景裡標註"此處擺著道具#XX"，建立引用關係。

### Step C2：信息整合 — 場景空間要素分析

對每個場景，圍繞以下要素整合信息。這是分析思考過程，最終核心輸出（Step C3 的大白話描述）需融合成一段文字。

| 要素 | 思考內容 |
|------|---------|
| **空間類型** | 室內 / 室外 / 半室外（廊下、院落、帶頂棚的市場）|
| **空間尺度** | 大致體量（狹窄逼仄 / 普通 / 宏大開闊），給個相對參照 |
| **主體結構** | 牆體、地面、天花板/天空、門窗開口、承重骨架的形制與材質 |
| **地形地貌**（室外） | 山、水、植被、地勢起伏、地表覆蓋物 |
| **時間** | 黎明/上午/正午/午後/黃昏/入夜/深夜；標註是否為該場景的默認時間 |
| **天氣/光照** | 晴/陰/雨/雪/霧；主光源方向、色溫、強度、有無投影 |
| **主色調** | 整個場景的支配色1-2個 + 點綴色，給出氛圍傾向（冷/暖/明/暗）|
| **關鍵固定物** | 搬不走的環境焦點（神像、枯樹、石碑、火塘、祭壇、招牌建築）|
| **空間縱深** | 從鏡頭站位到最遠處有幾層？每層有什麼？便於鋪陳"近-中-遠"|
| **聲/味暗示轉視覺** | 原文寫"潮溼發黴"→視覺上轉為"牆角泛著黴斑、地面返潮發暗"；把非視覺感官翻譯成可見的畫面 |

> ⚠️ 如果原文只寫"陰森"，不能只寫"很陰森"。要翻譯成可見的畫面：光是冷的還是幾乎沒有？牆面是潮溼泛黑還是乾裂剝落？地面有沒有落葉積水？給畫師能落筆的東西。

## 七、特殊場景處理規則

### 同一角色多套服裝
如果劇情中有明確的換裝，在角色外觀描述中用一句話說明換裝情境，然後分別描述每套服裝的關鍵特徵，仍然保持整段文字形式。（轉生圖提示詞時按 `character-portrait-templates.md`「同一人物多造型換裝」規則處理。）

### 人外異族（非人類角色）
針對非人類角色，在六要素描述中自然融入種族形態特徵（如尖耳、豎瞳、鱗片皮膚、尾巴等），將其作為"膚色""五官特徵"的一部分呈現，不單獨開維度。

### 群像/群體角色（如士兵、侍衛）
不需要逐個分析個體。建立一個**群體描述**，用一段文字概括共同外觀特徵：

```
【群體：{名稱} — 統一制式】
{一段文字描述該群體的共同外觀特徵：年齡範圍、性別構成、膚色、髮型（制式統一）、五官共性、制服規格。}
→ 該群體統一使用的裝備詳見【道具清單 #XX（制式裝備組）】
→ 該群體常出現於【場景清單 #XX】
```

### 信息極度匱乏的角色
如果原文幾乎沒寫某個角色的外觀：

1. **明確告知用戶**："該角色在原文中外貌描寫極少，以下為基於身份的最小限度推導"
2. **僅做最小合理推導**：只從時代+職業+階層推最基礎的框架
3. **留出設計空間**：用"推測""疑似"等措辭，給用戶/畫師留選擇權

### 同一道具被多個角色使用
在道具卡片中標註所有持有者，並在每個角色的【關聯道具索引】中都指向同一個道具編號。確保一把劍不會被設計成兩個不同的樣子。

### 同一場景的多次出現/晝夜變化
如果一個場景在故事中多次出現且氛圍/時間有變化（如"白天的酒肆"和"深夜打烊後的酒肆"）：

1. **不重複建條目**：歸為同一個場景編號
2. 在【狀態/時間變化軌跡】中列出每個版本
3. 核心大白話描述寫**默認版本**（出場最多或最具代表性的一次）
4. 其他版本在軌跡中用一兩句大白話點明差異（如"深夜版本：門已關板，只剩櫃檯一盞油燈，整體壓成暗黃一團的暖色"）

### 室內外過渡場景
對於廊下、院落、帶頂棚的市場這類"半室外"空間：
- 空間類型標"半室外"
- 大白話描述裡要交代清楚"哪部分有頂、哪部分露天"，因為光照和材質會因此不同

### 巨型/史詩場景
對於戰場、都城、山脈這類尺度極大的場景：
- 大白話描述仍保持"正面全景微俯視"，但可適當抬高俯角到30-45°以容納縱深
- 用"前景—中景—遠景"三層明確鋪陳，避免一筆糊塗賬
- 在美術備註裡標註"建議拆分為多個分鏡/區塊分別細化"

## 八、輸出檢查清單

生成報告後，自檢以下問題：

### 角色描述檢查
- [ ] 每個角色的描述是**一整段連貫文字**，而非分項清單？
- [ ] 六項核心要素（年齡、性別、膚色、髮型髮色、五官特徵、服裝）是否全部覆蓋？
- [ ] 描述有畫面感但**不過度展開**？（五官抓1-3個辨識特徵，服裝抓整體風格）
- [ ] 所有推導都標註了依據來源？
- [ ] 不同角色之間的視覺區分度足夠？
- [ ] 服化道是否符合時代和階層？
- [ ] 是否有道具誤留在角色描述中？（武器/裝備/功能性容器應全部移到道具清單）
- [ ] 是否有場景環境誤留在角色描述中？
- [ ] 【關聯道具索引】是否已指向正確的道具編號？
- [ ] 【關聯場景索引】是否已指向正確的場景編號？

### 道具清單檢查
- [ ] 每個道具都有完整的視覺描述？（不能只有名字）
- [ ] 道具材質和配色是否與世界觀匹配？
- [ ] 同一道具是否有唯一編號？是否存在重複條目？
- [ ] 製作優先級是否合理分配？
- [ ] 道具的狀態變化軌跡是否完整？
- [ ] 原文依據是否齊全？
- [ ] 擺放在場景中的道具，是否在場景描述裡有位置引用？

### 場景清單檢查
- [ ] 每個場景的核心描述是**正面全景微俯視大白話一段連貫文字**？
- [ ] 大白話裡有沒有混入文學意境詞？（"殘陽如血""靜謐如詩"應刪改）
- [ ] 大白話是否按"站位→近景地面→左右中景→縱深遠景→光線氛圍"的順序鋪開？
- [ ] 鏡頭站位和俯視角是否交代清楚了？
- [ ] 場景要素分析是否完整（空間類型/尺度/結構/時間/光照/色調/固定物/縱深）？
- [ ] 搬不走的固定環境元素是否歸在場景，能搬走的物件是否歸在道具並建立了引用？
- [ ] 同一場景的多次出現/晝夜變化是否歸在同一編號下、用軌跡說明？
- [ ] 原文依據是否齊全？
- [ ] 美術備註裡的氛圍關鍵詞（英文提示詞摘要）是否給出？

### 整體一致性檢查
- [ ] 角色描述中的服裝顏色 vs 道具中的武器配色 → 是否衝突或和諧？
- [ ] 道具佩戴位置是否與角色服裝描述兼容？（如：腰懸長劍需要腰帶上有掛鉤）
- [ ] 角色服裝主色 vs 常駐場景主色調 → 是否撞色讓人融進背景？（撞了要在美術備註提醒）
- [ ] 擺在場景裡的道具材質/配色是否與場景環境協調？
- [ ] 場景光照色溫是否與角色/道具的配色預設相符？（如暖光下的冷色服裝會偏色）
- [ ] 三份文檔的交叉索引（角色↔道具↔場景）是否閉環、無懸掛引用？
- [ ] 英文提示詞摘要是否已提供（角色/道具/場景各部分）？

## 九、使用方式

當用戶提供小說/劇本文本時：

1. 先確認分析範圍（全文 / 指定章節 / 指定角色 / 指定場景）
2. **並行執行三份文檔的分析**：
   - 左手：Step A1+A2+A3 → 角色外觀描述（每人一段文字）
   - 右手：Step B1+B2+B3 → 道具清單
   - 第三隻手：Step C1+C2+C3+C4 → 場景清單（每場一段大白話+要素分析）
3. 運行輸出檢查清單（角色描述 + 道具清單 + 場景清單 + 一致性）
4. 交付最終報告：**先輸出全部角色描述 → 再輸出完整道具清單 → 最後輸出完整場景清單**
5. 三份文檔之間用編號互相引用，確保人·物·場閉環
6. 三清單確認後，進入 sd-asset-engine 工作流 Step 3.5（素材清單狀態表）與 Step 4（按模板生成生圖提示詞）
