# 人物立繪提示詞模板（寫實 / 3D / 2D 三風格）

> 精編自《場景·人物·道具 生圖提示詞生成器》
> 歸屬技能：sd-asset-engine（資產生圖引擎）｜工作流 Step 4 人物模板
> **圖底橫向細節條（硬性 · 2026-10-12 用戶裁定 · 第五輪修正）** = **【聲紋錨】聲紋波形 / 頻譜可視化（非文字圖形 · 視覺一致性錨）＋【音色速覽標籤】≤8 詞英文（唯一入圖文字）**；**完整 Voice Description（2–4 句）不進圖**，以文本形式留在提示詞文檔與《素材接線單》。除此之外其餘文字一律禁止；銜接總控角色資產規範（權威在總控 short-drama-director）；資產編號沿用總控「圖N」體系。

## 一、使用說明（硬性規則）

- 先確認風格（3D / 2D / 寫實），三套模板**分開使用**，不得混用。
- **角色板式與畫風 100% 正交解耦**：通道① 角色四格純圖板固定 **16:9 橫版**（含四格與底部細節條），通道② 角色八格拼版固定 **3:2 橫版**；兩者僅代表畫布排布格式，不綁定任何畫風或光影，畫風與光影完全由 I 鎖決定。成片畫幅仍跟 B 鎖，不將豎屏成片比例套到角色整板。M0/M1 驗收提示詞是否寫明規格，不聲稱核驗圖片；M2 才核實實際圖面與尺寸。
- 所有「〔…〕」為佔位符，從劇本角色設定與用戶資產清單（圖N=角色名+造型要點）提取填充。
- 三套模板共用同一骨架：角色設定表 → 立繪提示詞 → 人物音色描述（完整版純文本 + 速覽標籤入圖）→ **角色四格純圖板（面部特寫 + 無臉正面/90°側面/背面全身 + 圖底聲紋錨）**。
- **Voice Description 為必填項（兩檔 · 2026-10-12 第五輪修正）**：① **完整版**（英文 2–4 句）必須用英文撰寫並原樣保留在提示詞文檔與《素材接線單》中，**不進圖**，禁止省略、禁止翻譯成中文；② **速覽標籤**（≤8 詞英文）必須撰寫，**渲染於圖底部（全圖唯一入圖文字）**，禁止省略。
- **圖底橫向細節條必須入圖（硬性 · 2026-10-12 用戶裁定 · 第五輪修正）**：圖底部**必須**有一條**橫向細節條**，只裝兩樣東西——**①【聲紋錨】聲紋波形 / 頻譜可視化（非文字圖形）**；**②【音色速覽標籤】≤8 詞英文，必須渲染於圖底部，是全圖唯一允許出現的文字**（文字清晰正確、無亂碼缺字變形，禁止漏標）。⚠️ **術語正名**：圖底那行英文 = **音色交接文本（Voice Description · timbre，指"聽起來什麼樣"）**，**不等於聲紋**（聲紋 = "這個人是誰"的生物特徵）；包內舊稱「音色鎖」一律更正為「**音色速覽標籤 / 音色交接文本**」。聲紋錨**非文字**、**不佔「唯一入圖文字」名額**、**不宣稱能鎖聲線**（聲線鎖定走音頻側 TTS 音色 ID / 參考音）。其餘一切文字（角色名 / 編號 / 視角名 / 臉部處理 / 水印 / logo 等）仍**一律禁止**。
- **除音色外零文字（硬性 · 2026-10-10 粉絲反饋納入 / 第四輪修訂 · 2026-10-12 第五輪口徑同步）**：角色資產圖**除圖底部的英文音色速覽標籤 + 聲紋波形外不得出現任何其他文字**——不標角色名、不標編號、不標視角名（正面/側面/背面/面部特寫）、不標臉部處理、不加邊框文字/水印/logo/角標。**圖上文字只有一處：底部英文音色速覽標籤（≤8 詞）；聲紋波形屬圖案，不算文字。** 病灶：出圖信息過多 + 中文字渲染成亂碼；另：完整版長英文（100+ 字符）易崩字/被模糊/被殺成字幕水印殘留，故縮為 ≤8 詞速覽標籤。
- **立繪純淨規則（硬性）**：人物立繪只呈現**人物本體 + 身上穿戴配飾**；**禁止手持任何道具、禁止身前/身側/地面放置任何獨立道具**（酒葫蘆、破碗、劍、手機、書本等一律不得入圖）；手部保持自然姿態（垂放/搭膝/交疊/負手等）；道具統一由 `prop-template.md` 單獨出設定圖，不得混入人物立繪。
- **立繪無 Pose（硬性）**：所有人物立繪統一為**端正站立展示（no pose）**——身體直立、正面朝向鏡頭、頭部端正、無任何動作姿態；**禁止坐姿、蹲姿、行走、戰鬥姿勢、動態動作等一切 pose**；4 View（正面/90°側面/背面全身）為同一站姿的不同觀察視角，不是動作變化；膝蓋以下特寫為站立姿態下的下裝+鞋襪細節。
- **同一人物多造型換裝（硬性）**：當資產清單中同一人物出現多套服裝/造型（如錢多多A乞丐造型=圖1、錢多多B整潔造型=圖2），每套造型必須**獨立生成一張立繪提示詞**。第一套造型使用完整「共用骨架」模板從零生成（含完整 Voice Description 文本 + 圖底橫向細節條：聲紋錨 + 音色速覽標籤）；第二套及之後的造型使用「同一人物多造型換裝生圖提示詞模板」（見第五部分），核心指令為：**保持人物臉型、人臉細節完全一致，人物音色一致，僅修改服裝**，禁止改變臉型、五官、膚色、年齡感；**換裝造型不重複寫 Voice Description 音色提示詞、圖底部不重複渲染音色速覽標籤**（聲紋波形沿用第一套造型的同一條波形），音色統一以第一套造型參考圖為準。
- **單一面部錨點（硬性 · Face-Anchor Uniqueness · 2026-10-09/10-10 粉絲反饋納入）**：**全圖只允許一處渲染清晰可辨識的五官**——即「面部特寫」格（頭部近景，頭部佔該格高度 ≥70%，五官 10 項鎖定 + 性別錨點收尾）。**除此之外的每一幅畫面**（全身正面立繪、正面/側面/背面全身）**臉部一律「無臉」——頭部完整保留在畫內（頭型/髮型/頸部/肩線齊全），只讓面部區域不刻畫五官**；禁止出現第二張可辨識的臉、禁止第二個清晰眼神光。⚠️ **禁止「砍頭」（2026-10-10 修正）**：**不得把頭部裁掉、抹去或推出畫框**——模型靠畫面裡的頭錨定**頭身比例**，**頭部不入畫會導致頭部比例失真（頭忽大忽小、頭身比走形）**；舊「無頭」寫法自本條起**廢棄**。⚠️ **禁止字面馬賽克**：提示詞中不得出現 `mosaic / pixelated / censored / 馬賽克 / 像素化 / 打碼`——生圖模型會把它們渲染成**真實像素塊與審查條紋理**，汙染畫面並被判為異物/水印；「馬賽克」在本包只作**口語別名**使用，落到提示詞必須轉譯成「無臉（無面部細節）」。完整規則見 **§七 角色資產板圖面規則**。
- **全身完整性（硬性 · Full-Body Integrity）**：三格全身格（正面② / 90°側面③ / 背面④）= **完整全身**——**頭頂到鞋（含鞋襪、含頭）全部入畫，禁止裁切腳部/頭部、禁止畫框截斷、禁止露白邊/露底**（頭部必須在畫內以保頭身比：砍頭會讓頭忽大忽小，見上方面部錨點條）；**鞋必須畫在全身格內**——三類特寫格（膝蓋以下至鞋 / 手部 / 材質）已於 2026-10-10 全部取消，**無處可補**（歷史問題：舊版主圖只到膝蓋以上、鞋只存在於特寫格 → 用戶拿到的主圖上"沒有鞋"；**2026-10-12 實測新病灶：提示詞同時出現「主圖」與「四格純圖板」→ 模型做加法出成 5 格（正面被畫兩次）**——故「主圖」一詞**自第六輪起廢棄**，一律改稱「**正面格**」，並**必須顯式聲明全圖格數**）。

### 立繪提示詞
一位約〔年齡〕歲的〔性別/身份〕純立繪展示，**〔頭身比：寫實寫「真人 6.5~7.5 頭身」；3D / 2D 按風格寫對應值——主動寫頭身比是防「頭大身小」的第一道鎖，與「頭部完整入畫」配套生效 · 2026-10-13 粉絲反饋〕**，**人物本體 + 身上配飾，不攜帶、不手持、不放置任何獨立道具**。**全圖共 4 格，橫向並排**：① **面部特寫**（全圖唯一清晰臉）② **正面全身** ③ **90°側面全身** ④ **背面全身**——**僅此 4 格，不設獨立大主圖、不重複任何視角、不出現第 5 格**。②③④三格均為**無臉全身立繪（no pose）**：**頭頂至鞋全部入畫（含鞋襪、含頭，不裁腳、不裁頭、不截斷、不露底）**，各格人物佔該格高度 85%-95%；**面部不刻畫任何五官**；**唯一清晰面部只在第①格「面部特寫」內**。〔背景描述，如：純白背景無場景〕。②③④三格為同一人的正面 / 90°側面 / 背面朝向，端正站立立繪，身體直立、**無任何動作姿態**，整板固定 16:9 橫屏畫幅，〔焦段，如：50mm〕等效焦距平視無畸變。**四格之下另設一行圖底細節條（聲紋波形 + 音色標籤），不計入格數、不佔主視圖區。**

**★ 身份外觀三件套（必寫 · 2026-10-12 新增 · 機檢 C26d）**：立繪提示詞首句裡那個「〔年齡〕歲的〔性別/身份〕」**光有身份詞是不夠的**——模型會按"這個職業大概穿什麼"的統計均值給一套泛化形象（粉絲實測：**外賣員被畫成協警**，因為它不知道外賣員該長什麼樣，就給了個"城市裡穿制服的公職人員"）。所以每個 S/A 角色的立繪提示詞必須**額外落紙三件套**：

| # | 項 | 寫什麼 | 正例（陳舟·外賣騎手） | 反例（必被判不合格） |
|---|---|---|---|---|
| ① | **職業標識物**（身上配飾，不算獨立道具） | 至少 1 個一眼認出行當的硬標識 | `胸前橙色方形外賣箱（保溫內膽外露）、平台工牌掛繩` | 無 |
| ② | **服裝形制與材質** | 形制 + 材質 + 磨損 + 標誌色 | `橙色騎手衝鋒衣·尼龍面料·袖口磨白起毛·肩背雙反光條掉漆、工裝褲沾泥` | `穿制服`、`穿工作服` |
| ③ | **氣質體態寫進身體** | 長期職業塑造的身體習慣 | `常年騎車致含胸駝背、右肩偏低、手掌粗大、指節發紅` | 無 |

**⛔ 反漂移清單（必寫，與三件套同段）**：逐條寫死這個角色**不能**被畫成什麼——`禁寫成協警警服/公文包/對講機/肩章`。正向描述禁不住漂移，必須同時給禁止項。

**年齡與體型（必寫 · 機檢 C26c）**：首句的 `〔年齡〕` 寫**年齡段**（`28~32歲`），禁只寫"青年/中年"；體型寫**數字或明確體型詞**（`178cm·精瘦，肩窄腿長`），禁"高大/健壯"這類不可複述的概括。

### 換裝執行規則（硬性）

1. **第一套造型為基準**：必須先完成第一套造型的完整立繪提示詞（使用「共用骨架」，含完整 Voice Description 文本 + 圖底**聲紋波形 + 音色速覽標籤**），後續造型均以第一套為臉型/五官/音色基準。
2. **鎖定字段不可改**：臉型、五官、膚色、年齡感必須逐字複用第一套描述，禁止 AI 重新設計或"優化"人臉。
3. **僅服裝可變**：除服裝、鞋襪、造型專屬配飾、（可選）髮型外，其餘人物特徵全部鎖定；髮型變化時必須寫明原因（如梳洗換裝），髮色和髮質不變。
4. **每套造型獨立圖號**：換裝提示詞標題必須寫明資產圖編號（如圖2=錢多多B整潔造型），與資產清單編號一一對應。
5. **音色不重複標註（硬性）**：換裝造型（第二套及之後）**不寫 Voice Description 提示詞、圖底部不重複渲染音色速覽標籤**；音色信息統一以第一套造型的**完整音色文本 + 圖底速覽標籤 + 聲紋波形**為唯一來源，下游讀取該文本，禁止在換裝造型中重新編造或修改音色；圖底**聲紋波形沿用第一套同一條**（同一角色 = 同一波形，換裝不改波形）。
6. **立繪純淨與 no pose 規則不變**：換裝造型同樣禁止手持道具、禁止動作姿態，固定站立立繪+完整全身（含鞋）+膝蓋以下細節放大。
7. **單一面部錨點 + 四格純圖 + 全身完整性同樣適用（硬性）**：換裝造型的**唯一清晰面部同樣只落「面部特寫」格**，其餘三格一律**無臉（無面部細節）**——頭部完整入畫、面部不刻畫五官；三格全身必須**完整全身（頭頂至鞋，含頭）**；**同樣只出四格、同樣除圖底聲紋錨 + 音色速覽標籤外零文字**。上方「人物鎖定」區裡的臉型/五官/膚色文字**照寫**（用於鎖參），但**只在面部特寫格渲染成清晰五官**——其餘畫面出現第二張清晰臉即違反本規則（見 §七）。

### 7.1 一句話定義

**一張角色資產圖 = 四格純圖板**：**面部特寫 + 正面 / 90°側面 / 背面無臉全身**，共四格（**「全圖共 4 格」是必須寫進提示詞的顯式總數聲明；不設獨立大主圖、任一視角不得重複出現、不得出現第 5 格**）；**除面部特寫格外，其餘三格頭部完整入畫但面部不刻畫五官**；**圖上文字只有一處 —— 圖底部的英文音色速覽標籤（≤8 詞）**（其餘一律無字）；**圖底另有一條聲紋波形（非文字圖形）**。

### 7.2 三條獨立不變量（各自為什麼）

**① 面部錨點唯一 → 臉更準（2026-10-09）**：一張圖裡出現多張清晰臉時，生圖模型會把這些臉**互相平均**（注意力與像素預算被攤薄），臉型/五官相對設定漂移。把全圖唯一清晰臉**收束到一格**後，模型對該臉的注意力與像素預算集中，**出圖臉部更精準**。

**② 頭部完整入畫 → 頭身比不失真（2026-10-10 第一輪）**：**禁止把頭部裁掉、抹掉或"砍頭"**。模型靠畫面裡的頭錨定**頭身比例**；頭部一旦不入畫，模型失去參照，**頭會忽大忽小、頭身比走形**。「無臉」必須是**保頭去五官**——頭型、髮型、頸部、肩線全部保留在畫內，只有**面部區域**不做刻畫。

**③ 除圖底速覽標籤外零文字 + 只出四格 → 畫面乾淨、模型不分心（2026-10-10 第二輪 / 第四輪修訂 · 2026-10-12 第五輪收緊）**：圖上每多一行字（視角名、臉部處理、角色名、編號……），模型就要分配一部分像素預算去"畫字"，**中文字極易渲染成亂碼**，還容易被判成水印/字幕殘留；而特寫格（膝蓋以下至鞋 / 手部 / 材質）會把畫布切碎，讓四格主視圖變小、臉與身體細節反而更糊。**去多餘字 + 去特寫格 + 縮到 ≤8 詞**後畫面只留圖案 + 一行底部短標籤 + 一條波形，模型注意力全部給人物本體。

> 📌 **底部為何是「波形 + 短標籤」這對組合**：**波形**是非文字圖形 —— 不佔模型"畫字"的像素預算、不會被渲染成亂碼、**抗模糊抗壓縮**（形狀糊了還是同一條曲線），在參考圖序列裡形成穩定的可匹配標記；**短標籤**是唯一入圖文字，純英文 + ≤8 詞 → 崩字率遠低於上百字符的長句，且一眼可讀。兩者互補：**波形兜一致性、標籤兜可讀性，誰崩了另一個還在**。**這是唯一的例外，不構成「可以在圖上隨便加字」的先例。**

### 7.3 落位表（**只四格** · 臉部處理列僅供自檢，不入圖）

| 畫面 | 臉部處理（自檢用·不入圖） | 必寫 | 禁止 |
|---|---|---|---|
| **面部特寫**（頭部近景，頭部佔該格高度 ≥70%） | **清晰 · 全圖唯一** | 五官 10 項 + 皮膚質感 + 性別錨點收尾 | — |
| 正面全身 | **無臉**（無面部細節） | **頭部完整入畫**（頭型/髮型/頸部保留）+ 面部不刻畫五官；**鞋必須在此格內畫完** | 任何五官刻畫；**裁頭 / 砍頭 / 頭部出畫** |
| 90°側面全身 | **無臉**（無面部細節） | **頭部完整入畫** + 面部不刻畫五官；完整含鞋 | 同上 |
| 背面全身 | **無臉**（無面部細節） | **後腦完整**（臉天然不在畫內）；完整含鞋 | 同上 |

**🥇 只此四格（無獨立主圖）。** 全圖**沒有**獨立於四格之外的全身主圖——正面全身**只在②格出現一次**，不得在四格之外再畫一個正面立繪（2026-10-12 實測：提示詞寫成「主圖 + 四格板」→ 模型按 1+4 出成 5 格）。「膝蓋以下至鞋」「手部細節」「服飾材質細節」三類特寫**已於 2026-10-10 取消**，其內容歸併：鞋襪 → 三格全身的描述文字（必須畫在全身格內）；手部/配飾 → 「面部特寫」行末尾或「配飾」行；服飾材質 → 「服裝」行。

**圖底橫向細節條（唯一入圖文字區 + 聲紋錨）**：四格之下**另設一行圖底細節條**，內含兩樣東西——**① 聲紋波形 / 頻譜可視化（非文字圖形 · 視覺一致性錨 · 不佔入圖文字名額）**；**② 該角色的英文音色速覽標籤 Voice Description Label（≤8 詞 · 唯一入圖文字 · 清晰正確、無亂碼缺字變形、禁止漏標）**。**不渲染** 完整版 Voice Description（**不進圖**，轉純文本交付）、角色名、編號。

**逐格「臉部處理」枚舉值只允許三種**：`清晰`（僅面部特寫格）／`無臉`（無面部細節）／`不適用`（臉部不在畫內）。**寫出第四種或留空 = 未執行本規則。** ⚠️ 該列**只用於提示詞側自檢，不是圖上要渲染的文字**。

### 7.4 「無臉」的兩種工程實現（**都保留頭部** · 二選一）

| 方式 | 寫法（英文，可直接進提示詞） | 適用 |
|---|---|---|
| **A · 無五官平面**（首選） | `featureless face, no facial features, smooth untextured facial plane, blank face` | 多數情況；保留頭型/髮型/頸部，面部為平滑無刻畫的平面 |
| **B · 柔和失焦**（口語「打馬賽克」的工程實現） | `face softly out of focus, blurred featureless face, no facial features` | 需要保留五官位置但不要清晰細節時 |

**❌ 已廢棄寫法（禁止再用）**：`無頭 / headless / cropped head / 頭部不入畫 / 自頸部截斷 / 砍頭`——會造成**頭身比失真**（見 7.2 ②）。

### 7.5 ⚠️ 禁用詞：「馬賽克」必須轉譯

「打馬賽克」是**口語別名**，**禁止**把它字面寫進提示詞。`mosaic / pixelated / censored / 馬賽克 / 像素化 / 打碼` 會被生圖模型渲染成**真實的像素塊與審查條紋理**。

> **轉譯紀律**：凡用戶說「臉打馬賽克 / 糊掉 / 蓋住」，一律轉譯成 **「無臉（無面部細節）」**（工程實現取 7.4 的 A 或 B），並在交付說明裡點明用的是哪一種。

### 7.7 配套：全身完整性（Full-Body Integrity）

- 三格全身**必須頭頂至鞋完整入畫**（**頭也在畫內**）：**禁止裁腳、禁止裁頭、禁止畫框截斷、禁止露白邊/露底**；
- **鞋必須畫在全身格內**——特寫格已取消，**無處可補**（這是 7.3 取消「膝蓋以下至鞋」後對鞋的唯一保障）；

### 7.8 交付前自檢七問（逐角色過）

0. **首句是不是「一名…角色立繪，全身完整入畫」，後面又寫「四格」？** 是 → **FAIL**：這正是「1 張主圖 + 4 格 = 5 格」的觸發式寫法。首句必須直接進四格語境（「一位約 X 歲的…，**全圖共 4 格，橫向並排**…」），⛔ 全篇不得出現正向的「主圖 / 大主圖」（否定用法如「不設獨立大主圖」可以）。機檢 `check_asset_blocks.py` A5 會攔。
1. **全圖一共幾個人像 / 幾格？** 必須**正好 4 個**（1 張清晰臉 + 3 個無臉全身）。出現 5 個（四格之外多一個獨立大正面立繪、或某視角重複）→ **FAIL**：刪掉多餘那一格，並在提示詞開頭補「**全圖共 4 格 · 不設獨立大主圖 · 不重複任何視角**」。
2. 全圖**數一數有幾處清晰可辨識的五官**？>1 → FAIL，收斂到面部特寫格。
3. **有沒有哪一幅畫面把頭部裁掉 / 抹掉 / 推出畫框**？有 → FAIL（改「無臉」：頭保留在畫內、只去五官）。
4. **圖上除圖底音色速覽標籤外，有沒有任何其他文字**（視角名 / 臉部處理 / 角色名 / 編號 / 邊框字 / 水印 / logo）？有 → FAIL，**只留圖案 + 圖底一條聲紋波形 + 一行 ≤8 詞短標籤**。
5. **是否只有四格**？出現了「膝蓋以下至鞋 / 手部 / 材質」等特寫格 → FAIL，刪除並把內容併入四格描述文字。
6. 三格全身**有沒有完整到鞋**？沒有 → FAIL，補「頭頂至鞋完整入畫、不裁腳」。
7. **圖底部有沒有「橫向細節條」**——內含 ① **聲紋波形 / 頻譜（非文字）** 與 ② **英文音色速覽標籤（≤8 詞、清晰、無亂碼、無缺字）**？缺任一 → FAIL，補上（**速覽標籤是全圖唯一允許出現的文字**；**完整版 Voice Description 不得入圖**，只留文本）。

### 8.1 通道①：16:9 四格純圖板（縱深比例硬鎖）
