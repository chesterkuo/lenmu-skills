# lenmu-digitalhuman · AI 數字人口播

給 AI 助理（Claude、Codex 等）用的 skill：一張主持人圖＋一句主題，做出一支有字幕、有包裝、聲音一致的口播影片。
生成和剪接都在 [Lenmu](https://lenmu.ai) 上完成，結果留在 Lenmu 畫布上，隨時可以打開接手修改。

適合「主持人對著鏡頭說話」這一類影片：知識解說、產品快評、懶人包、教學開場。

## 做法

1. 整份稿子用 Seed TTS 3.0 **一次**做成一條旁白，聲音和語氣從頭到尾一致；
2. 在句間停頓把旁白切成幾段，每段交給 OmniHuman 2.0 做對嘴影片；
3. 組片時關掉各段原聲、改鋪整條旁白，所以中間可以插 B-roll、切近景，嘴型不會跑掉；字幕直接從旁白產生。

## 安裝

需要先接上 Lenmu MCP（`https://lenmu.ai/mcp`），再把這個資料夾放進助理的 skills 目錄。
Claude Code、Claude 網頁版／桌面版、OpenAI Codex 的步驟見[倉庫根的 README](../README.md#安裝)。

沙盒要有 `python3`、`curl`、`ffmpeg`、`ffprobe`，並且能連到 `lenmu.ai`；連不上時 skill 會改走功能較少的備用路線。

## 開始使用

裝好後直接說，例如：

- 「用 Lenmu 做一支 60 秒的數字人口播影片，主題是○○，發在 IG Reels。」
- 「把這篇文章做成一支口播短片。」（貼上文章或網址）

它會先一次問完幾件事：主題與素材、發在哪個平台（決定直式或橫式）、片長與預算、主持人（新建 AI 主持人／沿用角色庫／你本人）、語言與聲音，然後推薦兩種風格讓你選。

接著依序過六道關卡，**每一道都要你確認才往下，花錢前先報價**：

| 關卡 | 你要確認的 | 約略花費 |
|---|---|---|
| ① 稿子 | 念稿、字幕稿、段落、B-roll 與包裝點 | 免費 |
| ② 聲音 | 試聽兩句，再聽整條旁白 | 幾美分 |
| ③ 主持人 | 從 4 張形象圖選一張 | 約 $0.1 |
| ④ 第一段 | 看第一段對嘴影片 | 約 $1–2 |
| ⑤ 其餘 | 一次報總價：剩下的段落、B-roll、音樂音效 | 依長度 |
| ⑥ 成片 | 看、聽成片 | 組裝免費 |

一支 60 秒直式口播大約 $5.5–6，八成以上花在對嘴影片上；實際以它當下的報價為準。

## 你自己要做的

- **聽和看**：AI 只看得到抽出來的靜態畫面，聽不到聲音。念錯字、停頓、嘴型、配樂音量都要你自己確認。
- **標示 AI**：成片會帶「本影片由 AI 數字人呈現」字卡，發布文案也請註明。
- **用自己的臉當主持人**：需要你本人同意並提供正面照；不能用名人、親友或網路上的照片和聲音。

## 檔案

| 檔案 | 用途 |
|---|---|
| `SKILL.md` | 給助理讀的完整流程 |
| `scripts/split_narration.py` | 把整條旁白依稿子段落切成 WAV（切在句間停頓） |
| `agents/openai.yaml` | 給 Codex 的設定：宣告需要 Lenmu MCP |

`SKILL.md` 第 14 節內嵌了 `split_narration.py` 的原始碼，改腳本時兩處要一起改。

## 目前的驗證程度

- 用到的工具、參數和上限已對照 Lenmu MCP 原始碼核對。
- 已用真實生成從頭到尾跑過一次（2026-11，Lenmu staging）：一支 68 秒的直式影片，主持人只在開頭和結尾出鏡，中間是旁白配圖卡與示範片段。流程走得通，過程中發現的問題（文字位置、字幕折行、切段要用字幕時間、對嘴影片長度會進位）都已寫回 `SKILL.md`。
- 還沒測過的：主持人全程出鏡並穿插 B-roll 與近景的剪法、橫式 16:9、超過 5 分鐘要分章節的長片、多主持人、備用路線。
- 聲音和嘴型 AI 無法自己檢查，每次都要你看過。
